# Language and standard library pending removal in 3.18: decimal

### Pending removal in Python 3.18

- [`decimal`](https://docs.python.org/3.14/library/decimal.html#module-decimal):

  - Deprecated since Python 3.13: the nonstandard, undocumented [`Decimal`](https://docs.python.org/3.14/library/decimal.html#decimal.Decimal) format specifier `'N'`, which the `decimal` module supports only in its C implementation. (Contributed by Serhiy Storchaka in [gh-89902](https://github.com/python/cpython/issues/89902).)
