# 7.3. App Store Compliance

### 7.3. App Store Compliance

Submitting an app to the iOS App Store is the lone route for getting apps onto third-party iOS devices; any app put forward for distribution has to clear Apple's app review process. Built into that process is a battery of automated validation rules that scan the submitted application bundle for troublesome code. Certain measures are required to make sure your app can clear those validation steps.
