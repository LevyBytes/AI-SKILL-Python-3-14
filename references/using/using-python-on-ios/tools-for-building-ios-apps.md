### 7.2. Installing Python on iOS

### 7.2.1. Tools for building iOS apps

iOS builds depend on Apple's Xcode tooling. Sticking with the newest stable Xcode release is strongly advised. Doing so means running the most recent (or next-most-recent) macOS release, given that Apple won't keep Xcode running on older macOS versions. The Xcode Command Line Tools alone won't cut it for iOS work; a *full* Xcode installation is required.

To exercise your code against the iOS simulator, you'll additionally have to install an iOS Simulator Platform. Xcode ought to prompt you to choose an iOS Simulator Platform the first time you launch it. Failing that, you can add an iOS Simulator Platform from the Platforms tab within the Xcode Settings panel.
