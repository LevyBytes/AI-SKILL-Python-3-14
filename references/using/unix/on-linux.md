### 2.1.1. On Linux

The majority of Linux distributions ship Python out of the box, and the rest offer it as an installable package. That said, you may need capabilities your distro's packaged build leaves out, in which case you can build the newest Python yourself from source.

Should the newest Python neither be bundled by default nor sit in the repositories, you have the option of rolling packages tailored to your own distro. The links below are worth a look:
