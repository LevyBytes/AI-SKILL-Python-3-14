# -X gil=*0,1*

- `-X gil=*0,1*` compels the GIL to be turned off or on, respectively. The `0` setting only works in builds set up with [`--disable-gil`](https://docs.python.org/3.14/using/configure.html#cmdoption-disable-gil). Refer also to `PYTHON_GIL` and [Free-threaded CPython](https://docs.python.org/3.14/whatsnew/3.13.html#whatsnew313-free-threaded-cpython).

Added in version 3.13.
