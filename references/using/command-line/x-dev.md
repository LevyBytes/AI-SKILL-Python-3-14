# -X dev

- `-X dev`: enable [Python Development Mode](https://docs.python.org/3.14/library/devmode.html#devmode), which adds extra runtime checks deemed too costly to leave on by default. See also `PYTHONDEVMODE`.

Added in version 3.7.
