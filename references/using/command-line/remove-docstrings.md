# -OO

-OO

Perform what `-O` does and additionally drop docstrings. Extend the name of compiled ([bytecode](https://docs.python.org/3.14/glossary.html#term-bytecode)) files by inserting `.opt-2` ahead of the `.pyc` extension (see [**PEP 488**](https://peps.python.org/pep-0488/)).

Changed in version 3.5: Modify `.pyc` filenames according to [**PEP 488**](https://peps.python.org/pep-0488/).
