# -X warn_default_encoding

- `-X warn_default_encoding` raises an [`EncodingWarning`](https://docs.python.org/3.14/library/exceptions.html#EncodingWarning) whenever the locale-specific default encoding gets used to open files. See also `PYTHONWARNDEFAULTENCODING`.

Added in version 3.10.
