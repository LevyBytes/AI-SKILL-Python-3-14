# PYTHONDUMPREFSFILE

PYTHONDUMPREFSFILE

When set, the objects and reference counts surviving interpreter teardown are written by Python into a file located at whatever path this environment variable holds.

Requires a Python built using the [`--with-trace-refs`](https://docs.python.org/3.14/using/configure.html#cmdoption-with-trace-refs) build option.

Added in version 3.11.
