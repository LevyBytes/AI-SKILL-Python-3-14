# PYTHON_TLBC

PYTHON_TLBC

A value of `1` turns thread-local bytecode on. A value of `0` shuts off both thread-local bytecode and the specializing interpreter. This has effect solely on builds set up with [`--disable-gil`](https://docs.python.org/3.14/using/configure.html#cmdoption-disable-gil).

The matching `-X tlbc` command-line option is documented as well.

Added in version 3.14.
