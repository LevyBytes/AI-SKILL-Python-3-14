# PYTHON_PERF_JIT_SUPPORT

PYTHON_PERF_JIT_SUPPORT

When this variable is set to a nonzero value, it switches on support for the Linux `perf` profiler so it can spot Python calls by means of DWARF information.

When set to `0`, switch off Linux `perf` profiler support.

Refer also to the `-X perf_jit` command-line option and [Python support for the Linux perf profiler](https://docs.python.org/3.14/howto/perf_profiling.html#perf-profiling).

Added in version 3.13.
