# PYTHONWARNDEFAULTENCODING

PYTHONWARNDEFAULTENCODING

When this environment variable holds a non-empty string, raise an [`EncodingWarning`](https://docs.python.org/3.14/library/exceptions.html#EncodingWarning) whenever the locale-specific default encoding gets used.

See [Opt-in EncodingWarning](https://docs.python.org/3.14/library/io.html#io-encoding-warning) for details.

Added in version 3.10.
