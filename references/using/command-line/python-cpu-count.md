# PYTHON_CPU_COUNT

PYTHON_CPU_COUNT

When this variable is set to a positive integer, it supersedes the return values of [`os.cpu_count()`](https://docs.python.org/3.14/library/os.html#os.cpu_count) and [`os.process_cpu_count()`](https://docs.python.org/3.14/library/os.html#os.process_cpu_count).

Refer also to the `-X cpu_count` command-line option.

Added in version 3.13.
