# PYTHONPLATLIBDIR

PYTHONPLATLIBDIR

When this holds a non-empty string, it supersedes the [`sys.platlibdir`](https://docs.python.org/3.14/library/sys.html#sys.platlibdir) value.

Added in version 3.9.
