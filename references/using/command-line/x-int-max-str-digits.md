# -X int_max_str_digits

- `-X int_max_str_digits` sets the [integer string conversion length limitation](https://docs.python.org/3.14/library/stdtypes.html#int-max-str-digits). See also `PYTHONINTMAXSTRDIGITS`.

Added in version 3.11.
