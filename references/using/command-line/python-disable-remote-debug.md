# PYTHON_DISABLE_REMOTE_DEBUG

PYTHON_DISABLE_REMOTE_DEBUG

When this variable holds a non-empty string, it turns off the remote debugging feature laid out in [**PEP 768**](https://peps.python.org/pep-0768/). This covers both the ability to schedule code to run in another process and the ability to receive code to run in the current process.

Refer also to the `-X disable_remote_debug` command-line option.

Added in version 3.14.
