# PYTHONDUMPREFS

### 1.2.1. Debug-mode variables

 PYTHONDUMPREFS

When this is set, Python writes out any objects plus their reference counts that remain alive once the interpreter has been torn down.

Requires a Python built using the [`--with-trace-refs`](https://docs.python.org/3.14/using/configure.html#cmdoption-with-trace-refs) build option.
