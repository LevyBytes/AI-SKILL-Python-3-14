# PYTHONPERFSUPPORT

PYTHONPERFSUPPORT

When this variable is set to a nonzero value, it switches on support for the Linux `perf` profiler so it can spot Python calls.

When set to `0`, switch off Linux `perf` profiler support.

Refer also to the `-X perf` command-line option and [Python support for the Linux perf profiler](https://docs.python.org/3.14/howto/perf_profiling.html#perf-profiling).

Added in version 3.12.
