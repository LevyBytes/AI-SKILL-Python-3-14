# PYTHONUSERBASE

PYTHONUSERBASE

Sets the [`user base directory`](https://docs.python.org/3.14/library/site.html#site.USER_BASE), which goes into computing the path of the [`user site-packages directory`](https://docs.python.org/3.14/library/site.html#site.USER_SITE) along with [installation paths](https://docs.python.org/3.14/library/sysconfig.html#sysconfig-user-scheme) for `python -m pip install --user`.

See also

[**PEP 370**](https://peps.python.org/pep-0370/) — Per user site-packages directory
