# -X showrefcount

- `-X showrefcount` to print the overall reference count plus the count of used memory blocks once the program ends or following each statement in the interactive interpreter. This functions only on [debug builds](https://docs.python.org/3.14/using/configure.html#debug-build).

Added in version 3.4.
