# PYTHONINTMAXSTRDIGITS

PYTHONINTMAXSTRDIGITS

When this variable is set to an integer, it configures the interpreter's global [integer string conversion length limitation](https://docs.python.org/3.14/library/stdtypes.html#int-max-str-digits).

Added in version 3.11.
