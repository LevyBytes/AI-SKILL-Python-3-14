# PYTHONASYNCIODEBUG

PYTHONASYNCIODEBUG

When this environment variable holds a non-empty string, switch on the [debug mode](https://docs.python.org/3.14/library/asyncio-dev.html#asyncio-debug-mode) of the [`asyncio`](https://docs.python.org/3.14/library/asyncio.html#module-asyncio) module.

Added in version 3.4.
