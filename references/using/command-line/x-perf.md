# -X perf

- `-X perf` turns on support for the Linux `perf` profiler. With this option supplied, the `perf` profiler can report Python calls. The option exists only on certain platforms and does nothing where the current system lacks support. Its default value is "off". See also `PYTHONPERFSUPPORT` and [Python support for the Linux perf profiler](https://docs.python.org/3.14/howto/perf_profiling.html#perf-profiling).

Added in version 3.12.
