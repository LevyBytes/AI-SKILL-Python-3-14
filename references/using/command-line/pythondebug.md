# PYTHONDEBUG

PYTHONDEBUG

When this holds a non-empty string it amounts to giving the `-d` option. When set to an integer, it amounts to giving `-d` that many times.

This environment variable requires a [debug build of Python](https://docs.python.org/3.14/using/configure.html#debug-build), otherwise it's ignored.
