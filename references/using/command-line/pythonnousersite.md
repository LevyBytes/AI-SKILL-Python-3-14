# PYTHONNOUSERSITE

PYTHONNOUSERSITE

When this is present, Python won't append the [`user site-packages directory`](https://docs.python.org/3.14/library/site.html#site.USER_SITE) onto [`sys.path`](https://docs.python.org/3.14/library/sys.html#sys.path).

See also

[**PEP 370**](https://peps.python.org/pep-0370/): Per user site-packages directory
