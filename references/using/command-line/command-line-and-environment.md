# 1. Command line and environment

### 1. Command line and environment

To determine its behavior, the CPython interpreter inspects both the command line and the surrounding environment.

**CPython implementation detail:** The way other implementations handle the command line can vary. Consult [Alternate Implementations](https://docs.python.org/3.14/reference/introduction.html#implementations) for additional pointers.
