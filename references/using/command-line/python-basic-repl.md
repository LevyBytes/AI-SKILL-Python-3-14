# PYTHON_BASIC_REPL

PYTHON_BASIC_REPL

Giving this variable any value at all stops the interpreter from bringing up the Python-based [REPL](https://docs.python.org/3.14/glossary.html#term-REPL), which depends on [`readline`](https://docs.python.org/3.14/library/readline.html#module-readline); the older parser-based REPL is used in its place.

Added in version 3.13.
