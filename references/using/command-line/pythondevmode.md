# PYTHONDEVMODE

PYTHONDEVMODE

When this environment variable holds a non-empty string, switch on [Python Development Mode](https://docs.python.org/3.14/library/devmode.html#devmode), which brings in extra runtime checks too costly to enable by default. This amounts to setting the `-X` `dev` option.

Added in version 3.7.
