# PYTHONUTF8

PYTHONUTF8

When set to `1`, switch on the [Python UTF-8 Mode](https://docs.python.org/3.14/library/os.html#utf8-mode).

When set to `0`, switch off the [Python UTF-8 Mode](https://docs.python.org/3.14/library/os.html#utf8-mode).

Assigning any other non-empty string triggers an error while the interpreter is initialising.

Added in version 3.7.
