# -X utf8

- `-X utf8` switches on the [Python UTF-8 Mode](https://docs.python.org/3.14/library/os.html#utf8-mode). `-X utf8=0` deliberately switches off [Python UTF-8 Mode](https://docs.python.org/3.14/library/os.html#utf8-mode) (even in situations where it would normally turn on by itself). See also `PYTHONUTF8`.

Added in version 3.7.
