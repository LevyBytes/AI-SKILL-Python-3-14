# PYTHONSAFEPATH

PYTHONSAFEPATH

When this holds a non-empty string, refrain from prepending a possibly unsafe path to [`sys.path`](https://docs.python.org/3.14/library/sys.html#sys.path): consult the `-P` option for specifics.

Added in version 3.11.
