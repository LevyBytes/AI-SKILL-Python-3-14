# PYTHONNODEBUGRANGES

PYTHONNODEBUGRANGES

When this variable is present, it turns off including the tables that map extra location information (end line, start column offset and end column offset) onto every instruction inside code objects. This helps when you want smaller code objects and pyc files plus want to suppress the extra visual location markers the interpreter shows while displaying tracebacks.

Added in version 3.11.
