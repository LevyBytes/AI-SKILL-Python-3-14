# PYTHONPYCACHEPREFIX

PYTHONPYCACHEPREFIX

When this is present, Python writes `.pyc` files into a mirror directory tree rooted at this path, rather than inside `__pycache__` directories within the source tree. This amounts to giving the `-X` `pycache_prefix=PATH` option.

Added in version 3.8.
