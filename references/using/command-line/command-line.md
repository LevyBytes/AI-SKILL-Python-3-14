# 1.1. Command line

### 1.1. Command line

Any of the following options can be passed when you run Python:

```sh
python [-bBdEhiIOPqRsSuvVWx?] [-c command | -m module-name | script | - ] [args]

```

Naturally, the typical scenario is just running a script in a straightforward way:

```sh
python myscript.py

```
