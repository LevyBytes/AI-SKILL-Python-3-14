# 8.1. IDLE — Python editor and shell

### 8.1. IDLE — Python editor and shell

IDLE, the name for Python's Integrated Development and Learning Environment, ships with most Python installations by default. Should you be running Linux without IDLE present, consult [Installing IDLE on Linux](https://docs.python.org/3.14/using/unix.html#installing-idle-on-linux). Additional detail lives in the [IDLE docs](https://docs.python.org/3.14/library/idle.html#idle).
