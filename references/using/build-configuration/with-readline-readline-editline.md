# --with-readline=readline/editline

--with-readline=readline|editline

Pick the backend library that powers the [`readline`](https://docs.python.org/3.14/library/readline.html#module-readline) module.

- readline: Rely on readline for the backend.

- editline: Rely on editline for the backend.

Added in version 3.10.
