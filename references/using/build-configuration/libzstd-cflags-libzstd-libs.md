# LIBZSTD_CFLAGS / LIBZSTD_LIBS

LIBZSTD_CFLAGS

 LIBZSTD_LIBS

The C compiler and linker flags for `libzstd`, drawn on by the [`compression.zstd`](https://docs.python.org/3.14/library/compression.zstd.html#module-compression.zstd) module, which take precedence over `pkg-config`.

Added in version 3.14.
