# 3.4.3.2. make platform

#### 3.4.3.2. make platform

Build the `python` program while skipping the standard library extension modules. Doing so writes a file called `platform` holding one line that lays out the build platform's details, for instance `macosx-14.3-arm64-3.12` or `linux-x86_64-3.13`.
