# --enable-wasm-dynamic-linking

### 3.3.5. WebAssembly Options

 --enable-wasm-dynamic-linking

Switch on dynamic linking support for WASM.

With dynamic linking, `dlopen` becomes available. The executable grows in size, owing to constrained dead code elimination plus extra features.

Added in version 3.11.
