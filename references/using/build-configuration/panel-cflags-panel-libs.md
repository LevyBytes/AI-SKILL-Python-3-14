# PANEL_CFLAGS / PANEL_LIBS

PANEL_CFLAGS

 PANEL_LIBS

C compiler and linker flags for PANEL, overriding `pkg-config`.

The C compiler and linker flags for `libpanel` or `libpanelw`, drawn on by the [`curses.panel`](https://docs.python.org/3.14/library/curses.panel.html#module-curses.panel) module, which take precedence over `pkg-config`.
