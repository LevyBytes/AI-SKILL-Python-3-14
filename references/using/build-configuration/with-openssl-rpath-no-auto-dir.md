# --with-openssl-rpath=[no/auto/DIR]

--with-openssl-rpath=[no|auto|DIR]

Choose the runtime library directory (rpath) used for OpenSSL libraries:

- `no` (default): leave rpath unset;

- `auto`: work out rpath automatically from `--with-openssl` and `pkg-config`;

- *DIR*: provide an explicit rpath.

Added in version 3.10.
