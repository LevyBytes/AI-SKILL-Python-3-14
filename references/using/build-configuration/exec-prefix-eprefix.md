# --exec-prefix=EPREFIX

--exec-prefix=EPREFIX

Place architecture-dependent files into EPREFIX, which defaults to `--prefix`.

You can read this value back at runtime through [`sys.exec_prefix`](https://docs.python.org/3.14/library/sys.html#sys.exec_prefix).
