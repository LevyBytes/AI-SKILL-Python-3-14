# BZIP2_CFLAGS / BZIP2_LIBS

<a id="334-options-for-third-party-dependencies"></a>

3.3.4. Options for third-party dependencies: Added in version 3.11.

BZIP2_CFLAGS

 BZIP2_LIBS

The C compiler and linker flags that link Python against `libbz2`, drawn on by the [`bz2`](https://docs.python.org/3.14/library/bz2.html#module-bz2) module, which take precedence over `pkg-config`.
