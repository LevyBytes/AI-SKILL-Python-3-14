# --with-framework-name=FRAMEWORK

--with-framework-name=FRAMEWORK

Give the name for the python framework on macOS; applies only once `--enable-framework` is set (default: `Python`).

--with-framework-name=FRAMEWORK

Give the framework its name (default: `Python`).
