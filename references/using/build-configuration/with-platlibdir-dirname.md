# --with-platlibdir=DIRNAME

--with-platlibdir=DIRNAME

The name of the Python library directory (`lib` by default).

On 64-bit platforms, Fedora and SuSE use `lib64`.

Refer to [`sys.platlibdir`](https://docs.python.org/3.14/library/sys.html#sys.platlibdir).

Added in version 3.9.
