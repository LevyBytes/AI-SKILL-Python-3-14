# --with-hash-algorithm=[fnv/siphash13/siphash24]

### 3.3.12. Security Options

 --with-hash-algorithm=[fnv|siphash13|siphash24]

Choose the hash algorithm employed within `Python/pyhash.c`:

- `siphash13` (default);

- `siphash24`;

- `fnv`.

Added in version 3.4.

Added in version 3.11: `siphash13` arrives and becomes the new default.
