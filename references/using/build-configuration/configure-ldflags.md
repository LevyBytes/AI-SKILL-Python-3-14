# CONFIGURE_LDFLAGS

CONFIGURE_LDFLAGS

The `LDFLAGS` variable's value as handed to the `./configure` script.

Refrain from assigning `CFLAGS`, `LDFLAGS`, and the like, so that users may append to these on the command line without trampling the values already set.

Added in version 3.2.
