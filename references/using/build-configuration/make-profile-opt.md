# 3.4.3.3. make profile-opt

#### 3.4.3.3. make profile-opt

Build Python with profile-guided optimization (PGO) applied. Passing the configure `--enable-optimizations` option promotes this to the default target for the `make` command (whether `make all` or plain `make`).
