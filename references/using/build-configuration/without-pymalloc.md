# --without-pymalloc

--without-pymalloc

Switch off the specialized Python memory allocator [pymalloc](https://docs.python.org/3.14/c-api/memory.html#pymalloc) (on by default).

Refer as well to the [`PYTHONMALLOC`](https://docs.python.org/3.14/using/cmdline.html#envvar-PYTHONMALLOC) environment variable.
