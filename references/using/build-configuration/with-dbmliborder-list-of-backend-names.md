# --with-dbmliborder=&lt;list of backend names&gt;

--with-dbmliborder=&lt;list of backend names&gt;

Replace the order in which db backends get checked for the [`dbm`](https://docs.python.org/3.14/library/dbm.html#module-dbm) module

An acceptable value is a string of backend names separated by a colon (`:`):

- `ndbm`;

- `gdbm`;

- `bdb`.
