# --enable-loadable-sqlite-extensions

### 3.3.1. General Options

 --enable-loadable-sqlite-extensions

Permit loadable extensions within the `_sqlite` extension module (the default is no) belonging to the [`sqlite3`](https://docs.python.org/3.14/library/sqlite3.html#module-sqlite3) module.

Refer to the [`sqlite3.Connection.enable_load_extension()`](https://docs.python.org/3.14/library/sqlite3.html#sqlite3.Connection.enable_load_extension) method on the [`sqlite3`](https://docs.python.org/3.14/library/sqlite3.html#module-sqlite3) module.

Added in version 3.6.
