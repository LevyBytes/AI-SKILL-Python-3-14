# --without-c-locale-coercion

--without-c-locale-coercion

Switch off C locale coercion toward a UTF-8 based locale (which is on by default).

Leave the `PY_COERCE_C_LOCALE` macro undefined.

Refer to [`PYTHONCOERCECLOCALE`](https://docs.python.org/3.14/using/cmdline.html#envvar-PYTHONCOERCECLOCALE) plus the [**PEP 538**](https://peps.python.org/pep-0538/).
