# PY_CPPFLAGS

PY_CPPFLAGS

Additional preprocessor flags tacked on when compiling the interpreter object files.

Default: `$(BASECPPFLAGS) -I. -I$(srcdir)/Include $(CONFIGURE_CPPFLAGS) $(CPPFLAGS)`.

Added in version 3.2.
