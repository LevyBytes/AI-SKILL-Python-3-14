# 3.3.15. Cross Compiling Options

### 3.3.15. Cross Compiling Options

Cross compiling — cross building, in other words — lets you build Python aimed at a different CPU architecture or platform. It calls for a Python interpreter that runs on the build platform, and that build Python's version has to line up with the version of the cross-compiled host Python.
