# --without-decimal-contextvar

--without-decimal-contextvar

Compile the `_decimal` extension module with a thread-local context instead of the default coroutine-local context; refer to the [`decimal`](https://docs.python.org/3.14/library/decimal.html#module-decimal) module.

Refer to [`decimal.HAVE_CONTEXTVAR`](https://docs.python.org/3.14/library/decimal.html#decimal.HAVE_CONTEXTVAR) plus the [`contextvars`](https://docs.python.org/3.14/library/contextvars.html#module-contextvars) module.

Added in version 3.9.
