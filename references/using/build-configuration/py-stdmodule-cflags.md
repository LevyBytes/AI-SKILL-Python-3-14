# PY_STDMODULE_CFLAGS

PY_STDMODULE_CFLAGS

The C flags applied when compiling the interpreter object files.

Default: `$(PY_CFLAGS) $(PY_CFLAGS_NODIST) $(PY_CPPFLAGS) $(CFLAGSFORSHARED)`.

Added in version 3.7.
