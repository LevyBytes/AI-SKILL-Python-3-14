# LIBMPDEC_CFLAGS / LIBMPDEC_LIBS

LIBMPDEC_CFLAGS

 LIBMPDEC_LIBS

The C compiler and linker flags for `libmpdec`, drawn on by the [`decimal`](https://docs.python.org/3.14/library/decimal.html#module-decimal) module, which take precedence over `pkg-config`.

Note

Unless `--with-system-libmpdec` has been specified, these environment variables do nothing.
