# CURSES_CFLAGS / CURSES_LIBS

CURSES_CFLAGS

 CURSES_LIBS

The C compiler and linker flags for `libncurses` or `libncursesw`, drawn on by the [`curses`](https://docs.python.org/3.14/library/curses.html#module-curses) module, which take precedence over `pkg-config`.
