# CPPFLAGS

CPPFLAGS

C preprocessor flags, e.g. `-I*include_dir*`.

CPPFLAGS

(Objective) C/C++ preprocessor flags: for instance `-I*include_dir*` when your headers live in a nonstandard directory *include_dir*.

For extension modules to build against the directories named in the environment variables, both `CPPFLAGS` and `LDFLAGS` have to carry the shell's value.
