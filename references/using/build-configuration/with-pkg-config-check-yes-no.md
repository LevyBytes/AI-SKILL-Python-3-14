# --with-pkg-config=[check/yes/no]

--with-pkg-config=[check|yes|no]

Controls whether configure relies on **pkg-config** to find build dependencies.

- `check` (default): **pkg-config** is optional

- `yes`: **pkg-config** is mandatory

- `no`: configure ignores **pkg-config** even when it is present

Added in version 3.11.
