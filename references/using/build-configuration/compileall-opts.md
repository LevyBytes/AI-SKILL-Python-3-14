# COMPILEALL_OPTS

COMPILEALL_OPTS

The options fed to the [`compileall`](https://docs.python.org/3.14/library/compileall.html#module-compileall) command line while `make install` produces PYC files. Default: `-j0`.

Added in version 3.12.
