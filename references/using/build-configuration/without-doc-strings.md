# --without-doc-strings

--without-doc-strings

Switch off static documentation strings to shrink the memory footprint (on by default). Documentation strings written in Python are not impacted.

Leave the `WITH_DOC_STRINGS` macro undefined.

Refer to the `PyDoc_STRVAR()` macro.
