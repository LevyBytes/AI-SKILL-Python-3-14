# --with-app-store-compliance / --with-app-store-compliance=PATCH-FILE

--with-app-store-compliance

 --with-app-store-compliance=PATCH-FILE

The Python standard library holds strings that are known to set off automated inspection tools and produce errors when a package goes to the macOS and iOS App Stores for distribution. Turn this option on and it applies the set of patches recognized as fixing app store compliance. You may also point it at a custom patch file. The option is off by default.

Added in version 3.13.
