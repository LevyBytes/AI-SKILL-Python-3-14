# LDFLAGS

### 3.3.3. Linker options

 LDFLAGS

Linker flags, e.g. `-L*library_directory*`.

LDFLAGS

Linker flags: for instance `-L*lib_dir*` when your libraries sit in a nonstandard directory *lib_dir*.

For extension modules to build against the directories named in the environment variables, both `CPPFLAGS` and `LDFLAGS` have to carry the shell's value.
