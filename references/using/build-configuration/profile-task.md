# PROFILE_TASK

PROFILE_TASK

The environment variable the Makefile reads: the Python command line arguments driving the PGO generation task.

Default: `-m test --pgo --timeout=$(TESTTIMEOUT)`.

Added in version 3.8.

Changed in version 3.13: Task failure is no longer ignored silently.
