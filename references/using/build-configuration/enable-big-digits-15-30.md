# --enable-big-digits=[15/30]

--enable-big-digits=[15|30]

Set how many bits a Python [`int`](https://docs.python.org/3.14/library/functions.html#int) digit occupies: either 15 or 30 bits.

The digit size is 30 by default.

Set `PYLONG_BITS_IN_DIGIT` to either `15` or `30`.

Refer to [`sys.int_info.bits_per_digit`](https://docs.python.org/3.14/library/sys.html#sys.int_info).
