# ZLIB_CFLAGS / ZLIB_LIBS

ZLIB_CFLAGS

 ZLIB_LIBS

The C compiler and linker flags for `libzlib`, drawn on by the [`gzip`](https://docs.python.org/3.14/library/gzip.html#module-gzip) module, which take precedence over `pkg-config`.
