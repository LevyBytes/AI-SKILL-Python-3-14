# 4.11.5. Modifying an install

### 4.11.5. Modifying an install

After Python is in place, you can add or drop features by way of the Programs and Features tool built into Windows. Pick the Python entry and choose "Uninstall/Change" to bring up the installer in maintenance mode.

"Modify" lets you add or drop features by toggling the checkboxes — checkboxes you leave alone install or remove nothing. A handful of options stay fixed in this mode, the install directory among them; changing those means uninstalling and then fully reinstalling Python.

"Repair" checks every file that the current settings say should be installed and restores any that were deleted or altered.

"Uninstall" strips Python out completely, apart from the Python install manager, which keeps its own entry in Programs and Features.
