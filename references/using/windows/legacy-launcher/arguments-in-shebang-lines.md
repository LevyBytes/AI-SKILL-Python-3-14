# 4.12.3. Arguments in shebang lines

### 4.12.3. Arguments in shebang lines

Shebang lines can additionally name extra options to hand off to the Python interpreter. As an example, suppose you have a shebang line:

```sh
#! /usr/bin/python -v

```

Then Python will be started with the `-v` option
