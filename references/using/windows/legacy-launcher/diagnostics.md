# 4.12.5. Diagnostics

### 4.12.5. Diagnostics

Setting the environment variable `PYLAUNCHER_DEBUG` (to any value) makes the launcher write diagnostic output to stderr (that is, to the console). Although that output contrives to be at once long-winded *and* terse, it should let you see which Python versions were located, why one particular version got picked, and the exact command line used to run the target Python. It is meant chiefly for testing and debugging.
