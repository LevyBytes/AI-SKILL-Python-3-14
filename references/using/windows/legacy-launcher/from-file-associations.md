# 4.12.1.4. From file associations

#### 4.12.1.4. From file associations

When it was installed, the launcher should have been linked with Python files (that is, `.py`, `.pyw`, `.pyc` files). The upshot is that double-clicking one of these files in Windows explorer invokes the launcher, so you can lean on the same mechanisms described above to let the script declare which version to use.

The chief advantage here is that one launcher can serve several Python versions side by side, governed by what the first line contains.
