# 4.9. Additional modules

### 4.9. Additional modules

Despite Python's goal of portability across every platform, certain features belong to Windows alone. A handful of modules, both within the standard library and outside it, plus various snippets, exist to tap into those features.

You can find the Windows-specific standard modules documented at [MS Windows Specific Services](https://docs.python.org/3.14/library/windows.html#mswin-specific-services).
