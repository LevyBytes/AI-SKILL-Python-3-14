# 4.5. Supported Windows versions

### 4.5. Supported Windows versions

According to [**PEP 11**](https://peps.python.org/pep-0011/), any given Python release backs a Windows platform only for as long as Microsoft treats that platform as being under extended support. Consequently, Python 3.14 backs Windows 10 and later. Should you need Windows 7 support, install Python 3.8 instead. Should you need Windows 8.1 support, install Python 3.12 instead.
