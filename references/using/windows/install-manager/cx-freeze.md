# 4.9.2. cx_Freeze

### 4.9.2. cx_Freeze

[cx_Freeze](https://cx-freeze.readthedocs.io/en/latest/) packs Python scripts into runnable Windows programs (`***.exe` files). Once that is finished, you can hand out your application without making your users install Python themselves.
