# 4.3.1. Free-threaded packages

### 4.3.1. Free-threaded packages

Added in version 3.13.

The packages that ship free-threaded binaries carry the names [python-freethreaded](https://www.nuget.org/packages/python-freethreaded) for the 64-bit build, [pythonx86-freethreaded](https://www.nuget.org/packages/pythonx86-freethreaded) for the 32-bit build, and [pythonarm64-freethreaded](https://www.nuget.org/packages/pythonarm64-freethreaded) for the ARM64 build. Each of these packages provides both the `python3.13t.exe` and `python.exe` entry points, and each one runs free threaded.
