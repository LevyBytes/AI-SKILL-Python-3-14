### 5. Using Python on macOS

The purpose of this document is to walk through the macOS-specific behavior worth knowing as you begin working with Python on Mac machines. Running Python under macOS feels much like running it on the other Unix-descended platforms, yet a few aspects of installation and certain features behave differently.

Python for macOS can be acquired and set up through several routes. A number of distributors offer pre-built copies of the latest Python releases. The bulk of this document covers working with the Pythons that the CPython release team publishes for download via the [python.org website](https://www.python.org/downloads/). Consult Alternative Distributions for a few additional choices.
