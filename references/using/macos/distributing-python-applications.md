# 5.5.3. Distributing Python Applications

### 5.5.3. Distributing Python Applications

A variety of tools are available for turning your Python code into a standalone distributable application:

- [py2app](https://pypi.org/project/py2app/): Supports building macOS `.app` bundles out of a Python project.

- [Briefcase](https://briefcase.readthedocs.io): A piece of the [BeeWare Project](https://beeware.org); a cross-platform packaging tool that supports building `.app` bundles on macOS, plus handling signing and notarization.

- [PyInstaller](https://pyinstaller.org/): A cross-platform packaging tool producing a single file or folder as the distributable artifact.
