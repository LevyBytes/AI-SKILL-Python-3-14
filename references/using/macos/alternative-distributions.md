# 5.2. Alternative Distributions

### 5.2. Alternative Distributions

Apart from the standard `python.org` for macOS installer, third-party distributions for macOS exist that may bundle extra functionality. A few popular distributions along with their notable features:

[ActivePython](https://www.activestate.com/products/python/)

Installer offering multi-platform compatibility plus documentation

[Anaconda](https://www.anaconda.com/download/)

Well-known scientific modules (numpy, scipy, and pandas among them) together with the `conda` package manager.

[Homebrew](https://brew.sh)

A macOS package manager covering multiple Python versions and a great many third-party Python-based packages (numpy, scipy, and pandas included).

[MacPorts](https://www.macports.org)

Yet another macOS package manager covering multiple Python versions and a great many third-party Python-based packages. It may carry pre-built versions of Python and many packages for older macOS releases.

Bear in mind that such distributions may lag behind the newest Python or library versions, and the core Python team neither maintains nor supports them.
