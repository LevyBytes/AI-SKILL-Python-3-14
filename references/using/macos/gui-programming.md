# 5.4. GUI Programming

### 5.4. GUI Programming

When building GUI applications on the Mac with Python, you have several options.

Python's standard GUI toolkit is [`tkinter`](https://docs.python.org/3.14/library/tkinter.html#module-tkinter), built atop the cross-platform Tk toolkit ([https://www.tcl.tk](https://www.tcl.tk)). The installer bundles a macOS-native build of Tk.

*PyObjC* is a Python binding into Apple's Objective-C/Cocoa framework. You can find information about PyObjC at [pyobjc](https://pypi.org/project/pyobjc/).

Several alternative macOS GUI toolkits are on offer, among them:

- [PySide](https://www.qt.io/qt-for-python): The official Python bindings into the [Qt GUI toolkit](https://wiki.qt.io/Qt_for_Python).

- [PyQt](https://riverbankcomputing.com/software/pyqt/): An alternative set of Python bindings into Qt.

- [Kivy](https://kivy.org): A cross-platform GUI toolkit covering both desktop and mobile platforms.

- [Toga](https://toga.readthedocs.io): A piece of the [BeeWare Project](https://beeware.org); it covers desktop, mobile, web and console apps.

- [wxPython](https://wxpython.org): A cross-platform toolkit covering desktop operating systems.
