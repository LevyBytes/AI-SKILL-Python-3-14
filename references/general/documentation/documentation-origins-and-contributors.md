## About this documentation

### About this documentation

Starting from [reStructuredText](https://docutils.sourceforge.io/rst.html) source files, the Python docs get built by [Sphinx](https://www.sphinx-doc.org/) — a documentation-building tool that began life inside Python and is these days run as its own separate project.

Both the docs and the tools behind them are built purely by volunteers, exactly as Python is. Should you wish to pitch in, head over to the [Dealing with Bugs](https://docs.python.org/3.14/bugs.html#reporting-bugs) page, which explains how. There is always room for fresh volunteers!

Many thanks go to:

- Fred L. Drake, Jr., who built the first Python documentation toolset and wrote a large share of the material;

- the [Docutils](https://docutils.sourceforge.io/) project, behind both reStructuredText and the Docutils suite themselves;

- Fredrik Lundh, whose Alternative Python Reference project supplied Sphinx with a number of solid ideas.

### Contributors to the Python documentation

Countless individuals have helped shape the Python language, its standard library, and the Python documentation. A partial roster of those contributors lives in [Misc/ACKS](https://github.com/python/cpython/tree/3.14/Misc/ACKS) within the Python source distribution.

Python ends up with documentation this good only thanks to everything the Python community puts in – Thank You!
