# Documentation and theme bug reports

## Dealing with Bugs

### Dealing with Bugs

As a well-established programming language, Python has built up a name for being stable. To keep that name intact, its developers want to hear about whatever shortcomings you run into in Python.

Repairing bugs on your own and sending patches to Python is occasionally the quicker route, since it cuts steps and keeps fewer people in the loop. Learn how to contribute.

### Documentation bugs

Spotting a flaw in this documentation, or having an enhancement in mind, is reason to file a bug report on the issue tracker. Got an idea for the fix? Add that too.

Another option is to start a discussion thread over on our [Documentation Discourse forum](https://discuss.python.org/c/documentation/26).

Should the bug instead sit in the documentation's theme (HTML / CSS / JavaScript), file your report on the [python-doc-theme issue tracker](https://github.com/python/python-docs-theme) instead.
