# Building C and C++ Extensions with setuptools

### 4.1. Building C and C++ Extensions with setuptools

Third-party tools handle the building, packaging, and distribution of extension modules best, and that work lies beyond what this document covers. Setuptools is one fitting choice, with its documentation available at [https://setuptools.pypa.io/en/latest/setuptools.html](https://setuptools.pypa.io/en/latest/setuptools.html).

Up until Python 3.12 the [`distutils`](https://docs.python.org/3.14/library/distutils.html#module-distutils) module shipped in the standard library; these days it lives on as part of Setuptools.
