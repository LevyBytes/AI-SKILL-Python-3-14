## 4. Building C and C++ Extensions

### 4. Building C and C++ Extensions

Where CPython is concerned, a C extension takes the form of a shared library (say a `.so` file under Linux or a `.pyd` under Windows) that exposes an *initialization function*.

Consult [Defining extension modules](https://docs.python.org/3.14/c-api/extension-modules.html#extension-modules) for the specifics.
