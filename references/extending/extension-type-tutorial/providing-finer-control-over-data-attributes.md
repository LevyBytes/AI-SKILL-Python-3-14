# Providing finer control over data attributes

### 2.3. Providing finer control over data attributes

This section tightens the control over the way the `first` and `last` attributes get assigned within the `Custom` example. Earlier in the module's evolution, the `first` and `last` instance variables could hold non-string values or be removed entirely. Our goal now is to guarantee these attributes hold strings at all times.
