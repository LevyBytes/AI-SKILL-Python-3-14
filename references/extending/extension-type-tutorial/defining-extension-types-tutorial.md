# Defining Extension Types: Tutorial

### 2. Defining Extension Types: Tutorial

When authoring a C extension module, Python lets you declare brand-new types whose instances can be driven from Python code in the same way as the built-in [`str`](https://docs.python.org/3.14/library/stdtypes.html#str) and [`list`](https://docs.python.org/3.14/library/stdtypes.html#list) types. Every extension type follows a shared template, yet a handful of details have to click into place before you can begin. Treat this document as an easy-paced introduction to that material.
