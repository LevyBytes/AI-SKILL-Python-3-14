# Embedding Python in C++

### 1.5. Embedding Python in C++

Embedding Python inside a C++ program can be done as well; the exact procedure hinges on the specifics of the C++ system at hand. As a rule you will write the main program in C++ and lean on the C++ compiler to compile and link it. Recompiling Python itself with C++ is unnecessary.
