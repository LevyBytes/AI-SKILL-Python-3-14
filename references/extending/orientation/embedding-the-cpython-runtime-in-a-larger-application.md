# Embedding the CPython runtime in a larger application

### Embedding the CPython runtime in a larger application

On occasion, instead of building an extension that lives inside the Python interpreter while the interpreter acts as the primary program, you'd rather tuck the CPython runtime into a bigger host program. The pages here walk through several of the particulars you must handle to pull that off cleanly.
