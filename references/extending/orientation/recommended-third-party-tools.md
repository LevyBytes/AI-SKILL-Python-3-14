# Recommended third party tools

### Recommended third party tools

What this guide documents is limited to the foundational extension-building tools bundled with the current CPython release. A range of [third party tools](https://docs.python.org/3.14/c-api/intro.html#c-api-tools) supply alternatives — some easier to use, some far more capable — for assembling C and C++ extensions aimed at Python.
