# What's New In Python 3.13 / tkinter.tix

### tkinter.tix

- Drop the `tkinter.tix` module, which carried a Python 3.6 deprecation. The third-party Tix library that the module wrapped no longer has maintenance. (Contributed by Zachary Ware in [gh-75552](https://github.com/python/cpython/issues/75552).)
