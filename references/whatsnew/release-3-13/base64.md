# What's New In Python 3.13 / base64 — base64

### base64

- Add [`z85encode()`](https://docs.python.org/3.14/library/base64.html#base64.z85encode) plus [`z85decode()`](https://docs.python.org/3.14/library/base64.html#base64.z85decode) functions that encode [`bytes`](https://docs.python.org/3.14/library/stdtypes.html#bytes) into [Z85 data](https://rfc.zeromq.org/spec/32/) and turn Z85-encoded data back into `bytes`. (Contributed by Matan Perelman in [gh-75299](https://github.com/python/cpython/issues/75299).)
