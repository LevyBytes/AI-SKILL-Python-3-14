# What's New In Python 3.13 / re - re

### re

- For better clarity, `re.error` is renamed to [`PatternError`](https://docs.python.org/3.14/library/re.html#re.PatternError). The old `re.error` name stays for backward compatibility.

### re

- Drop the undocumented, deprecated, broken `re.template()` function together with the `re.TEMPLATE` / `re.T` flag. (Contributed by Serhiy Storchaka and Nikita Sobolev in [gh-105687](https://github.com/python/cpython/issues/105687).)
