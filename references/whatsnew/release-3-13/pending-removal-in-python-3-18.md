# What's New In Python 3.13 / Pending removal in Python 3.18 - decimal

### Pending removal in Python 3.18

- [`decimal`](https://docs.python.org/3.14/library/decimal.html#module-decimal):

  - Carrying a deprecation since Python 3.13, the [`Decimal`](https://docs.python.org/3.14/library/decimal.html#decimal.Decimal) format specifier `'N'` is non-standard, undocumented, and present only within the C implementation of the `decimal` module. (Contributed by Serhiy Storchaka in [gh-89902](https://github.com/python/cpython/issues/89902).)
