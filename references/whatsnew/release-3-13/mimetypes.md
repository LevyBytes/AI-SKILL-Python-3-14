# What's New In Python 3.13 / mimetypes - mimetypes

### mimetypes

- A new [`guess_file_type()`](https://docs.python.org/3.14/library/mimetypes.html#mimetypes.guess_file_type) function infers a MIME type straight from a filesystem path. Handing paths to [`guess_type()`](https://docs.python.org/3.14/library/mimetypes.html#mimetypes.guess_type) is henceforth [soft deprecated](https://docs.python.org/3.14/glossary.html#term-soft-deprecated). (Contributed by Serhiy Storchaka in [gh-66543](https://github.com/python/cpython/issues/66543).)
