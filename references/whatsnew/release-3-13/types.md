# What's New In Python 3.13 / types - types

### types

- [`SimpleNamespace`](https://docs.python.org/3.14/library/types.html#types.SimpleNamespace) now accepts a lone positional argument for seeding the namespace's arguments. That argument has to be either a mapping or an iterable made of key-value pairs. (Contributed by Serhiy Storchaka in [gh-108191](https://github.com/python/cpython/issues/108191).)
