# What's New In Python 3.13 / argparse - argparse

### Improved Modules

### argparse

- Add the *deprecated* parameter onto the [`add_argument()`](https://docs.python.org/3.14/library/argparse.html#argparse.ArgumentParser.add_argument) and `add_parser()` methods so that command-line options, positional arguments, and subcommands can be marked deprecated. (Contributed by Serhiy Storchaka in [gh-83648](https://github.com/python/cpython/issues/83648).)
