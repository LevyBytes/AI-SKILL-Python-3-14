# What's New In Python 3.13 / dbm - dbm

### dbm

- Add [`dbm.sqlite3`](https://docs.python.org/3.14/library/dbm.html#module-dbm.sqlite3), a fresh module providing an SQLite backend, and turn it into the default `dbm` backend. (Contributed by Raymond Hettinger and Erlend E. Aasland in [gh-100414](https://github.com/python/cpython/issues/100414).)

- Permit wiping every item out of the database via the fresh `clear()` methods on the GDBM and NDBM database objects. (Contributed by Donghee Na in [gh-107122](https://github.com/python/cpython/issues/107122).)
