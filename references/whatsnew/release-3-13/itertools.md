# What's New In Python 3.13 / itertools - itertools

### itertools

- A fresh *strict* parameter on [`batched()`](https://docs.python.org/3.14/library/itertools.html#itertools.batched) triggers a [`ValueError`](https://docs.python.org/3.14/library/exceptions.html#ValueError) whenever the closing batch falls below the requested batch size. (Contributed by Raymond Hettinger in [gh-113202](https://github.com/python/cpython/issues/113202).)
