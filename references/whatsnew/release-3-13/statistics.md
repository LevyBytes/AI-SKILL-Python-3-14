# What's New In Python 3.13 / statistics - statistics

### statistics

- A new [`kde()`](https://docs.python.org/3.14/library/statistics.html#statistics.kde) supports kernel density estimation. With it you can derive a continuous probability density function out of a fixed count of discrete samples. (Contributed by Raymond Hettinger in [gh-115863](https://github.com/python/cpython/issues/115863).)

- A new [`kde_random()`](https://docs.python.org/3.14/library/statistics.html#statistics.kde_random) draws samples from an estimated probability density function that [`kde()`](https://docs.python.org/3.14/library/statistics.html#statistics.kde) produced. (Contributed by Raymond Hettinger in [gh-115863](https://github.com/python/cpython/issues/115863).)
