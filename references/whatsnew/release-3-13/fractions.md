# What's New In Python 3.13 / fractions — fractions, string

### fractions

- [`Fraction`](https://docs.python.org/3.14/library/fractions.html#fractions.Fraction) objects henceforth honor the standard [format specification mini-language](https://docs.python.org/3.14/library/string.html#formatspec) rules governing fill, alignment, sign handling, minimum width, plus grouping. (Contributed by Mark Dickinson in [gh-111320](https://github.com/python/cpython/issues/111320).)
