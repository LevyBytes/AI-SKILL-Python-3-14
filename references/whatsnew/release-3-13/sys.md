# What's New In Python 3.13 / sys - sys

### sys

- A new [`_is_interned()`](https://docs.python.org/3.14/library/sys.html#sys._is_interned) function checks whether a string has been interned. Not every Python implementation is guaranteed to provide it. (Contributed by Serhiy Storchaka in [gh-78573](https://github.com/python/cpython/issues/78573).)
