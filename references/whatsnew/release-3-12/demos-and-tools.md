# What’s New In Python 3.12 / Demos and Tools

### Demos and Tools

- The `Tools/demo/` directory, which held the old demo scripts, has been removed. You can find a copy over at the [old-demos project](https://github.com/gvanrossum/old-demos). (Contributed by Victor Stinner in [gh-97681](https://github.com/python/cpython/issues/97681).)

- The dated example scripts under the `Tools/scripts/` directory have been removed. A copy lives in the [old-demos project](https://github.com/gvanrossum/old-demos). (Contributed by Victor Stinner in [gh-97669](https://github.com/python/cpython/issues/97669).)
