# What’s New In Python 3.12 / itertools - itertools

### itertools

- Add [`itertools.batched()`](https://docs.python.org/3.14/library/itertools.html#itertools.batched) that gathers items into equally sized tuples, where the final batch can run shorter than the others. (Contributed by Raymond Hettinger in [gh-98363](https://github.com/python/cpython/issues/98363).)
