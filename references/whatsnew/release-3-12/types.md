# What’s New In Python 3.12 / types — types, typing

### types

- A new [`types.get_original_bases()`](https://docs.python.org/3.14/library/types.html#types.get_original_bases) helper makes it possible to introspect subclassed [User-defined generic types](https://docs.python.org/3.14/library/typing.html#user-defined-generics) more deeply. (Contributed by James Hilton-Balfe and Alex Waygood in [gh-101827](https://github.com/python/cpython/issues/101827).)
