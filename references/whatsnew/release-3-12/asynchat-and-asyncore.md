# What’s New In Python 3.12 / asynchat and asyncore - asyncio

### Removed

### asynchat and asyncore

- Both modules were dropped following the timeline laid out in [**PEP 594**](https://peps.python.org/pep-0594/), after being deprecated in Python 3.6. Reach for [`asyncio`](https://docs.python.org/3.14/library/asyncio.html#module-asyncio) instead. (Contributed by Nikita Sobolev in [gh-96580](https://github.com/python/cpython/issues/96580).)
