# What’s New In Python 3.12 / tokenize - tokenize

### tokenize

- What [**PEP 701**](https://peps.python.org/pep-0701/) introduced is now reflected within the [`tokenize`](https://docs.python.org/3.14/library/tokenize.html#module-tokenize) module. (Contributed by Marta Gómez Macías and Pablo Galindo in [gh-102856](https://github.com/python/cpython/issues/102856).) For details on what shifted in the `tokenize` module, consult Porting to Python 3.12.
