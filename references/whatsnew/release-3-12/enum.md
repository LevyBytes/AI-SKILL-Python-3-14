# What’s New In Python 3.12 / enum — enum

### enum

- Drop the `EnumMeta.__getattr__` of [`enum`](https://docs.python.org/3.14/library/enum.html#module-enum), no longer required for reaching enum attributes. (Contributed by Ethan Furman in [gh-95083](https://github.com/python/cpython/issues/95083).)
