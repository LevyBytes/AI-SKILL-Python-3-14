# What’s New In Python 3.12 / smtpd - asyncio

### smtpd

- The `smtpd` module was dropped following the timeline in [**PEP 594**](https://peps.python.org/pep-0594/), after being deprecated in Python 3.4.7 and 3.5.4. Reach for the [aiosmtpd](https://pypi.org/project/aiosmtpd/) PyPI module, or any other server built on [`asyncio`](https://docs.python.org/3.14/library/asyncio.html#module-asyncio), instead. (Contributed by Oleg Iarygin in [gh-93243](https://github.com/python/cpython/issues/93243).)
