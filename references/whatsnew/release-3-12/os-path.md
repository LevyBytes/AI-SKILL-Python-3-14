# What’s New In Python 3.12 / os.path — os.path

### os.path

- Add [`os.path.isjunction()`](https://docs.python.org/3.14/library/os.path.html#os.path.isjunction) for testing whether a supplied path is a junction. (Contributed by Charles Machalow in [gh-99547](https://github.com/python/cpython/issues/99547).)

- Add [`os.path.splitroot()`](https://docs.python.org/3.14/library/os.path.html#os.path.splitroot) that breaks a path into a triad `(drive, root, tail)`. (Contributed by Barney Gale in [gh-101000](https://github.com/python/cpython/issues/101000).)
