# What’s New In Python 3.12 / locale - locale

### locale

- Drop the `locale.format()` function of [`locale`](https://docs.python.org/3.14/library/locale.html#module-locale), deprecated back in Python 3.7: switch to [`locale.format_string()`](https://docs.python.org/3.14/library/locale.html#locale.format_string) instead. (Contributed by Victor Stinner in [gh-94226](https://github.com/python/cpython/issues/94226).)
