# What’s New In Python 3.12 / platform

### platform

- Add the ability to detect Windows 11 plus Windows Server editions newer than 2012. Formerly, queries against Windows Server platforms released after Windows Server 2012, and against Windows 11, came back as `Windows-10`. (Contributed by Steve Dower in [gh-89545](https://github.com/python/cpython/issues/89545).)
