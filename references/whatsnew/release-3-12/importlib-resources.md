# What’s New In Python 3.12 / importlib.resources — importlib.resources

### importlib.resources

- [`importlib.resources.as_file()`](https://docs.python.org/3.14/library/importlib.resources.html#importlib.resources.as_file) handles resource directories from now on. (Contributed by Jason R. Coombs in [gh-97930](https://github.com/python/cpython/issues/97930).)

- The leading parameter of [`importlib.resources.files()`](https://docs.python.org/3.14/library/importlib.resources.html#importlib.resources.files) was renamed to *anchor*. (Contributed by Jason R. Coombs in [gh-100598](https://github.com/python/cpython/issues/100598).)
