# What’s New In Python 3.12 / webbrowser — webbrowser

### webbrowser

- Drop support for browsers that are now obsolete out of [`webbrowser`](https://docs.python.org/3.14/library/webbrowser.html#module-webbrowser). Those dropped entries cover: Grail, Mosaic, Netscape, Galeon, Skipstone, Iceape, Firebird, plus any Firefox at version 35 or earlier ([gh-102871](https://github.com/python/cpython/issues/102871)).
