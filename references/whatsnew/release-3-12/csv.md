# What’s New In Python 3.12 / csv - csv

### csv

- Add the [`csv.QUOTE_NOTNULL`](https://docs.python.org/3.14/library/csv.html#csv.QUOTE_NOTNULL) and [`csv.QUOTE_STRINGS`](https://docs.python.org/3.14/library/csv.html#csv.QUOTE_STRINGS) flags, granting tighter control over `None` together with empty strings for [`reader`](https://docs.python.org/3.14/library/csv.html#csv.reader) and [`writer`](https://docs.python.org/3.14/library/csv.html#csv.writer) objects.
