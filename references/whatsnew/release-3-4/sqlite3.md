# What's New In Python 3.4 / sqlite3 — sqlite3

### sqlite3

The [`connect()`](https://docs.python.org/3.14/library/sqlite3.html#sqlite3.connect) function gained a new boolean parameter, *uri*, that signals the *database* argument should be treated as a `uri` (consult the [SQLite URI documentation](https://www.sqlite.org/uri.html)). (Contributed by poq in [bpo-13773](https://bugs.python.org/issue?@action=redirect&bpo=13773).)
