# What's New In Python 3.4 / statistics - statistics

### statistics

The fresh [`statistics`](https://docs.python.org/3.14/library/statistics.html#module-statistics) module (specified in [**PEP 450**](https://peps.python.org/pep-0450/)) brings a handful of core statistics routines straight into the standard library. Through this module you can compute the mean, median, mode, variance and standard deviation across a data series.
