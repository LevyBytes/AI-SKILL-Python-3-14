# What's New In Python 3.4 / poplib - poplib

### poplib

A pair of fresh methods joined [`poplib`](https://docs.python.org/3.14/library/poplib.html#module-poplib): [`capa()`](https://docs.python.org/3.14/library/poplib.html#poplib.POP3.capa), giving back the roster of capabilities the POP server announces, and [`stls()`](https://docs.python.org/3.14/library/poplib.html#poplib.POP3.stls), which upgrades a clear-text POP3 session into an encrypted POP3 session when the POP server allows it. (Contributed by Lorenzo Catucci in [bpo-4473](https://bugs.python.org/issue?@action=redirect&bpo=4473).)
