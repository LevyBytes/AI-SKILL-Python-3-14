# What's New In Python 3.4 / selectors — select, selectors

### selectors

The fresh [`selectors`](https://docs.python.org/3.14/library/selectors.html#module-selectors) module (produced while building [**PEP 3156**](https://peps.python.org/pep-3156/)) enables high-level, efficient I/O multiplexing layered over the primitives of the [`select`](https://docs.python.org/3.14/library/select.html#module-select) module.
