# What's New In Python 3.4 / pty - os, pty

### pty

[`pty.spawn()`](https://docs.python.org/3.14/library/pty.html#pty.spawn) hands back the status value from [`os.waitpid()`](https://docs.python.org/3.14/library/os.html#os.waitpid) for the child process now, rather than `None`. (Contributed by Gregory P. Smith.)
