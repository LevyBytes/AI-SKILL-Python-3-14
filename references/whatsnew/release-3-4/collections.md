# What's New In Python 3.4 / collections — collections

### collections

The [`ChainMap.new_child()`](https://docs.python.org/3.14/library/collections.html#collections.ChainMap.new_child) method will now take an *m* argument that names the child map to push onto the chain. With it you can supply an existing mapping and/or a custom mapping type for the child. (Contributed by Vinay Sajip in [bpo-16613](https://bugs.python.org/issue?@action=redirect&bpo=16613).)
