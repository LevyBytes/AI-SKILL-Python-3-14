# What's New In Python 3.4 / pathlib - pathlib

### pathlib

The fresh [`pathlib`](https://docs.python.org/3.14/library/pathlib.html#module-pathlib) module supplies classes that model filesystem paths with semantics suited to the various operating systems. The path classes split into two groups: *pure paths*, which expose only computational operations and never touch I/O, and *concrete paths*, which derive from pure paths yet additionally expose I/O operations.

Within Python 3.4, this module counts as a [provisional API](https://docs.python.org/3.14/glossary.html#term-provisional-API).
