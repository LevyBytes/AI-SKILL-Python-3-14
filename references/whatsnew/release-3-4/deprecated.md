# What's New In Python 3.4 / Deprecated

### Deprecated

This part walks through assorted APIs and other features marked deprecated in Python 3.4, slated for removal in Python 3.5 or some later release. For most though not every case, reaching for the deprecated APIs will raise a [`DeprecationWarning`](https://docs.python.org/3.14/library/exceptions.html#DeprecationWarning) once the interpreter runs with deprecation warnings turned on (say, via `-Wd`).
