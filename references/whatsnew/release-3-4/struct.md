# What's New In Python 3.4 / struct — struct

### struct

A new function [`iter_unpack`](https://docs.python.org/3.14/library/struct.html#struct.iter_unpack), paired with a new [`struct.Struct.iter_unpack()`](https://docs.python.org/3.14/library/struct.html#struct.Struct.iter_unpack) method on compiled formats, delivers streamed unpacking across a buffer that holds repeated instances of one given data format. (Contributed by Antoine Pitrou in [bpo-17804](https://bugs.python.org/issue?@action=redirect&bpo=17804).)
