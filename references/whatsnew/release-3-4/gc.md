# What's New In Python 3.4 / gc - gc

### gc

A new function, [`get_stats()`](https://docs.python.org/3.14/library/gc.html#gc.get_stats), hands back a list of three per-generation dictionaries holding the collection statistics gathered since interpreter startup. (Contributed by Antoine Pitrou in [bpo-16351](https://bugs.python.org/issue?@action=redirect&bpo=16351).)
