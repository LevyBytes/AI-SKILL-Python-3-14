# What's New In Python 3.4 / sys - readline, site, sys

### sys

A new function, [`sys.getallocatedblocks()`](https://docs.python.org/3.14/library/sys.html#sys.getallocatedblocks), reports how many blocks the interpreter currently has allocated. (Within CPython under the default `--with-pymalloc` setting, that covers allocations going through the [`PyObject_Malloc()`](https://docs.python.org/3.14/c-api/memory.html#c.PyObject_Malloc) API.) It comes in handy for chasing memory leaks, all the more so when wired into a test suite. (Contributed by Antoine Pitrou in [bpo-13390](https://bugs.python.org/issue?@action=redirect&bpo=13390).)

Once the Python interpreter boots up in [interactive mode](https://docs.python.org/3.14/tutorial/interpreter.html#tut-interactive), it looks for an [`__interactivehook__`](https://docs.python.org/3.14/library/sys.html#sys.__interactivehook__) attribute on the [`sys`](https://docs.python.org/3.14/library/sys.html#module-sys) module. Should that attribute be present, its value gets called with zero arguments right before interactive mode begins. This lookup happens after the [`PYTHONSTARTUP`](https://docs.python.org/3.14/using/cmdline.html#envvar-PYTHONSTARTUP) file has been read, so you can assign it there. The [`site`](https://docs.python.org/3.14/library/site.html#module-site) module [sets it](https://docs.python.org/3.14/library/site.html#rlcompleter-config) to a function turning on tab completion plus history saving (into `~/.python-history`) whenever the platform offers [`readline`](https://docs.python.org/3.14/library/readline.html#module-readline). To opt out of this (new) behavior, you may override it inside `PYTHONSTARTUP`, [`sitecustomize`](https://docs.python.org/3.14/library/site.html#module-sitecustomize), or [`usercustomize`](https://docs.python.org/3.14/library/site.html#module-usercustomize) by removing that attribute from `sys` (or pointing it at some other callable). (Contributed by ??ric Araujo and Antoine Pitrou in [bpo-5845](https://bugs.python.org/issue?@action=redirect&bpo=5845).)
