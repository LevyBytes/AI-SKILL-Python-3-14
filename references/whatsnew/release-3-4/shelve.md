# What's New In Python 3.4 / shelve - shelve

### shelve

[`Shelf`](https://docs.python.org/3.14/library/shelve.html#shelve.Shelf) instances are now permitted inside [`with`](https://docs.python.org/3.14/reference/compound_stmts.html#with) statements, and they close themselves once the `with` block ends. (Contributed by Filip Gruszczyński in [bpo-13896](https://bugs.python.org/issue?@action=redirect&bpo=13896).)
