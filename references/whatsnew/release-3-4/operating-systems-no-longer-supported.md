# What's New In Python 3.4 / Operating Systems No Longer Supported

### Removed

### Operating Systems No Longer Supported

The source tree and build tooling have dropped support for these operating systems:

- OS/2 ([bpo-16135](https://bugs.python.org/issue?@action=redirect&bpo=16135)).

- Windows 2000 (changeset e52df05b496a).

- Windows installations on which `COMSPEC` resolves to `command.com` ([bpo-14470](https://bugs.python.org/issue?@action=redirect&bpo=14470)).

- VMS ([bpo-16136](https://bugs.python.org/issue?@action=redirect&bpo=16136)).
