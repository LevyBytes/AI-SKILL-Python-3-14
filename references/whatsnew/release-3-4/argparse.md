# What's New In Python 3.4 / argparse — argparse

### argparse

The [`FileType`](https://docs.python.org/3.14/library/argparse.html#argparse.FileType) class will now take *encoding* and *errors* arguments, both forwarded straight to [`open()`](https://docs.python.org/3.14/library/functions.html#open). (Contributed by Lucas Maystre in [bpo-11175](https://bugs.python.org/issue?@action=redirect&bpo=11175).)
