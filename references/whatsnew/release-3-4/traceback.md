# What's New In Python 3.4 / traceback — traceback

### traceback

A new [`traceback.clear_frames()`](https://docs.python.org/3.14/library/traceback.html#traceback.clear_frames) function accepts a traceback object and wipes the local variables across every frame it points to, trimming how much memory is held. (Contributed by Andrew Kuchling in [bpo-1565525](https://bugs.python.org/issue?@action=redirect&bpo=1565525).)
