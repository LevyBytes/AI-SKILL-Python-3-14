# What's New In Python 3.4 / PEP 453: Explicit Bootstrapping of PIP in Python Installations / Documentation Changes

#### Documentation Changes

Alongside this update, the [Installing Python modules](https://docs.python.org/3.14/installing/index.html#installing-index) and [Distributing Python Modules](https://docs.python.org/3.14/distributing/index.html#distributing-index) portions of the documentation got fully reworked into brief getting started and FAQ documents. The bulk of packaging documentation has since relocated to the Python Packaging Authority maintained [Python Packaging User Guide](https://packaging.python.org) plus the documentation belonging to the individual projects.

Because that migration remains unfinished for now, the older editions of those guides stay accessible as [Building C and C++ Extensions with setuptools](https://docs.python.org/3.14/extending/building.html#install-index) and [Building C and C++ Extensions with setuptools](https://docs.python.org/3.14/extending/building.html#setuptools-index).

See also

[**PEP 453**](https://peps.python.org/pep-0453/): Explicit bootstrapping of pip in Python installations

PEP authored by Donald Stufft and Nick Coghlan; the implementation came from Donald Stufft, Nick Coghlan, Martin von Löwis and Ned Deily.
