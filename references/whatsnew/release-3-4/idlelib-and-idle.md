# What's New In Python 3.4 / idlelib and IDLE

### idlelib and IDLE

Because idlelib provides the IDLE shell and editor and was never meant to be imported by outside code, every release brings refinements to it. Consult `Lib/idlelib/NEWS.txt` for a running record of edits since 3.3.0, plus those landing in later 3.4.x point releases. That same file can be opened through the IDLE Help ? About IDLE dialog.
