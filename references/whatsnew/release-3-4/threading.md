# What's New In Python 3.4 / threading — threading

### threading

You can fetch the [`Thread`](https://docs.python.org/3.14/library/threading.html#threading.Thread) object standing in for the main thread from the new [`main_thread()`](https://docs.python.org/3.14/library/threading.html#threading.main_thread) function. Under ordinary circumstances that is the thread out of which the Python interpreter got launched. (Contributed by Andrew Svetlov in [bpo-18882](https://bugs.python.org/issue?@action=redirect&bpo=18882).)
