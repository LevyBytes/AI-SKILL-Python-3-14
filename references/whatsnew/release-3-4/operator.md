# What's New In Python 3.4 / operator - operator

### operator

The fresh function [`length_hint()`](https://docs.python.org/3.14/library/operator.html#operator.length_hint) supplies an implementation of the rules governing how the [`__length_hint__()`](https://docs.python.org/3.14/reference/datamodel.html#object.__length_hint__) special method ought to be applied, forming part of the [**PEP 424**](https://peps.python.org/pep-0424/) formal specification for this language feature. (Contributed by Armin Ronacher in [bpo-16148](https://bugs.python.org/issue?@action=redirect&bpo=16148).)

A pure-python edition of the [`operator`](https://docs.python.org/3.14/library/operator.html#module-operator) module now exists, both as a reference and for adoption by other Python implementations. (Contributed by Zachary Ware in [bpo-16694](https://bugs.python.org/issue?@action=redirect&bpo=16694).)
