# What's New In Python 3.4 / tarfile - tarfile

### tarfile

The [`tarfile`](https://docs.python.org/3.14/library/tarfile.html#module-tarfile) module now offers a basic [Command-Line Interface](https://docs.python.org/3.14/library/tarfile.html#tarfile-commandline) when invoked straight as a script or through `-m`. With it you can build and unpack tarfile archives. (Contributed by Berker Peksag in [bpo-13477](https://bugs.python.org/issue?@action=redirect&bpo=13477).)
