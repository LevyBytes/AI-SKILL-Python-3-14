# What's New In Python 3.4 / colorsys

### colorsys

The coefficient digits used in the RGB ? YIQ conversions have been widened to line up with the FCC NTSC versions. Resulting values should differ by under 1% and may align more closely with results seen elsewhere. (Contributed by Brian Landers and Serhiy Storchaka in [bpo-14323](https://bugs.python.org/issue?@action=redirect&bpo=14323).)
