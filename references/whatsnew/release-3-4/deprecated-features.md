# What's New In Python 3.4 / Deprecated Features — idle

### Deprecated Features

- Launching [IDLE — Python editor and shell](https://docs.python.org/3.14/library/idle.html#idle) using the `-n` flag (no subprocess) is now obsolete. That said, the capability stays in place until [bpo-18823](https://bugs.python.org/issue?@action=redirect&bpo=18823) gets resolved.

- Having the site module append a "site-python" directory onto sys.path when one is present is now obsolete ([bpo-19375](https://bugs.python.org/issue?@action=redirect&bpo=19375)).
