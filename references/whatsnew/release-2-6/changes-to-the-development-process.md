# What’s New in Python 2.6 / Changes to the Development Process

### Changes to the Development Process

Over the course of building 2.6, two notable shifts happened in how Python is developed: we moved off SourceForge’s issue tracker onto a tailored Roundup setup, and the docs were migrated away from LaTeX into reStructuredText.
