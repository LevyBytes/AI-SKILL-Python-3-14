# What’s New in Python 2.6 / Port-Specific Changes: IRIX

Several aging IRIX-only modules now carry a deprecation and are slated to vanish with Python 3.0: `al` and `AL`, `cd`, `cddb`, `cdplayer`, `CL` and `cl`, `DEVICE`, `ERRNO`, `FILE`, `FL` and `fl`, `flp`, `fm`, `GET`, `GLWS`, `GL` and `gl`, `IN`, `IOCTL`, `jpeg`, `panelparser`, `readcd`, `SV` and `sv`, `torgb`, `videoreader`, and `WAIT`.
