# What's New In Python 3.3 / shlex - shlex

### shlex

Formerly an undocumented helper inside the `pipes` modules, the `quote` function has relocated to the [`shlex`](https://docs.python.org/3.14/library/shlex.html#module-shlex) module and now carries documentation. [`quote()`](https://docs.python.org/3.14/library/shlex.html#shlex.quote) correctly escapes every character within a string that the shell might otherwise interpret specially.
