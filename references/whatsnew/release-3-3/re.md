# What's New In Python 3.3 / re

### re

The `\u` and `\U` escapes are now honored within [`str`](https://docs.python.org/3.14/library/stdtypes.html#str) regular expressions.

(Contributed by Serhiy Storchaka in [bpo-3665](https://bugs.python.org/issue?@action=redirect&bpo=3665).)
