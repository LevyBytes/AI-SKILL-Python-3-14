# What's New In Python 3.3 / imaplib - imaplib

### imaplib

To tune the secure channel, the [`IMAP4_SSL`](https://docs.python.org/3.14/library/imaplib.html#imaplib.IMAP4_SSL) constructor now takes an SSLContext parameter.

Sijin Joseph landed this ([bpo-8808](https://bugs.python.org/issue?@action=redirect&bpo=8808)).
