# What's New In Python 3.3 / tempfile - tempfile

### tempfile

The `truncate()` method on [`tempfile.SpooledTemporaryFile`](https://docs.python.org/3.14/library/tempfile.html#tempfile.SpooledTemporaryFile) henceforth takes a `size` parameter. Ryan Kelly added it; refer to [bpo-9957](https://bugs.python.org/issue?@action=redirect&bpo=9957).
