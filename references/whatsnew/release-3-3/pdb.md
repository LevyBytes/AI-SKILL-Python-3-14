# What's New In Python 3.3 / pdb

### pdb

Beyond just command names, tab-completion now reaches the arguments of those commands too. Take the `break` command, for instance, where function names and file names get completed.

(Contributed by Georg Brandl in [bpo-14210](https://bugs.python.org/issue?@action=redirect&bpo=14210))
