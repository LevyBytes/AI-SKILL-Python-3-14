# What's New In Python 3.3 / types — types

### types

A new [`types.MappingProxyType`](https://docs.python.org/3.14/library/types.html#types.MappingProxyType) class arrives: a read-only proxy wrapping a mapping. ([bpo-14386](https://bugs.python.org/issue?@action=redirect&bpo=14386))

Two fresh functions, [`types.new_class()`](https://docs.python.org/3.14/library/types.html#types.new_class) and [`types.prepare_class()`](https://docs.python.org/3.14/library/types.html#types.prepare_class), back dynamic type construction in line with [**PEP 3115**](https://peps.python.org/pep-3115/). ([bpo-14588](https://bugs.python.org/issue?@action=redirect&bpo=14588))
