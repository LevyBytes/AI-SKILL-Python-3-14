# What's New In Python 3.3 / ipaddress - ipaddress

### ipaddress

For building and working with objects that stand for IPv4 and IPv6 addresses, networks, and interfaces (that is, an IP address tied to a particular IP subnet), the new [`ipaddress`](https://docs.python.org/3.14/library/ipaddress.html#module-ipaddress) module supplies the tooling.

(Contributed by Google and Peter Moody in [**PEP 3144**](https://peps.python.org/pep-3144/).)
