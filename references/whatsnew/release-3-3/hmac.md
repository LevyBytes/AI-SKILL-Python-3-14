# What's New In Python 3.3 / hmac - hmac

### hmac

To shut down side channel attacks that read digests via timing, a new [`compare_digest()`](https://docs.python.org/3.14/library/hmac.html#hmac.compare_digest) function has arrived. Nick Coghlan and Christian Heimes landed this ([bpo-15061](https://bugs.python.org/issue?@action=redirect&bpo=15061)).
