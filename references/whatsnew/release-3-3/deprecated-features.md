# What's New In Python 3.3 / Deprecated features - array

### Deprecated features

Deprecation now applies to the `'u'` format code of the [`array`](https://docs.python.org/3.14/library/array.html#module-array) module; it is slated for removal in Python 4 alongside everything else in the ([`Py_UNICODE`](https://docs.python.org/3.14/c-api/unicode.html#c.Py_UNICODE)) API.
