# What's New In Python 3.3 / Unsupported Operating Systems

### Deprecated

### Unsupported Operating Systems

With no one left to maintain them, OS/2 and VMS have lost support.

Because of the upkeep cost, Windows 2000 ? and any Windows setup that points `COMSPEC` at `command.com` ? is no longer supported.

OSF support, flagged for deprecation back in 3.2, is now gone entirely.
