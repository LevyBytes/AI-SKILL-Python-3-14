# What's New In Python 3.3 / pydoc — pydoc

### pydoc

Both the Tk GUI and the `serve()` function are gone from the [`pydoc`](https://docs.python.org/3.14/library/pydoc.html#module-pydoc) module: `pydoc -g` together with `serve()` had been marked deprecated back in Python 3.2.
