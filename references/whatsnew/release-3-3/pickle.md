# What's New In Python 3.3 / pickle - pickle

### pickle

An optional [`dispatch_table`](https://docs.python.org/3.14/library/pickle.html#pickle.Pickler.dispatch_table) attribute is now available on [`pickle.Pickler`](https://docs.python.org/3.14/library/pickle.html#pickle.Pickler) objects, letting you register reduction functions on a per-pickler basis.

(Contributed by Richard Oudkerk in [bpo-14166](https://bugs.python.org/issue?@action=redirect&bpo=14166).)
