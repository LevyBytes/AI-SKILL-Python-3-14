# What's New In Python 3.3 / functools - functools

### functools

A `typed` keyword argument now reaches the [`functools.lru_cache()`](https://docs.python.org/3.14/library/functools.html#functools.lru_cache) decorator (defaulting to `False`) so that values of distinct types that compare equal land in their own cache slots. Raymond Hettinger landed this ([bpo-13227](https://bugs.python.org/issue?@action=redirect&bpo=13227)).
