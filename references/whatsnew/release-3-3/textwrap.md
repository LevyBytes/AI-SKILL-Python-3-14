# What's New In Python 3.3 / textwrap - textwrap

### textwrap

A new [`indent()`](https://docs.python.org/3.14/library/textwrap.html#textwrap.indent) in the [`textwrap`](https://docs.python.org/3.14/library/textwrap.html#module-textwrap) module makes prefixing chosen lines within a text block easy ([bpo-13857](https://bugs.python.org/issue?@action=redirect&bpo=13857)).
