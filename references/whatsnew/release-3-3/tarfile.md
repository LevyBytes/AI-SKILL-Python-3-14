# What's New In Python 3.3 / tarfile - lzma, tarfile

### tarfile

Via the [`lzma`](https://docs.python.org/3.14/library/lzma.html#module-lzma) module, [`tarfile`](https://docs.python.org/3.14/library/tarfile.html#module-tarfile) can now do `lzma` encoding. Lars Gustäbel contributed this ? see [bpo-5689](https://bugs.python.org/issue?@action=redirect&bpo=5689).
