# What's New In Python 3.3 / array - array

### array

Through the `q` and `Q` type codes, the [`array`](https://docs.python.org/3.14/library/array.html#module-array) module now backs the long long type.

(Oren Tirosh along with Hirokazu Yamamoto contributed this in [bpo-1172711](https://bugs.python.org/issue?@action=redirect&bpo=1172711).)
