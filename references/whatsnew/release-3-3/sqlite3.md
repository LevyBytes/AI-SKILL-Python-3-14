# What's New In Python 3.3 / sqlite3 - sqlite3

### sqlite3

A fresh [`sqlite3.Connection`](https://docs.python.org/3.14/library/sqlite3.html#sqlite3.Connection) method, [`set_trace_callback()`](https://docs.python.org/3.14/library/sqlite3.html#sqlite3.Connection.set_trace_callback), records a trace of every sql statement that sqlite handles. Torsten Landschoff supplied this addition ? see [bpo-11688](https://bugs.python.org/issue?@action=redirect&bpo=11688).
