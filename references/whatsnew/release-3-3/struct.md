# What's New In Python 3.3 / struct — struct

### struct

Two fresh codes, `n` and `N`, let the [`struct`](https://docs.python.org/3.14/library/struct.html#module-struct) module work with `ssize_t` and `size_t` respectively. Antoine Pitrou added this; refer to [bpo-3163](https://bugs.python.org/issue?@action=redirect&bpo=3163).
