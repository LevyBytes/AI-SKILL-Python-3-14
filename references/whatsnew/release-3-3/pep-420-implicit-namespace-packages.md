# What's New In Python 3.3 / PEP 420: Implicit Namespace Packages

### PEP 420: Implicit Namespace Packages

Built-in handling for package directories that need no `__init__.py` marker files and may stretch across several path segments on their own (drawing on assorted third party takes on namespace packages, as laid out in [**PEP 420**](https://peps.python.org/pep-0420/))
