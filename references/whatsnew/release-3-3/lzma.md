# What's New In Python 3.3 / lzma - lzma

### lzma

Compression and decompression of data via the LZMA algorithm — covering the `.xz` and `.lzma` file formats — is what the just-added [`lzma`](https://docs.python.org/3.14/library/lzma.html#module-lzma) module delivers.

(Nadeem Vawda together with Per Øyvind Karlsen contributed this in [bpo-6715](https://bugs.python.org/issue?@action=redirect&bpo=6715).)
