# What's New In Python 3.3 / binascii

### binascii

Beyond the binary objects they ordinarily handle, the `a2b_` functions now every one of them additionally take ASCII-only strings as their input. (Contributed by Antoine Pitrou in [bpo-13637](https://bugs.python.org/issue?@action=redirect&bpo=13637).)
