# What's New In Python 3.3 / webbrowser — webbrowser

### webbrowser

A wider set of ?browsers? is recognized by the [`webbrowser`](https://docs.python.org/3.14/library/webbrowser.html#module-webbrowser) module: Google Chrome (called **chrome**, **chromium**, **chrome-browser** or **chromium-browser**, varying with the release and the OS), together with the general-purpose launchers **xdg-open** (from the FreeDesktop.org project) and **gvfs-open** (GNOME 3's default URI handler). Arnaud Calmettes contributed the former in [bpo-13620](https://bugs.python.org/issue?@action=redirect&bpo=13620), while Matthias Klose added the latter in [bpo-14493](https://bugs.python.org/issue?@action=redirect&bpo=14493).
