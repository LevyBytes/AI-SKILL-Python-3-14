# What's New In Python 3.3 / select — select

### select

On Solaris and platforms derived from it there is a new [`select.devpoll`](https://docs.python.org/3.14/library/select.html#select.devpoll) class delivering high-performance asynchronous sockets by way of `/dev/poll`. (Contributed by Jesús Cea Avión in [bpo-6397](https://bugs.python.org/issue?@action=redirect&bpo=6397).)
