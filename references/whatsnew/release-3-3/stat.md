# What's New In Python 3.3 / stat — stat

### stat

What was the undocumented tarfile.filemode function now lives at [`stat.filemode()`](https://docs.python.org/3.14/library/stat.html#stat.filemode). Feed it a file's mode and it returns a string shaped like ?-rwxrwxrwx?.
