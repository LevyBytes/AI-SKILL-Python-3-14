### ttk: Themed Widgets for Tk

A collection of themed widgets ships with Tcl/Tk 8.5; these re-create the basic Tk widgets while offering an appearance that is easier to customize, letting them match the host platform’s native widgets far more closely. Initially this widget collection went by the name Tile, but once it joined Tcl/Tck release 8.5 it was renamed to Ttk (short for “themed Tk”).

For further information, see the [`ttk`](https://docs.python.org/3.14/library/tkinter.ttk.html#module-tkinter.ttk) module documentation. It may also be worthwhile to look over the Tcl/Tk manual page covering the Ttk theme engine, found at [https://www.tcl.tk/man/tcl8.5/TkCmd/ttk_intro.html](https://www.tcl.tk/man/tcl8.5/TkCmd/ttk_intro.html). A handful of screenshots showing the Python/Ttk code at work can be seen at [https://code.google.com/archive/p/python-ttk/wikis/Screenshots.wiki](https://code.google.com/archive/p/python-ttk/wikis/Screenshots.wiki).

Guilherme Polo authored the [`tkinter.ttk`](https://docs.python.org/3.14/library/tkinter.ttk.html#module-tkinter.ttk) module, which landed in [bpo-2983](https://bugs.python.org/issue?@action=redirect&bpo=2983). A competing variant named `Tile.py`, authored by Martin Franklin and kept up by Kevin Walzer, was put forward for inclusion under [bpo-2618](https://bugs.python.org/issue?@action=redirect&bpo=2618), yet the authors made the case that Guilherme Polo’s implementation covered more ground.
