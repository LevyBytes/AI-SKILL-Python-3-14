# What’s New in Python 2.7 / New and Improved Modules - __main__, os, os.path, pydoc, re, runpy, shutil, signal, site, socket, socketserver, sqlite3, ssl, struct, subprocess

Functions that are new: the [`os`](https://docs.python.org/3.14/library/os.html#module-os) module now wraps these POSIX system calls: [`getresgid()`](https://docs.python.org/3.14/library/os.html#os.getresgid) along with [`getresuid()`](https://docs.python.org/3.14/library/os.html#os.getresuid), reporting the real, effective, and saved GIDs and UIDs; [`setresgid()`](https://docs.python.org/3.14/library/os.html#os.setresgid) plus [`setresuid()`](https://docs.python.org/3.14/library/os.html#os.setresuid), which assign fresh values to the real, effective, and saved GIDs and UIDs; and [`initgroups()`](https://docs.python.org/3.14/library/os.html#os.initgroups), which sets up the group access list for the running process. (The GID/UID helpers came from Travis H.; [bpo-6508](https://bugs.python.org/issue?@action=redirect&bpo=6508). initgroups support was added by Jean-Paul Calderone; [bpo-7333](https://bugs.python.org/issue?@action=redirect&bpo=7333).)

The [`os.fork()`](https://docs.python.org/3.14/library/os.html#os.fork) function will now reset the import lock inside the child process; doing so resolves trouble seen on Solaris whenever `fork()` is invoked from a thread. (Fixed by Zsolt Cserna; [bpo-7242](https://bugs.python.org/issue?@action=redirect&bpo=7242).)

- Within the [`os.path`](https://docs.python.org/3.14/library/os.path.html#module-os.path) module, both the [`normpath()`](https://docs.python.org/3.14/library/os.path.html#os.path.normpath) and [`abspath()`](https://docs.python.org/3.14/library/os.path.html#os.path.abspath) functions now keep Unicode intact; when the supplied path is a Unicode string, what comes back is a Unicode string as well. ([`normpath()`](https://docs.python.org/3.14/library/os.path.html#os.path.normpath) fixed by Matt Giuca in [bpo-5827](https://bugs.python.org/issue?@action=redirect&bpo=5827); [`abspath()`](https://docs.python.org/3.14/library/os.path.html#os.path.abspath) fixed by Ezio Melotti in [bpo-3426](https://bugs.python.org/issue?@action=redirect&bpo=3426).)

- The [`pydoc`](https://docs.python.org/3.14/library/pydoc.html#module-pydoc) module now offers help on the assorted symbols that Python relies on. As an example, you can now run `help('<<')` or `help('@')`. (Contributed by David Laban; [bpo-4739](https://bugs.python.org/issue?@action=redirect&bpo=4739).)

- Within the [`re`](https://docs.python.org/3.14/library/re.html#module-re) module, [`split()`](https://docs.python.org/3.14/library/re.html#re.split), [`sub()`](https://docs.python.org/3.14/library/re.html#re.sub), and [`subn()`](https://docs.python.org/3.14/library/re.html#re.subn) now take an optional *flags* argument, bringing them in line with the module's other functions. (Added by Gregory P. Smith.)

- New function: [`run_path()`](https://docs.python.org/3.14/library/runpy.html#runpy.run_path), found in the [`runpy`](https://docs.python.org/3.14/library/runpy.html#module-runpy) module, runs whatever code sits at a supplied *path* argument. The accepted targets for *path* are a Python source file (`example.py`), then a compiled bytecode file (`example.pyc`), as well as a directory (`./package/`), and finally a zip archive (`example.zip`). Should a directory or zip path be given, it gets prepended to `sys.path` and the [`__main__`](https://docs.python.org/3.14/library/__main__.html#module-__main__) module is then imported. The directory or zip is expected to hold a `__main__.py`; when it lacks one, a different `__main__.py` could be imported from somewhere further along in `sys.path`. By doing this, more of the inner workings of `runpy` become reachable for scripts wishing to imitate how Python's command line handles an explicit path name. (Added by Nick Coghlan; [bpo-6816](https://bugs.python.org/issue?@action=redirect&bpo=6816).)

- New function: inside the [`shutil`](https://docs.python.org/3.14/library/shutil.html#module-shutil) module, [`make_archive()`](https://docs.python.org/3.14/library/shutil.html#shutil.make_archive) accepts a filename, an archive type (zip or tar-format), and a directory path, then builds an archive holding that directory's contents. (Added by Tarek Ziad??.)

The [`copyfile()`](https://docs.python.org/3.14/library/shutil.html#shutil.copyfile) and [`copytree()`](https://docs.python.org/3.14/library/shutil.html#shutil.copytree) functions belonging to [`shutil`](https://docs.python.org/3.14/library/shutil.html#module-shutil) now raise a [`SpecialFileError`](https://docs.python.org/3.14/library/shutil.html#shutil.SpecialFileError) exception if they are asked to copy a named pipe. Formerly the code handled named pipes as though they were ordinary files, opening them to read, and that would hang forever. (Fixed by Antoine Pitrou; [bpo-3002](https://bugs.python.org/issue?@action=redirect&bpo=3002).)

- The [`signal`](https://docs.python.org/3.14/library/signal.html#module-signal) module no longer reinstalls the signal handler except where doing so is genuinely required, correcting a defect that could make it impossible to reliably trap the EINTR signal. (Fixed by Charles-Francois Natali; [bpo-8354](https://bugs.python.org/issue?@action=redirect&bpo=8354).)

- New functions: the [`site`](https://docs.python.org/3.14/library/site.html#module-site) module gained three functions that hand back various site- and user-specific paths. [`getsitepackages()`](https://docs.python.org/3.14/library/site.html#site.getsitepackages) yields a list of every global site-packages directory, [`getusersitepackages()`](https://docs.python.org/3.14/library/site.html#site.getusersitepackages) yields the path to the user's site-packages directory, and [`getuserbase()`](https://docs.python.org/3.14/library/site.html#site.getuserbase) yields whatever the [`USER_BASE`](https://docs.python.org/3.14/library/site.html#site.USER_BASE) environment variable holds, pointing at a directory usable for storing data. (Contributed by Tarek Ziad??; [bpo-6693](https://bugs.python.org/issue?@action=redirect&bpo=6693).)

The [`site`](https://docs.python.org/3.14/library/site.html#module-site) module now surfaces any exceptions thrown while the [`sitecustomize`](https://docs.python.org/3.14/library/site.html#module-sitecustomize) module is being imported, and it will stop catching and discarding the [`KeyboardInterrupt`](https://docs.python.org/3.14/library/exceptions.html#KeyboardInterrupt) exception. (Fixed by Victor Stinner; [bpo-3137](https://bugs.python.org/issue?@action=redirect&bpo=3137).)

- The [`create_connection()`](https://docs.python.org/3.14/library/socket.html#socket.create_connection) function picked up a *source_address* parameter, a `(host, port)` 2-tuple supplying the source address to be applied to the connection. (Contributed by Eldon Ziegler; [bpo-3972](https://bugs.python.org/issue?@action=redirect&bpo=3972).)

The [`recv_into()`](https://docs.python.org/3.14/library/socket.html#socket.socket.recv_into) and [`recvfrom_into()`](https://docs.python.org/3.14/library/socket.html#socket.socket.recvfrom_into) methods now write straight into objects offering the buffer API, the most useful being [`bytearray`](https://docs.python.org/3.14/library/stdtypes.html#bytearray) and [`memoryview`](https://docs.python.org/3.14/library/stdtypes.html#memoryview) objects. (Implemented by Antoine Pitrou; [bpo-8104](https://bugs.python.org/issue?@action=redirect&bpo=8104).)

- The [`TCPServer`](https://docs.python.org/3.14/library/socketserver.html#socketserver.TCPServer) class in the [`SocketServer`](https://docs.python.org/3.14/library/socketserver.html#module-socketserver) module now handles socket timeouts and lets you switch off the Nagle algorithm. Its `disable_nagle_algorithm` class attribute is `False` by default; when you set it to true, freshly arriving request connections get the TCP_NODELAY option, stopping many small sends from being buffered together into one TCP packet. The [`timeout`](https://docs.python.org/3.14/library/socketserver.html#socketserver.BaseServer.timeout) class attribute may carry a timeout, in seconds, that applies to the request socket; should no request arrive within that span, [`handle_timeout()`](https://docs.python.org/3.14/library/socketserver.html#socketserver.BaseServer.handle_timeout) runs and [`handle_request()`](https://docs.python.org/3.14/library/socketserver.html#socketserver.BaseServer.handle_request) returns. (Contributed by Kristján Valur Jánsson; [bpo-6192](https://bugs.python.org/issue?@action=redirect&bpo=6192) and [bpo-6267](https://bugs.python.org/issue?@action=redirect&bpo=6267).)

- Updated module: the [`sqlite3`](https://docs.python.org/3.14/library/sqlite3.html#module-sqlite3) module was bumped to version 2.6.0 of the [pysqlite package](https://github.com/ghaering/pysqlite). That 2.6.0 release carries several bugfixes and brings the capability to load SQLite extensions out of shared libraries. Invoke the `enable_load_extension(True)` method to turn extensions on, then call [`load_extension()`](https://docs.python.org/3.14/library/sqlite3.html#sqlite3.Connection.load_extension) to bring in a specific shared library. (Updated by Gerhard Häring.)

- The [`SSLSocket`](https://docs.python.org/3.14/library/ssl.html#ssl.SSLSocket) objects in the [`ssl`](https://docs.python.org/3.14/library/ssl.html#module-ssl) module now honor the buffer API, which cleared up a test suite failure (fix by Antoine Pitrou; [bpo-7133](https://bugs.python.org/issue?@action=redirect&bpo=7133)) and turn on OpenSSL's `SSL_MODE_AUTO_RETRY` automatically, heading off an error code coming back from `recv()` operations that set off an SSL renegotiation (fix by Antoine Pitrou; [bpo-8222](https://bugs.python.org/issue?@action=redirect&bpo=8222)).

The [`wrap_socket()`](https://docs.python.org/3.14/library/ssl.html#ssl.SSLContext.wrap_socket) constructor function now accepts a *ciphers* argument, a string that lists which encryption algorithms may be used; that string's format is laid out [in the OpenSSL documentation](https://docs.openssl.org/1.0.2/man1/ciphers/). (Added by Antoine Pitrou; [bpo-8322](https://bugs.python.org/issue?@action=redirect&bpo=8322).)

A further change has the extension pull in every one of OpenSSL's ciphers and digest algorithms so all of them become available. Certain SSL certificates had been failing verification, throwing an "unknown algorithm" error instead. (The report came from Beda Kosata; the fix came from Antoine Pitrou; [bpo-8484](https://bugs.python.org/issue?@action=redirect&bpo=8484).)

Which version of OpenSSL is in use can now be read from these module attributes: [`ssl.OPENSSL_VERSION`](https://docs.python.org/3.14/library/ssl.html#ssl.OPENSSL_VERSION), holding a string; [`ssl.OPENSSL_VERSION_INFO`](https://docs.python.org/3.14/library/ssl.html#ssl.OPENSSL_VERSION_INFO), holding a 5-tuple; and [`ssl.OPENSSL_VERSION_NUMBER`](https://docs.python.org/3.14/library/ssl.html#ssl.OPENSSL_VERSION_NUMBER), holding an integer. (Added by Antoine Pitrou; [bpo-8321](https://bugs.python.org/issue?@action=redirect&bpo=8321).)

- When a value overflows a given integer format code (any of `bBhHiIlLqQ`), the [`struct`](https://docs.python.org/3.14/library/struct.html#module-struct) module will no longer quietly disregard the overflow; an exception [`struct.error`](https://docs.python.org/3.14/library/struct.html#struct.error) is now raised in every such case. (Changed by Mark Dickinson; [bpo-1523](https://bugs.python.org/issue?@action=redirect&bpo=1523).) Where a non-integer is supplied, [`pack()`](https://docs.python.org/3.14/library/struct.html#struct.pack) will now try [`__index__()`](https://docs.python.org/3.14/reference/datamodel.html#object.__index__) first to convert and pack it, falling back to the [`__int__()`](https://docs.python.org/3.14/reference/datamodel.html#object.__int__) method or else signalling an error. (Changed by Mark Dickinson; [bpo-8300](https://bugs.python.org/issue?@action=redirect&bpo=8300).)

- New function: the [`check_output()`](https://docs.python.org/3.14/library/subprocess.html#subprocess.check_output) helper in the [`subprocess`](https://docs.python.org/3.14/library/subprocess.html#module-subprocess) module executes a command together with a given set of arguments and hands back the command's output as a string if it finishes without error; otherwise it raises a [`CalledProcessError`](https://docs.python.org/3.14/library/subprocess.html#subprocess.CalledProcessError) exception.

```python
>>> subprocess.check_output(['df', '-h', '.'])
'Filesystem     Size   Used  Avail Capacity  Mounted on\n
/dev/disk0s2    52G    49G   3.0G    94%    /\n'

>>> subprocess.check_output(['df', '-h', '/bogus'])
  ...
subprocess.CalledProcessError: Command '['df', '-h', '/bogus']' returned non-zero exit status 1

```
