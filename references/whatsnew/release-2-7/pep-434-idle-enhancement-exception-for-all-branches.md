# What’s New in Python 2.7 / PEP 434: IDLE Enhancement Exception for All Branches

### PEP 434: IDLE Enhancement Exception for All Branches

[**PEP 434**](https://peps.python.org/pep-0434/) lays out a broad exemption covering changes to the IDLE development environment that ships with Python. Because of this exemption, the IDLE developers can deliver a more uniform user experience over every supported version across Python 2 and 3.

To find any IDLE changes, consult the NEWS file belonging to the specific release.
