### New Features Added to Python 2.7 Maintenance Releases

Maintenance releases of Python 2.7 may gain new features whenever the circumstances truly warrant it. Every such addition has to pass through the Python Enhancement Proposal process and present a strong argument for why it can't be sufficiently handled either by adding the new feature to Python 3, or by publishing it instead on the Python Package Index.

Beyond the particular proposals enumerated below, a blanket exemption permits fresh `-3` warnings to be introduced in any Python 2.7 maintenance release.
