# What’s New in Python 2.7 / PEP 477: Backport ensurepip (PEP 453) to Python 2.7 / Documentation Changes

#### Documentation Changes

Alongside this change, the documentation's [Installing Python modules](https://docs.python.org/3.14/installing/index.html#installing-index) and [Distributing Python Modules](https://docs.python.org/3.14/distributing/index.html#distributing-index) sections were entirely reworked into brief getting-started and FAQ pieces. The greater part of the packaging documentation has since relocated to the [Python Packaging User Guide](https://packaging.python.org) kept up by the Python Packaging Authority, plus the docs belonging to each individual project.

That said, because the migration has not yet wrapped up, the older copies of those guides stay reachable as [Building C and C++ Extensions with setuptools](https://docs.python.org/3.14/extending/building.html#install-index) and [Building C and C++ Extensions with setuptools](https://docs.python.org/3.14/extending/building.html#setuptools-index).

See also

[**PEP 453**](https://peps.python.org/pep-0453/) – Explicit bootstrapping of pip in Python installations

The PEP was authored by Donald Stufft and Nick Coghlan, with the implementation handled by Donald Stufft, Nick Coghlan, Martin von Löwis, and Ned Deily.
