# What’s New in Python 2.7 / PEP 477: Backport ensurepip (PEP 453) to Python 2.7

### PEP 477: Backport ensurepip (PEP 453) to Python 2.7

[**PEP 477**](https://peps.python.org/pep-0477/) signs off on bringing the [**PEP 453**](https://peps.python.org/pep-0453/) ensurepip module, plus the better documentation it made possible, into the Python 2.7 maintenance line, with its debut in the Python 2.7.9 release.
