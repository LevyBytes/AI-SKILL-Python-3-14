# What's New In Python 3.2 / Code Repository

### Code Repository

Alongside the Subversion code repository already hosted at [https://svn.python.org](https://svn.python.org), a [Mercurial](https://www.mercurial-scm.org/) repository now lives at [https://hg.python.org/](https://hg.python.org/).

Once 3.2 ships, the intention is to make Mercurial the main repository going forward. That distributed version control system ought to let community members build and pass around external changesets more readily. Consult [**PEP 385**](https://peps.python.org/pep-0385/) for the specifics.

For getting up to speed on the new version control system, turn to the [Quick Start](https://www.mercurial-scm.org/wiki/QuickStart) or the [Guide to Mercurial Workflows](https://www.mercurial-scm.org/guide).
