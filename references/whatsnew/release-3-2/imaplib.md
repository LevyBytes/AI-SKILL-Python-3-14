# What's New In Python 3.2 / imaplib — imaplib

### imaplib

You can now use explicit TLS over ordinary IMAP4 connections thanks to the new [`imaplib.IMAP4.starttls`](https://docs.python.org/3.14/library/imaplib.html#imaplib.IMAP4.starttls) method.

(Contributed by Lorenzo M. Catucci and Antoine Pitrou, [bpo-4471](https://bugs.python.org/issue?@action=redirect&bpo=4471).)
