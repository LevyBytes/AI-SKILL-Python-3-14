# What's New In Python 3.2 / ctypes - ctypes

### ctypes

The C `ssize_t` datatype is now mirrored by a freshly added type, [`ctypes.c_ssize_t`](https://docs.python.org/3.14/library/ctypes.html#ctypes.c_ssize_t).
