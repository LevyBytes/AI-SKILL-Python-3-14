# What's New In Python 3.2 / Unicode

### Unicode

Python now tracks [Unicode 6.0.0](https://unicode.org/versions/Unicode6.0.0/). That revision of the standard introduces more than 2,000 fresh characters, among them [emoji](https://en.wikipedia.org/wiki/Emoji) symbols that matter a great deal for mobile phones.

The revised standard additionally changed the character properties of two Kannada characters (U+0CF1, U+0CF2) plus one New Tai Lue numeric character (U+19DA), which renders the former usable within identifiers while ruling the latter out. Further detail lives at [Unicode Character Database Changes](https://www.unicode.org/versions/Unicode6.0.0/#Database_Changes).
