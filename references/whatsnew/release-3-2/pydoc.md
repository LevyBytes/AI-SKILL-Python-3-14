# What's New In Python 3.2 / pydoc - pydoc

### pydoc

A much-better web server interface now ships with the [`pydoc`](https://docs.python.org/3.14/library/pydoc.html#module-pydoc) module, along with a new command-line flag `-b` that pops open a browser window pointed at that server automatically:

```shell
$ pydoc3.2 -b

```
