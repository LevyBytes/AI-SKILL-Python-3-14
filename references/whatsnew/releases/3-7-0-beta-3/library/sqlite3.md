# Python 3.7.0 beta 3 / library / sqlite3

[bpo-27645](https://bugs.python.org/issue?@action=redirect&bpo=27645): [`sqlite3.Connection`](https://docs.python.org/3.14/library/sqlite3.html#sqlite3.Connection) now offers a [`backup`](https://docs.python.org/3.14/library/sqlite3.html#sqlite3.Connection.backup) method when the underlying SQLite library reaches version 3.6.11 or later. Patch by Lele Gaifax.
