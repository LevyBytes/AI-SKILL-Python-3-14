# Python 3.14.6 final / macos / logging

[gh-150644](https://github.com/python/cpython/issues/150644): With system logging turned on (via `config.use_system_logger`, emitted messages now carry a public tag. The result is that the macOS 26 system logger can read them without any extra setup.
