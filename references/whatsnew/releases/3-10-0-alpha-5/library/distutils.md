# Python 3.10.0 alpha 5 / library / distutils

[bpo-41282](https://bugs.python.org/issue?@action=redirect&bpo=41282): Mark `distutils` as deprecated in the docs and emit a warning the moment it is imported.

[bpo-42802](https://bugs.python.org/issue?@action=redirect&bpo=42802): The distutils `bdist_wininst` command, deprecated back in Python 3.8, has now been removed. For shipping binary packages on Windows the distutils `bdist_wheel` command is the recommended route going forward.
