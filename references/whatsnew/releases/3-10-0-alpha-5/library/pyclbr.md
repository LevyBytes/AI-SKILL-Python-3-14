# Python 3.10.0 alpha 5 / library / pyclbr

[bpo-38307](https://bugs.python.org/issue?@action=redirect&bpo=38307): Attach an 'end_lineno' attribute to the Class and Function objects found in the tree that pyclbr functions return. Together with the 'lineno' attribute already there, this marks how far class and def statements reach. Aviral Srivastava contributed the patch.
