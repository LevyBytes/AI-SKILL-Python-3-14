# Python 3.10.0 alpha 5 / library / tests and documentation

[bpo-24464](https://bugs.python.org/issue?@action=redirect&bpo=24464): The undocumented built-in `sqlite3.enable_shared_cache` function is now deprecated and slated for removal in Python 3.12. The SQLite3 documentation strongly advises against using it. Erlend E. Aasland contributed the patch.
