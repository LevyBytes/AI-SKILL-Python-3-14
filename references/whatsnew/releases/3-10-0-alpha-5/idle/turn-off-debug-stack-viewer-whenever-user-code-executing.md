# Python 3.10.0 alpha 5 / idle / turn off debug stack viewer whenever user code executing

[bpo-23544](https://bugs.python.org/issue?@action=redirect&bpo=23544): Turn off Debug=>Stack Viewer whenever user code is executing or the Debugger is active, which keeps a hang or crash from occurring. Zackery Spytz contributed the patch.
