# Python 3.14.0 alpha 3 / library / http cookies

[gh-123401](https://github.com/python/cpython/issues/123401): The [`http.cookies`](https://docs.python.org/3.14/library/http.cookies.html#module-http.cookies) module is now able to parse the legacy [**RFC 850**](https://datatracker.ietf.org/doc/html/rfc850.html) date formats, satisfying the [**RFC 9110**](https://datatracker.ietf.org/doc/html/rfc9110.html) mandate. Nano Zheng wrote the patch.
