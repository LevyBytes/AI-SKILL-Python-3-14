# Python 3.6.0 release candidate 1 / library / aid people moving up formerly documented deprecation inspect getfullargspec undone

[bpo-27172](https://bugs.python.org/issue?@action=redirect&bpo=27172): As an aid to people moving up from 2.7, the formerly documented deprecation of `inspect.getfullargspec()` has been undone. The matter may come up for review once more after official support for the Python 2.7 branch ends.
