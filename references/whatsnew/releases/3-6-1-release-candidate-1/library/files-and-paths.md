# Python 3.6.1 release candidate 1 / library / files and paths

[bpo-29623](https://bugs.python.org/issue?@action=redirect&bpo=29623): Permit a path-like object to serve as a single argument in ConfigParser.read(). David Ellis wrote the patch.

[bpo-29416](https://bugs.python.org/issue?@action=redirect&bpo=29416): Stop the infinite loop within pathlib.Path.mkdir

[bpo-29094](https://bugs.python.org/issue?@action=redirect&bpo=29094): Within a ZIP file built using an extern file object and the modes "w" and "x", offsets are now measured relative to the file's start.

[bpo-28847](https://bugs.python.org/issue?@action=redirect&bpo=28847): dbm.dumb now handles reading read-only files and no longer rewrites the index file whenever it has not changed.
