# Python 3.5.0 alpha 1 / library / numeric

[bpo-22127](https://bugs.python.org/issue?@action=redirect&bpo=22127): For host names that are pure ASCII (numeric IPs in particular), the socket module now skips IDNA.

[bpo-21723](https://bugs.python.org/issue?@action=redirect&bpo=21723): asyncio.Queue: The maximum size may now be any numeric type (for instance float). Vajrasky Kok wrote the patch.
