# Python 3.5.0 alpha 1 / library / ssl

[bpo-21965](https://bugs.python.org/issue?@action=redirect&bpo=21965): In-memory SSL support was added to the ssl module. Geert Jansen supplied the patch.

[bpo-20995](https://bugs.python.org/issue?@action=redirect&bpo=20995): Strengthened the default ciphers the ssl module uses, for stronger security and to favor perfect forward secrecy.

[bpo-20188](https://bugs.python.org/issue?@action=redirect&bpo=20188): Support Application-Layer Protocol Negotiation (ALPN) in the ssl module.

[bpo-23248](https://bugs.python.org/issue?@action=redirect&bpo=23248): Refresh the ssl error codes from the latest OpenSSL git master.
