# Python 3.5.0 alpha 1 / library / reprlib

[bpo-22824](https://bugs.python.org/issue?@action=redirect&bpo=22824): The reprlib output format for sets was updated so it uses set literals. Berker Peksag contributed the patch.

[bpo-22824](https://bugs.python.org/issue?@action=redirect&bpo=22824): The reprlib output format for arrays was updated so empty arrays render without a needless empty list. Serhiy Storchaka suggested this.
