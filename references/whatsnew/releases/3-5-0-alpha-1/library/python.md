# Python 3.5.0 alpha 1 / library / python

[bpo-18807](https://bugs.python.org/issue?@action=redirect&bpo=18807): When a venv is set to copy rather than use symlinks, the interpreter aliases (python, python3) are now produced by copying instead of symlinking.

[bpo-21711](https://bugs.python.org/issue?@action=redirect&bpo=21711): The site module has dropped its handling of ?site-python? directories (which had been deprecated back in 3.4).
