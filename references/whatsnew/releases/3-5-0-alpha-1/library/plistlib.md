# Python 3.5.0 alpha 1 / library / plistlib

[bpo-21538](https://bugs.python.org/issue?@action=redirect&bpo=21538): Loading binary plist files where the reference or offset size is not a power of two is now supported by the plistlib module.

[bpo-21888](https://bugs.python.org/issue?@action=redirect&bpo=21888): When the fmt parameter is given, the load() and loads() functions of plistlib now work.
