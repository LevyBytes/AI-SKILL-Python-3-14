# Python 3.5.0 alpha 1 / library / inspect

[bpo-21597](https://bugs.python.org/issue?@action=redirect&bpo=21597): A user can now grab the divider lying between the turtledemo text pane and its drawing canvas and drag it with the mouse. Widening the code text pane makes it simple to inspect or copy the entire text width. On small displays the canvas may also be expanded. Jan Kanis and Lita Cho contributed the initial patches.
