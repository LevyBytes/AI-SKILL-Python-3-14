# Python 3.5.0 alpha 1 / library / logging

[bpo-21149](https://bugs.python.org/issue?@action=redirect&bpo=21149): Made logging cleanup more thread-safe while the interpreter is shutting down. The patch is thanks to Devin Jeanpierre.

[bpo-20537](https://bugs.python.org/issue?@action=redirect&bpo=20537): logging methods now take an exception instance just as readily as a Boolean value or an exception tuple. Yury Selivanov provided the patch, with thanks.
