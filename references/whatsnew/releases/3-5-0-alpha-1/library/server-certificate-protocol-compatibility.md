# Python 3.5.0 alpha 1 / library / broadest compatibility ssl get server certificate relies protocol sslv23 rather than protocol sslv3

[bpo-20896](https://bugs.python.org/issue?@action=redirect&bpo=20896): For the broadest compatibility, ssl.get_server_certificate() now relies on PROTOCOL_SSLv23 rather than PROTOCOL_SSLv3.
