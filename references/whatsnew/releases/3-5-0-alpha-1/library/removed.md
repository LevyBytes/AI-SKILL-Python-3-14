# Python 3.5.0 alpha 1 / library / removed

[bpo-19414](https://bugs.python.org/issue?@action=redirect&bpo=19414): OrderedDict now flags removed links as no longer usable. That produces an immediate failure should a link be dropped mid-iteration.
