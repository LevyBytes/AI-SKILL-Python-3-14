# Python 3.5.0 alpha 1 / library / compileall

[bpo-21338](https://bugs.python.org/issue?@action=redirect&bpo=21338): compileall gained a silent mode. The quiet parameters on the compile_{dir, file, path} functions now carry a multilevel value. Likewise, the CLI's -q option now carries a multilevel value. Thomas Kluyver supplied the patch.
