# Python 3.5.0 alpha 1 / idle / dialog

[bpo-20577](https://bugs.python.org/issue?@action=redirect&bpo=20577): The FormatParagraph extension’s max line length setting has been relocated, leaving the General tab of the Idle preferences dialog and arriving on the FormatParagraph tab within the Config Extensions dialog. Tal Einat wrote the patch.

[bpo-3068](https://bugs.python.org/issue?@action=redirect&bpo=3068): Put an Idle extension configuration dialog onto the Options menu. The changes get written into HOME/.idlerc/config-extensions.cfg. Tal Einat supplied the original patch.
