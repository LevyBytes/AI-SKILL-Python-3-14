# Python 3.5.0 alpha 1 / core and builtins / numeric behavior

[bpo-22470](https://bugs.python.org/issue?@action=redirect&bpo=22470): Resolved integer overflow problems across the "backslashreplace", "xmlcharrefreplace", and "surrogatepass" error handlers.

[bpo-22519](https://bugs.python.org/issue?@action=redirect&bpo=22519): Fix overflow checking in PyBytes_Repr.

[bpo-20929](https://bugs.python.org/issue?@action=redirect&bpo=20929): Add a type cast to avoid shifting a negative number.

[bpo-19995](https://bugs.python.org/issue?@action=redirect&bpo=19995): %c, %o, %x, and %X now raise TypeError on non-integer input.
