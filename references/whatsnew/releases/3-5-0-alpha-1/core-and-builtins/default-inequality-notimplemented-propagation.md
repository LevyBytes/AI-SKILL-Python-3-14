# Python 3.5.0 alpha 1 / core and builtins / if eq handed back notimplemented default ne returns notimplemented

[bpo-21408](https://bugs.python.org/issue?@action=redirect&bpo=21408): If __eq__() handed back NotImplemented, the default __ne__() now returns NotImplemented as well. Martin Panter wrote the original patch.
