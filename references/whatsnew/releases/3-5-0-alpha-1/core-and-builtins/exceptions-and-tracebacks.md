# Python 3.5.0 alpha 1 / core and builtins / exceptions and tracebacks

[bpo-8931](https://bugs.python.org/issue?@action=redirect&bpo=8931): Have alternate formatting ("#") for type "c" throw an exception. Across versions before 3.5, "#" paired with "c" did nothing. Supplying it is now an error. Torsten Landschoff supplied the patch.
