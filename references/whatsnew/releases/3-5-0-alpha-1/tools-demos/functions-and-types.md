# Python 3.5.0 alpha 1 / tools demos / functions and types

[bpo-22615](https://bugs.python.org/issue?@action=redirect&bpo=22615): Argument Clinic now accepts the “type” argument for the int converter. That makes it possible to pair the int converter with enums and typedefs.

[bpo-21629](https://bugs.python.org/issue?@action=redirect&bpo=21629): Repair the “–converters” capability of Argument Clinic.

- Add `yield from` support to 2to3.

- Add support to 2to3 for the [**PEP 465**](https://peps.python.org/pep-0465/) matrix multiplication operator.
