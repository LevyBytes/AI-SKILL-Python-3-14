# Python 3.5.0 alpha 1 / windows / files and paths

[bpo-23260](https://bugs.python.org/issue?@action=redirect&bpo=23260): Refresh the Windows installer

- The bundled Tcl/Tk has been moved up to 8.6.3. What you will most readily notice from this change is the arrival of the new native file dialogs when running on Windows Vista or later. Consult Tcl/Tk’s TIP 432 for further detail. This Tcl/Tk build also brings Windows 10 support.
