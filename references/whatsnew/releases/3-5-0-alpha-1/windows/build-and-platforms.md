# Python 3.5.0 alpha 1 / windows / build and platforms

[bpo-17896](https://bugs.python.org/issue?@action=redirect&bpo=17896): The Windows build scripts now look for external library sources under `PCbuild\..\externals` rather than `PCbuild\..\..`.

[bpo-17717](https://bugs.python.org/issue?@action=redirect&bpo=17717): The Windows build scripts now rely on a copy of NASM fetched from svn.python.org to build OpenSSL.

[bpo-10747](https://bugs.python.org/issue?@action=redirect&bpo=10747): Use version-stamped labels within the Windows start menu. Patch by Olive Kilburn.
