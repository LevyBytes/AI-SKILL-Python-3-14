# Python 3.11.0 alpha 6 / build / functions and types

[bpo-46640](https://bugs.python.org/issue?@action=redirect&bpo=46640): Compiling Python now demands a C99 `<math.h>` header supplying a `NAN` constant, or else the `__builtin_nan()` built-in function. Victor Stinner wrote the patch.
