# Python 3.11.0 alpha 6 / library / serializing html xml etree elementtree emits embed source track wbr empty

[bpo-46786](https://bugs.python.org/issue?@action=redirect&bpo=46786): When serializing HTML, xml.etree.ElementTree now emits `embed`, `source`, `track` and `wbr` as empty tags, matching how HTML 5 specifies them.
