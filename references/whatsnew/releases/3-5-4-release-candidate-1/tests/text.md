# Python 3.5.4 release candidate 1 / tests / text

[bpo-30383](https://bugs.python.org/issue?@action=redirect&bpo=30383): regrtest: Improve regrtest, porting capabilities back off the master branch. Fresh options arrive: --coverage; --testdir; --list-tests, which prints the test files without executing any; --list-cases, which prints the test identifiers without executing them ([bpo-30523](https://bugs.python.org/issue?@action=redirect&bpo=30523)); --matchfile, which reads a set of test filters out of a plain text file ([bpo-30540](https://bugs.python.org/issue?@action=redirect&bpo=30540)); and --slowest, an alias for --slow. The reporting grew richer as well, gaining a timestamp, each test's outcome, the tests presently in flight, and a "Tests result: xxx" line carrying the overall duration, among other additions. Reference-leak hunting inside regrtest got repaired; under --huntrleaks, regrtest now primes its caches and eagerly builds every internal singleton that would otherwise come into being lazily, so false positives no longer appear while reference leaks are checked. ([bpo-30675](https://bugs.python.org/issue?@action=redirect&bpo=30675)).
