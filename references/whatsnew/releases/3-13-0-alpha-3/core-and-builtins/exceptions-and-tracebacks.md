# Python 3.13.0 alpha 3 / core and builtins / exceptions and tracebacks

[gh-112730](https://github.com/python/cpython/issues/112730): Apply color so that error locations stand out within tracebacks. Pablo Galindo wrote the patch

[gh-107901](https://github.com/python/cpython/issues/107901): A jump that exits an exception handler and returns to normal code will no longer test the eval breaker.

[gh-111488](https://github.com/python/cpython/issues/111488): Reworded the error message produced when the ‘in’ keyword is missing after ‘for’ inside list comprehensions

[gh-111375](https://github.com/python/cpython/issues/111375): Restrict `NULL` in the exception stack to signaling that an exception was handled. Carey Metcalfe supplied this patch.
