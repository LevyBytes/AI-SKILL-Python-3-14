# Python 3.13.0 alpha 3 / macos / stat

[gh-113666](https://github.com/python/cpython/issues/113666): Bring these constants into the [`stat`](https://docs.python.org/3.14/library/stat.html#module-stat) module: `UF_SETTABLE`, `UF_TRACKED`, `UF_DATAVAULT`, `SF_SUPPORTED`, `SF_SETTABLE`, `SF_SYNTHETIC`, `SF_RESTRICTED`, `SF_FIRMLINK` and `SF_DATALESS`. Among them, `UF_SETTABLE`, `SF_SUPPORTED`, `SF_SETTABLE` and `SF_SYNTHETIC` exist on macOS alone.
