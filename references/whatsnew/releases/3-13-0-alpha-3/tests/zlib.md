# Python 3.13.0 alpha 3 / tests / zlib

[gh-112769](https://github.com/python/cpython/issues/112769): zlib version comparisons in the tests are now accurate even when [`zlib.ZLIB_RUNTIME_VERSION`](https://docs.python.org/3.14/library/zlib.html#zlib.ZLIB_RUNTIME_VERSION) carries non-integer suffixes. As an illustration, zlib-ng reports its version as `1.3.0.zlib-ng`.
