# Python 3.13.0 alpha 3 / library / plistlib

[gh-113537](https://github.com/python/cpython/issues/113537): Support loading `str` through [`plistlib.loads()`](https://docs.python.org/3.14/library/plistlib.html#plistlib.loads).

[gh-53502](https://github.com/python/cpython/issues/53502): Add a fresh option `aware_datetime` within [`plistlib`](https://docs.python.org/3.14/library/plistlib.html#module-plistlib) for loading or dumping aware datetime.

[gh-111803](https://github.com/python/cpython/issues/111803): [`plistlib`](https://docs.python.org/3.14/library/plistlib.html#module-plistlib) is now able to load more deeply nested lists when reading binary format.
