# Python 3.13.0 alpha 3 / library / termios

[gh-51944](https://github.com/python/cpython/issues/51944): The constants below were added to the [`termios`](https://docs.python.org/3.14/library/termios.html#module-termios) module; macOS system headers define each of these: `ALTWERASE`, `B14400`, `B28800`, `B7200`, `B76800`, `CCAR_OFLOW`, `CCTS_OFLOW`, `CDSR_OFLOW`, `CDTR_IFLOW`, `CIGNORE`, `CRTS_IFLOW`, `EXTPROC`, `IUTF8`, `MDMBUF`, `NL2`, `NL3`, `NOKERNINFO`, `ONOEOT`, `OXTABS`, `VDSUSP`, `VSTATUS`.
