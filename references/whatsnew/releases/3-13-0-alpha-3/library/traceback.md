# Python 3.13.0 alpha 3 / library / traceback

[gh-112332](https://github.com/python/cpython/issues/112332): Mark the `exc_type` field of [`traceback.TracebackException`](https://docs.python.org/3.14/library/traceback.html#traceback.TracebackException) as deprecated. A replacement, `exc_type_str`, is added.

[gh-106922](https://github.com/python/cpython/issues/106922): Show several lines via `traceback` whenever an error stretches over multiple lines.
