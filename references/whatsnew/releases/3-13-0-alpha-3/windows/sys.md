# Python 3.13.0 alpha 3 / windows / sys

[gh-73427](https://github.com/python/cpython/issues/73427): Mark [`sys._enablelegacywindowsfsencoding()`](https://docs.python.org/3.14/library/sys.html#sys._enablelegacywindowsfsencoding) deprecated. Reach for [`PYTHONLEGACYWINDOWSFSENCODING`](https://docs.python.org/3.14/using/cmdline.html#envvar-PYTHONLEGACYWINDOWSFSENCODING) in its place. Inada Naoki supplied the patch.
