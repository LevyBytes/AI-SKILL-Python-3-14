# Python 3.13.0 alpha 1 / core and builtins / ctypes

[gh-107659](https://github.com/python/cpython/issues/107659): Docstrings were added for [`ctypes.pointer()`](https://docs.python.org/3.14/library/ctypes.html#ctypes.pointer) and [`ctypes.POINTER()`](https://docs.python.org/3.14/library/ctypes.html#ctypes.POINTER).

[gh-107455](https://github.com/python/cpython/issues/107455): Error messages were improved for the case of converting an incompatible type into [`ctypes.c_char_p`](https://docs.python.org/3.14/library/ctypes.html#ctypes.c_char_p), [`ctypes.c_wchar_p`](https://docs.python.org/3.14/library/ctypes.html#ctypes.c_wchar_p) and [`ctypes.c_void_p`](https://docs.python.org/3.14/library/ctypes.html#ctypes.c_void_p).
