# Python 3.13.0 alpha 1 / core and builtins / delete old trashcan macros py trashcan safe begin py trashcan safe end

[gh-105111](https://github.com/python/cpython/issues/105111): Delete the old trashcan macros `Py_TRASHCAN_SAFE_BEGIN` and `Py_TRASHCAN_SAFE_END`. The new macros `Py_TRASHCAN_BEGIN` and `Py_TRASHCAN_END` should stand in for them.
