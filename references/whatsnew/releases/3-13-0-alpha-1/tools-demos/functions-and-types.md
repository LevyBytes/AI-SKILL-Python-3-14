# Python 3.13.0 alpha 1 / tools demos / functions and types

[gh-107880](https://github.com/python/cpython/issues/107880): Cloning of `__init__()` and `__new__()` methods is now possible in Argument Clinic.

[gh-104683](https://github.com/python/cpython/issues/104683): The Argument Clinic CLI gains an `--exclude` option.

[gh-107467](https://github.com/python/cpython/issues/107467): On failure, the Argument Clinic command-line tool now writes to stderr rather than to stdout.

[gh-106359](https://github.com/python/cpython/issues/106359): When a function call serves as an annotation, Argument Clinic now expressly disallows ?kwarg splats? within it.
