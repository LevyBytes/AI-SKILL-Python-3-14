# Python 3.13.0 alpha 1 / security / hashlib

[gh-99108](https://github.com/python/cpython/issues/99108): Our newer HACL* built-in [`hashlib`](https://docs.python.org/3.14/library/hashlib.html#module-hashlib) code was refreshed from upstream. The built-in SHA2 ought to run faster, and a SHA3 defect on 32-bit platforms has been resolved.
