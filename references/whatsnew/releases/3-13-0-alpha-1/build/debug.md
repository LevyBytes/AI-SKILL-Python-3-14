# Python 3.13.0 alpha 1 / build / debug

[gh-108634](https://github.com/python/cpython/issues/108634): Python compiled with `configure` [`--with-trace-refs`](https://docs.python.org/3.14/using/configure.html#cmdoption-with-trace-refs) (tracing references) is henceforth ABI compatible alongside the Python release build and the [debug build](https://docs.python.org/3.14/using/configure.html#debug-build). Victor Stinner authored the patch.
