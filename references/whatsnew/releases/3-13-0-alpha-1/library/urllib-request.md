# Python 3.13.0 alpha 1 / library / urllib request

[gh-105382](https://github.com/python/cpython/issues/105382): Dropped the *cafile*, *capath* and *cadefault* parameters from the [`urllib.request.urlopen()`](https://docs.python.org/3.14/library/urllib.request.html#urllib.request.urlopen) function; these had been deprecated back in Python 3.6. Victor Stinner authored the change.
