# Python 3.13.0 alpha 1 / library / tests and documentation

[gh-104886](https://github.com/python/cpython/issues/104886): Deleted the undocumented `configparser.LegacyInterpolation` class, which the docstring had marked deprecated since Python 3.2 and which carried a deprecation warning starting in Python 3.11. Hugo van Kemenade authored the change.

[gh-104876](https://github.com/python/cpython/issues/104876): Deleted the `turtle.RawTurtle.settiltangle()` method, which the docs had listed as deprecated since Python 3.1 and which gained a deprecation warning in Python 3.11. Hugo van Kemenade authored the change.
