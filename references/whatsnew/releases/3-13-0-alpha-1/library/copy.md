# Python 3.13.0 alpha 1 / library / copy

[gh-108751](https://github.com/python/cpython/issues/108751): Introduce a [`copy.replace()`](https://docs.python.org/3.14/library/copy.html#copy.replace) function for producing a modified copy of an object. It works with named tuples, dataclasses, and a great many other objects.

[gh-110222](https://github.com/python/cpython/issues/110222): Bring struct sequence objects into the supported set for [`copy.replace()`](https://docs.python.org/3.14/library/copy.html#copy.replace). Xuehai Pan provided the patch.
