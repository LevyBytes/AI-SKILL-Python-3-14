# Python 3.13.0 alpha 1 / library / wave

[gh-105096](https://github.com/python/cpython/issues/105096): [`wave`](https://docs.python.org/3.14/library/wave.html#module-wave): Marked the `getmark()`, `setmark()` and `getmarkers()` methods on the [`wave.Wave_read`](https://docs.python.org/3.14/library/wave.html#wave.Wave_read) and [`wave.Wave_write`](https://docs.python.org/3.14/library/wave.html#wave.Wave_write) classes as deprecated. Their removal is slated for Python 3.15. Victor Stinner authored the change.
