# Python 3.13.0 alpha 1 / library / pdb

[gh-106734](https://github.com/python/cpython/issues/106734): Turn off tab completion within the multiline mode of [`pdb`](https://docs.python.org/3.14/library/pdb.html#module-pdb)

[gh-103464](https://github.com/python/cpython/issues/103464): Surfaced helpful usage messages whenever malformed [`pdb`](https://docs.python.org/3.14/library/pdb.html#module-pdb) commands get parsed.

[gh-103124](https://github.com/python/cpython/issues/103124): Brought multiline statement support to [`pdb`](https://docs.python.org/3.14/library/pdb.html#module-pdb)

[gh-109164](https://github.com/python/cpython/issues/109164): Within [`pdb`](https://docs.python.org/3.14/library/pdb.html#module-pdb): switch from [`getopt`](https://docs.python.org/3.14/library/getopt.html#module-getopt) to [`argparse`](https://docs.python.org/3.14/library/argparse.html#module-argparse) for handling command line arguments.

[gh-109375](https://github.com/python/cpython/issues/109375): The [`pdb`](https://docs.python.org/3.14/library/pdb.html#module-pdb) `alias` command now stops you from registering aliases that have no arguments.

[gh-65052](https://github.com/python/cpython/issues/65052): Stop [`pdb`](https://docs.python.org/3.14/library/pdb.html#module-pdb) from crashing while attempting to render objects that cannot be displayed

[gh-106670](https://github.com/python/cpython/issues/106670): Within [`pdb`](https://docs.python.org/3.14/library/pdb.html#module-pdb), the convenience variable `$_exception` is now set during post mortem debugging.

[gh-108463](https://github.com/python/cpython/issues/108463): Get expressions and statements to behave as one would expect inside pdb
