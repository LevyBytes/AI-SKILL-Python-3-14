# Python 3.13.0 alpha 1 / library / hashlib

[gh-99108](https://github.com/python/cpython/issues/99108): The GIL is now released around reasonably sized built-in [`hashlib`](https://docs.python.org/3.14/library/hashlib.html#module-hashlib) computations for the SHA families plus the MD5 hash functions, mirroring the behavior our OpenSSL-backed hash computations already provide.
