# Python 3.13.0 alpha 1 / library / webbrowser

[gh-104804](https://github.com/python/cpython/issues/104804): Deleted the untested and undocumented [`webbrowser`](https://docs.python.org/3.14/library/webbrowser.html#module-webbrowser) `MacOSX` class, which had been deprecated in Python 3.11. Hugo van Kemenade authored the change.
