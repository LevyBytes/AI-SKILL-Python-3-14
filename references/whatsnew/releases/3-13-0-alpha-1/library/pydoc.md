# Python 3.13.0 alpha 1 / library / pydoc

[gh-107782](https://github.com/python/cpython/issues/107782): [`pydoc`](https://docs.python.org/3.14/library/pydoc.html#module-pydoc) can now display signatures that Python itself cannot represent, such as those for `getattr` and `dict.pop`.
