# Python 3.13.0 alpha 1 / library / operator

[bpo-44850](https://bugs.python.org/issue?@action=redirect&bpo=44850): Boosted [`operator.methodcaller()`](https://docs.python.org/3.14/library/operator.html#operator.methodcaller) speed by adopting the [**PEP 590**](https://peps.python.org/pep-0590/) `vectorcall` convention. Anthony Lee and Pieter Eendebak authored the patch.
