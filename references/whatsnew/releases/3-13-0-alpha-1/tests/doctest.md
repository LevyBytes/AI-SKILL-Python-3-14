# Python 3.13.0 alpha 1 / tests / doctest

[gh-108794](https://github.com/python/cpython/issues/108794): The [`doctest.DocTestRunner.run()`](https://docs.python.org/3.14/library/doctest.html#doctest.DocTestRunner.run) method now tallies how many tests got skipped. Added the [`doctest.DocTestRunner.skips`](https://docs.python.org/3.14/library/doctest.html#doctest.DocTestRunner.skips) plus [`doctest.TestResults.skipped`](https://docs.python.org/3.14/library/doctest.html#doctest.TestResults.skipped) attributes. Victor Stinner authored the patch.
