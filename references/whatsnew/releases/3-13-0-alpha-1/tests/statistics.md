# Python 3.13.0 alpha 1 / tests / statistics

[gh-108822](https://github.com/python/cpython/issues/108822): `regrtest` now tallies statistics over every test: the successes, the failures, and the skipped. `test_netrc`, `test_pep646_syntax`, and `test_xml_etree` now hand back results from inside their `test_main()` function. Victor Stinner and Alex Waygood authored the patch.
