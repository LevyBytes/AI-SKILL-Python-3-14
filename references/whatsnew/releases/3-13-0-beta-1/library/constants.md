# Python 3.13.0 beta 1 / library / constants

[gh-102247](https://github.com/python/cpython/issues/102247): The status-code enumeration of constants in http.HTTPStatus was refreshed to carry the names from RFC9110. That RFC promotes several HTTP statuses formerly reserved for WEBDAV and gives them more general-purpose names.

The earlier constants stay in place for backward compatibility.
