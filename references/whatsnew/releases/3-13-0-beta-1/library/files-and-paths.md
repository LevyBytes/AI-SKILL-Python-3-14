# Python 3.13.0 beta 1 / library / files and paths

[gh-118271](https://github.com/python/cpython/issues/118271): Two new `PhotoImage` methods arrive: `read()` loads an image from a file, while `data()` returns the underlying image data. The `write()` method on `PhotoImage` also gained *background* and *grayscale* parameters.
