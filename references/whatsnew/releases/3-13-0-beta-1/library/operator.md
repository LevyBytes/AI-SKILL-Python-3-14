# Python 3.13.0 beta 1 / library / operator

[gh-118285](https://github.com/python/cpython/issues/118285): Custom callable instances of an extension type may now declare their signature through the `__text_signature__` attribute. Signatures were supplied for instances of [`operator.attrgetter`](https://docs.python.org/3.14/library/operator.html#operator.attrgetter), [`operator.itemgetter`](https://docs.python.org/3.14/library/operator.html#operator.itemgetter), and [`operator.methodcaller`](https://docs.python.org/3.14/library/operator.html#operator.methodcaller).
