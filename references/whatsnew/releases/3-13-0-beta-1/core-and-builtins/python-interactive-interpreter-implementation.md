# Python 3.13.0 beta 1 / core and builtins / interactive interpreter runs python opening way several fresh capabilities

[gh-111201](https://github.com/python/cpython/issues/111201): The [interactive](https://docs.python.org/3.14/glossary.html#term-interactive) interpreter now runs in Python, opening the way to several fresh capabilities such as colors, multiline input, history viewing, and paste mode. Pablo Galindo, ??ukasz Langa and Lysandros Nikolaou built this, drawing on code originating in the PyPy project.
