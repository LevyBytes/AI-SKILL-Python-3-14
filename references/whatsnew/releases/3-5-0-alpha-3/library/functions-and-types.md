# Python 3.5.0 alpha 3 / library / functions and types

[bpo-14260](https://bugs.python.org/issue?@action=redirect&bpo=14260): On a regular expression pattern object, the groupindex attribute is now a non-modifiable mapping.

[bpo-21717](https://bugs.python.org/issue?@action=redirect&bpo=21717): The "x" (exclusive creation) mode is now supported by the zipfile.ZipFile.open function.

[bpo-23704](https://bugs.python.org/issue?@action=redirect&bpo=23704): collections.deque() objects now provide methods for index(), insert(), and copy(). That lets deques register as a MutableSequence and sharpens how well they stand in for lists.

[bpo-2052](https://bugs.python.org/issue?@action=redirect&bpo=2052): Add a charset parameter onto HtmlDiff.make_file().
