# Python 3.5.0 alpha 3 / library / zipapp

[bpo-23491](https://bugs.python.org/issue?@action=redirect&bpo=23491): A zipapp module was added to help build executable zip file archives holding Python code. The ".pyz" and ".pyzw" extensions were registered on Windows for such archives (PEP 441).

[bpo-23657](https://bugs.python.org/issue?@action=redirect&bpo=23657): Drop the explicit str checks inside zipapp, gaining support for pathlib.Path objects passed as arguments.
