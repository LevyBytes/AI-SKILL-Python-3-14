# Python 3.5.0 alpha 3 / library / imports and modules

[bpo-4727](https://bugs.python.org/issue?@action=redirect&bpo=4727): The copy module now relies on pickle protocol 4 (PEP 3154) and can copy instances of classes whose __new__ method accepts keyword-only arguments.

[bpo-22903](https://bugs.python.org/issue?@action=redirect&bpo=22903): The placeholder test case that unittest.loader builds upon failing to import a test module is now picklable.
