# Python 3.5.0 alpha 3 / library / pprint

[bpo-23775](https://bugs.python.org/issue?@action=redirect&bpo=23775): pprint() applied to an OrderedDict now emits the identical representation that repr() does.

[bpo-23502](https://bugs.python.org/issue?@action=redirect&bpo=23502): Mapping proxies are now supported by the pprint module.
