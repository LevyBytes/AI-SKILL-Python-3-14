# Python 3.14.0 alpha 2 / library / getopt

[gh-126390](https://github.com/python/cpython/issues/126390): [`getopt.gnu_getopt()`](https://docs.python.org/3.14/library/getopt.html#getopt.gnu_getopt) can now return options together with non-option arguments interleaved, preserving their original order.

[gh-126374](https://github.com/python/cpython/issues/126374): The [`getopt`](https://docs.python.org/3.14/library/getopt.html#module-getopt) module now handles options whose arguments are optional.
