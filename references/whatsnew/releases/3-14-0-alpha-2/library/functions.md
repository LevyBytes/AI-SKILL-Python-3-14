# Python 3.14.0 alpha 2 / library / functions

[gh-125767](https://github.com/python/cpython/issues/125767): [`super`](https://docs.python.org/3.14/library/functions.html#super) objects can now be [`pickleable`](https://docs.python.org/3.14/library/pickle.html#module-pickle) plus [`copyable`](https://docs.python.org/3.14/library/copy.html#module-copy).

[gh-125063](https://github.com/python/cpython/issues/125063): [`slice`](https://docs.python.org/3.14/library/functions.html#slice) objects are now handled by [`marshal`](https://docs.python.org/3.14/library/marshal.html#module-marshal). Version 5 is the new marshal format level.
