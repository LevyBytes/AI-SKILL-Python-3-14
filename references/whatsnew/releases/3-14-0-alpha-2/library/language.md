# Python 3.14.0 alpha 2 / library / language

[gh-124111](https://github.com/python/cpython/issues/124111): The tkinter module may now be compiled against either the fresh release 9.0.0 of Tcl/Tk or the most recent 8.6.15 build of Tcl/Tk 8. Tcl/Tk 9 brings plenty of upgrades, both within the Tcl language itself and across the look and usefulness of the graphical user interface that Tk supplies.
