# Python 3.14.0 alpha 2 / library / functions and types

[gh-99749](https://github.com/python/cpython/issues/99749): Introduces an opt-in capability that offers suggestions for argument choices together with subparser names should the user mistype them.

[gh-84852](https://github.com/python/cpython/issues/84852): Register MIME types covering MS Embedded OpenType, OpenType Layout, TrueType, plus WOFF 1.0 and 2.0 fonts. Sahil Prajapati and Hugo van Kemenade wrote the patch.

[gh-113570](https://github.com/python/cpython/issues/113570): Corrected a defect in `reprlib.repr` where it mistakenly invoked the repr method belonging to shadowed Python built-in types.

[gh-89416](https://github.com/python/cpython/issues/89416): Register the [**RFC 9559**](https://datatracker.ietf.org/doc/html/rfc9559.html) MIME types covering the Matroska audiovisual container formats. Hugo van Kemenade wrote the patch.

[gh-85957](https://github.com/python/cpython/issues/85957): Supply the MIME types that were missing for images carrying RFCs: emf, fits, g3fax, jp2, jpm, jpx, t38, tiff-fx and wmf. Hugo van Kemenade wrote the patch.
