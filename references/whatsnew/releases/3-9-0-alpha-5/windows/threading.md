# Python 3.9.0 alpha 5 / windows / threading

[bpo-39847](https://bugs.python.org/issue?@action=redirect&bpo=39847): Prevent a hang that could occur when the machine hibernates while a mutex is being awaited (for lock-related objects from [`threading`](https://docs.python.org/3.14/library/threading.html#module-threading)) near 49-day uptime.
