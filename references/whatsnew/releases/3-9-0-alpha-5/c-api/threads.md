# Python 3.9.0 alpha 5 / c api / threads

[bpo-39947](https://bugs.python.org/issue?@action=redirect&bpo=39947): Provide the [`PyThreadState_GetFrame()`](https://docs.python.org/3.14/c-api/threads.html#c.PyThreadState_GetFrame) function, which retrieves the current frame belonging to a Python thread state.

[bpo-39947](https://bugs.python.org/issue?@action=redirect&bpo=39947): Provide [`PyThreadState_GetInterpreter()`](https://docs.python.org/3.14/c-api/threads.html#c.PyThreadState_GetInterpreter), which retrieves the interpreter belonging to a Python thread state.
