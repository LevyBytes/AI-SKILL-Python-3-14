# Python 3.9.0 alpha 5 / library / importlib

[bpo-38691](https://bugs.python.org/issue?@action=redirect&bpo=38691): Whenever the [`-E`](https://docs.python.org/3.14/using/cmdline.html#cmdoption-E) or [`-I`](https://docs.python.org/3.14/using/cmdline.html#cmdoption-I) command line options are active, the [`importlib`](https://docs.python.org/3.14/library/importlib.html#module-importlib) module now disregards the [`PYTHONCASEOK`](https://docs.python.org/3.14/using/cmdline.html#envvar-PYTHONCASEOK) environment variable.
