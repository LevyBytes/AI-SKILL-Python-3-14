# Python 3.9.0 alpha 5 / library / http

[bpo-39509](https://bugs.python.org/issue?@action=redirect&bpo=39509): The HTTP status codes `103 EARLY_HINTS` and `425 TOO_EARLY` are now part of [`http.HTTPStatus`](https://docs.python.org/3.14/library/http.html#http.HTTPStatus). Donghee Na supplied the patch.

[bpo-39507](https://bugs.python.org/issue?@action=redirect&bpo=39507): The http library's HTTPStatus gained HTTP status 418 "I'm a Teapot". Ross Rhodes supplied the patch.
