# Python 3.9.0 alpha 5 / library / xml

[bpo-37534](https://bugs.python.org/issue?@action=redirect&bpo=37534): The minidom module, when producing XML documents, can now insert a Standalone Document Declaration. Every one of these changes serves to emit a document that conforms to the Extensible Markup Language (XML) 1.0 (Fifth Edition) W3C Recommendation (available here: [https://www.w3.org/TR/xml/#sec-prolog-dtd](https://www.w3.org/TR/xml/#sec-prolog-dtd)).
