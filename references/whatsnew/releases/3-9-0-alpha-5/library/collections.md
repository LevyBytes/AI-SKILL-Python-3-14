# Python 3.9.0 alpha 5 / library / collections

[bpo-36144](https://bugs.python.org/issue?@action=redirect&bpo=36144): The `|` operator is now supported by [`collections.defaultdict`](https://docs.python.org/3.14/library/collections.html#collections.defaultdict) ([**PEP 584**](https://peps.python.org/pep-0584/)).

[bpo-36144](https://bugs.python.org/issue?@action=redirect&bpo=36144): The `|` and `|=` operators are now provided by [`collections.OrderedDict`](https://docs.python.org/3.14/library/collections.html#collections.OrderedDict) ([**PEP 584**](https://peps.python.org/pep-0584/)).
