# Python 3.9.0 alpha 5 / library / compiler and parser

[bpo-39638](https://bugs.python.org/issue?@action=redirect&bpo=39638): Preserve the ASDL signatures within the docstrings of `AST` nodes. Batuhan Taskaya wrote this.

[bpo-39639](https://bugs.python.org/issue?@action=redirect&bpo=39639): The `ast.Suite` node class, now unused, has been deprecated. Batuhan Taskaya supplied the patch.

[bpo-40000](https://bugs.python.org/issue?@action=redirect&bpo=40000): Validation of `ast.Constant` nodes now produces clearer error messages. Batuhan Taskaya supplied the patch.

[bpo-39988](https://bugs.python.org/issue?@action=redirect&bpo=39988): Since they have fallen out of use, the `ast.AugLoad` and `ast.AugStore` node classes are now deprecated.

[bpo-39969](https://bugs.python.org/issue?@action=redirect&bpo=39969): The `ast.Param` node class, now unused, has been deprecated. Batuhan Taskaya supplied the patch.
