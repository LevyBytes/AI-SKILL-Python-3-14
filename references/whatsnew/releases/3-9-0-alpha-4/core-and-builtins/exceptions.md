# Python 3.9.0 alpha 4 / core and builtins / exceptions

[bpo-39434](https://bugs.python.org/issue?@action=redirect&bpo=39434): The [floor division](https://docs.python.org/3.14/glossary.html#term-floor-division) of float operation now runs faster. The accompanying [`ZeroDivisionError`](https://docs.python.org/3.14/library/exceptions.html#ZeroDivisionError) message for that operation has also been revised. Donghee Na wrote the patch.
