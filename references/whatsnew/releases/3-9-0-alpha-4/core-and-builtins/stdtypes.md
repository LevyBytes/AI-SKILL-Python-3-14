# Python 3.9.0 alpha 4 / core and builtins / stdtypes

[bpo-36144](https://bugs.python.org/issue?@action=redirect&bpo=36144): [`dict`](https://docs.python.org/3.14/library/stdtypes.html#dict) (along with [`collections.UserDict`](https://docs.python.org/3.14/library/collections.html#collections.UserDict)) objects now accept PEP 584's merge (`|`) plus update (`|=`) operators. Brandt Bucher provided the patch.
