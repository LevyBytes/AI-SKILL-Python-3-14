# Python 3.9.0 alpha 4 / c api / functions and types

[bpo-39245](https://bugs.python.org/issue?@action=redirect&bpo=39245): The Vectorcall API (PEP 590) became public, which added the functions `PyObject_Vectorcall`, `PyObject_VectorcallMethod`, `PyVectorcall_Function`, `PyObject_CallOneArg`, `PyObject_CallMethodNoArgs`, `PyObject_CallMethodOneArg`, `PyObject_FastCallDict`, and the flag `Py_TPFLAGS_HAVE_VECTORCALL`.
