# Python 3.9.0 alpha 4 / library / sys

[bpo-38149](https://bugs.python.org/issue?@action=redirect&bpo=38149): [`sys.audit()`](https://docs.python.org/3.14/library/sys.html#sys.audit) now fires just a single time for each invocation of [`glob.glob()`](https://docs.python.org/3.14/library/glob.html#glob.glob) and [`glob.iglob()`](https://docs.python.org/3.14/library/glob.html#glob.iglob).
