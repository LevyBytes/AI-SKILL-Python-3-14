# Python 3.9.0 alpha 4 / library / distutils

[bpo-39586](https://bugs.python.org/issue?@action=redirect&bpo=39586): The distutils `bdist_msi` command becomes deprecated in Python 3.9; reach for `bdist_wheel` (wheel packages) in its place.

[bpo-39432](https://bugs.python.org/issue?@action=redirect&bpo=39432): Apply the PEP-489 algorithm to non-ascii `PyInit_…` symbol names within distutils so the right init symbol is exported on Windows as well.
