# Python 3.10.0 alpha 2 / core and builtins / legacy aix only mechanism loading shared libraries taken out

[bpo-42030](https://bugs.python.org/issue?@action=redirect&bpo=42030): The legacy AIX-only mechanism for loading shared libraries has been taken out. Every AIX release from 4.3 onward has supported, and defaulted to, the standard Unix approach instead.
