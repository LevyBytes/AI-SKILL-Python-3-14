# Python 3.10.0 alpha 2 / library / unicodedata

[bpo-42157](https://bugs.python.org/issue?@action=redirect&bpo=42157): Move the [`unicodedata`](https://docs.python.org/3.14/library/unicodedata.html#module-unicodedata) extension module over to the multiphase initialization API ([**PEP 489**](https://peps.python.org/pep-0489/)) and turn the `unicodedata.UCD` static type into a heap type. Mohamed Koubaa and Victor Stinner supplied the patch.
