# Python 3.10.0 alpha 2 / library / dataclasses

[bpo-41747](https://bugs.python.org/issue?@action=redirect&bpo=41747): Guarantee that every method generated from [`dataclasses.dataclass()`](https://docs.python.org/3.14/library/dataclasses.html#dataclasses.dataclass) objects now carries the right `__qualname__` attribute pointing to its owning class. Batuhan Taskaya supplied the patch.
