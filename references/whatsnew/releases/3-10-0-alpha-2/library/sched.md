# Python 3.10.0 alpha 2 / library / sched

[bpo-19270](https://bugs.python.org/issue?@action=redirect&bpo=19270): [`sched.scheduler.cancel()`](https://docs.python.org/3.14/library/sched.html#sched.scheduler.cancel) henceforth cancels the right event whenever two events sharing a priority are queued for the same moment. Bar Harel supplied the patch.
