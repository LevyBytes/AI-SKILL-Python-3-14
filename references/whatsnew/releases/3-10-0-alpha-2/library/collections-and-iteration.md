# Python 3.10.0 alpha 2 / library / collections and iteration

[bpo-41229](https://bugs.python.org/issue?@action=redirect&bpo=41229): Introduces `contextlib.aclosing`, the async-generator counterpart of `contextlib.closing`, giving reliable teardown for asynchronous generators much as the synchronous helper does for ordinary ones. Joongi Kim and John Belmonte supplied the patch.
