# Python 3.10.0 alpha 2 / library / shelve

[bpo-34204](https://bugs.python.org/issue?@action=redirect&bpo=34204): By default the [`shelve`](https://docs.python.org/3.14/library/shelve.html#module-shelve) module now relies on [`pickle.DEFAULT_PROTOCOL`](https://docs.python.org/3.14/library/pickle.html#pickle.DEFAULT_PROTOCOL) rather than the older [`pickle`](https://docs.python.org/3.14/library/pickle.html#module-pickle) protocol `3`.
