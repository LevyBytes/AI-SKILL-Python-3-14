# Python 3.10.0 alpha 2 / library / functions

[bpo-42233](https://bugs.python.org/issue?@action=redirect&bpo=42233): Formerly the [`repr()`](https://docs.python.org/3.14/library/functions.html#repr) for [`typing`](https://docs.python.org/3.14/library/typing.html#module-typing) types holding [Generic Alias Types](https://docs.python.org/3.14/library/stdtypes.html#types-genericalias) omitted the parameterized types from the `GenericAlias`. That behavior has been altered so they now appear.
