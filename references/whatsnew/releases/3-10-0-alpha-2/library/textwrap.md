# Python 3.10.0 alpha 2 / library / textwrap

[bpo-28660](https://bugs.python.org/issue?@action=redirect&bpo=28660): [`textwrap.wrap()`](https://docs.python.org/3.14/library/textwrap.html#textwrap.wrap) will now try to split lengthy words following hyphens whenever `break_long_words=True` and `break_on_hyphens=True`.
