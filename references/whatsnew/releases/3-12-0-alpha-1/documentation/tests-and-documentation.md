# Python 3.12.0 alpha 1 / documentation / tests and documentation

[bpo-43689](https://bugs.python.org/issue?@action=redirect&bpo=43689): The `Differ` documentation now additionally calls out other whitespace characters that complicate reading the diff output.

[bpo-13553](https://bugs.python.org/issue?@action=redirect&bpo=13553): Provide documentation for tkinter.Tk args.

[gh-96432](https://github.com/python/cpython/issues/96432): Whitespace surrounding the forward slash is now accepted in Fraction literals, for example `Fraction('2 / 3')`.

[gh-95454](https://github.com/python/cpython/issues/95454): Corrected true/false values that were written incorrectly throughout the documentation. Robert O'Shea wrote the patch.

[gh-86986](https://github.com/python/cpython/issues/86986): Building the documentation now needs a minimum Sphinx version of 3.2.

[gh-88831](https://github.com/python/cpython/issues/88831): Expanded the documentation for asyncio.create_task(). It now explains why strong references to tasks must be kept and includes a code snippet showing one way to do so.
