# Python 3.12.0 alpha 1 / library / configparser

[gh-89336](https://github.com/python/cpython/issues/89336): Deleted several [`configparser`](https://docs.python.org/3.14/library/configparser.html#module-configparser) module APIs: the `SafeConfigParser` class alias, the `ParsingError.filename` property along with its parameter, and the `ConfigParser.readfp` method — every one of them deprecated since Python 3.2.
