# Python 3.12.0 alpha 1 / library / ctypes

[gh-92869](https://github.com/python/cpython/issues/92869): Introduced [`c_time_t`](https://docs.python.org/3.14/library/ctypes.html#ctypes.c_time_t) into [`ctypes`](https://docs.python.org/3.14/library/ctypes.html#module-ctypes); its size matches that of C's `time_t` type.

[gh-90005](https://github.com/python/cpython/issues/90005): The [`ctypes`](https://docs.python.org/3.14/library/ctypes.html#module-ctypes) dependency `libffi` is now located through `pkg-config`.
