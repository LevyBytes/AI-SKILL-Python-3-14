# Python 3.12.0 alpha 1 / library / mimetypes

[gh-97646](https://github.com/python/cpython/issues/97646): Swaps the deprecated `application/javascript` for `text/javascript` throughout [`mimetypes`](https://docs.python.org/3.14/library/mimetypes.html#module-mimetypes). Refer to [**RFC 9239**](https://datatracker.ietf.org/doc/html/rfc9239.html). Noam Cohen wrote the patch.
