# Python 3.12.0 alpha 1 / library / imports and modules

[gh-96145](https://github.com/python/cpython/issues/96145): The JSON module gains AttrDict, intended for use alongside object_hook.

[gh-96415](https://github.com/python/cpython/issues/96415): The `types._cell_factory` entry no longer appears in the module namespace.

[gh-94382](https://github.com/python/cpython/issues/94382): The static types of the `_multiprocessing` module are ported over to heap types. Kumar Aditya wrote the patch.
