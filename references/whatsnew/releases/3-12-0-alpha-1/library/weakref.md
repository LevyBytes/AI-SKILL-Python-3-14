# Python 3.12.0 alpha 1 / library / weakref

[gh-79512](https://github.com/python/cpython/issues/79512): Corrected the names and the `__module__` value for the [`weakref`](https://docs.python.org/3.14/library/weakref.html#module-weakref) classes [`ReferenceType`](https://docs.python.org/3.14/library/weakref.html#weakref.ReferenceType), [`ProxyType`](https://docs.python.org/3.14/library/weakref.html#weakref.ProxyType), and [`CallableProxyType`](https://docs.python.org/3.14/library/weakref.html#weakref.CallableProxyType), which renders them pickleable.
