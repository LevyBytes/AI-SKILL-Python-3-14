# Python 3.12.0 alpha 1 / library / timeit

[gh-90085](https://github.com/python/cpython/issues/90085): The `-c/--clock` and `-t/--time` CLI options belonging to [`timeit`](https://docs.python.org/3.14/library/timeit.html#module-timeit) are removed. Those options carried a deprecation since Python 3.3, and their functionality was already removed back in Python 3.7. Shantanu Jain wrote the patch.
