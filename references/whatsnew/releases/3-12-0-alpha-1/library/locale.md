# Python 3.12.0 alpha 1 / library / locale

[gh-94226](https://github.com/python/cpython/issues/94226): The `locale.format()` function, deprecated in Python 3.7, is removed; rely on [`locale.format_string()`](https://docs.python.org/3.14/library/locale.html#locale.format_string) instead. Victor Stinner wrote the patch.
