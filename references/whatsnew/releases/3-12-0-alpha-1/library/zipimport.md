# Python 3.12.0 alpha 1 / library / zipimport

[gh-94379](https://github.com/python/cpython/issues/94379): [`zipimport`](https://docs.python.org/3.14/library/zipimport.html#module-zipimport): The `find_loader()` and `find_module()` methods, deprecated in Python 3.10, are removed; use the `find_spec()` method in their place. The reasoning lives in [**PEP 451**](https://peps.python.org/pep-0451/). Victor Stinner wrote the patch.
