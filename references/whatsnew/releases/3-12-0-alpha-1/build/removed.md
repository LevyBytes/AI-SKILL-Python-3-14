# Python 3.12.0 alpha 1 / build / removed

[gh-93744](https://github.com/python/cpython/issues/93744): Drop the `configure --with-cxx-main` build option, which had been broken for years. The `MAINCC` variable is removed from `configure` and `Makefile`. Victor Stinner wrote the patch.
