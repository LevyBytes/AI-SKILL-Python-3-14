# Python 3.12.0 alpha 5 / library / warnings

[gh-39615](https://github.com/python/cpython/issues/39615): Through the fresh `skip_file_prefixes` keyword argument, [`warnings.warn()`](https://docs.python.org/3.14/library/warnings.html#warnings.warn) can now omit stack frames by code filename prefix rather than relying purely on a numeric `stacklevel`.
