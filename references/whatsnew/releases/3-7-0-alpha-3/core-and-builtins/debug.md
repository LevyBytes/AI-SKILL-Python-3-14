# Python 3.7.0 alpha 3 / core and builtins / debug

[bpo-32043](https://bugs.python.org/issue?@action=redirect&bpo=32043): Introduces a fresh "developer mode": the new "-X dev" command line option switches on runtime debug checks.

[bpo-31626](https://bugs.python.org/issue?@action=redirect&bpo=31626): Squashes a defect in the debug memory allocator, where freed memory was being written to after a memory block had been shrunk.
