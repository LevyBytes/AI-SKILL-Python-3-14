# Python 3.7.0 alpha 3 / c api / py useclassexceptionsflag flag gone

[bpo-32125](https://bugs.python.org/issue?@action=redirect&bpo=32125): The `Py_UseClassExceptionsFlag` flag is gone. It had been deprecated and has gone unused ever since Python 2.0.
