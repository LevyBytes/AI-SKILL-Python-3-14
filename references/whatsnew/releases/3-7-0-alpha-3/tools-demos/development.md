# Python 3.7.0 alpha 3 / tools demos / development

[bpo-32159](https://bugs.python.org/issue?@action=redirect&bpo=32159): Drop the CVS and Subversion tooling: delete the svneol.py and treesync.py scripts. The path of CPython went from CVS to Subversion, then Mercurial, and finally Git. Neither CVS nor Subversion is used for CPython development any longer.
