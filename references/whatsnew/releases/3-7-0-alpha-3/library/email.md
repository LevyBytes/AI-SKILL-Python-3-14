# Python 3.7.0 alpha 3 / library / email

[bpo-27240](https://bugs.python.org/issue?@action=redirect&bpo=27240): The header folding routine for the newer email policies was reworked, an effort that also resolves [bpo-30788](https://bugs.python.org/issue?@action=redirect&bpo=30788), [bpo-31831](https://bugs.python.org/issue?@action=redirect&bpo=31831), and [bpo-32182](https://bugs.python.org/issue?@action=redirect&bpo=32182). Notably, RFC2231 folding now happens correctly.
