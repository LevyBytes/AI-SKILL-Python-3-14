# Python 3.7.0 alpha 3 / library / subprocess

[bpo-31884](https://bugs.python.org/issue?@action=redirect&bpo=31884): added required constants to subprocess module for setting priority on windows

[bpo-31756](https://bugs.python.org/issue?@action=redirect&bpo=31756): Adds a `subprocess.Popen(text=False)` keyword argument across the `subprocess` functions, spelling out more plainly when the library should try to decode outputs into text. Andrew Clegg wrote the patch.
