# Python 3.7.0 alpha 3 / library / nullcontext no op context manager joins contextlib

[bpo-10049](https://bugs.python.org/issue?@action=redirect&bpo=10049): A *nullcontext* no-op context manager joins contextlib. It serves as a leaner, quicker substitute for ExitStack() whenever optional context managers are in play.
