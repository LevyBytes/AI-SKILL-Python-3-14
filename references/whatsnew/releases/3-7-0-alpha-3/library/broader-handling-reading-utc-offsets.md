# Python 3.7.0 alpha 3 / library / broader handling reading utc offsets

[bpo-31800](https://bugs.python.org/issue?@action=redirect&bpo=31800): Broader handling for reading UTC offsets. The strptime ?%z? directive is now able to read what datetime.isoformat emits, seconds and microseconds included.
