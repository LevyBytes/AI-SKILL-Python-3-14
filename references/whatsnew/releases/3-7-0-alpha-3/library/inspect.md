# Python 3.7.0 alpha 3 / library / inspect

[bpo-30639](https://bugs.python.org/issue?@action=redirect&bpo=30639): To guard against badly behaved custom reprs, [`inspect.getfile()`](https://docs.python.org/3.14/library/inspect.html#inspect.getfile) no longer builds the repr of unknown objects for display within an error message.
