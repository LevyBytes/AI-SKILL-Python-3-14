# Python 3.7.0 alpha 3 / library / binary

[bpo-32072](https://bugs.python.org/issue?@action=redirect&bpo=32072): Several binary-plist troubles were addressed: bytearray saving is fixed; identical objects are written only a single time; equal references load back as the same object; and saving plus loading of recursive data structures is now supported.
