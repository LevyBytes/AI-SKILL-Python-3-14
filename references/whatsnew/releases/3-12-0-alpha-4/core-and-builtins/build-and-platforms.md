# Python 3.12.0 alpha 4 / core and builtins / build and platforms

[gh-100143](https://github.com/python/cpython/issues/100143): With a `--enable-pystats` build, gathering stats is disabled by default now. Use the `-Xpystats` flag to turn it on early during startup. Regardless of whether collection was on, stats are now dumped every time.
