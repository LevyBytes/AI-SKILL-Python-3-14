# Python 3.13.0 alpha 2 / core and builtins / modules

[gh-111374](https://github.com/python/cpython/issues/111374): Introduced one more environment variable, [`PYTHON_FROZEN_MODULES`](https://docs.python.org/3.14/using/cmdline.html#envvar-PYTHON_FROZEN_MODULES). It governs whether the import machinery passes over frozen modules, the counterpart of the [`-X frozen_modules`](https://docs.python.org/3.14/using/cmdline.html#cmdoption-X) command-line option.
