# Python 3.13.0 alpha 2 / library / pathlib

[gh-111259](https://github.com/python/cpython/issues/111259): Speed up recursive wildcard handling in [`pathlib`](https://docs.python.org/3.14/library/pathlib.html#module-pathlib).

[gh-110745](https://github.com/python/cpython/issues/110745): A *newline* parameter was added to [`pathlib.Path.read_text()`](https://docs.python.org/3.14/library/pathlib.html#pathlib.Path.read_text). Junya Okabe contributed the patch.

[gh-111429](https://github.com/python/cpython/issues/111429): Make [`pathlib.PurePath.relative_to()`](https://docs.python.org/3.14/library/pathlib.html#pathlib.PurePath.relative_to) and [`is_relative_to()`](https://docs.python.org/3.14/library/pathlib.html#pathlib.PurePath.is_relative_to) faster.
