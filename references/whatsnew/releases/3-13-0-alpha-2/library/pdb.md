# Python 3.13.0 alpha 2 / library / pdb

[gh-110944](https://github.com/python/cpython/issues/110944): Provide alias and convenience variable support for [`pdb`](https://docs.python.org/3.14/library/pdb.html#module-pdb) completion

[gh-84583](https://github.com/python/cpython/issues/84583): Have [`pdb`](https://docs.python.org/3.14/library/pdb.html#module-pdb) drop into post-mortem mode even on a [`SyntaxError`](https://docs.python.org/3.14/library/exceptions.html#SyntaxError)

[gh-80675](https://github.com/python/cpython/issues/80675): Whenever [`pdb.set_trace()`](https://docs.python.org/3.14/library/pdb.html#pdb.set_trace) runs, every frame now gets `f_trace_lines = True`

[gh-59013](https://github.com/python/cpython/issues/59013): Sharpen the line number reported for a function breakpoint in [`pdb`](https://docs.python.org/3.14/library/pdb.html#module-pdb)

[gh-111719](https://github.com/python/cpython/issues/111719): Supply more argument validation for the `alias` command within [`pdb`](https://docs.python.org/3.14/library/pdb.html#module-pdb)

[gh-108791](https://github.com/python/cpython/issues/108791): Strengthen error handling in the [`pdb`](https://docs.python.org/3.14/library/pdb.html#module-pdb) command line interface so the messages it emits are more concise.
