# Python 3.13.0 alpha 2 / library / curses

[gh-111460](https://github.com/python/cpython/issues/111460): [`curses`](https://docs.python.org/3.14/library/curses.html#module-curses): wide character handling, [`curses.unget_wch()`](https://docs.python.org/3.14/library/curses.html#curses.unget_wch) and [`get_wch()`](https://docs.python.org/3.14/library/curses.html#curses.window.get_wch) included, is restored on macOS after a Python 3.12 regression had broken it.
