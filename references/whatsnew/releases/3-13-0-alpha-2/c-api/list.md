# Python 3.13.0 alpha 2 / c api / list

[gh-111138](https://github.com/python/cpython/issues/111138): Two new routines, [`PyList_Extend()`](https://docs.python.org/3.14/c-api/list.html#c.PyList_Extend) and [`PyList_Clear()`](https://docs.python.org/3.14/c-api/list.html#c.PyList_Clear), mirror the Python `list.extend()` and `list.clear()` methods. Victor Stinner authored it.
