# Python 3.8.0 alpha 1 / documentation / tests and documentation

[bpo-33197](https://bugs.python.org/issue?@action=redirect&bpo=33197): Attach a versionadded tag to the ParameterKind.description documentation

[bpo-32436](https://bugs.python.org/issue?@action=redirect&bpo=32436): Document the [**PEP 567**](https://peps.python.org/pep-0567/) modifications to asyncio.

[bpo-33594](https://bugs.python.org/issue?@action=redirect&bpo=33594): Mark `getargspec`, `from_function` and `from_builtin` as deprecated within each docstring, and state the version of first deprecation in the DeprecationWarning message.

[bpo-33421](https://bugs.python.org/issue?@action=redirect&bpo=33421): Supply the documentation that was missing for `typing.AsyncContextManager`.

[bpo-33487](https://bugs.python.org/issue?@action=redirect&bpo=33487): BZ2file now raises a DeprecationWarning whenever buffering=None is supplied; both the deprecation message and the docs now plainly note it has been deprecated since 3.0.

[bpo-33201](https://bugs.python.org/issue?@action=redirect&bpo=33201): Bring the documentation on authoring C extension types up to date.

[bpo-33195](https://bugs.python.org/issue?@action=redirect&bpo=33195): Mark `Py_UNICODE` usage as deprecated in the `c-api/arg` document. The APIs tied to `Py_UNICODE` have carried deprecation since Python 3.3, yet the document overlooked it.

[bpo-33126](https://bugs.python.org/issue?@action=redirect&bpo=33126): Document PyBuffer_ToContiguous().

[bpo-27212](https://bugs.python.org/issue?@action=redirect&bpo=27212): Adjust the docs covering the `islice()` recipe so initial values are consumed right up to the start index.

[bpo-18802](https://bugs.python.org/issue?@action=redirect&bpo=18802): Documentation updates for ipaddress. Patch by Jon Foster and Berker Peksag.

[bpo-27428](https://bugs.python.org/issue?@action=redirect&bpo=27428): Revise the docs to make plain that `WindowsRegistryFinder` provides `MetaPathFinder`. (Patch by Himanshu Lakhara)

[bpo-34764](https://bugs.python.org/issue?@action=redirect&bpo=34764): Sharpen the iter() example that uses a second sentinel argument.

[bpo-35038](https://bugs.python.org/issue?@action=redirect&bpo=35038): Correct the docs that mentioned a nonexistent `f_restricted` attribute on the frame object. Patch by Stéphane Wirtel

[bpo-11233](https://bugs.python.org/issue?@action=redirect&bpo=11233): Add an availability directive for the documentation. Original patch by Georg Brandl.

[bpo-17232](https://bugs.python.org/issue?@action=redirect&bpo=17232): Make the docs for -O and -OO clearer. Patch by Terry Reedy.

[bpo-32337](https://bugs.python.org/issue?@action=redirect&bpo=32337): Refresh the documentation touching on `dict` order.
