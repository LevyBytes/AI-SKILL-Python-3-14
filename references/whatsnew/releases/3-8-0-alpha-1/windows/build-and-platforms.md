# Python 3.8.0 alpha 1 / windows / build and platforms

[bpo-29734](https://bugs.python.org/issue?@action=redirect&bpo=29734): Repair handle leaks within os.stat under Windows.

[bpo-35402](https://bugs.python.org/issue?@action=redirect&bpo=35402): Refresh the Windows build so it adopts Tcl and Tk 8.6.9.

[bpo-35401](https://bugs.python.org/issue?@action=redirect&bpo=35401): Moves the Windows build up to OpenSSL 1.1.0j.

[bpo-34006](https://bugs.python.org/issue?@action=redirect&bpo=34006): Roll back the line length cap for the Windows help docs. The line-length cap is unnecessary because the pages render in a standalone app rather than within a browser tab. It can additionally clash with the DPI setting.

[bpo-33184](https://bugs.python.org/issue?@action=redirect&bpo=33184): Refresh the Windows installer so it uses OpenSSL 1.1.0h.
