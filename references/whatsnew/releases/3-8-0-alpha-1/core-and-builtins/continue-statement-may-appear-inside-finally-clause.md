# Python 3.8.0 alpha 1 / core and builtins / continue statement may appear inside finally clause

[bpo-32489](https://bugs.python.org/issue?@action=redirect&bpo=32489): The [`continue`](https://docs.python.org/3.14/reference/simple_stmts.html#continue) statement may now appear inside a [`finally`](https://docs.python.org/3.14/reference/compound_stmts.html#finally) clause.
