# Python 3.8.0 alpha 1 / core and builtins / iter

[bpo-33738](https://bugs.python.org/issue?@action=redirect&bpo=33738): Seven macro incompatibilities with the Limited API were resolved, and the macros [`PyIter_Check()`](https://docs.python.org/3.14/c-api/iter.html#c.PyIter_Check), [`PyIndex_Check()`](https://docs.python.org/3.14/c-api/number.html#c.PyIndex_Check) and [`PyExceptionClass_Name()`](https://docs.python.org/3.14/c-api/exceptions.html#c.PyExceptionClass_Name) were introduced as functions. A script that checks macros automatically was added.
