# Python 3.8.0 alpha 1 / core and builtins / numeric behavior

[bpo-34141](https://bugs.python.org/issue?@action=redirect&bpo=34141): Sped up the pickling of atomic types (None, bool, int, float, bytes, str).

[bpo-1621](https://bugs.python.org/issue?@action=redirect&bpo=1621): Avoid relying on signed integer overflow behavior (C undefined behavior) while resizing the set hash table.
