# Python 3.8.0 alpha 1 / idle / text

[bpo-34548](https://bugs.python.org/issue?@action=redirect&bpo=34548): Apply the configured color theme to read-only text views.

[bpo-33856](https://bugs.python.org/issue?@action=redirect&bpo=33856): Include "help" inside IDLE's greeting text shown at launch

[bpo-33656](https://bugs.python.org/issue?@action=redirect&bpo=33656): For Windows, invoke an API declaring that tk handles DPI scaling. Running Windows 8.1+ or 10, leaving the Python executable's DPI compatibility settings as-is, and using a display above 96 DPI, text and lines ought to render crisper. Elsewhere there should be no change.

[bpo-33763](https://bugs.python.org/issue?@action=redirect&bpo=33763): IDLE: Swap the label widget out for a `read-only text widget` driving code context.

[bpo-21474](https://bugs.python.org/issue?@action=redirect&bpo=21474): Move the word/identifier definition from ascii over to unicode. Across text and entry boxes this changes double-click selection, control-left/right movement, plus control-BACKSPACE/DEL deletion on either side.
