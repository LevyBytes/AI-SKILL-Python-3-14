# Python 3.8.0 alpha 1 / security / xml dom minidom

[bpo-17239](https://bugs.python.org/issue?@action=redirect&bpo=17239): The xml.sax and xml.dom.minidom parsers from now on do not process external entities by default. External DTD and ENTITY declarations no longer fetch files or open network connections.
