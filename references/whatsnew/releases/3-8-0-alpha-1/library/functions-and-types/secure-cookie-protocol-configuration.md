# Python 3.8.0 alpha 1 / library / secure cookie protocol configuration

[bpo-34911](https://bugs.python.org/issue?@action=redirect&bpo=34911): A *secure_protocols* argument now exists on *http.cookiejar.DefaultCookiePolicy*, both to permit tuning of protocols and to enable *wss*, the secure websocket protocol, by default.
