# Python 3.8.0 alpha 1 / library / dropped argument support tkinter ttk treeview selection

[bpo-31508](https://bugs.python.org/issue?@action=redirect&bpo=31508): Dropped argument support from `tkinter.ttk.Treeview.selection`. That was deprecated back in 3.6. To alter the selection, use dedicated methods such as `selection_set`.
