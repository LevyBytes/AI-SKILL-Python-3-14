# Python 3.8.0 alpha 1 / library / datetime instance d non none tzinfo yet whose d tzinfo utcoffset d

[bpo-33812](https://bugs.python.org/issue?@action=redirect&bpo=33812): A Datetime instance d that has non-None tzinfo, yet whose d.tzinfo.utcoffset(d) yields None, is now regarded as naive by the astimezone() method.
