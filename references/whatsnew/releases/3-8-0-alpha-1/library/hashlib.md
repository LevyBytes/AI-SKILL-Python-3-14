# Python 3.8.0 alpha 1 / library / hashlib

[bpo-34922](https://bugs.python.org/issue?@action=redirect&bpo=34922): Corrected an integer overflow within the [`digest()`](https://docs.python.org/3.14/library/hashlib.html#hashlib.shake.digest) and [`hexdigest()`](https://docs.python.org/3.14/library/hashlib.html#hashlib.shake.hexdigest) methods of the SHAKE algorithm in the [`hashlib`](https://docs.python.org/3.14/library/hashlib.html#module-hashlib) module.

[bpo-33729](https://bugs.python.org/issue?@action=redirect&bpo=33729): Resolved argument-parsing problems inside [`hashlib`](https://docs.python.org/3.14/library/hashlib.html#module-hashlib).
