# Python 3.8.0 alpha 1 / library / csv

[bpo-34197](https://bugs.python.org/issue?@action=redirect&bpo=34197): The *skipinitialspace*, *doublequote* and *strict* attributes belonging to the *dialect* attribute of the [`csv`](https://docs.python.org/3.14/library/csv.html#module-csv) reader are now [`bool`](https://docs.python.org/3.14/library/functions.html#bool) instances rather than the integers 0 or 1.
