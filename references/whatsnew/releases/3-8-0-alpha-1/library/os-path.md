# Python 3.8.0 alpha 1 / library / os path

[bpo-33721](https://bugs.python.org/issue?@action=redirect&bpo=33721): The [`os.path`](https://docs.python.org/3.14/library/os.path.html#module-os.path) functions yielding a boolean such as [`exists()`](https://docs.python.org/3.14/library/os.path.html#os.path.exists), [`lexists()`](https://docs.python.org/3.14/library/os.path.html#os.path.lexists), [`isdir()`](https://docs.python.org/3.14/library/os.path.html#os.path.isdir), [`isfile()`](https://docs.python.org/3.14/library/os.path.html#os.path.isfile), [`islink()`](https://docs.python.org/3.14/library/os.path.html#os.path.islink), and [`ismount()`](https://docs.python.org/3.14/library/os.path.html#os.path.ismount), together with the [`pathlib.Path`](https://docs.python.org/3.14/library/pathlib.html#pathlib.Path) methods yielding a boolean such as [`exists()`](https://docs.python.org/3.14/library/pathlib.html#pathlib.Path.exists), [`is_dir()`](https://docs.python.org/3.14/library/pathlib.html#pathlib.Path.is_dir), [`is_file()`](https://docs.python.org/3.14/library/pathlib.html#pathlib.Path.is_file), [`is_mount()`](https://docs.python.org/3.14/library/pathlib.html#pathlib.Path.is_mount), [`is_symlink()`](https://docs.python.org/3.14/library/pathlib.html#pathlib.Path.is_symlink), [`is_block_device()`](https://docs.python.org/3.14/library/pathlib.html#pathlib.Path.is_block_device), [`is_char_device()`](https://docs.python.org/3.14/library/pathlib.html#pathlib.Path.is_char_device), [`is_fifo()`](https://docs.python.org/3.14/library/pathlib.html#pathlib.Path.is_fifo), [`is_socket()`](https://docs.python.org/3.14/library/pathlib.html#pathlib.Path.is_socket) now hand back `False` rather than raising [`ValueError`](https://docs.python.org/3.14/library/exceptions.html#ValueError) or its subclasses [`UnicodeEncodeError`](https://docs.python.org/3.14/library/exceptions.html#UnicodeEncodeError) and [`UnicodeDecodeError`](https://docs.python.org/3.14/library/exceptions.html#UnicodeDecodeError) for paths holding characters or bytes that cannot be represented at the OS level.
