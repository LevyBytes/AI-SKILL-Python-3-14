# Python 3.8.0 alpha 1 / library / shutil

[bpo-33671](https://bugs.python.org/issue?@action=redirect&bpo=33671): On Linux and macOS, [`shutil.copyfile()`](https://docs.python.org/3.14/library/shutil.html#shutil.copyfile), [`shutil.copy()`](https://docs.python.org/3.14/library/shutil.html#shutil.copy), [`shutil.copy2()`](https://docs.python.org/3.14/library/shutil.html#shutil.copy2), [`shutil.copytree()`](https://docs.python.org/3.14/library/shutil.html#shutil.copytree) and [`shutil.move()`](https://docs.python.org/3.14/library/shutil.html#shutil.move) now lean on platform-specific fast-copy syscalls to move file data more efficiently. Under Windows, `shutil.copyfile()` adopts a larger default buffer size (1 MiB rather than 16 KiB) and a [`memoryview()`](https://docs.python.org/3.14/library/stdtypes.html#memoryview)-based variant of [`shutil.copyfileobj()`](https://docs.python.org/3.14/library/shutil.html#shutil.copyfileobj) is employed. Copying a 512MiB file gains roughly +26% on Linux, +50% on macOS and +40% on Windows. CPU cycles consumed also fall considerably. (Contributed by Giampaolo Rodola' in [bpo-25427](https://bugs.python.org/issue?@action=redirect&bpo=25427).)

[bpo-33695](https://bugs.python.org/issue?@action=redirect&bpo=33695): [`shutil.copytree()`](https://docs.python.org/3.14/library/shutil.html#shutil.copytree) now calls the [`os.scandir()`](https://docs.python.org/3.14/library/os.html#os.scandir) function, and every copy routine that depends on it reuses cached [`os.stat()`](https://docs.python.org/3.14/library/os.html#os.stat) values. Copying a directory holding 8000 files speeds up by roughly +9% on Linux, +20% on Windows and + 30% across a Windows SMB share. The count of `os.stat()` syscalls also drops by 38%, which makes `shutil.copytree()` notably quicker over network filesystems. (Contributed by Giampaolo Rodola' in [bpo-33695](https://bugs.python.org/issue?@action=redirect&bpo=33695).)

[bpo-13041](https://bugs.python.org/issue?@action=redirect&bpo=13041): The `argparse.HelpFormatter` class now relies on [`shutil.get_terminal_size()`](https://docs.python.org/3.14/library/shutil.html#shutil.get_terminal_size) to compute terminal width accurately. Initial patch by Zbyszek Jędrzejewski-Szmek.
