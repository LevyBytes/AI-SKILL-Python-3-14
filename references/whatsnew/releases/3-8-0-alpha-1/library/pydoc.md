# Python 3.8.0 alpha 1 / library / pydoc

[bpo-34966](https://bugs.python.org/issue?@action=redirect&bpo=34966): Aliases pointing at inherited methods, and not solely those defined directly in the end class, are now handled by [`pydoc`](https://docs.python.org/3.14/library/pydoc.html#module-pydoc). Docstrings are not repeated for the aliases.

[bpo-940286](https://bugs.python.org/issue?@action=redirect&bpo=940286): The `Helper.showtopic()` method in pydoc now renders a topic's cross references correctly.
