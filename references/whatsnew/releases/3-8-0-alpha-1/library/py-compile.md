# Python 3.8.0 alpha 1 / library / py compile

[bpo-34022](https://bugs.python.org/issue?@action=redirect&bpo=34022): Rather than overriding the *invalidation_mode* argument given to [`py_compile.compile()`](https://docs.python.org/3.14/library/py_compile.html#py_compile.compile), the `SOURCE_DATE_EPOCH` environment variable now merely supplies that argument's default value.
