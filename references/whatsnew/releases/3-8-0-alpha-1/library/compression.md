# Python 3.8.0 alpha 1 / library / compression

[bpo-34969](https://bugs.python.org/issue?@action=redirect&bpo=34969): gzip: the gzip CLI gains --fast and --best; these select the quick compression path (fast) or the strongest one (slower yet producing a smaller file). The default compression level also moves to 6 as a tradeoff.
