# Python 3.8.0 alpha 1 / library / smtplib

[bpo-34246](https://bugs.python.org/issue?@action=redirect&bpo=34246): The content of the *mail_options* argument is no longer altered by [`smtplib.SMTP.send_message()`](https://docs.python.org/3.14/library/smtplib.html#smtplib.SMTP.send_message). Pablo S. Blum de Aguiar wrote the patch.

[bpo-32680](https://bugs.python.org/issue?@action=redirect&bpo=32680): A `sock` attribute is now always present on [`smtplib.SMTP`](https://docs.python.org/3.14/library/smtplib.html#smtplib.SMTP) objects
