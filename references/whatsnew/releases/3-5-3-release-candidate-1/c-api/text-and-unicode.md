# Python 3.5.3 release candidate 1 / c api / text and unicode

[bpo-26754](https://bugs.python.org/issue?@action=redirect&bpo=26754): PyUnicode_FSDecoder() used to take a filename argument supplied as an iterable of integers. From now on it accepts only strings and bytes-like objects.
