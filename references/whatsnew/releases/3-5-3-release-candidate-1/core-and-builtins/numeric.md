# Python 3.5.3 release candidate 1 / core and builtins / numeric

[bpo-27936](https://bugs.python.org/issue?@action=redirect&bpo=27936): The round() function had accepted a second None argument for certain types yet not for others. This inconsistency is fixed by allowing None across all numeric types.
