# Python 3.5.3 release candidate 1 / core and builtins / builtins

[bpo-27419](https://bugs.python.org/issue?@action=redirect&bpo=27419): Standard __import__() no longer consults "__import__" in globals or builtins when importing submodules or doing "from import". Handling of an error from a non-string package name is corrected as well.
