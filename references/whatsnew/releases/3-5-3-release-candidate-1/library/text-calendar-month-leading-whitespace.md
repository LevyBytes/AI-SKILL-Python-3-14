# Python 3.5.3 release candidate 1 / library / calendar textcalendar prmonth will no longer emit leading space new

[bpo-28255](https://bugs.python.org/issue?@action=redirect&bpo=28255): calendar.TextCalendar().prmonth() will no longer emit a leading space on a new line once a month's calendar has printed. Xiang Zhang supplied the patch.
