[bpo-27517](https://bugs.python.org/issue?@action=redirect&bpo=27517): The LZMA compressor and decompressor no longer throw exceptions when handed empty data a second time. Benjamin Fogle supplied the patch.

[bpo-26844](https://bugs.python.org/issue?@action=redirect&bpo=26844): Corrected the imp.find_module() error message so it cites "path" rather than "name". Lev Maximov supplied the patch.
