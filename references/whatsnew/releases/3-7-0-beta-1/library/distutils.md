# Python 3.7.0 beta 1 / library / distutils

[bpo-32304](https://bugs.python.org/issue?@action=redirect&bpo=32304): The distutils' upload command no longer mangles tar files that end on a CR byte, and no longer attempts to turn CR into CRLF in any of the upload text fields.
