# Python 3.7.0 beta 1 / core and builtins / python expressly retains definition order keyword only parameters

[bpo-32697](https://bugs.python.org/issue?@action=redirect&bpo=32697): Python now expressly retains the definition order of keyword-only parameters. Their order has always been kept, yet this behavior had never been guaranteed previously; the behavior is now guaranteed as well as tested.
