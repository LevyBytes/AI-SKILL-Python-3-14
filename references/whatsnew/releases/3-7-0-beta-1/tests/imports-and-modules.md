# Python 3.7.0 beta 1 / tests / imports and modules

[bpo-32721](https://bugs.python.org/issue?@action=redirect&bpo=32721): Keep test_hashlib from failing whenever the _md5 module has not been built.

[bpo-32604](https://bugs.python.org/issue?@action=redirect&bpo=32604): Introduce a fresh "_xxsubinterpreters" extension module surfacing the current subinterpreter C-API alongside a new mechanism for sharing data across interpreters. Its main purpose is more exhaustive testing of the existing subinterpreter support. Be aware that the _xxsubinterpreters module was dropped in 3.7.0rc1.
