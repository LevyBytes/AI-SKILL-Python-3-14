# Python 3.7.0 beta 1 / macos / build and platforms

[bpo-32726](https://bugs.python.org/issue?@action=redirect&bpo=32726): Ship an extra, more current macOS installer flavor targeting macOS 10.9+ systems exclusively in 64-bit mode. The bundled third-party libraries move up to OpenSSL 1.1.0g and SQLite 3.22.0. This 10.9+ installer now bundles and links against its own Tcl/Tk 8.6.
