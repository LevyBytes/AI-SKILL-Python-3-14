# Python 3.14.0 beta 4 / core and builtins / sys

[gh-135543](https://github.com/python/cpython/issues/135543): A `sys.remote_exec` audit event is now emitted whenever [`sys.remote_exec()`](https://docs.python.org/3.14/library/sys.html#sys.remote_exec) gets called, and `remote_debugger_script` was migrated to `cpython.remote_debugger_script`.
