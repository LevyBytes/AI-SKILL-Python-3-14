# Python 3.5.0 beta 3 / library / functions and types

[bpo-24336](https://bugs.python.org/issue?@action=redirect&bpo=24336): The contextmanager decorator now copes with functions whose keyword arguments are named "func" and "self". Martin Panter supplied the patch.

[bpo-24408](https://bugs.python.org/issue?@action=redirect&bpo=24408): Corrected the AttributeError raised by the measure() and metrics() methods of tkinter.Font.

[bpo-14373](https://bugs.python.org/issue?@action=redirect&bpo=14373): methods can now be wrapped by the C implementation of functools.lru_cache().

[bpo-24368](https://bugs.python.org/issue?@action=redirect&bpo=24368): Permit keyword arguments across OrderedDict methods.
