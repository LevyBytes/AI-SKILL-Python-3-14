# Python 3.6.0 alpha 1 / library / unittest mock

[bpo-26323](https://bugs.python.org/issue?@action=redirect&bpo=26323): unittest.mock gained the Mock.assert_called() and Mock.assert_called_once() methods. Amit Saha wrote the patch.

[bpo-23661](https://bugs.python.org/issue?@action=redirect&bpo=23661): unittest.mock side_effects are once more permitted to be exceptions. The previous behavior was a regression relative to Python 3.4. Ignacio Rossi submitted the patch
