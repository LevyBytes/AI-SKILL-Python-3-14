# Python 3.6.0 alpha 1 / library / build and platforms

[bpo-26782](https://bugs.python.org/issue?@action=redirect&bpo=26782): On Windows, STARTUPINFO is now part of subprocess.__all__.

[bpo-24426](https://bugs.python.org/issue?@action=redirect&bpo=24426): Within regular expressions, the fast searching optimization now applies to patterns that begin with capturing groups. That fast searching optimization can no longer be turned off at compile time.
