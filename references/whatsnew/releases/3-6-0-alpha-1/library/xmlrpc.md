# Python 3.6.0 alpha 1 / library / xmlrpc

[bpo-26873](https://bugs.python.org/issue?@action=redirect&bpo=26873): Rather than quietly returning a wrong result, xmlrpc now throws ResponseError when it meets unsupported type tags.

[bpo-26147](https://bugs.python.org/issue?@action=redirect&bpo=26147): xmlrpc now copes with strings that cannot be encoded under the chosen non-UTF-8 encoding.
