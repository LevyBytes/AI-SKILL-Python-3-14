# Python 3.6.0 alpha 1 / library / tracemalloc

[bpo-26530](https://bugs.python.org/issue?@action=redirect&bpo=26530): Introduced the C functions `_PyTraceMalloc_Track()` and `_PyTraceMalloc_Untrack()` for following memory blocks through the [`tracemalloc`](https://docs.python.org/3.14/library/tracemalloc.html#module-tracemalloc) module, plus `_PyTraceMalloc_GetTraceback()` to fetch an object's traceback.
