# Python 3.6.0 alpha 1 / library / pydoc

[bpo-24879](https://bugs.python.org/issue?@action=redirect&bpo=24879): Both help() and pydoc are now capable of listing named tuple fields in definition order instead of alphabetically. That order comes from the _fields attribute when one is present.

[bpo-18010](https://bugs.python.org/issue?@action=redirect&bpo=18010): Corrected the module search routine of the pydoc web server so it copes with exceptions thrown while importing packages.
