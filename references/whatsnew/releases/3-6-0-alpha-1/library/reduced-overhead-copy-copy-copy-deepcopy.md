# Python 3.6.0 alpha 1 / library / reduced overhead copy copy copy deepcopy

[bpo-26167](https://bugs.python.org/issue?@action=redirect&bpo=26167): Reduced the overhead of copy.copy() and copy.deepcopy(). Copying and deepcopying of bytearrays, NotImplemented, slices, short lists, tuples, dicts, and sets was optimized.
