# Python 3.6.0 alpha 1 / idle / html

[bpo-25198](https://bugs.python.org/issue?@action=redirect&bpo=25198): Improved the initial html viewer that Idle Help now uses. Fixed-pitch text is now indented properly (Mark Roseman supplied that patch). Code snippets get a very Sphinx-like light blueish-gray background. The initial width and height that users picked for shell and editor are reused. Whenever the Table of Contents (TOC) menu gets used, the section header is placed at the top of the screen.
