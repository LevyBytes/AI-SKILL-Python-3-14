# Python 3.6.0 alpha 1 / idle / dialog

[bpo-24782](https://bugs.python.org/issue?@action=redirect&bpo=24782): Rather than living in a separate dialog, Extension configuration is now a tab within the IDLE Preferences dialog. What used to be tabs now form a sorted list. Mark Roseman contributed this patch.

[bpo-22726](https://bugs.python.org/issue?@action=redirect&bpo=22726): Brought back the config dialog help button, carrying some content describing the other buttons plus the new IDLE Dark theme.
