# Python 3.5.0 alpha 2 / library / subprocess

[bpo-23361](https://bugs.python.org/issue?@action=redirect&bpo=23361): Closed a possible overflow in the Windows subprocess creation code.

- logging.handlers.QueueListener gains a respect_handler_level keyword argument; setting it to True forwards messages to handlers while honoring handler levels.
