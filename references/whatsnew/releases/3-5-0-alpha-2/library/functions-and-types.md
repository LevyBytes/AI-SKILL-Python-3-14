# Python 3.5.0 alpha 2 / library / functions and types

[bpo-14910](https://bugs.python.org/issue?@action=redirect&bpo=14910): Gave argparse.ArgumentParser an allow_abbrev parameter. The patch came from Jonathan Paugh, Steven Bethard, paul j3 and Daniel Eriksson.

[bpo-20204](https://bugs.python.org/issue?@action=redirect&bpo=20204): The __module__ attribute is now present on _tkinter classes.

[bpo-814253](https://bugs.python.org/issue?@action=redirect&bpo=814253): Inside lookbehind assertions for regular expressions, group references plus conditional group references now function. (See also: [bpo-9179](https://bugs.python.org/issue?@action=redirect&bpo=9179))
