[bpo-19980](https://bugs.python.org/issue?@action=redirect&bpo=19980): Better help() output for strings it doesn't recognize. Now `help('')` brings up the help on str, while help("help") brings up the help on help(). Mark Lawrence wrote the first version of the patch.
