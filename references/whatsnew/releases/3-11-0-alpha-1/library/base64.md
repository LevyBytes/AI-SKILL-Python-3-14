# Python 3.11.0 alpha 1 / library / base64

[bpo-43086](https://bugs.python.org/issue?@action=redirect&bpo=43086): A fresh optional `strict_mode` parameter is now available on *binascii.a2b_base64*. With `scrict_mode` flipped to `True`, *a2b_base64* tolerates only valid base64 content. The function’s documentation explains in more detail what counts as “valid base64 content”.
