# Python 3.11.0 alpha 1 / library / contextlib

[bpo-38415](https://bugs.python.org/issue?@action=redirect&bpo=38415): [`contextlib.asynccontextmanager()`](https://docs.python.org/3.14/library/contextlib.html#contextlib.asynccontextmanager) gained the behavior it was missing so that, like [`contextlib.contextmanager()`](https://docs.python.org/3.14/library/contextlib.html#contextlib.contextmanager), the functions it decorates can act as decorators in their own right.
