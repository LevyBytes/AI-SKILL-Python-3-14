# Python 3.11.0 alpha 1 / library / email message

[bpo-41402](https://bugs.python.org/issue?@action=redirect&bpo=41402): Repaired [`email.message.EmailMessage.set_content()`](https://docs.python.org/3.14/library/email.message.html#email.message.EmailMessage.set_content) for invocations carrying binary data together with `7bit` content transfer encoding.
