# Python 3.11.0 alpha 1 / library / numeric behavior

[bpo-20524](https://bugs.python.org/issue?@action=redirect&bpo=20524): Sharpens the diagnostics produced by `.format()` for `str`, `float`, `int`, and `complex`. The revised wording surfaces both the offending pattern and the object type.

[bpo-45030](https://bugs.python.org/issue?@action=redirect&bpo=45030): Closed an integer overflow that struck when the range iterator is pickled or copied.
