# Python 3.11.0 alpha 1 / library / webbrowser

[bpo-44059](https://bugs.python.org/issue?@action=redirect&bpo=44059): Register the SerenityOS Browser in the [`webbrowser`](https://docs.python.org/3.14/library/webbrowser.html#module-webbrowser) module.

[bpo-42255](https://bugs.python.org/issue?@action=redirect&bpo=42255): `webbrowser.MacOSX` now carries a deprecation and is slated to disappear in Python 3.13. Nothing tests or documents it, and [`webbrowser`](https://docs.python.org/3.14/library/webbrowser.html#module-webbrowser) itself never touches it. Donghee Na wrote this patch.
