# Python 3.11.0 alpha 1 / tests / functions

[bpo-44891](https://bugs.python.org/issue?@action=redirect&bpo=44891): New tests were introduced to confirm [`id()`](https://docs.python.org/3.14/library/functions.html#id) survives when `obj * 1` is applied to [`str`](https://docs.python.org/3.14/library/stdtypes.html#str) and [`bytes`](https://docs.python.org/3.14/library/stdtypes.html#bytes) objects. Nikita Sobolev authored the change.
