# Python 3.11.0 alpha 1 / core and builtins / apply pep machinery specialize binary add instruction

[bpo-44945](https://bugs.python.org/issue?@action=redirect&bpo=44945): Apply the PEP 659 machinery to specialize the BINARY_ADD instruction. This brings five fresh instructions:

  - BINARY_ADD_ADAPTIVE

  - BINARY_ADD_FLOAT

  - BINARY_ADD_INT

  - BINARY_ADD_UNICODE

  - BINARY_ADD_UNICODE_INPLACE_FAST
