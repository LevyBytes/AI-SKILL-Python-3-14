# Python 3.11.0 alpha 1 / core and builtins / debug

[bpo-44895](https://bugs.python.org/issue?@action=redirect&bpo=44895): A new debug variable, [`PYTHONDUMPREFSFILE`](https://docs.python.org/3.14/using/cmdline.html#envvar-PYTHONDUMPREFSFILE), now produces a dump file emitted by [`--with-trace-refs`](https://docs.python.org/3.14/using/configure.html#cmdoption-with-trace-refs). Donghee Na supplied the patch.
