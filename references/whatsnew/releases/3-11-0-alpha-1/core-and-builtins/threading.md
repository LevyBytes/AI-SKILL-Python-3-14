# Python 3.11.0 alpha 1 / core and builtins / threading

[bpo-44584](https://bugs.python.org/issue?@action=redirect&bpo=44584): The threading debug (`PYTHONTHREADDEBUG` environment variable) became deprecated in Python 3.10 and is slated for removal in Python 3.12. A debug build of Python is required for this feature. Victor Stinner authored the patch.
