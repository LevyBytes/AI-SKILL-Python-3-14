# Python 3.11.0 alpha 1 / core and builtins / numeric

[bpo-43833](https://bugs.python.org/issue?@action=redirect&bpo=43833): Raise a deprecation warning whenever a numeric literal is followed straight away by one of the keywords and, else, for, if, in, is, or. If instead it is followed immediately by another keyword or identifier, raise a syntax error with a more helpful message.
