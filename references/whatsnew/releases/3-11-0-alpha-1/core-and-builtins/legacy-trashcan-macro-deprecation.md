# Python 3.11.0 alpha 1 / core and builtins / legacy trashcan macros py trashcan safe begin py trashcan safe end deprecated

[bpo-44874](https://bugs.python.org/issue?@action=redirect&bpo=44874): The legacy trashcan macros (`Py_TRASHCAN_SAFE_BEGIN`/`Py_TRASHCAN_SAFE_END`) are now deprecated. Use the replacement macros `Py_TRASHCAN_BEGIN` and `Py_TRASHCAN_END` in their place.
