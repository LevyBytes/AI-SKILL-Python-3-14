# Python 3.11.0 alpha 1 / documentation / tests and documentation

[bpo-27752](https://bugs.python.org/issue?@action=redirect&bpo=27752): The csv.Dialect documentation is now more descriptive.

[bpo-44392](https://bugs.python.org/issue?@action=redirect&bpo=44392): A new section covering the types used in type hinting was added to the C API documentation. `Py_GenericAlias` and `Py_GenericAliasType` are now documented.

[bpo-38291](https://bugs.python.org/issue?@action=redirect&bpo=38291): In the documentation, `typing.io` and `typing.re` are flagged as deprecated since Python 3.8. Type checkers never gave them proper support.

[bpo-44195](https://bugs.python.org/issue?@action=redirect&bpo=44195): Fixed the docs’ references to `TraversableResources`. No `TraversableReader` exists.

[bpo-41706](https://bugs.python.org/issue?@action=redirect&bpo=41706): Corrected the docs describing how methods such as `__add__` get called during the evaluation of operator expressions.
