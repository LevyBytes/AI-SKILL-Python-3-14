# Python 3.11.0 alpha 1 / documentation / collections abc

[bpo-45024](https://bugs.python.org/issue?@action=redirect&bpo=45024): The [`collections.abc`](https://docs.python.org/3.14/library/collections.abc.html#module-collections.abc) documentation now spells out explicitly how instance and subclass checks behave, adding more doctest examples plus a complete roster of ABCs whose membership test depends solely on the presence of the appropriate [special method](https://docs.python.org/3.14/glossary.html#term-special-method)s. Raymond Hettinger authored the change.
