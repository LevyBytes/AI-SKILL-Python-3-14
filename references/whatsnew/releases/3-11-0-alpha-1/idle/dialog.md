# Python 3.11.0 alpha 1 / idle / dialog

[bpo-40468](https://bugs.python.org/issue?@action=redirect&bpo=40468): Divide the settings dialog General tab into separate Windows and Shell/ED tabs. Relocate help sources, which augment the Help menu, onto the Extensions tab. This opens room for new options and trims the dialog. That shorter form lets the dialog sit better on small screens.
