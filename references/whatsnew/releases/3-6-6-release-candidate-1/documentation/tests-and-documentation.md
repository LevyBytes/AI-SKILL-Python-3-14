# Python 3.6.6 release candidate 1 / documentation / tests and documentation

[bpo-33421](https://bugs.python.org/issue?@action=redirect&bpo=33421): Supplied the missing documentation covering `typing.AsyncContextManager`.

[bpo-33201](https://bugs.python.org/issue?@action=redirect&bpo=33201): Brought the documentation on authoring C extension types up to date.

[bpo-33195](https://bugs.python.org/issue?@action=redirect&bpo=33195): Marked `Py_UNICODE` usage as deprecated within the `c-api/arg` document. Although the `Py_UNICODE` family of APIs has been deprecated ever since Python 3.3, the document had overlooked it.

[bpo-27212](https://bugs.python.org/issue?@action=redirect&bpo=27212): Adjusted the documentation of the `islice()` recipe so it consumes the initial values up through the start index.

[bpo-18802](https://bugs.python.org/issue?@action=redirect&bpo=18802): Documentation updates for ipaddress. Jon Foster and Berker Peksag supplied the patch.

[bpo-27428](https://bugs.python.org/issue?@action=redirect&bpo=27428): Clarified in the documentation that `WindowsRegistryFinder` is an implementation of `MetaPathFinder`. (Himanshu Lakhara contributed the patch)
