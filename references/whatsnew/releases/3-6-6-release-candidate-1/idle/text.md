# Python 3.6.6 release candidate 1 / idle / text

[bpo-33763](https://bugs.python.org/issue?@action=redirect&bpo=33763): IDLE: Code context now uses a read-only text widget in place of a label widget.

[bpo-21474](https://bugs.python.org/issue?@action=redirect&bpo=21474): Moved the word/identifier definition from ascii over to unicode. Inside text and entry boxes, this touches double-click selection, left/right movement via control-left/right, and left/right deletion via control-BACKSPACE/DEL.
