# Python 3.6.6 release candidate 1 / idle / binary

[bpo-33656](https://bugs.python.org/issue?@action=redirect&bpo=33656): Added a Windows API call on Windows declaring that tk scales for DPI. Running Windows 8.1+ or 10, with the Python binary's DPI compatibility properties left alone and a monitor above 96 DPI, this ought to render text and lines crisper. Otherwise it changes nothing.
