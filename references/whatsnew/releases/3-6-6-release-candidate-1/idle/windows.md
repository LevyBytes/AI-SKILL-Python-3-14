# Python 3.6.6 release candidate 1 / idle / windows

[bpo-33664](https://bugs.python.org/issue?@action=redirect&bpo=33664): Made IDLE’s editor scroll text by whole lines. Previously the mouse wheel along with the scrollbar slider shifted text by a set pixel count, which left partial lines along the top of the editor box. This also covers the shell and grep output windows, though not the read-only text views.
