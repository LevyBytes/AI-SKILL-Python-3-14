# Python 3.8.0 alpha 3 / library / tarfile

[bpo-36268](https://bugs.python.org/issue?@action=redirect&bpo=36268): Change the default format that [`tarfile`](https://docs.python.org/3.14/library/tarfile.html#module-tarfile) uses for writing tars, moving from the vendor-specific GNU to the modern POSIX.1-2001 pax standard. C.A.M. Gerlach contributed this.
