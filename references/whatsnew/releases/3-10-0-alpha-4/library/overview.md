# Python 3.10.0 alpha 4 / library / overview

Passing non-integer arguments to `randrange()` is now deprecated.

  - In place of the `ValueError`, a `TypeError` is now preferred and the former is deprecated.

  - Its speed has improved slightly over the previous version.

Raymond Hettinger and Serhiy Storchaka contributed this.
