# Python 3.10.0 alpha 4 / library / text and unicode

[bpo-42644](https://bugs.python.org/issue?@action=redirect&bpo=42644): `logging.disable` now checks both the type and the value of its argument. On top of that it now takes level names as strings (just like `logging.setLevel`) rather than purely numerical values.

[bpo-42257](https://bugs.python.org/issue?@action=redirect&bpo=42257): Cope with an empty string for the variable executable inside platform.libc_ver()

[bpo-23328](https://bugs.python.org/issue?@action=redirect&bpo=23328): Permit the / character inside the username and password fields of _PROXY envars.
