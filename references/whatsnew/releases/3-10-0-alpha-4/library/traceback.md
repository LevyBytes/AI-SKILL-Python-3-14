# Python 3.10.0 alpha 4 / library / traceback

[bpo-34463](https://bugs.python.org/issue?@action=redirect&bpo=34463): Closed the gap between [`traceback`](https://docs.python.org/3.14/library/traceback.html#module-traceback) and the interpreter when formatting a SyntaxError whose lineno is unset (`traceback` was adjusted to follow the interpreter).
