# Python 3.10.0 alpha 4 / core and builtins / command supplied through c command line option coding cookie

[bpo-32381](https://bugs.python.org/issue?@action=redirect&bpo=32381): For the command supplied through the [`-c`](https://docs.python.org/3.14/using/cmdline.html#cmdoption-c) command line option, the coding cookie (ex: `# coding: latin1`) is from now on disregarded. Victor Stinner wrote the patch.
