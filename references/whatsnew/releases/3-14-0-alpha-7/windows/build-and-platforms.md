# Python 3.14.0 alpha 7 / windows / build and platforms

[gh-131423](https://github.com/python/cpython/issues/131423): The bundled OpenSSL was bumped to 3.0.16. This new build additionally turns off uplink support — something embedders may care about, though ordinary use sees no impact.

[gh-131025](https://github.com/python/cpython/issues/131025): The Windows installer now ships alongside SQLite 3.49.1.
