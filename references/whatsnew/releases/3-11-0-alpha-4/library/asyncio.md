# Python 3.11.0 alpha 4 / library / asyncio

[bpo-46070](https://bugs.python.org/issue?@action=redirect&bpo=46070): Eliminate a possible segfault that could arise when the [`asyncio`](https://docs.python.org/3.14/library/asyncio.html#module-asyncio) module is imported in parallel across separate sub-interpreters. Erlend E. Aasland wrote the patch.
