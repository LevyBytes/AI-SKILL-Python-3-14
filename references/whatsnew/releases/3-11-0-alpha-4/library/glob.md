# Python 3.11.0 alpha 4 / library / glob

[bpo-37578](https://bugs.python.org/issue?@action=redirect&bpo=37578): Introduce an *include_hidden* parameter for [`glob()`](https://docs.python.org/3.14/library/glob.html#glob.glob) and [`iglob()`](https://docs.python.org/3.14/library/glob.html#glob.iglob) so hidden files and directories match when special characters such as `*`, `**`, `?` and `[]` are used.
