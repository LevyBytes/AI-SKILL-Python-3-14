# Python 3.11.0 alpha 3 / build / socket

[bpo-40280](https://bugs.python.org/issue?@action=redirect&bpo=40280): `configure` now probes for the socket `shutdown` function. That probe lets you disable `SYS_shutdown` by setting `ac_cv_func_shutdown=no` in CONFIG_SITE.
