# Python 3.11.0 alpha 3 / build / files and paths

[bpo-45866](https://bugs.python.org/issue?@action=redirect&bpo=45866): `make regen-all` now yields identical output regardless of which directory it runs from, including out-of-tree Python builds. pegen now removes the directory portion from the ?generated by pygen from &lt;FILENAME&gt;? header. Victor Stinner supplied the patch.

[bpo-45881](https://bugs.python.org/issue?@action=redirect&bpo=45881): To find multiarch and cross compile paths, `setup.py` now consults `CC` from the environment first.

[bpo-45886](https://bugs.python.org/issue?@action=redirect&bpo=45886): It is now possible to override the `_freeze_module` program path from the command line, such as `make FREEZE_MODULE=../x86_64/Program/_freeze_module`.
