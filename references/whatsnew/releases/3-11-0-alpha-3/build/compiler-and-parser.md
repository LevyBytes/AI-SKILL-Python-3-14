# Python 3.11.0 alpha 3 / build / compiler and parser

[bpo-45573](https://bugs.python.org/issue?@action=redirect&bpo=45573): A consistent format is now used by `configure` to define state, compiler flags, and linker flags within the Makefile. A fresh macro, `PY_STDLIB_MOD`, defines three variables that `Modules/Setup` and `setup.py` then read.
