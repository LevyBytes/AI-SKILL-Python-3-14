# Python 3.11.0 alpha 3 / build / decimal

[bpo-45798](https://bugs.python.org/issue?@action=redirect&bpo=45798): The `configure` step now detects settings for the [`decimal`](https://docs.python.org/3.14/library/decimal.html#module-decimal) internal C extension. Its bundled `libmpdec` library gets built within `Makefile`.
