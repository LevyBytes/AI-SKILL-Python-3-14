# Python 3.11.0 alpha 3 / tests / drop findleaks command line option regrtest reach fail env changed option

[bpo-45745](https://bugs.python.org/issue?@action=redirect&bpo=45745): Drop the `--findleaks` command line option from regrtest; reach for the `--fail-env-changed` option in its place. Ever since Python 3.7, it had been a deprecated alias pointing at the `--fail-env-changed` option.
