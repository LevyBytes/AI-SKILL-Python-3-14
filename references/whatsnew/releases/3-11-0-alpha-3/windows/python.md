# Python 3.11.0 alpha 3 / windows / python

[bpo-45901](https://bugs.python.org/issue?@action=redirect&bpo=45901): After being installed via the Microsoft Store and registered as the default handler for `*.py` files, arguments on the command line are now forwarded to Python when a script runs without Python being launched explicitly (in other words, `script.py args` rather than `python script.py args`).
