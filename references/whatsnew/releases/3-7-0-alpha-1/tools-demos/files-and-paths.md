# Python 3.7.0 alpha 1 / tools demos / files and paths

[bpo-24037](https://bugs.python.org/issue?@action=redirect&bpo=24037): For semantical booleans, Argument Clinic switched to the `bool(accept={int})` converter in place of `int`. The benefit is not duplicating the default across Python and C, and an easier path toward `bool` down the road.
