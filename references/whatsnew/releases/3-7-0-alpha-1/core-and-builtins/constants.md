# Python 3.7.0 alpha 1 / core and builtins / constants

[bpo-28350](https://bugs.python.org/issue?@action=redirect&bpo=28350): String constants containing a null character are no longer interned.

[bpo-27942](https://bugs.python.org/issue?@action=redirect&bpo=27942): String constants are interned recursively within tuples and frozensets from now on.
