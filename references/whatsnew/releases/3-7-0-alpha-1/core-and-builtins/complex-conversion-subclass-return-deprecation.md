# Python 3.7.0 alpha 1 / core and builtins / deprecation warning fires complex yields instance strict subclass complex

[bpo-29894](https://bugs.python.org/issue?@action=redirect&bpo=29894): A deprecation warning now fires when __complex__ yields an instance of a strict subclass of complex. Some future Python version may turn this into an error.
