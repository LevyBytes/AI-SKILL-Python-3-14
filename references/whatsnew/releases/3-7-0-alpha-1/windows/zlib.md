# Python 3.7.0 alpha 1 / windows / zlib

[bpo-31358](https://bugs.python.org/issue?@action=redirect&bpo=31358): zlib no longer ships inside the CPython source; it is instead fetched on demand, just as bz2, lzma, OpenSSL, Tcl/Tk, and SQLite are.
