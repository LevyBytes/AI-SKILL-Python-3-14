# Python 3.7.0 alpha 1 / idle / repair several issues idle s autocompletion box

[bpo-15786](https://bugs.python.org/issue?@action=redirect&bpo=15786): Repair several issues with IDLE’s autocompletion box. These should all behave now: clicking on selection box items; using the scrollbar; choosing an item by pressing Return. Hangs under MacOSX should also stop occurring. Louie Lu supplied the patch.
