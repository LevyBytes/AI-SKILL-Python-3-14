# Python 3.7.0 alpha 1 / idle / text and unicode

[bpo-29071](https://bugs.python.org/issue?@action=redirect&bpo=29071): IDLE colors f-string prefixes (though not the invalid ur prefixes).

[bpo-31477](https://bugs.python.org/issue?@action=redirect&bpo=31477): IDLE - Sharpen the rstrip entry in the documentation. Stripping trailing whitespace removes more than plain blank spaces. Multiline string literals are left untouched.

[bpo-29910](https://bugs.python.org/issue?@action=redirect&bpo=29910): IDLE no longer removes a character after a region is commented out via a key shortcut. A `return 'break'` was added to handle this and other possible clashes between IDLE bindings and the default ones.
