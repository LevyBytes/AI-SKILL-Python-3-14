# Python 3.7.0 alpha 1 / library / unittest

[bpo-30190](https://bugs.python.org/issue?@action=redirect&bpo=30190): On failure, the assertAlmostEqual and assertNotAlmostEqual helpers from unittest now give a clearer message that reports the gap between the left and right arguments. (Giampaolo Rodola’ contributed the patch.)

[bpo-30664](https://bugs.python.org/issue?@action=redirect&bpo=30664): A unittest subtest's description now keeps the keyword arguments of TestCase.subTest() in order.
