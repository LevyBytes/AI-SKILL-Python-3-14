# Python 3.7.0 alpha 1 / library / calendar textcalendar prmonth stopped emitting leading space start new line once

[bpo-28255](https://bugs.python.org/issue?@action=redirect&bpo=28255): calendar.TextCalendar.prmonth() stopped emitting a leading space at the start of a new line once a month’s calendar finishes printing. Xiang Zhang supplied the patch.
