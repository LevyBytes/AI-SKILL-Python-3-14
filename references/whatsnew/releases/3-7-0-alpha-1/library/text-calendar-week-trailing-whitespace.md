# Python 3.7.0 alpha 1 / library / calendar textcalendar prweek stopped emitting trailing space after week s calendar

[bpo-28255](https://bugs.python.org/issue?@action=redirect&bpo=28255): calendar.TextCalendar.prweek() stopped emitting a trailing space after a week’s calendar. calendar.TextCalendar.pryear() stopped emitting a superfluous newline following a year’s calendar. This builds on a patch from Xiang Zhang.
