# Python 3.7.0 alpha 1 / library / builtin or extension class help output carries constructor signature

[bpo-29338](https://bugs.python.org/issue?@action=redirect&bpo=29338): For a builtin or extension class, the help output now carries the constructor signature whenever __text_signature__ is supplied for that class.
