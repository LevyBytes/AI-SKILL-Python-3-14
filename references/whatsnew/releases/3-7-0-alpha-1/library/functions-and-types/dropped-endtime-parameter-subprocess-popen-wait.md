# Python 3.7.0 alpha 1 / library / dropped endtime parameter subprocess popen wait

[bpo-20572](https://bugs.python.org/issue?@action=redirect&bpo=20572): Dropped the endtime parameter from subprocess.Popen.wait. That parameter had been deprecated since 3.4 and went undocumented before then.
