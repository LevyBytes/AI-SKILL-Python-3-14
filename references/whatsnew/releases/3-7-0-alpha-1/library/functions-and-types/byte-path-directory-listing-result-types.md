# Python 3.7.0 alpha 1 / library / os listdir os scandir produce bytes names whenever they called bytes like

[bpo-30879](https://bugs.python.org/issue?@action=redirect&bpo=30879): os.listdir() and os.scandir() now produce bytes names whenever they are called with a bytes-like argument.
