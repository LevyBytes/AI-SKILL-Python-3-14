# Python 3.7.0 alpha 1 / library / datetime

[bpo-29953](https://bugs.python.org/issue?@action=redirect&bpo=29953): Memory leaks in the replace() method on datetime and time objects, occurring when an out-of-bound fold argument was passed, were corrected.

[bpo-28752](https://bugs.python.org/issue?@action=redirect&bpo=28752): Brought back the __reduce__() methods belonging to datetime objects.
