# Python 3.7.0 alpha 1 / library / urllib parse quote follows rfc means falls among characters left unquoted

[bpo-16285](https://bugs.python.org/issue?@action=redirect&bpo=16285): urllib.parse.quote now follows RFC 3986, which means ‘~’ falls among the characters left unquoted by default. Christian Theune and Ratnadeep Debnath provided the patch.
