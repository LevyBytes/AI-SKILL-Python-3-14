# Python 3.7.0 alpha 1 / library / pathlib

[bpo-28229](https://bugs.python.org/issue?@action=redirect&bpo=28229): The lzma module gained pathlib support.

[bpo-28225](https://bugs.python.org/issue?@action=redirect&bpo=28225): The bz2 module gained pathlib support. Ethan Furman supplied the initial patch.

[bpo-28227](https://bugs.python.org/issue?@action=redirect&bpo=28227): The gzip module gained pathlib support. Ethan Furman provided the patch.

[bpo-28228](https://bugs.python.org/issue?@action=redirect&bpo=28228): The imghdr module gained pathlib support.

[bpo-29694](https://bugs.python.org/issue?@action=redirect&bpo=29694): A race in pathlib mkdir using the parents=True flag was corrected. Armin Rigo provided the patch.
