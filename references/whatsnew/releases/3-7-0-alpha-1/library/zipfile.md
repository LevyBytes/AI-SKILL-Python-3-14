# Python 3.7.0 alpha 1 / library / zipfile

[bpo-28115](https://bugs.python.org/issue?@action=redirect&bpo=28115): The zipfile module's command-line interface now relies on argparse. Long-option support was added.

[bpo-28231](https://bugs.python.org/issue?@action=redirect&bpo=28231): Path-like objects for external paths are now accepted by the zipfile module.
