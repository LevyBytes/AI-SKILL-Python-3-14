# Python 3.7.0 alpha 1 / c api / every stable api extension introduced after python reachable only

[bpo-29058](https://bugs.python.org/issue?@action=redirect&bpo=29058): Every stable API extension introduced after Python 3.2 is now reachable only once Py_LIMITED_API equals the PY_VERSION_HEX value for the earliest Python version that carries that API.
