# Python 3.7.0 alpha 1 / build / non osx unix platforms full copy libffi no longer shipped

[bpo-27979](https://bugs.python.org/issue?@action=redirect&bpo=27979): On non-OSX UNIX platforms a full copy of libffi is no longer shipped for building _ctypes. Building _ctypes on those platforms now demands that a copy of libffi already be installed.
