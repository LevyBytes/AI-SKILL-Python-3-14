# Python 3.7.0 alpha 4 / c api / undocumented c api covering ordereddict pulled out limited c

[bpo-29084](https://bugs.python.org/issue?@action=redirect&bpo=29084): The undocumented C API covering OrderedDict has been pulled out of the limited C API. Its inclusion was accidental, and it had in fact never functioned within the limited C API at all.
