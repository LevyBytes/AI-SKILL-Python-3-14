# Python 3.7.0 alpha 4 / core and builtins / warnings

[bpo-31975](https://bugs.python.org/issue?@action=redirect&bpo=31975): A "default::DeprecationWarning:__main__" entry now heads the default warning filter list, which means deprecation warnings show up again by default in single-file scripts as well as at the interactive prompt.
