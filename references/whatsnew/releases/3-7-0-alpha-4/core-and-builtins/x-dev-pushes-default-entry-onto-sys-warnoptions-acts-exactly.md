# Python 3.7.0 alpha 4 / core and builtins / x dev pushes default entry onto sys warnoptions acts exactly

[bpo-32230](https://bugs.python.org/issue?@action=redirect&bpo=32230): `-X dev` now pushes a `'default'` entry onto sys.warnoptions, so it acts exactly as though `-Wdefault` had actually been passed at the command line.
