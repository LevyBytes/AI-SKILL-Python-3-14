# Python 3.7.0 alpha 4 / library / importlib resources

[bpo-32248](https://bugs.python.org/issue?@action=redirect&bpo=32248): Introduce `importlib.abc.ResourceReader` — an ABC letting loaders deliver one unified API for reading resources held inside packages. Also bring in [`importlib.resources`](https://docs.python.org/3.14/library/importlib.resources.html#module-importlib.resources) as the port of `importlib_resources`.
