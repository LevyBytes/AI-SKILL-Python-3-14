# Python 3.7.0 alpha 4 / library / pydoc

[bpo-32265](https://bugs.python.org/issue?@action=redirect&bpo=32265): Every class and static method of the builtin types is now classified correctly by inspect.classify_class_attrs() and grouped within pydoc output. types.ClassMethodDescriptorType was added for unbound class methods belonging to builtin types.
