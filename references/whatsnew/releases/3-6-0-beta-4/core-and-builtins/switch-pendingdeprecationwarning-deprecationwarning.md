# Python 3.6.0 beta 4 / core and builtins / switch pendingdeprecationwarning deprecationwarning

[bpo-27243](https://bugs.python.org/issue?@action=redirect&bpo=27243): Switch PendingDeprecationWarning -> DeprecationWarning. The issue settled that an __aiter__ that returns an awaitable ought to yield PendingDeprecationWarning in 3.5 and DeprecationWarning in 3.6.
