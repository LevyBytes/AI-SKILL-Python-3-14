# Python 3.6.0 beta 4 / core and builtins / functions and types

[bpo-27100](https://bugs.python.org/issue?@action=redirect&bpo=27100): The with-statement now looks for __enter__ ahead of looking for __exit__. The result is clearer error messages when both methods are absent. Jonathan Ellington wrote the patch.
