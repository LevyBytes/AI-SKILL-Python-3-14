# Python 3.6.0 beta 4 / library / gettext

[bpo-28563](https://bugs.python.org/issue?@action=redirect&bpo=28563): Repaired a potential DoS and arbitrary code execution while processing plural form selections within the gettext module. The expression parser now backs the exact syntax that GNU gettext supports.
