# Python 3.9.0 alpha 6 / core and builtins / collections and iteration

[bpo-39481](https://bugs.python.org/issue?@action=redirect&bpo=39481): Carry out PEP 585. That enables list[int], tuple[str, ?], and so on.

[bpo-37207](https://bugs.python.org/issue?@action=redirect&bpo=37207): Make `list()` calls quicker by adopting the [**PEP 590**](https://peps.python.org/pep-0590/) `vectorcall` calling convention. Mark Shannon supplied the patch.
