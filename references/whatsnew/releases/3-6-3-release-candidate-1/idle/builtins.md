# Python 3.6.3 release candidate 1 / idle / builtins

[bpo-19903](https://bugs.python.org/issue?@action=redirect&bpo=19903): IDLE: Have Calltips rely on `inspect.signature` rather than `inspect.getfullargspec`. The result sharpens calltips for builtins that were moved onto Argument Clinic. Louie Lu wrote the patch.
