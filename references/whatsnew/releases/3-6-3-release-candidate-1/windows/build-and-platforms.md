# Python 3.6.3 release candidate 1 / windows / build and platforms

[bpo-31340](https://bugs.python.org/issue?@action=redirect&bpo=31340): Switched the build over to MSVC v141 (which ships alongside Visual Studio 2017)

[bpo-30581](https://bugs.python.org/issue?@action=redirect&bpo=30581): os.cpu_count() will now hand back the accurate processor count under Windows in cases where more than 64 logical processors are present.
