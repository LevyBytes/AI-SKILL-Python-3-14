# Python 3.13.0 alpha 6 / library / math

[gh-73468](https://github.com/python/cpython/issues/73468): Added the new [`math.fma()`](https://docs.python.org/3.14/library/math.html#math.fma) function, which wraps C99's `fma()` operation, the fused multiply-add. Mark Dickinson and Victor Stinner supplied the patch.
