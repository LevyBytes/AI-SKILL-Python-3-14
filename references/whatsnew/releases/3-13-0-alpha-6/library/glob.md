# Python 3.13.0 alpha 6 / library / glob

[gh-117337](https://github.com/python/cpython/issues/117337): Mark the undocumented `glob.glob0()` and `glob.glob1()` functions as deprecated. Reach for [`glob.glob()`](https://docs.python.org/3.14/library/glob.html#glob.glob) instead and hand a directory to its *root_dir* argument.
