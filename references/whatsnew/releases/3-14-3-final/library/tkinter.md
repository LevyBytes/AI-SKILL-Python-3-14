# Python 3.14.3 final / library / tkinter

[gh-143310](https://github.com/python/cpython/issues/143310): [`tkinter`](https://docs.python.org/3.14/library/tkinter.html#module-tkinter): a crash arising when a Python [`list`](https://docs.python.org/3.14/library/stdtypes.html#list) is mutated while it is being converted into a Tcl object (for example, when a Tcl variable is set) is now fixed. Bénédikt Tran supplied the patch.
