# Python 3.5.5 release candidate 1 / library / binary

[bpo-32072](https://bugs.python.org/issue?@action=redirect&bpo=32072): Addressed several binary-plist problems: bytearray saving is fixed; objects that are identical are now stored just once; references that are equal load back as identical objects; and saving plus loading of recursive data structures is now supported.
