# Python 3.5.5 release candidate 1 / security / numeric behavior

[bpo-30657](https://bugs.python.org/issue?@action=redirect&bpo=30657): Repaired a possible integer overflow inside PyBytes_DecodeEscape, [**CVE 2017-1000158**](https://www.cve.org/CVERecord?id=CVE-2017-1000158). Jay Bosamiya wrote the original patch, and Miro Hrončok rebased it onto Python 3.
