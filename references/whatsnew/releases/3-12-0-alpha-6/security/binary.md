# Python 3.12.0 alpha 6 / security / binary

[gh-101727](https://github.com/python/cpython/issues/101727): The OpenSSL version baked into the Windows and macOS binary release builds was bumped to 1.1.1t, addressing [**CVE 2023-0286**](https://www.cve.org/CVERecord?id=CVE-2023-0286), [**CVE 2022-4303**](https://www.cve.org/CVERecord?id=CVE-2022-4303), and [**CVE 2022-4303**](https://www.cve.org/CVERecord?id=CVE-2022-4303) following [the OpenSSL 2023-02-07 security advisory](https://openssl-library.org/news/secadv/20230207.txt).
