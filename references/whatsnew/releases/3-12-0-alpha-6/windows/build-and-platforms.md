# Python 3.12.0 alpha 6 / windows / build and platforms

[gh-102344](https://github.com/python/cpython/issues/102344): Build `winreg.QueryValue` on top of `QueryValueEx`, and `winreg.SetValue` on top of `SetValueEx`. Max Bachmann authored this change.

[gh-101881](https://github.com/python/cpython/issues/101881): Bring the os.get_blocking() and os.set_blocking() functions to Windows.

[gh-101763](https://github.com/python/cpython/issues/101763): Bump the libffi copy shipped with Windows installs to 3.4.4.

[gh-101759](https://github.com/python/cpython/issues/101759): Move the Windows installer up to SQLite 3.40.1.
