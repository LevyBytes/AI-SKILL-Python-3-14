# Python 3.12.0 alpha 6 / library / hashlib

[gh-99108](https://github.com/python/cpython/issues/99108): The built-in extension modules supplying [`hashlib`](https://docs.python.org/3.14/library/hashlib.html#module-hashlib) SHA2 algorithms when OpenSSL does not now reside in one internal `_sha2` module rather than the separate `_sha256` and `_sha512` modules.
