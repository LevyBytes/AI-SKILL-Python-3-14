# Python 3.14.0 alpha 1 / library / sqlite3

[gh-118924](https://github.com/python/cpython/issues/118924): Strip `version` and `version_info` from [`sqlite3`](https://docs.python.org/3.14/library/sqlite3.html#module-sqlite3). Hugo van Kemenade wrote the patch.

[gh-118928](https://github.com/python/cpython/issues/118928): Forbid pairing a sequence of parameters with named placeholders inside [`sqlite3`](https://docs.python.org/3.14/library/sqlite3.html#module-sqlite3) queries. Erlend E. Aasland authored the patch.
