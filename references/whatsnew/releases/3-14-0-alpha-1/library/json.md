# Python 3.14.0 alpha 1 / library / json

[gh-122873](https://github.com/python/cpython/issues/122873): Allow the [`json`](https://docs.python.org/3.14/library/json.html#module-json) module to run as a script through the [`-m`](https://docs.python.org/3.14/using/cmdline.html#cmdoption-m) switch: `python -m json`. Consult the [JSON command-line interface](https://docs.python.org/3.14/library/json.html#json-commandline) documentation. Patch by Trey Hunner.
