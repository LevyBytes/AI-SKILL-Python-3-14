# Python 3.14.0 alpha 1 / library / bdb

[gh-124552](https://github.com/python/cpython/issues/124552): Makes [`bdb`](https://docs.python.org/3.14/library/bdb.html#module-bdb)'s test for whether a breakpoint can sit in a frame more accurate. Because of this, needless events inside functions can be turned off.
