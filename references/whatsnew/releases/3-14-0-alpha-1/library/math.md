# Python 3.14.0 alpha 1 / library / math

[gh-121486](https://github.com/python/cpython/issues/121486): The [`math`](https://docs.python.org/3.14/library/math.html#module-math) functions [`isqrt()`](https://docs.python.org/3.14/library/math.html#math.isqrt), [`log()`](https://docs.python.org/3.14/library/math.html#math.log), [`log2()`](https://docs.python.org/3.14/library/math.html#math.log2) and [`log10()`](https://docs.python.org/3.14/library/math.html#math.log10) now accept integers above `2**2**32` on 32-bit platforms.
