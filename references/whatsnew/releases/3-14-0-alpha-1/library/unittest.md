# Python 3.14.0 alpha 1 / library / unittest

[gh-120388](https://github.com/python/cpython/issues/120388): Sharpen the warning text shown when a [`unittest`](https://docs.python.org/3.14/library/unittest.html#module-unittest) test method gives back a value that isn't `None`. The type of the returned object is now displayed, together with an optional asyncio-related hint.
