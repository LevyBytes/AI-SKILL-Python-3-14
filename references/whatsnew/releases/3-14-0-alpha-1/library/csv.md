# Python 3.14.0 alpha 1 / library / csv

[gh-113785](https://github.com/python/cpython/issues/113785): [`csv`](https://docs.python.org/3.14/library/csv.html#module-csv) now handles numeric fields that begin with an escape character correctly (when paired with [`csv.QUOTE_NONNUMERIC`](https://docs.python.org/3.14/library/csv.html#csv.QUOTE_NONNUMERIC) or [`csv.QUOTE_STRINGS`](https://docs.python.org/3.14/library/csv.html#csv.QUOTE_STRINGS)).
