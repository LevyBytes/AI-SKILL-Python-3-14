# Python 3.14.0 alpha 1 / library / asyncio

[gh-118894](https://github.com/python/cpython/issues/118894): The [`asyncio`](https://docs.python.org/3.14/library/asyncio.html#module-asyncio) REPL now offers the very same capabilities that PyREPL does.

[gh-124594](https://github.com/python/cpython/issues/124594): Every [`asyncio`](https://docs.python.org/3.14/library/asyncio.html#module-asyncio) REPL prompt now executes inside one shared [`context`](https://docs.python.org/3.14/library/contextvars.html#contextvars.Context). Bartosz Sławecki sent this in.
