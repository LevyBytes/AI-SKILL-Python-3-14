# Python 3.14.0 alpha 1 / windows / build and platforms

[gh-124487](https://github.com/python/cpython/issues/124487): Raises the OS and API level Windows demands up to Windows 10.

[gh-124609](https://github.com/python/cpython/issues/124609): Repair `_Py_ThreadId` for Windows builds produced with MinGW. Patch by Tony Roberts.

[gh-123418](https://github.com/python/cpython/issues/123418): The Windows build now relies on OpenSSL 3.0.15.

[gh-123476](https://github.com/python/cpython/issues/123476): On Windows platforms, add support for `socket.TCP_QUICKACK`.

[gh-122573](https://github.com/python/cpython/issues/122573): CPython's Windows build now demands 3.10 or a newer version.

[gh-111201](https://github.com/python/cpython/issues/111201): Bring the new pyrepl to Windows

[gh-79846](https://github.com/python/cpython/issues/79846): Causes `ssl.create_default_context()` to disregard invalid certificates found in the Windows certificate store
