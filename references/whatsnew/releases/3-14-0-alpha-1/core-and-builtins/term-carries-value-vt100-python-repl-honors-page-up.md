# Python 3.14.0 alpha 1 / core and builtins / term carries value vt100 python repl honors page up

[gh-124027](https://github.com/python/cpython/issues/124027): When `$TERM` carries the value `vt100`, the Python REPL now honors the `<page up>`, `<page down>`, and `<delete>` keys.
