# Python 3.14.0 alpha 1 / documentation / contextvars

[gh-124872](https://github.com/python/cpython/issues/124872): Definitions for [context](https://docs.python.org/3.14/glossary.html#term-context), [current context](https://docs.python.org/3.14/glossary.html#term-current-context), and [context management protocol](https://docs.python.org/3.14/glossary.html#term-context-management-protocol) are added, related definitions are aligned for consistency, and the documentation for [`contextvars.Context`](https://docs.python.org/3.14/library/contextvars.html#contextvars.Context) is broadened.
