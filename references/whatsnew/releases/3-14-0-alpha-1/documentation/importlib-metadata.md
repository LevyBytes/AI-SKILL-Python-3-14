# Python 3.14.0 alpha 1 / documentation / importlib metadata

[gh-125018](https://github.com/python/cpython/issues/125018): The [`importlib.metadata`](https://docs.python.org/3.14/library/importlib.metadata.html#module-importlib.metadata) documentation now carries semantic cross-reference targets for its major documented APIs. As a result, intersphinx references such as [`importlib.metadata.version()`](https://docs.python.org/3.14/library/importlib.metadata.html#importlib.metadata.version) will resolve as one would expect.
