# Python 3.12.0 alpha 3 / library / typing

[gh-99957](https://github.com/python/cpython/issues/99957): Provide a `frozen_default` parameter for [`typing.dataclass_transform()`](https://docs.python.org/3.14/library/typing.html#typing.dataclass_transform).

[gh-99382](https://github.com/python/cpython/issues/99382): Validate the argument count during substitution into user generics that contain a [`TypeVarTuple`](https://docs.python.org/3.14/library/typing.html#typing.TypeVarTuple) plus one or more [`TypeVar`](https://docs.python.org/3.14/library/typing.html#typing.TypeVar).

[gh-99379](https://github.com/python/cpython/issues/99379): Correct substitution of a [`ParamSpec`](https://docs.python.org/3.14/library/typing.html#typing.ParamSpec) trailed by a [`TypeVarTuple`](https://docs.python.org/3.14/library/typing.html#typing.TypeVarTuple) within generic aliases.

[gh-99344](https://github.com/python/cpython/issues/99344): Correct the joint substitution of [`TypeVarTuple`](https://docs.python.org/3.14/library/typing.html#typing.TypeVarTuple) alongside [`ParamSpec`](https://docs.python.org/3.14/library/typing.html#typing.ParamSpec) inside user generics.
