# Python 3.12.0 alpha 3 / core and builtins / stdtypes

[bpo-45026](https://bugs.python.org/issue?@action=redirect&bpo=45026): Tune the [`range`](https://docs.python.org/3.14/library/stdtypes.html#range) object iterator. It now occupies less space, iterates ranges holding large numbers more quickly, pickles into smaller output, and unpickles faster.
