# Python 3.14.1 final / tools demos / modules

[gh-141692](https://github.com/python/cpython/issues/141692): Every slice of an iOS XCframework now holds a `lib` folder carrying a symlink to the libpython dylib. With this, binary modules can be built for iOS through dynamic libreary linking rather than Framework linking.
