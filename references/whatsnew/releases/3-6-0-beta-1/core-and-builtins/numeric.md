# Python 3.6.0 beta 1 / core and builtins / numeric

[bpo-27936](https://bugs.python.org/issue?@action=redirect&bpo=27936): round() used to take a second None argument for some types but not others. That inconsistency is gone now that None is accepted for every numeric type.
