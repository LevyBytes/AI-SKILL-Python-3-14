# Python 3.6.0 beta 1 / core and builtins / platforms must provide long long

[bpo-27961](https://bugs.python.org/issue?@action=redirect&bpo=27961): Platforms must now provide `long long`. Since Python hasn’t built without `long long` in years, this merely formalizes the status quo.
