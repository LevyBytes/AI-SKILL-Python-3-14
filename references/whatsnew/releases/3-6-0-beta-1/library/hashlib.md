# Python 3.6.0 beta 1 / library / hashlib

[bpo-26470](https://bugs.python.org/issue?@action=redirect&bpo=26470): Port the ssl and hashlib module across to OpenSSL 1.1.0.

[bpo-16113](https://bugs.python.org/issue?@action=redirect&bpo=16113): The hashlib module gained SHA-3 and SHAKE support.

- A tautological-pointer-compare warning emitted from _scproxy.c was removed.

[bpo-27928](https://bugs.python.org/issue?@action=redirect&bpo=27928): scrypt (a password-based key derivation function) joined the hashlib module (needs OpenSSL 1.1.0).
