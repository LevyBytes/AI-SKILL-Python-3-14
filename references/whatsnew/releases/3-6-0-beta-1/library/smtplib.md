# Python 3.6.0 beta 1 / library / smtplib

[bpo-28022](https://bugs.python.org/issue?@action=redirect&bpo=28022): Mark ssl-related arguments as deprecated, preferring SSLContext. The deprecation covers manual creation of SSLSocket plus certfile/keyfile (or similar) across ftplib, httplib, imaplib, smtplib, poplib and urllib.
