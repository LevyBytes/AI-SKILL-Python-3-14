# Python 3.6.0 beta 1 / library / imports and modules

[bpo-11734](https://bugs.python.org/issue?@action=redirect&bpo=11734): The struct module gained IEEE 754 half-precision float support. Eli Stevens supplied the underlying patch.

[bpo-25596](https://bugs.python.org/issue?@action=redirect&bpo=25596): The glob module's glob() and iglob() functions were optimized and now run roughly 3–6 times faster.

[bpo-17941](https://bugs.python.org/issue?@action=redirect&bpo=17941): Give collections.namedtuple() a *module* parameter.
