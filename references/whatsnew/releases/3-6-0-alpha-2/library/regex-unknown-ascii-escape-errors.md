# Python 3.6.0 alpha 2 / library / inside regular expressions unknown escapes built ascii letter errors

[bpo-27030](https://bugs.python.org/issue?@action=redirect&bpo=27030): Inside regular expressions, unknown escapes built from `'\'` and an ASCII letter are now errors. The re.LOCALE flag may now pair only with bytes patterns.
