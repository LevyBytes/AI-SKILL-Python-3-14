# Python 3.6.0 alpha 2 / library / inspect

[bpo-19611](https://bugs.python.org/issue?@action=redirect&bpo=19611): [`inspect`](https://docs.python.org/3.14/library/inspect.html#module-inspect) now describes the implicit `.0` parameters that the compiler creates for comprehension and generator-expression scopes as though they were positional-only parameters named `implicit0`. Jelle Zijlstra wrote the patch.
