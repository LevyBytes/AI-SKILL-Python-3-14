# Python 3.6.0 alpha 2 / windows / build and platforms

[bpo-27064](https://bugs.python.org/issue?@action=redirect&bpo=27064): Python 3 is now the default for the py.exe launcher. When run interactively, the Windows launcher `py.exe` will no longer favor an installed Python 2 over Python 3 by default.
