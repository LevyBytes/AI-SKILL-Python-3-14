# Python 3.6.0 alpha 2 / security / smtplib

[bpo-26556](https://bugs.python.org/issue?@action=redirect&bpo=26556): Moved expat up to 2.1.1, which resolves [**CVE 2015-1283**](https://www.cve.org/CVERecord?id=CVE-2015-1283).

- Closed a TLS stripping vulnerability inside smtplib, [**CVE 2016-0772**](https://www.cve.org/CVERecord?id=CVE-2016-0772). Team Oststrom reported it.
