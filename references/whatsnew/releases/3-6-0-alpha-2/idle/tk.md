# Python 3.6.0 alpha 2 / idle / tk

[bpo-24759](https://bugs.python.org/issue?@action=redirect&bpo=24759): IDLE now depends on tk 8.5 plus the availability of ttk widgets. The now-pointless tk version checks and code for older versions were deleted. A test for the IDLE syntax colorizer was added.
