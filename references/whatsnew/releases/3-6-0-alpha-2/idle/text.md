# Python 3.6.0 alpha 2 / idle / text

[bpo-5124](https://bugs.python.org/issue?@action=redirect&bpo=5124): On X11, pasting while text is selected now overwrites that selection. This mirrors how paste behaves on Windows, Mac, the majority of modern Linux apps, and ttk widgets. Serhiy Storchaka wrote the original patch.

[bpo-27117](https://bugs.python.org/issue?@action=redirect&bpo=27117): Get the colorizer htest and turtledemo functioning under dark themes. The logic that sets text widget colors moves into a fresh function.
