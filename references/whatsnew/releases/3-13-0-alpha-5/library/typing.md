# Python 3.13.0 alpha 5 / library / typing

[gh-116127](https://github.com/python/cpython/issues/116127): [`typing`](https://docs.python.org/3.14/library/typing.html#module-typing): roll out [**PEP 705**](https://peps.python.org/pep-0705/), which brings [`typing.ReadOnly`](https://docs.python.org/3.14/library/typing.html#typing.ReadOnly) support to [`typing.TypedDict`](https://docs.python.org/3.14/library/typing.html#typing.TypedDict).

[gh-116325](https://github.com/python/cpython/issues/116325): [`typing`](https://docs.python.org/3.14/library/typing.html#module-typing): throw [`SyntaxError`](https://docs.python.org/3.14/library/exceptions.html#SyntaxError) rather than [`AttributeError`](https://docs.python.org/3.14/library/exceptions.html#AttributeError) for forward references given as empty strings.
