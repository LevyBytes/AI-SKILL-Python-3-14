# Python 3.13.0 alpha 5 / library / linecache

[bpo-42125](https://bugs.python.org/issue?@action=redirect&bpo=42125): linecache: obtain the module name from `__spec__` where present. With this, source for the `__main__` module is retrievable even under a custom loader.
