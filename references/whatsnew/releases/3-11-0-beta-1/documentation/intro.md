# Python 3.11.0 beta 1 / documentation / intro

[bpo-46962](https://bugs.python.org/issue?@action=redirect&bpo=46962): Every docstring inside code snippets is now enclosed in [`PyDoc_STR`](https://docs.python.org/3.14/c-api/intro.html#c.PyDoc_STR), honoring the guidance of [**PEP 7’s Documentation Strings paragraph**](https://peps.python.org/pep-0007/#documentation-strings). Oleg Iarygin authored the patch.
