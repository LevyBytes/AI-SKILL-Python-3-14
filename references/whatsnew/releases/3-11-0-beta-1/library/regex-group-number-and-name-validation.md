# Python 3.11.0 beta 1 / library / tighter rules coming numerical group references plus group names

[gh-91760](https://github.com/python/cpython/issues/91760): Tighter rules are coming for numerical group references plus group names in regular expressions. For the time being, group references and group names raise a deprecation warning, since they turn into errors in upcoming Python releases.
