# Python 3.11.0 beta 1 / library / warnings

[gh-91230](https://github.com/python/cpython/issues/91230): [`warnings.catch_warnings()`](https://docs.python.org/3.14/library/warnings.html#warnings.catch_warnings) will now take the arguments belonging to [`warnings.simplefilter()`](https://docs.python.org/3.14/library/warnings.html#warnings.simplefilter), giving a tighter way to silence warnings locally or turn them into errors.
