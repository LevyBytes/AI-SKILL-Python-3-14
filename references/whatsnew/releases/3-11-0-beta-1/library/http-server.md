# Python 3.11.0 beta 1 / library / http server

[bpo-46285](https://bugs.python.org/issue?@action=redirect&bpo=46285): Introduce the `-p`/`--protocol` command-line option to the [`http.server`](https://docs.python.org/3.14/library/http.server.html#module-http.server) module, naming the HTTP version that the server conforms to (you can now start an HTTP/1.1 conformant server straight from the command-line interface of the `http.server` module). Géry Ogam authored the patch.
