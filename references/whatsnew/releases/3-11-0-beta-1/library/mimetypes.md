# Python 3.11.0 beta 1 / library / mimetypes

[gh-68966](https://github.com/python/cpython/issues/68966): The `mailcap` module is deprecated now and is slated for removal in Python 3.13. Refer to [**PEP 594**](https://peps.python.org/pep-0594/) for the reasoning and to the [`mimetypes`](https://docs.python.org/3.14/library/mimetypes.html#module-mimetypes) module as a replacement. Victor Stinner authored the patch.

[bpo-45639](https://bugs.python.org/issue?@action=redirect&bpo=45639): The entries `image/avif` and `image/webp` joined [`mimetypes`](https://docs.python.org/3.14/library/mimetypes.html#module-mimetypes).
