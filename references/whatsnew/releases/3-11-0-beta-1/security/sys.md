# Python 3.11.0 beta 1 / security / sys

[gh-57684](https://github.com/python/cpython/issues/57684): Introduce the [`-P`](https://docs.python.org/3.14/using/cmdline.html#cmdoption-P) command line option together with the [`PYTHONSAFEPATH`](https://docs.python.org/3.14/using/cmdline.html#envvar-PYTHONSAFEPATH) environment variable, which keep a possibly unsafe path from being prepended to [`sys.path`](https://docs.python.org/3.14/library/sys.html#sys.path). Victor Stinner authored the patch.
