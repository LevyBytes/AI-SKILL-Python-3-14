# Python 3.12.0 beta 1 / c api / unicode

[gh-98836](https://github.com/python/cpython/issues/98836): Broaden the formatting choices ([`PyUnicode_FromFormat()`](https://docs.python.org/3.14/c-api/unicode.html#c.PyUnicode_FromFormat) and [`PyUnicode_FromFormatV()`](https://docs.python.org/3.14/c-api/unicode.html#c.PyUnicode_FromFormatV) now handle left aligning, octals, uppercase hexadecimals, `intmax_t`, `ptrdiff_t`, `wchar_t` C strings, plus variable width and precision).
