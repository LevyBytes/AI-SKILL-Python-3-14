# Python 3.12.0 beta 1 / library / turtle

[gh-88773](https://github.com/python/cpython/issues/88773): Introduced [`turtle.teleport()`](https://docs.python.org/3.14/library/turtle.html#turtle.teleport) within the [`turtle`](https://docs.python.org/3.14/library/turtle.html#module-turtle) module so a turtle can jump to another point without drawing a line, whether visible or invisible. Liam Gersten supplied the patch.
