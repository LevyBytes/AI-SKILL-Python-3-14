# Python 3.12.0 beta 1 / library / logging

[gh-103357](https://github.com/python/cpython/issues/103357): Wired up support for the [`logging.Formatter`](https://docs.python.org/3.14/library/logging.html#logging.Formatter) `defaults` parameter within [`logging.config.dictConfig()`](https://docs.python.org/3.14/library/logging.config.html#logging.config.dictConfig) and [`logging.config.fileConfig()`](https://docs.python.org/3.14/library/logging.config.html#logging.config.fileConfig). Bar Harel authored the patch.
