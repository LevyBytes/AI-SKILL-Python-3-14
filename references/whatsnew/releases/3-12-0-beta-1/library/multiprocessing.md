# Python 3.12.0 beta 1 / library / multiprocessing

[bpo-17258](https://bugs.python.org/issue?@action=redirect&bpo=17258): For authenticating connections between processes, [`multiprocessing`](https://docs.python.org/3.14/library/multiprocessing.html#module-multiprocessing) can now rely on HMAC variants tougher than the HMAC-MD5 it was previously limited to.
