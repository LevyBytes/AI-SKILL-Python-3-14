# Python 3.12.0 beta 1 / library / compiler and parser

[bpo-46797](https://bugs.python.org/issue?@action=redirect&bpo=46797): The names `ast.Num`, `ast.Bytes`, `ast.Str`, `ast.NameConstant` and `ast.Ellipsis` now trigger deprecation warnings. Their deprecation was recorded in the docs as far back as Python 3.8, with removal slated for Python 3.14.
