# Python 3.12.0 beta 1 / library / let tkinter canvas coords take flattened arguments

[gh-94473](https://github.com/python/cpython/issues/94473): Let `tkinter.Canvas.coords()` take flattened arguments. Beyond `x1, y1, x2, y2, ...` and `[x1, y1, x2, y2, ...]`, it now also handles `(x1, y1), (x2, y2), ...` and `[(x1, y1), (x2, y2), ...]`.
