# Python 3.12.0 beta 1 / security / hashlib

[gh-99108](https://github.com/python/cpython/issues/99108): Replace the bundled [`hashlib`](https://docs.python.org/3.14/library/hashlib.html#module-hashlib) SHA3 code with a verified build sourced from the `HACL*` project. It applies whenever OpenSSL is missing or does not provide SHA3.
