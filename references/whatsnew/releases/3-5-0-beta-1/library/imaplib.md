# Python 3.5.0 beta 1 / library / imaplib

[bpo-21800](https://bugs.python.org/issue?@action=redirect&bpo=21800): RFC 5161 (enable) and RFC 6855 (utf8/internationalized email) are now supported by imaplib, which also encodes non-ASCII usernames and passwords to UTF8 automatically.
