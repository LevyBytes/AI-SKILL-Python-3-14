# Python 3.5.0 beta 1 / library / email

[bpo-20098](https://bugs.python.org/issue?@action=redirect&bpo=20098): A new mangle_from policy option arrived for email, defaulting to True for compat32 but False under every other policy.

[bpo-24211](https://bugs.python.org/issue?@action=redirect&bpo=24211): RFC 6532 is now supported by the email library: headers may be generated with utf-8 rather than encoded words.
