# Python 3.5.0 beta 1 / library / compiler and parser

[bpo-23917](https://bugs.python.org/issue?@action=redirect&bpo=23917): Drop back to sequential compilation whenever ProcessPoolExecutor is absent. Claudiu Popa supplied the patch.

[bpo-24178](https://bugs.python.org/issue?@action=redirect&bpo=24178): The new "async with" syntax is now supported by asyncio.Lock, Condition, Semaphore, and BoundedSemaphore. Yury Selivanov contributed this.
