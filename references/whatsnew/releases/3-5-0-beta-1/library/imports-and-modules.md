# Python 3.5.0 beta 1 / library / imports and modules

[bpo-23973](https://bugs.python.org/issue?@action=redirect&bpo=23973): PEP 484: Add the typing module.

[bpo-20035](https://bugs.python.org/issue?@action=redirect&bpo=20035): Swapped the `tkinter._fix` module that set up the Tcl/Tk environment on Windows for a private function in the `_tkinter` module that leaves no permanent change to the environment.

[bpo-22955](https://bugs.python.org/issue?@action=redirect&bpo=22955): pickling is now supported by attrgetter, itemgetter and methodcaller objects in the operator module. They also gained a readable and evaluable repr. Josh Rosenberg's patch was the basis.
