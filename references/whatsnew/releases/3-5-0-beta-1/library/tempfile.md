# Python 3.5.0 beta 1 / library / tempfile

[bpo-24230](https://bugs.python.org/issue?@action=redirect&bpo=24230): bytes are now accepted by the tempfile module for the prefix, suffix and dir parameters, and bytes come back in those cases (mirroring the os module APIs).
