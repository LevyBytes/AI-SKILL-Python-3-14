# Python 3.6.0 beta 2 / core and builtins / collections and iteration

[bpo-28183](https://bugs.python.org/issue?@action=redirect&bpo=28183): Make dict iteration faster and tidier.

[bpo-28376](https://bugs.python.org/issue?@action=redirect&bpo=28376): The long range iterator type is now registered as an Iterator. Oren Milman wrote the patch.

[bpo-28086](https://bugs.python.org/issue?@action=redirect&bpo=28086): A single var-positional argument of a tuple subtype used to reach the C-defined function untouched. It is now turned into an exact tuple.
