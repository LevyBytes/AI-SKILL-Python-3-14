# Python 3.6.0 beta 2 / core and builtins / functions and types

[bpo-26182](https://bugs.python.org/issue?@action=redirect&bpo=26182): Emit a DeprecationWarning whenever the async and await keywords appear as a variable/attribute/class/function name.

[bpo-28376](https://bugs.python.org/issue?@action=redirect&bpo=28376): Building range_iterator instances by invoking the range_iterator type is now deprecated. Oren Milman wrote the patch.

[bpo-26906](https://bugs.python.org/issue?@action=redirect&bpo=26906): Looking up the special methods of an uninitialized type now triggers implicit initialization of that type rather than a failure.

[bpo-28214](https://bugs.python.org/issue?@action=redirect&bpo=28214): __set_name__ is now resolved on the class rather than on the instance.
