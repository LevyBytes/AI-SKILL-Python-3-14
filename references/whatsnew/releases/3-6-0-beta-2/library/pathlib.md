# Python 3.6.0 beta 2 / library / pathlib

[bpo-28225](https://bugs.python.org/issue?@action=redirect&bpo=28225): pathlib is now accepted by the bz2 module. Ethan Furman provided the initial patch.

[bpo-28228](https://bugs.python.org/issue?@action=redirect&bpo=28228): pathlib is now accepted by imghdr.

[bpo-28226](https://bugs.python.org/issue?@action=redirect&bpo=28226): pathlib is now accepted by compileall.
