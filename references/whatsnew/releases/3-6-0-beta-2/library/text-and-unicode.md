# Python 3.6.0 beta 2 / library / text and unicode

[bpo-28114](https://bugs.python.org/issue?@action=redirect&bpo=28114): Corrects a crash inside parse_envlist() whenever env holds byte strings. Eryk Sun wrote the patch.

[bpo-27897](https://bugs.python.org/issue?@action=redirect&bpo=27897): Headed off a possible crash in sqlite3.Connection.create_collation() when an invalid string-like object is handed in as a name. Xiang Zhang wrote the patch.
