# Python 3.11.0 alpha 2 / build / math

[bpo-45548](https://bugs.python.org/issue?@action=redirect&bpo=45548): The [`math`](https://docs.python.org/3.14/library/math.html#module-math) and [`cmath`](https://docs.python.org/3.14/library/cmath.html#module-cmath) code now depends on a C99-conformant `libm` and drops the shims that covered absent acosh, asinh, atanh, expm1, and log1p functions.
