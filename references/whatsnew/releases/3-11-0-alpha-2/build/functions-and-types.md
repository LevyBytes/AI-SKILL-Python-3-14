# Python 3.11.0 alpha 2 / build / functions and types

[bpo-45440](https://bugs.python.org/issue?@action=redirect&bpo=45440): Compiling Python now needs a C99 `<math.h>` header that supplies these functions: `copysign()`, `hypot()`, `isfinite()`, `isinf()`, `isnan()`, `round()`. Victor Stinner contributed the patch.
