# Python 3.11.0 alpha 2 / build / tests and documentation

[bpo-45221](https://bugs.python.org/issue?@action=redirect&bpo=45221): Corrected a regression around `LDFLAGS` and `CPPFLAGS` handling, where `argparse.parse_known_args()` might read an option as one of the built-in command line arguments — `-h` for help being one example.
