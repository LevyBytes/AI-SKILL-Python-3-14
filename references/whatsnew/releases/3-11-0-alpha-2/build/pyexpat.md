# Python 3.11.0 alpha 2 / build / pyexpat

[bpo-45570](https://bugs.python.org/issue?@action=redirect&bpo=45570): The obsolete macros `HAVE_EXPAT_CONFIG_H` and `USE_PYEXPAT_CAPI` are no longer defined by `pyexpat` and `_elementtree`. `expat_config.h` now carries the definition of `XML_POOR_ENTROPY`.
