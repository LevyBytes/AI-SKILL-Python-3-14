# Python 3.11.0 alpha 2 / library / argparse

[bpo-24444](https://bugs.python.org/issue?@action=redirect&bpo=24444): Repaired an error thrown during [`argparse`](https://docs.python.org/3.14/library/argparse.html#module-argparse) help rendering whenever an option’s help is set to one or more blank spaces, or whenever the *choices* arg is an empty container.
