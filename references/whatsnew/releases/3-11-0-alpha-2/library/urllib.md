# Python 3.11.0 alpha 2 / library / urllib

[bpo-40321](https://bugs.python.org/issue?@action=redirect&bpo=40321): Brings HTTP 308 redirect support to [`urllib`](https://docs.python.org/3.14/library/urllib.html#module-urllib). Consult [**RFC 7538**](https://datatracker.ietf.org/doc/html/rfc7538.html) for the specifics. Jochem Schulenklopper wrote the patch.
