# Python 3.11.0 alpha 2 / windows / venv

[bpo-45337](https://bugs.python.org/issue?@action=redirect&bpo=45337): venv now emits a warning whenever the new environment might have to be reached through a different path because of redirections, links, or junctions. It also performs correct installs or upgrades of components once the alternate path becomes necessary.
