# Python 3.11.0 alpha 2 / core and builtins / initialization python aborts whenever invalid x option encountered command

[bpo-45445](https://bugs.python.org/issue?@action=redirect&bpo=45445): Initialization of Python now aborts whenever an invalid [`-X`](https://docs.python.org/3.14/using/cmdline.html#cmdoption-X) option is encountered on the command line. Pablo Galindo wrote the patch.
