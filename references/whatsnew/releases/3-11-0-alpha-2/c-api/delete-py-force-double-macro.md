# Python 3.11.0 alpha 2 / c api / delete py force double macro

[bpo-45440](https://bugs.python.org/issue?@action=redirect&bpo=45440): Delete the `Py_FORCE_DOUBLE()` macro. The `Py_IS_INFINITY()` macro had relied on it. Victor Stinner contributed the patch.
