# Python 3.8.0 alpha 4 / core and builtins / text and unicode

[bpo-36549](https://bugs.python.org/issue?@action=redirect&bpo=36549): str.capitalize was changed so the leading character is now titlecased rather than uppercased.

[bpo-20844](https://bugs.python.org/issue?@action=redirect&bpo=20844): Addressed a Windows failure that could occur when running a script carrying an encoding cookie together with LF line endings.

[bpo-24214](https://bugs.python.org/issue?@action=redirect&bpo=24214): The UTF-8 incremental decoder now correctly honors the surrogatepass error handler.
