# Python 3.8.0 alpha 4 / library / fileinput

[bpo-1613500](https://bugs.python.org/issue?@action=redirect&bpo=1613500): When the constructor receives `inplace=True`, [`fileinput.FileInput`](https://docs.python.org/3.14/library/fileinput.html#fileinput.FileInput) now derives the output file mode from the input file mode instead of leaving it pinned to `'w'`.
