# Python 3.8.0 alpha 4 / library / datetime

[bpo-36004](https://bugs.python.org/issue?@action=redirect&bpo=36004): Two fresh alternate constructors, [`datetime.date.fromisocalendar()`](https://docs.python.org/3.14/library/datetime.html#datetime.date.fromisocalendar) and [`datetime.datetime.fromisocalendar()`](https://docs.python.org/3.14/library/datetime.html#datetime.datetime.fromisocalendar), build date objects out of an ISO year, week number and weekday, inverting each class's `isocalendar` method. Paul Ganssle authored the patch.
