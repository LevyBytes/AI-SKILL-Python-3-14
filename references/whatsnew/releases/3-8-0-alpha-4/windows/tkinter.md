# Python 3.8.0 alpha 4 / windows / tkinter

[bpo-36509](https://bugs.python.org/issue?@action=redirect&bpo=36509): Introduced a preset-iot layout aimed at Windows IoT ARM containers. UI pieces such as tkinter and IDLE are left out of this layout. It likewise omits the files needed for on-target builds, given that Windows ARM32 builds have to be cross-compiled with MSVC.
