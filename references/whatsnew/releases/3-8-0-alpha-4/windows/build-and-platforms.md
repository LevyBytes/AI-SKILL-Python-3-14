# Python 3.8.0 alpha 4 / windows / build and platforms

[bpo-35947](https://bugs.python.org/issue?@action=redirect&bpo=35947): Brought the latest libffi into cpython-source-deps. Switched _ctypes over to that current libffi on Windows.

[bpo-34060](https://bugs.python.org/issue?@action=redirect&bpo=34060): The test suite now reports system load while running on Windows. Ammar Askar wrote the patch, drawing on earlier work from Jeremy Kloth.

[bpo-31512](https://bugs.python.org/issue?@action=redirect&bpo=31512): Thanks to the Windows 10 Creators Update, users without elevation are able to create symlinks provided the machine has Developer Mode turned on.
