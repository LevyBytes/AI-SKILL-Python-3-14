# Python 3.8.0 alpha 4 / windows / compiler and parser

[bpo-35920](https://bugs.python.org/issue?@action=redirect&bpo=35920): Introduced platform.win32_edition() together with platform.win32_is_iot(). Cross-compilation of packages targeting Windows ARM32 is now supported. Tests not anticipated to succeed under Windows IoT Core ARM32 are skipped.
