# Python 3.10.0 alpha 6 / library / traceback

[bpo-43146](https://bugs.python.org/issue?@action=redirect&bpo=43146): None is now accepted by the single-argument forms of [`print_exception()`](https://docs.python.org/3.14/library/traceback.html#traceback.print_exception) plus [`format_exception()`](https://docs.python.org/3.14/library/traceback.html#traceback.format_exception).

[bpo-43146](https://bugs.python.org/issue?@action=redirect&bpo=43146): Address a fresh regression involving how None arguments are handled across [`traceback`](https://docs.python.org/3.14/library/traceback.html#module-traceback) module functions.
