# Python 3.10.0 alpha 1 / library / curses

[bpo-36982](https://bugs.python.org/issue?@action=redirect&bpo=36982): Where they exist, the ncurses extended color functions are now used so terminals offering 256 colors are supported, alongside a new [`curses.has_extended_color_support()`](https://docs.python.org/3.14/library/curses.html#curses.has_extended_color_support) function that reports whether the underlying ncurses library furnishes extended color support.
