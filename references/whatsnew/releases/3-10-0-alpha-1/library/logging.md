# Python 3.10.0 alpha 1 / library / logging

[bpo-40884](https://bugs.python.org/issue?@action=redirect&bpo=40884): Gave [`logging.Formatter`](https://docs.python.org/3.14/library/logging.html#logging.Formatter) a `defaults` parameter so that default values can be set for custom fields. Asaf Alon and Bar Harel wrote the patch.

[bpo-39385](https://bugs.python.org/issue?@action=redirect&bpo=39385): A fresh test assertion context-manager, `unittest.assertNoLogs()`, confirms that a given chunk of code produces no log messages through the logging module. Kit Yan Choi contributed it.
