# Python 3.10.0 alpha 1 / library / rlcompleter

[bpo-39314](https://bugs.python.org/issue?@action=redirect&bpo=39314): For functions taking no arguments, [`rlcompleter.Completer`](https://docs.python.org/3.14/library/rlcompleter.html#rlcompleter.Completer) together with the standard Python shell now adds the closing parenthesis. Rémi Lapeyre submitted the contributing patch.
