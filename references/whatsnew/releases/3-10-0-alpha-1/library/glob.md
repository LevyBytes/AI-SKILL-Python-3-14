# Python 3.10.0 alpha 1 / library / glob

[bpo-41043](https://bugs.python.org/issue?@action=redirect&bpo=41043): Corrected how [`glob()`](https://docs.python.org/3.14/library/glob.html#glob.glob) behaves in the stdlib so that the literal portion of a path now gets escaped reliably every time.

[bpo-38144](https://bugs.python.org/issue?@action=redirect&bpo=38144): Added the *root_dir* and *dir_fd* parameters to [`glob.glob()`](https://docs.python.org/3.14/library/glob.html#glob.glob).
