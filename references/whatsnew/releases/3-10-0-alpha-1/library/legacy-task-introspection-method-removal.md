# Python 3.10.0 alpha 1 / library / dropped asyncio task current task along asyncio task all tasks

[bpo-40967](https://bugs.python.org/issue?@action=redirect&bpo=40967): Dropped `asyncio.Task.current_task()` along with `asyncio.Task.all_tasks()`. Rémi Lapeyre submitted the contributing patch.
