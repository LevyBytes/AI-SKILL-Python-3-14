# Python 3.10.0 alpha 1 / library / asyncio runner

[bpo-41696](https://bugs.python.org/issue?@action=redirect&bpo=41696): Corrected how debug mode is handled within [`asyncio.run()`](https://docs.python.org/3.14/library/asyncio-runner.html#asyncio.run). You can therefore set `PYTHONASYNCIODEBUG` or `-X dev` to switch on asyncio debug mode while using `asyncio.run()`.
