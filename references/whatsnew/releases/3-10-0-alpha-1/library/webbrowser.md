# Python 3.10.0 alpha 1 / library / webbrowser

[bpo-40767](https://bugs.python.org/issue?@action=redirect&bpo=40767): On pure Wayland setups, [`webbrowser`](https://docs.python.org/3.14/library/webbrowser.html#module-webbrowser) now locates the default browser correctly by reading the WAYLAND_DISPLAY environment variable. Jérémy Attali submitted the contributing patch.
