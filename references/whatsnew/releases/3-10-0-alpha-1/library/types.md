# Python 3.10.0 alpha 1 / library / types

[bpo-41810](https://bugs.python.org/issue?@action=redirect&bpo=41810): [`types.EllipsisType`](https://docs.python.org/3.14/library/types.html#types.EllipsisType), [`types.NotImplementedType`](https://docs.python.org/3.14/library/types.html#types.NotImplementedType) and [`types.NoneType`](https://docs.python.org/3.14/library/types.html#types.NoneType) are back again, offering a new collection of types that static type checkers can readily interpret.
