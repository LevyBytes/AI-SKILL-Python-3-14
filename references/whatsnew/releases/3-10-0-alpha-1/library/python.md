# Python 3.10.0 alpha 1 / library / python

[bpo-41792](https://bugs.python.org/issue?@action=redirect&bpo=41792): Add an is_typeddict function to typing.py so a type can be checked for being a TypedDict class

There had been no way to perform that check before without resorting to private API. Consult the [relevant issue in python/typing](https://github.com/python/typing/issues/751).
