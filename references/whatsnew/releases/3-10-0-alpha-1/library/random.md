# Python 3.10.0 alpha 1 / library / random

[bpo-41773](https://bugs.python.org/issue?@action=redirect&bpo=41773): The docs now note that [`random.choices()`](https://docs.python.org/3.14/library/random.html#random.choices) rejects non-finite weights, and a [`ValueError`](https://docs.python.org/3.14/library/exceptions.html#ValueError) is raised whenever non-finite weights are passed.
