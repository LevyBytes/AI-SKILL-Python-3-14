# Python 3.10.0 alpha 1 / library / distutils

[bpo-40698](https://bugs.python.org/issue?@action=redirect&bpo=40698): The `distutils` upload now produces SHA2-256 and Blake2b-256 digests. The MD5 digest is omitted whenever the platform forbids MD5.
