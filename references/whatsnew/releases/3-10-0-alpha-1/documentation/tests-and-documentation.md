# Python 3.10.0 alpha 1 / documentation / tests and documentation

[bpo-41428](https://bugs.python.org/issue?@action=redirect&bpo=41428): Document [**PEP 604**](https://peps.python.org/pep-0604/) (Allow writing union types as `X | Y`).

[bpo-35293](https://bugs.python.org/issue?@action=redirect&bpo=35293): Clear the RemovedInSphinx40Warning that appeared while building the documentation. Donghee Na wrote the patch.

[bpo-40204](https://bugs.python.org/issue?@action=redirect&bpo=40204): Turn on the Sphinx 3.2 `c_allow_pre_v3` option and turn off the `c_warn_on_allowed_pre_v3` option, keeping the documentation usable with both Sphinx 2 and Sphinx 3.

[bpo-39883](https://bugs.python.org/issue?@action=redirect&bpo=39883): License the code, examples, and recipes throughout the Python documentation under the more permissive BSD0 license on top of the existing Python 2.0 license.

[bpo-37703](https://bugs.python.org/issue?@action=redirect&bpo=37703): Revised the documentation so it spells out the behaviour of gather.cancel() far more thoroughly.
