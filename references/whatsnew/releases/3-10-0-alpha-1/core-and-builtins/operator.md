# Python 3.10.0 alpha 1 / core and builtins / operator

[bpo-40824](https://bugs.python.org/issue?@action=redirect&bpo=40824): Unforeseen errors raised while calling the `__iter__` method are no longer hidden behind `TypeError` in the [`in`](https://docs.python.org/3.14/reference/expressions.html#in) operator and in the [`contains()`](https://docs.python.org/3.14/library/operator.html#operator.contains), [`indexOf()`](https://docs.python.org/3.14/library/operator.html#operator.indexOf) and [`countOf()`](https://docs.python.org/3.14/library/operator.html#operator.countOf) functions of the [`operator`](https://docs.python.org/3.14/library/operator.html#module-operator) module.
