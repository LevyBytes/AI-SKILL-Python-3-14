# Python 3.10.0 alpha 1 / core and builtins / numeric behavior

[bpo-26680](https://bugs.python.org/issue?@action=redirect&bpo=26680): For parity with float, the int type now offers the x.is_integer() method.

[bpo-41873](https://bugs.python.org/issue?@action=redirect&bpo=41873): Thanks to the `vectorcall` calling convention, invoking `float()` is now quicker. Dennis Sweeney sent the patch.
