# Python 3.10.0 alpha 1 / core and builtins / builtins

[bpo-41295](https://bugs.python.org/issue?@action=redirect&bpo=41295): Clears a CPython 3.8.4 regression in which declaring "__setattr__" across a multi-inheritance arrangement and walking up the hierarchy chain might break when builtins or extension types sat among the base types.
