# Python 3.10.0 alpha 1 / c api / functions and types

[bpo-40724](https://bugs.python.org/issue?@action=redirect&bpo=40724): Permit buffer slots to be declared within type specs.

[bpo-40679](https://bugs.python.org/issue?@action=redirect&bpo=40679): Repair a `_PyEval_EvalCode()` crash that occurred when the *qualname* argument was NULL.

[bpo-40703](https://bugs.python.org/issue?@action=redirect&bpo=40703): When the type's "__module__" attribute has been supplied through "Py_tp_members" or "Py_tp_getset", the PyType_FromSpec*() functions no longer clobber it.
