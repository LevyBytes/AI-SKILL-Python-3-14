# Python 3.10.0 alpha 1 / macos / build and platforms

[bpo-41557](https://bugs.python.org/issue?@action=redirect&bpo=41557): Bring the macOS installer up to SQLite 3.33.0.

[bpo-41100](https://bugs.python.org/issue?@action=redirect&bpo=41100): Repair the configure failure seen when building under macOS 11. Keep in mind that this Python release shipped not long after the first developer preview of macOS 11 (Big Sur), and other build-and-run problems on that developer preview remain known. Full support for Big Sur is anticipated in an upcoming Python 3.8.x bugfix release and in 3.9.0.

[bpo-40741](https://bugs.python.org/issue?@action=redirect&bpo=40741): Bring the macOS installer up to SQLite 3.32.3.

[bpo-41005](https://bugs.python.org/issue?@action=redirect&bpo=41005): corrected an XDG settings problem that kept macos from opening the browser via webbrowser.py

[bpo-40741](https://bugs.python.org/issue?@action=redirect&bpo=40741): Bring the macOS installer up to SQLite 3.32.2.
