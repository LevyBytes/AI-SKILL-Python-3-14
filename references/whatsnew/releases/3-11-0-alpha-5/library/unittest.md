# Python 3.11.0 alpha 5 / library / unittest

[bpo-45162](https://bugs.python.org/issue?@action=redirect&bpo=45162): The deprecated [`unittest`](https://docs.python.org/3.14/library/unittest.html#module-unittest) APIs that were dropped in 3.11a1 have been brought back for now, to be removed in 3.12 while external projects finish their cleanups.
