# Python 3.11.0 alpha 5 / library / pdb

[bpo-46434](https://bugs.python.org/issue?@action=redirect&bpo=46434): [`pdb`](https://docs.python.org/3.14/library/pdb.html#module-pdb) now copes gracefully with `help` whenever [`__doc__`](https://docs.python.org/3.14/reference/datamodel.html#module.__doc__) is absent, such as when running against pregenerated optimized `.pyc` files.
