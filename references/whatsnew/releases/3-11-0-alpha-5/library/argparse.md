# Python 3.11.0 alpha 5 / library / argparse

[bpo-46080](https://bugs.python.org/issue?@action=redirect&bpo=46080): Stop an exception during argparse help text generation that occurred when an [`argparse.BooleanOptionalAction`](https://docs.python.org/3.14/library/argparse.html#argparse.BooleanOptionalAction) argument carried a default of `argparse.SUPPRESS` along with specified `help`. Felix Fontein authored the patch.
