# Python 3.11.0 alpha 5 / c api / functions and types

[bpo-40170](https://bugs.python.org/issue?@action=redirect&bpo=40170): Relocate the private functions _Py_GetAllocatedBlocks() and _PyObject_DebugMallocStats() into the internal C API. Victor Stinner contributed the patch.

[bpo-46433](https://bugs.python.org/issue?@action=redirect&bpo=46433): The internal function _PyType_GetModuleByDef now handles inheritance arrangements that involve static types correctly.
