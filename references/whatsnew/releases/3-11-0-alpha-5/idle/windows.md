# Python 3.11.0 alpha 5 / idle / windows

[bpo-45296](https://bugs.python.org/issue?@action=redirect&bpo=45296): Make close, quit, and exit clearer in IDLE. Within the File menu, ?Close? now reads ?Close Window? (the current window) and ?Exit? now reads ?Exit IDLE? (which shuts every window). In Shell, ?quit()? and ?exit()? stand for ?close Shell?. When no further windows remain, that also exits IDLE.
