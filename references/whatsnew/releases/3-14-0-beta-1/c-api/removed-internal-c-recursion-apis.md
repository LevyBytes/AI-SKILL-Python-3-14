# Python 3.14.0 beta 1 / c api / removed internal c recursion apis

[gh-133079](https://github.com/python/cpython/issues/133079): Two undocumented APIs introduced in 3.13 — `Py_C_RECURSION_LIMIT` along with `PyThreadState.c_recursion_remaining` — have been dropped, with no deprecation period preceding their removal.
