# Python 3.14.0 beta 1 / library / getpass

[gh-77065](https://github.com/python/cpython/issues/77065): A keyword-only optional *echo_char* argument is now available on [`getpass.getpass()`](https://docs.python.org/3.14/library/getpass.html#getpass.getpass), giving optional on-screen feedback as keys are typed. Semyon Moroz wrote this patch.
