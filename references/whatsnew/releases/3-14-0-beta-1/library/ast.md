# Python 3.14.0 beta 1 / library / ast

[gh-133367](https://github.com/python/cpython/issues/133367): Extend the [`ast`](https://docs.python.org/3.14/library/ast.html#module-ast) command-line interface with the `--feature-version`, `--optimize`, and `--show-empty` options. Patch by Semyon Moroz.

[gh-133194](https://github.com/python/cpython/issues/133194): When an older *feature_version* is supplied, [`ast.parse()`](https://docs.python.org/3.14/library/ast.html#ast.parse) will now decline to parse the new [**PEP 758**](https://peps.python.org/pep-0758/) syntax.
