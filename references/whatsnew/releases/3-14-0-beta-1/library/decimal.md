# Python 3.14.0 beta 1 / library / decimal

[gh-53032](https://github.com/python/cpython/issues/53032): [`decimal.IEEEContext()`](https://docs.python.org/3.14/library/decimal.html#decimal.IEEEContext) is now exposed so that you can build contexts matching the IEEE 754 (2008) decimal interchange formats. Sergey B Kirpichev wrote this patch.

[gh-130664](https://github.com/python/cpython/issues/130664): Allow the `'_'` digit separator while formatting the integral portion of a [`Decimal`](https://docs.python.org/3.14/library/decimal.html#decimal.Decimal)'s value. Patch by Sergey B Kirpichev.
