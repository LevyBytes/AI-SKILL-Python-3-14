# Python 3.14.0 beta 1 / library / codecs

[gh-133036](https://github.com/python/cpython/issues/133036): [`codecs.open()`](https://docs.python.org/3.14/library/codecs.html#codecs.open) has now become deprecated. Reach for [`open()`](https://docs.python.org/3.14/library/functions.html#open) in its place. Contributed by Inada Naoki.
