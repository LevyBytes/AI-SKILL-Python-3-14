# Python 3.14.0 beta 1 / library / pdb

[gh-113081](https://github.com/python/cpython/issues/113081): Apply syntax highlighting to source code shown in [`pdb`](https://docs.python.org/3.14/library/pdb.html#module-pdb).

[gh-133349](https://github.com/python/cpython/issues/133349): Brought auto-indent to multi-line input within [`pdb`](https://docs.python.org/3.14/library/pdb.html#module-pdb).

[gh-133153](https://github.com/python/cpython/issues/133153): Refrain from completing [`pdb`](https://docs.python.org/3.14/library/pdb.html#module-pdb) commands while `pdb` is in `interact` mode.

[gh-124703](https://github.com/python/cpython/issues/124703): Return code `1` whenever the process is aborted from [`pdb`](https://docs.python.org/3.14/library/pdb.html#module-pdb).

[gh-93696](https://github.com/python/cpython/issues/93696): Corrected the breakpoint display fault affecting frozen modules within [`pdb`](https://docs.python.org/3.14/library/pdb.html#module-pdb).

[gh-121468](https://github.com/python/cpython/issues/121468): Introduce the [`pdb.set_trace_async()`](https://docs.python.org/3.14/library/pdb.html#pdb.set_trace_async) function so that [`await`](https://docs.python.org/3.14/reference/expressions.html#await) statements work in [`pdb`](https://docs.python.org/3.14/library/pdb.html#module-pdb).
