# Python 3.14.0 beta 1 / tests / tests and documentation

[gh-132678](https://github.com/python/cpython/issues/132678): Add `--prioritize` to `-m test`. With this option a user names which selected tests ought to run first, even when ordering is otherwise randomized. It comes in handy for the tests that take the longest.

[gh-131290](https://github.com/python/cpython/issues/131290): Tests within `Lib/test` can now run correctly as standalone scripts.
