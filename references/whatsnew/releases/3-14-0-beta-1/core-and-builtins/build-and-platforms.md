# Python 3.14.0 beta 1 / core and builtins / build and platforms

[gh-114809](https://github.com/python/cpython/issues/114809): Support is added for macOS multi-arch builds when the JIT is enabled

[gh-132942](https://github.com/python/cpython/issues/132942): Two races within the type lookup cache are fixed. The free-threaded build was affected, and crashes (seemingly rather hard to provoke) were possible.
