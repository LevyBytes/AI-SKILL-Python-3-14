# Python 3.14.0 beta 1 / core and builtins / exceptions

[gh-123539](https://github.com/python/cpython/issues/123539): The [`SyntaxError`](https://docs.python.org/3.14/library/exceptions.html#SyntaxError) message is improved when `import ... as` and `from ... import ... as` are used with something that is not a name.

[gh-116436](https://github.com/python/cpython/issues/116436): The error message is improved when a [`TypeError`](https://docs.python.org/3.14/library/exceptions.html#TypeError) is raised during [`dict.update()`](https://docs.python.org/3.14/library/stdtypes.html#dict.update)

[gh-133197](https://github.com/python/cpython/issues/133197): The [`SyntaxError`](https://docs.python.org/3.14/library/exceptions.html#SyntaxError) messages reported for mismatched string / bytes prefixes are now clearer.
