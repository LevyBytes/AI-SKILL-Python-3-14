# Python 3.14.0 beta 1 / core and builtins / warnings

[gh-131927](https://github.com/python/cpython/issues/131927): A compiler warning that shares its module and line number with another is now emitted only one time, mirroring how warnings from user code behave. [`warnings`](https://docs.python.org/3.14/library/warnings.html#module-warnings) filters can also configure this.
