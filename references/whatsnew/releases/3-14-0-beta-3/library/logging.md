# Python 3.14.0 beta 3 / library / logging

[gh-127319](https://github.com/python/cpython/issues/127319): On the XMLRPC, logging, and HTTP servers, the `allow_reuse_port` class variable is now set to `False`. This restores the behavior of earlier Python releases, where port reuse is disallowed.
