# Python 3.14.0 beta 3 / library / random

[gh-133489](https://github.com/python/cpython/issues/133489): [`random.getrandbits()`](https://docs.python.org/3.14/library/random.html#random.getrandbits) is now able to produce more than 231 bits. [`random.randbytes()`](https://docs.python.org/3.14/library/random.html#random.randbytes) is now able to produce more than 256 MiB.
