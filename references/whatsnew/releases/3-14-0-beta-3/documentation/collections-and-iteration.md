# Python 3.14.0 beta 3 / documentation / collections and iteration

[gh-135171](https://github.com/python/cpython/issues/135171): It is now documented that, for a generator expression, the [iterator](https://docs.python.org/3.14/glossary.html#term-iterator) belonging to the leftmost `for` clause is created right away.

[bpo-45210](https://bugs.python.org/issue?@action=redirect&bpo=45210): It is now documented that the error indicator can be set within tp_dealloc, along with how one avoids clobbering it.
