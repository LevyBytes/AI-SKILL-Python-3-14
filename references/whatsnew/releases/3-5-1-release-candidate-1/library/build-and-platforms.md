# Python 3.5.1 release candidate 1 / library / build and platforms

[bpo-25155](https://bugs.python.org/issue?@action=redirect&bpo=25155): On Windows, datetime.datetime.now() and datetime.datetime.utcnow() now cope with dates past the year 2038. Python 3.5.0 had introduced this regression.

[bpo-25118](https://bugs.python.org/issue?@action=redirect&bpo=25118): Addressed a Python 3.5.0 regression affecting os.waitpid() on Windows.
