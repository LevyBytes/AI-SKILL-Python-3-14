# Python 3.5.1 release candidate 1 / library / asyncio

[bpo-25441](https://bugs.python.org/issue?@action=redirect&bpo=25441): asyncio: an error is now raised from drain() once the socket is closed.

[bpo-23572](https://bugs.python.org/issue?@action=redirect&bpo=23572): Repaired functools.singledispatch when used on classes that have false metaclasses. Ethan Furman wrote the patch.

- asyncio: awaitable objects are now accepted by ensure_future().
