# Python 3.5.1 release candidate 1 / library / files and paths

[bpo-24657](https://bugs.python.org/issue?@action=redirect&bpo=24657): Stopped CGIRequestHandler from collapsing slashes within the query portion of the URL as though it were a path. Xiang Zhang sent the patch.

[bpo-24982](https://bugs.python.org/issue?@action=redirect&bpo=24982): When used with the "zip" format, shutil.make_archive() now records entries for directories, empty ones included, inside the ZIP file.
