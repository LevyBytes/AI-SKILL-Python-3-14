# Python 3.13.0 alpha 4 / core and builtins / sys

[gh-114695](https://github.com/python/cpython/issues/114695): Introduce [`sys._clear_internal_caches()`](https://docs.python.org/3.14/library/sys.html#sys._clear_internal_caches) to flush every internal performance-related cache, while deprecating the narrower [`sys._clear_type_cache()`](https://docs.python.org/3.14/library/sys.html#sys._clear_type_cache) function.
