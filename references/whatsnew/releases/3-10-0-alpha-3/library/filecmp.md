# Python 3.10.0 alpha 3 / library / filecmp

[bpo-15450](https://bugs.python.org/issue?@action=redirect&bpo=15450): Make [`filecmp.dircmp`](https://docs.python.org/3.14/library/filecmp.html#filecmp.dircmp) honour subclassing. As a result [`filecmp.dircmp.subdirs`](https://docs.python.org/3.14/library/filecmp.html#filecmp.dircmp.subdirs) now behaves correctly when dircmp is subclassed.
