# Python 3.10.0 alpha 3 / library / stdtypes

[bpo-42264](https://bugs.python.org/issue?@action=redirect&bpo=42264): `sqlite3.OptimizedUnicode` has gone undocumented and obsolete ever since Python 3.3 made it an alias for [`str`](https://docs.python.org/3.14/library/stdtypes.html#str). It is now deprecated, with removal scheduled for Python 3.12.
