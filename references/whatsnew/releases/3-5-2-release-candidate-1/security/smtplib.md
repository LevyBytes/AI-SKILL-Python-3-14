# Python 3.5.2 release candidate 1 / security / smtplib

[bpo-26556](https://bugs.python.org/issue?@action=redirect&bpo=26556): Refreshed expat to 2.1.1, which fixes [**CVE 2015-1283**](https://www.cve.org/CVERecord?id=CVE-2015-1283).

- Closed a TLS stripping vulnerability within smtplib, [**CVE 2016-0772**](https://www.cve.org/CVERecord?id=CVE-2016-0772). Team Oststrom reported it.
