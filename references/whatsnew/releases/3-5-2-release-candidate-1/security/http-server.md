# Python 3.5.2 release candidate 1 / security / http server

[bpo-26657](https://bugs.python.org/issue?@action=redirect&bpo=26657): Closed a directory traversal vulnerability affecting http.server on Windows. This repairs a regression first introduced across 3.3.4rc1 and 3.4.0rc1. The work builds on a patch from Philipp Hagemeister.
