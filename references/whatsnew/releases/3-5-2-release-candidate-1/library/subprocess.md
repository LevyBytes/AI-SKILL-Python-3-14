# Python 3.5.2 release candidate 1 / library / subprocess

[bpo-22274](https://bugs.python.org/issue?@action=redirect&bpo=22274): Within the subprocess module, permit stderr to be sent to stdout even though stdout itself is not redirected. Akira Li wrote the patch.

[bpo-25764](https://bugs.python.org/issue?@action=redirect&bpo=25764): Within the subprocess module, retain whichever exception fork() failure raised when preexec_fn is in use.
