# Python 3.5.2 release candidate 1 / library / xmlrpc

[bpo-26873](https://bugs.python.org/issue?@action=redirect&bpo=26873): For unsupported type tags, xmlrpc now raises ResponseError rather than quietly returning an incorrect result.

[bpo-26147](https://bugs.python.org/issue?@action=redirect&bpo=26147): xmlrpc now operates with strings that cannot be encoded by the chosen non-UTF-8 encoding.
