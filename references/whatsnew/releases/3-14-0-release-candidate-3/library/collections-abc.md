# Python 3.14.0 release candidate 3 / library / collections abc

[gh-118803](https://github.com/python/cpython/issues/118803): Reinstate [`collections.abc.ByteString`](https://docs.python.org/3.14/library/collections.abc.html#collections.abc.ByteString) along with [`typing.ByteString`](https://docs.python.org/3.14/library/typing.html#typing.ByteString). Each had been dropped across earlier alpha, beta, and release candidate builds of Python 3.14, yet that removal is now deferred until Python 3.17.
