# Python 3.12.0 alpha 7 / core and builtins / sys

[gh-102778](https://github.com/python/cpython/issues/102778): Introduce [`sys.last_exc`](https://docs.python.org/3.14/library/sys.html#sys.last_exc) while deprecating [`sys.last_type`](https://docs.python.org/3.14/library/sys.html#sys.last_type), [`sys.last_value`](https://docs.python.org/3.14/library/sys.html#sys.last_value) and [`sys.last_traceback`](https://docs.python.org/3.14/library/sys.html#sys.last_traceback), which carry that same data in its legacy shape.
