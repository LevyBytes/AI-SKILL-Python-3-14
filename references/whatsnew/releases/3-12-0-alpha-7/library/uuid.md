# Python 3.12.0 alpha 7 / library / uuid

[gh-94684](https://github.com/python/cpython/issues/94684): The [`uuid.uuid3()`](https://docs.python.org/3.14/library/uuid.html#uuid.uuid3) and [`uuid.uuid5()`](https://docs.python.org/3.14/library/uuid.html#uuid.uuid5) functions will now take [`bytes`](https://docs.python.org/3.14/library/stdtypes.html#bytes) objects for their *name* argument.
