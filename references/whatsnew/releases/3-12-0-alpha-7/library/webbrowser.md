# Python 3.12.0 alpha 7 / library / webbrowser

[gh-102871](https://github.com/python/cpython/issues/102871): Drop obsolete browsers from [`webbrowser`](https://docs.python.org/3.14/library/webbrowser.html#module-webbrowser). The ones removed are Grail, Mosaic, Netscape, Galeon, Skipstone, Iceape, Firebird, and any Firefox at version 35 or lower.

[gh-101313](https://github.com/python/cpython/issues/101313): The webbrowser CLI gained -h and ?help arguments
