# Python 3.6.4 release candidate 1 / idle / python

[bpo-31460](https://bugs.python.org/issue?@action=redirect&bpo=31460): Streamline the API of IDLE’s Module Browser. Handing it a widget rather than an flist plus a root widget makes it possible to build a browser frame occupying only part of a window. Handing it a complete file name rather than fragments presumed to originate from a .py file makes it possible to browse python files whose names do not finish in .py.
