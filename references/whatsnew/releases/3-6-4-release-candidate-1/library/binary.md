# Python 3.6.4 release candidate 1 / library / binary

[bpo-32072](https://bugs.python.org/issue?@action=redirect&bpo=32072): Resolved several issues affecting binary plists: bytearray saving was repaired; identical objects are now stored a single time; equal references load back as identical objects; and saving plus loading of recursive data structures is now supported.
