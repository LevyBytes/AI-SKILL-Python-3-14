# Python 3.6.4 release candidate 1 / library / email

[bpo-27240](https://bugs.python.org/issue?@action=redirect&bpo=27240): The header folding logic used by the new email policies was rewritten, which along the way resolves [bpo-30788](https://bugs.python.org/issue?@action=redirect&bpo=30788), [bpo-31831](https://bugs.python.org/issue?@action=redirect&bpo=31831), and [bpo-32182](https://bugs.python.org/issue?@action=redirect&bpo=32182). RFC2231 folding in particular is now carried out correctly.
