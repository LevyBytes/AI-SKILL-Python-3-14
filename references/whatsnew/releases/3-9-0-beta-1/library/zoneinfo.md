# Python 3.9.0 beta 1 / library / zoneinfo

[bpo-40536](https://bugs.python.org/issue?@action=redirect&bpo=40536): Brought the [`available_timezones()`](https://docs.python.org/3.14/library/zoneinfo.html#zoneinfo.available_timezones) function into the [`zoneinfo`](https://docs.python.org/3.14/library/zoneinfo.html#module-zoneinfo) module. Paul Ganssle wrote the patch.

[bpo-40503](https://bugs.python.org/issue?@action=redirect&bpo=40503): [**PEP 615**](https://peps.python.org/pep-0615/), namely the [`zoneinfo`](https://docs.python.org/3.14/library/zoneinfo.html#module-zoneinfo) module. It brings support for the IANA time zone database.
