# Python 3.9.0 beta 1 / library / imports and modules

[bpo-40645](https://bugs.python.org/issue?@action=redirect&bpo=40645): The internal `_hashlib` module now wraps and surfaces OpenSSL's HMAC API. Python 3.10 will adopt the new code once the internal implementation details of the pure Python HMAC module stop being part of the public API.
