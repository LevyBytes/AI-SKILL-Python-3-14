# Python 3.6.0 alpha 3 / core and builtins / text

[bpo-23034](https://bugs.python.org/issue?@action=redirect&bpo=23034): A special Python build compiled with the COUNT_ALLOCS, SHOW_ALLOC_COUNT or SHOW_TRACK_COUNT macros no longer prints that output by default. Turn it back on through the "-X showalloccount" switch. The text now lands on stderr in place of stdout.
