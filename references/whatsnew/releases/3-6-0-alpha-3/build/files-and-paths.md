# Python 3.6.0 alpha 3 / build / files and paths

[bpo-28066](https://bugs.python.org/issue?@action=redirect&bpo=28066): Corrected the logic that scans build directories for generated include files during a build outside the source tree.

[bpo-27434](https://bugs.python.org/issue?@action=redirect&bpo=27434): The interpreter driving the cross-build, located via PATH, is now required to share the same feature version (for instance 3.6) as the source under construction.
