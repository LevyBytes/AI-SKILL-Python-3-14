# Python 3.6.0 alpha 3 / library / collections and iteration

[bpo-27319](https://bugs.python.org/issue?@action=redirect&bpo=27319): The selection_set(), selection_add(), selection_remove() and selection_toggle() methods of ttk.TreeView now accept several items as separate arguments rather than requiring a single tuple. Calling the selection() method with arguments — an undocumented feature — has been deprecated.
