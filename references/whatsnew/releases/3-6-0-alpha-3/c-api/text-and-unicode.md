# Python 3.6.0 alpha 3 / c api / text and unicode

[bpo-26754](https://bugs.python.org/issue?@action=redirect&bpo=26754): PyUnicode_FSDecoder() used to take a filename argument given as an iterable of integers. From now on only strings and byte-like objects are permitted.
