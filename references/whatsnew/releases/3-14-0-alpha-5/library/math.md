# Python 3.14.0 alpha 5 / library / math

[gh-101410](https://github.com/python/cpython/issues/101410): Allow custom messages for domain errors throughout the [`math`](https://docs.python.org/3.14/library/math.html#module-math) module (with [`math.sqrt()`](https://docs.python.org/3.14/library/math.html#math.sqrt), [`math.log()`](https://docs.python.org/3.14/library/math.html#math.log) and [`math.atanh()`](https://docs.python.org/3.14/library/math.html#math.atanh) adjusted as examples). Charlie Zhao and Sergey B Kirpichev supplied the patch.
