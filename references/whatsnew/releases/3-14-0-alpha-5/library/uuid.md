# Python 3.14.0 alpha 5 / library / uuid

[gh-128427](https://github.com/python/cpython/issues/128427): The constants [`uuid.NIL`](https://docs.python.org/3.14/library/uuid.html#uuid.NIL) and [`uuid.MAX`](https://docs.python.org/3.14/library/uuid.html#uuid.MAX) now exist to express the Nil and Max UUID forms specified by [**RFC 9562**](https://datatracker.ietf.org/doc/html/rfc9562.html).
