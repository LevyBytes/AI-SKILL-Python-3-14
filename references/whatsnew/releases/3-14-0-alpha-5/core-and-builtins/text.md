# Python 3.14.0 alpha 5 / core and builtins / text

[gh-128016](https://github.com/python/cpython/issues/128016): The `SyntaxWarning` text for invalid escape sequences was reworded so it makes plain that those sequences are slated to become a `SyntaxError` in a later Python version. A candidate correction is now offered too, for example `Did you mean "\\e"?`.
