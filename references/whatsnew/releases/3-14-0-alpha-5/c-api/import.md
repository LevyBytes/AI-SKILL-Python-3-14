# Python 3.14.0 alpha 5 / c api / import

[gh-128911](https://github.com/python/cpython/issues/128911): Introduced the [`PyImport_ImportModuleAttr()`](https://docs.python.org/3.14/c-api/import.html#c.PyImport_ImportModuleAttr) and [`PyImport_ImportModuleAttrString()`](https://docs.python.org/3.14/c-api/import.html#c.PyImport_ImportModuleAttrString) helpers, which import a module and then retrieve one of its attributes. Victor Stinner wrote the patch.
