# Python 3.14.0 alpha 5 / c api / functions and types

[gh-129033](https://github.com/python/cpython/issues/129033): Took out the private `_Py_InitializeMain()` function, a [provisional API](https://docs.python.org/3.14/glossary.html#term-provisional-API) that [**PEP 587**](https://peps.python.org/pep-0587/) had introduced in Python 3.8. Victor Stinner wrote the patch.
