# Python 3.10.0 beta 1 / library / os

[bpo-39906](https://bugs.python.org/issue?@action=redirect&bpo=39906): For parity with the matching functions in the [`os`](https://docs.python.org/3.14/library/os.html#module-os) module, [`pathlib.Path.stat()`](https://docs.python.org/3.14/library/pathlib.html#pathlib.Path.stat) and [`chmod()`](https://docs.python.org/3.14/library/pathlib.html#pathlib.Path.chmod) now take a *follow_symlinks* keyword-only argument.
