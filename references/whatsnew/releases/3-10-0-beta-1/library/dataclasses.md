# Python 3.10.0 beta 1 / library / dataclasses

[bpo-43764](https://bugs.python.org/issue?@action=redirect&bpo=43764): Fix a situation in which [`__match_args__`](https://docs.python.org/3.14/reference/datamodel.html#object.__match_args__) generation might break for certain [`dataclasses`](https://docs.python.org/3.14/library/dataclasses.html#module-dataclasses).

[bpo-36470](https://bugs.python.org/issue?@action=redirect&bpo=36470): Repaired dataclasses that combine `InitVar`s with [`replace()`](https://docs.python.org/3.14/library/dataclasses.html#dataclasses.replace). Claudiu Popa supplied the patch.
