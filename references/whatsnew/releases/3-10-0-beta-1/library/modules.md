# Python 3.10.0 beta 1 / library / modules

[bpo-38659](https://bugs.python.org/issue?@action=redirect&bpo=38659): The `enum` module gains a `simple_enum` decorator that turns an ordinary class into an Enum. A `test_simple_enum` was added to check simple enums against the matching normal Enum. Standard library modules were updated to adopt `simple_enum`.
