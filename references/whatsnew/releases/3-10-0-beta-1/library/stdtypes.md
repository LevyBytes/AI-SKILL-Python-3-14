# Python 3.10.0 beta 1 / library / stdtypes

[bpo-42967](https://bugs.python.org/issue?@action=redirect&bpo=42967): Permit a [`bytes`](https://docs.python.org/3.14/library/stdtypes.html#bytes) `separator` argument in `urllib.parse.parse_qs` and `urllib.parse.parse_qsl` while parsing [`str`](https://docs.python.org/3.14/library/stdtypes.html#str) query strings. Formerly this would raise a `TypeError`.
