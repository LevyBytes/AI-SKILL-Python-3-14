# Python 3.10.0 beta 1 / library / turtle

[bpo-43937](https://bugs.python.org/issue?@action=redirect&bpo=43937): Repaired the [`turtle`](https://docs.python.org/3.14/library/turtle.html#module-turtle) module so it cooperates with a non-default root window.

[bpo-43534](https://bugs.python.org/issue?@action=redirect&bpo=43534): [`turtle.textinput()`](https://docs.python.org/3.14/library/turtle.html#turtle.textinput) plus [`turtle.numinput()`](https://docs.python.org/3.14/library/turtle.html#turtle.numinput) now build a transient window that operates on behalf of the canvas window.
