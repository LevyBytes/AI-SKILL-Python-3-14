# Python 3.10.0 beta 1 / idle / numeric behavior

[bpo-37903](https://bugs.python.org/issue?@action=redirect&bpo=37903): Mouse interactions were added to the shell sidebar. A left click, optionally with a drag, selects one or more lines, just like the editor's line-number sidebar. Once a selection is made, a right click brings up a context menu offering "copy with prompts", which zips the sidebar's prompts together with the lines drawn from the selected text.
