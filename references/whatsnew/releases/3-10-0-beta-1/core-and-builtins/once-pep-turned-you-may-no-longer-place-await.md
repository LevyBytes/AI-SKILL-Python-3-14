# Python 3.10.0 beta 1 / core and builtins / once pep turned you may no longer place await

[bpo-42725](https://bugs.python.org/issue?@action=redirect&bpo=42725): Once PEP 563 is turned on, you may no longer place `await`/`yield`/`yield from` or named expressions inside an annotation.
