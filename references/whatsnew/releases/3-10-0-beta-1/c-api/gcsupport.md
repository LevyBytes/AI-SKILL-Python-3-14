# Python 3.10.0 beta 1 / c api / gcsupport

[bpo-28254](https://bugs.python.org/issue?@action=redirect&bpo=28254): New C-API functions were added for steering the garbage collector — [`PyGC_Enable()`](https://docs.python.org/3.14/c-api/gcsupport.html#c.PyGC_Enable), [`PyGC_Disable()`](https://docs.python.org/3.14/c-api/gcsupport.html#c.PyGC_Disable), [`PyGC_IsEnabled()`](https://docs.python.org/3.14/c-api/gcsupport.html#c.PyGC_IsEnabled) — which mirror the matching functions in the [`gc`](https://docs.python.org/3.14/library/gc.html#module-gc) module.
