# Python 3.14.0 alpha 6 / core and builtins / typing

[gh-126085](https://github.com/python/cpython/issues/126085): Star unpacking is now supported by [`typing.TypeAliasType`](https://docs.python.org/3.14/library/typing.html#typing.TypeAliasType).

[gh-124445](https://github.com/python/cpython/issues/124445): Specialization of generic aliases that are generic over a [`typing.ParamSpec`](https://docs.python.org/3.14/library/typing.html#typing.ParamSpec) and were then specialized with a nested type variable has been fixed.
