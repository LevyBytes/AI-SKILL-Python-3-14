# Python 3.14.0 alpha 6 / build / pragma based linking against python3 lib can turned off through py no link lib

[gh-82909](https://github.com/python/cpython/issues/82909): The `#pragma`-based linking against `python3*.lib` can now be turned off through [Py_NO_LINK_LIB](https://docs.python.org/3.14/extending/windows.html#c.Py_NO_LINK_LIB). Jean-Christophe Fillion-Robin supplied the patch.
