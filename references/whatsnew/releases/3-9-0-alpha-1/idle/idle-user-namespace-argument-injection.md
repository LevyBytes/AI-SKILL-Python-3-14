# Python 3.9.0 alpha 1 / idle / during initialization idle stops inserting argv into user namespace

[bpo-38077](https://bugs.python.org/issue?@action=redirect&bpo=38077): During initialization, IDLE stops inserting "argv" into the user namespace. The defect was present only in 3.7.4 and across 3.8.0b2 through 3.8.0b4.
