# Python 3.9.0 alpha 1 / idle / imports and modules

[bpo-5680](https://bugs.python.org/issue?@action=redirect&bpo=5680): Put Run → Customized on the Run menu so a module can run under tailored settings. Whatever "command line arguments" you type get appended to sys.argv. The usual Shell main module restart can be suppressed.

[bpo-37902](https://bugs.python.org/issue?@action=redirect&bpo=37902): Enable mousewheel scrolling within IDLE's module, path, and stack browsers. George Zhang supplied the patch.

[bpo-37748](https://bugs.python.org/issue?@action=redirect&bpo=37748): Rearrange the Run menu so the most common pick, Run Module, sits at the top.
