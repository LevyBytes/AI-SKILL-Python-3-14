# Python 3.9.0 alpha 1 / idle / tailor zoom height per screen briefly maximizing window first

[bpo-37039](https://bugs.python.org/issue?@action=redirect&bpo=37039): Tailor "Zoom Height" per screen by briefly maximizing the window the first time it meets a given screen. Altering screen settings can void the stored height. A maximized window gets no effect from "Zoom Height".
