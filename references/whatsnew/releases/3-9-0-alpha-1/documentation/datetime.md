# Python 3.9.0 alpha 1 / documentation / datetime

[bpo-34903](https://bugs.python.org/issue?@action=redirect&bpo=34903): It is now documented that within [`datetime.datetime.strptime()`](https://docs.python.org/3.14/library/datetime.html#datetime.datetime.strptime) a few two-digit formats treat the leading zero as optional. Mike Gleen supplied the patch.

[bpo-36960](https://bugs.python.org/issue?@action=redirect&bpo=36960): Reorganized the [`datetime`](https://docs.python.org/3.14/library/datetime.html#module-datetime) docs to make them friendlier and easier to read. Brad Solomon supplied the patch.
