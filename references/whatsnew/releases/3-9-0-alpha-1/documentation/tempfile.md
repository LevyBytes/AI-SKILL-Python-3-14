# Python 3.9.0 alpha 1 / documentation / tempfile

[bpo-35803](https://bugs.python.org/issue?@action=redirect&bpo=35803): It is now documented and tested that `tempfile` functions can take a [path-like object](https://docs.python.org/3.14/glossary.html#term-path-like-object) as the `dir` argument. Anthony Sottile supplied the patch.
