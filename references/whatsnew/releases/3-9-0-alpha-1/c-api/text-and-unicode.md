# Python 3.9.0 alpha 1 / c api / text and unicode

[bpo-37645](https://bugs.python.org/issue?@action=redirect&bpo=37645): Introduce `_PyObject_FunctionStr()` to obtain a reader-friendly string form of a function-like object. Jeroen Demeyer authored the patch.

[bpo-37540](https://bugs.python.org/issue?@action=redirect&bpo=37540): Under the vectorcall protocol, a caller must now supply keyword names exclusively as strings.
