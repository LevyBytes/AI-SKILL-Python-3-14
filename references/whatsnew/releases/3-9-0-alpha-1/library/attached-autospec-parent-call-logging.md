# Python 3.9.0 alpha 1 / library / calls made parent logged autospecced object gets attached mock

[bpo-21478](https://bugs.python.org/issue?@action=redirect&bpo=21478): Calls made to a parent are now logged when an autospecced object gets attached to a mock through `unittest.mock.attach_mock()`. Karthikeyan Singaravelan authored the patch.
