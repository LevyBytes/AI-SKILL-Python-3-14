# Python 3.9.0 alpha 1 / library / threading

[bpo-37312](https://bugs.python.org/issue?@action=redirect&bpo=37312): The `_dummy_thread` and `dummy_threading` modules have been taken out. Deprecated ever since Python 3.7, which mandates threading support, they are no longer needed.
