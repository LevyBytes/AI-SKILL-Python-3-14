# Python 3.9.0 alpha 1 / library / gzip

[bpo-28286](https://bugs.python.org/issue?@action=redirect&bpo=28286): Opening a [`GzipFile`](https://docs.python.org/3.14/library/gzip.html#gzip.GzipFile) for writing without an explicit declaration is now deprecated. When writing, always state the *mode* argument.
