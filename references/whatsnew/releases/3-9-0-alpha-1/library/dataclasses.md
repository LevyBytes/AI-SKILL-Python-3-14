# Python 3.9.0 alpha 1 / library / dataclasses

[bpo-37163](https://bugs.python.org/issue?@action=redirect&bpo=37163): For [`dataclasses.replace()`](https://docs.python.org/3.14/library/dataclasses.html#dataclasses.replace) the *obj* argument has become positional-only.

[bpo-38431](https://bugs.python.org/issue?@action=redirect&bpo=38431): Samuel Colvin patched the `__repr__` method of [`dataclasses.InitVar`](https://docs.python.org/3.14/library/dataclasses.html#dataclasses.InitVar) so that typing objects are supported.
