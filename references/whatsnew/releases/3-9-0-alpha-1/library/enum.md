# Python 3.9.0 alpha 1 / library / enum

[bpo-34443](https://bugs.python.org/issue?@action=redirect&bpo=34443): When [`enum`](https://docs.python.org/3.14/library/enum.html#module-enum) raises an exception, its message now references the enum class's `__qualname` rather than the `__name__`.
