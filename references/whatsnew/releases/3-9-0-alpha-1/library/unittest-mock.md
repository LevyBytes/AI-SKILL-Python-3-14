# Python 3.9.0 alpha 1 / library / unittest mock

[bpo-37212](https://bugs.python.org/issue?@action=redirect&bpo=37212): The repr output of [`unittest.mock.call()`](https://docs.python.org/3.14/library/unittest.mock.html#unittest.mock.call) now keeps keyword arguments in their original order. Karthikeyan Singaravelan wrote the patch.

[bpo-37828](https://bugs.python.org/issue?@action=redirect&bpo=37828): Abraham Toriz Cruz patched the default mock name reported in [`unittest.mock.Mock.assert_called()`](https://docs.python.org/3.14/library/unittest.mock.html#unittest.mock.Mock.assert_called) exceptions.
