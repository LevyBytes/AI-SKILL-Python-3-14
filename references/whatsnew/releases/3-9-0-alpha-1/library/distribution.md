# Python 3.9.0 alpha 1 / library / distribution

[bpo-36546](https://bugs.python.org/issue?@action=redirect&bpo=36546): For statistics.quantiles() the *dist* argument has been made positional only. Its present name fails to convey that the argument may be either a dataset or a distribution; keeping the parameter positional sidesteps that confusion and leaves room to rename it down the road.
