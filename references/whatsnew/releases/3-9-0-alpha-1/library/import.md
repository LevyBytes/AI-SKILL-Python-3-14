# Python 3.9.0 alpha 1 / library / import

[bpo-35943](https://bugs.python.org/issue?@action=redirect&bpo=35943): Any module handed back by [`PyImport_GetModule()`](https://docs.python.org/3.14/c-api/import.html#c.PyImport_GetModule) is now guaranteed to be fully initialized. Joannah Nanjekye contributed the patch.
