# Python 3.9.0 alpha 1 / library / compileall

[bpo-38112](https://bugs.python.org/issue?@action=redirect&bpo=38112): [`compileall`](https://docs.python.org/3.14/library/compileall.html#module-compileall) now ships with a raised default recursion limit plus new command-line arguments covering path manipulation, symlinks handling, and several optimization levels.
