# Python 3.9.0 alpha 1 / library / hashing algorithm names coming openssl standardized match python s

[bpo-38153](https://bugs.python.org/issue?@action=redirect&bpo=38153): Hashing algorithm names coming from OpenSSL are now standardized to match Python’s naming conventions. As one illustration, OpenSSL writes sha3-512 in place of sha3_512, or blake2b512 in place of blake2b.
