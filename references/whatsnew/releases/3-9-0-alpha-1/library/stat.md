# Python 3.9.0 alpha 1 / library / stat

[bpo-38109](https://bugs.python.org/issue?@action=redirect&bpo=38109): The Python implementation of [`stat`](https://docs.python.org/3.14/library/stat.html#module-stat) gained the previously absent [`stat.S_IFDOOR`](https://docs.python.org/3.14/library/stat.html#stat.S_IFDOOR), [`stat.S_IFPORT`](https://docs.python.org/3.14/library/stat.html#stat.S_IFPORT), [`stat.S_IFWHT`](https://docs.python.org/3.14/library/stat.html#stat.S_IFWHT), [`stat.S_ISDOOR()`](https://docs.python.org/3.14/library/stat.html#stat.S_ISDOOR), [`stat.S_ISPORT()`](https://docs.python.org/3.14/library/stat.html#stat.S_ISPORT), and [`stat.S_ISWHT()`](https://docs.python.org/3.14/library/stat.html#stat.S_ISWHT) values.
