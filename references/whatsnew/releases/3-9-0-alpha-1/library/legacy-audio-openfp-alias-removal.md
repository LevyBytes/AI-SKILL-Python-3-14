# Python 3.9.0 alpha 1 / library / aliases aifc openfp aifc open sunau openfp sunau open wave openfp wave open gone

[bpo-37320](https://bugs.python.org/issue?@action=redirect&bpo=37320): The aliases `aifc.openfp()` for `aifc.open()`, `sunau.openfp()` for `sunau.open()`, and `wave.openfp()` for `wave.open()` are gone. Their deprecation reached back to Python 3.7.
