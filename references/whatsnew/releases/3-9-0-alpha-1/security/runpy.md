# Python 3.9.0 alpha 1 / security / runpy

[bpo-38722](https://bugs.python.org/issue?@action=redirect&bpo=38722): [`runpy`](https://docs.python.org/3.14/library/runpy.html#module-runpy) now relies on [`io.open_code()`](https://docs.python.org/3.14/library/io.html#io.open_code) for opening code files. Jason Killen wrote the patch.
