# Python 3.9.0 alpha 3 / core and builtins / functions and types

[bpo-39215](https://bugs.python.org/issue?@action=redirect&bpo=39215): Anthony Sottile fixed a `SystemError` raised when a nested function carries an annotation on a positional-only argument.

[bpo-39166](https://bugs.python.org/issue?@action=redirect&bpo=39166): Trace functions reported the wrong executing line while tracing the final pass of asynchronous for loops; this is now fixed. Pablo Galindo wrote the patch.
