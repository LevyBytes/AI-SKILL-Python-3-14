# Python 3.9.0 alpha 3 / core and builtins / imports and modules

[bpo-39336](https://bugs.python.org/issue?@action=redirect&bpo=39336): Import loaders that publish immutable module objects can additionally publish immutable packages now, on top of individual modules.

[bpo-1635741](https://bugs.python.org/issue?@action=redirect&bpo=1635741): The _json extension module was migrated to multiphase initialization ([**PEP 489**](https://peps.python.org/pep-0489/)).
