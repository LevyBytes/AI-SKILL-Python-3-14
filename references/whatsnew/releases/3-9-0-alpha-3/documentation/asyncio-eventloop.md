# Python 3.9.0 alpha 3 / documentation / asyncio eventloop

[bpo-39381](https://bugs.python.org/issue?@action=redirect&bpo=39381): The docs now note that [`asyncio.get_event_loop()`](https://docs.python.org/3.14/library/asyncio-eventloop.html#asyncio.get_event_loop) only creates a new event loop implicitly when it is called from within the main thread.
