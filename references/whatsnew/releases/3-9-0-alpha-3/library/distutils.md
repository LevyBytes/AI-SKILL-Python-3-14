# Python 3.9.0 alpha 3 / library / distutils

[bpo-38914](https://bugs.python.org/issue?@action=redirect&bpo=38914): The wording of distutils’ `check` command warning was adjusted for the case where the `author` and `maintainer` fields appear but the matching e-mail field (`author_email` or `maintainer_email`) is missing. The text now makes clear these fields are recommended rather than mandatory. Juergen Gmach wrote the patch.
