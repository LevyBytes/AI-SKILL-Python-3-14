# Python 3.9.0 alpha 3 / library / math

[bpo-39350](https://bugs.python.org/issue?@action=redirect&bpo=39350): The `fractions.gcd()` function, deprecated since Python 3.5 ([bpo-22486](https://bugs.python.org/issue?@action=redirect&bpo=22486)), was removed; use [`math.gcd()`](https://docs.python.org/3.14/library/math.html#math.gcd) in its place.

[bpo-39310](https://bugs.python.org/issue?@action=redirect&bpo=39310): Introduced [`math.ulp()`](https://docs.python.org/3.14/library/math.html#math.ulp): it returns the value carried by a float’s least significant bit.

[bpo-39288](https://bugs.python.org/issue?@action=redirect&bpo=39288): Introduced [`math.nextafter()`](https://docs.python.org/3.14/library/math.html#math.nextafter): it returns the floating-point value immediately after *x* in the direction of *y*.
