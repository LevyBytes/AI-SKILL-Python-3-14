# Python 3.9.0 alpha 3 / library / gzip

[bpo-39389](https://bugs.python.org/issue?@action=redirect&bpo=39389): [`gzip`](https://docs.python.org/3.14/library/gzip.html#module-gzip) archives now record the true compression level in their metadata, instead of always reporting maximum compression.
