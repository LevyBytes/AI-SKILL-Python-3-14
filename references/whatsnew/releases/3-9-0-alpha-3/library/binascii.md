# Python 3.9.0 alpha 3 / library / binascii

[bpo-39353](https://bugs.python.org/issue?@action=redirect&bpo=39353): The binhex4 and hexbin4 standards became deprecated, along with the `binhex` module and these [`binascii`](https://docs.python.org/3.14/library/binascii.html#module-binascii) functions: `b2a_hqx()`, `a2b_hqx()`, `rlecode_hqx()`, `rledecode_hqx()`, [`crc_hqx()`](https://docs.python.org/3.14/library/binascii.html#binascii.crc_hqx).
