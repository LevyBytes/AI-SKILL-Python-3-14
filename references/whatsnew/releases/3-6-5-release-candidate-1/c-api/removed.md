# Python 3.6.5 release candidate 1 / c api / removed

[bpo-29084](https://bugs.python.org/issue?@action=redirect&bpo=29084): The undocumented C API covering OrderedDict has been removed from the limited C API. It was introduced by accident and in fact never functioned within the limited C API.
