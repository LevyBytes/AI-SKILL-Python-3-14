# Python 3.6.5 release candidate 1 / macos / build and platforms

[bpo-32726](https://bugs.python.org/issue?@action=redirect&bpo=32726): Ship an extra, more current macOS installer flavor that targets macOS 10.9+ systems running only 64-bit mode. The bundled third-party libraries move up to OpenSSL 1.0.2n, XZ 5.2.3, and SQLite 3.22.0. This 10.9+ installer links against, and carries, its own copy of Tcl/Tk 8.6.8.
