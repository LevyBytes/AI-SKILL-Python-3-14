# Python 3.9.0 alpha 2 / idle / files and paths

[bpo-38862](https://bugs.python.org/issue?@action=redirect&bpo=38862): On the Format menu, "Strip Trailing Whitespace" now strips extra newlines from the end of non-shell files.

[bpo-38636](https://bugs.python.org/issue?@action=redirect&bpo=38636): Repair the IDLE Format menu tab toggle along with the file indent width. The default shortcuts Alt-T and Alt-U for these functions had been disabled by mistake back in 3.7.5 and 3.8.0.
