# Python 3.9.0 alpha 2 / library / signal

[bpo-38712](https://bugs.python.org/issue?@action=redirect&bpo=38712): Introduce the Linux-only [`signal.pidfd_send_signal()`](https://docs.python.org/3.14/library/signal.html#signal.pidfd_send_signal) function, by which a signal can be delivered to a process named through a file descriptor instead of a pid.
