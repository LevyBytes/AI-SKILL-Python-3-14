# Python 3.9.0 alpha 2 / library / readline

[bpo-38634](https://bugs.python.org/issue?@action=redirect&bpo=38634): At runtime the [`readline`](https://docs.python.org/3.14/library/readline.html#module-readline) module now figures out whether Python is linked against libedit on every platform. That detection used to run on macOS alone.
