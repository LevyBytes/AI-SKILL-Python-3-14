# Python 3.9.0 alpha 2 / library / argparse

[bpo-38821](https://bugs.python.org/issue?@action=redirect&bpo=38821): Repair unhandled exceptions in [`argparse`](https://docs.python.org/3.14/library/argparse.html#module-argparse) that arose while internationalizing error messages for arguments whose `nargs` was set to special (non-integer) values. Federico Bond supplied the patch.
