# Python 3.9.0 alpha 2 / library / array

[bpo-38916](https://bugs.python.org/issue?@action=redirect&bpo=38916): [`array.array`](https://docs.python.org/3.14/library/array.html#array.array): Drop the `tostring()` and `fromstring()` methods. These had been aliases for `tobytes()` and `frombytes()`, marked deprecated as far back as Python 3.2.
