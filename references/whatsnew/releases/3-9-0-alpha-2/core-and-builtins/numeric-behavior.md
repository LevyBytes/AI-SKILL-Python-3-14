# Python 3.9.0 alpha 2 / core and builtins / numeric behavior

[bpo-38629](https://bugs.python.org/issue?@action=redirect&bpo=38629): The float object gained `__floor__` and `__ceil__` methods. Batuhan Taşkaya supplied the patch.

[bpo-27145](https://bugs.python.org/issue?@action=redirect&bpo=27145): Both int + int and int - int operators may now hand back small integer singletons. hongweipeng contributed the patch.
