# Python 3.9.0 alpha 2 / core and builtins / repl mode prompt no longer flips ps2 if line

[bpo-38673](https://bugs.python.org/issue?@action=redirect&bpo=38673): When in REPL mode, the prompt no longer flips to PS2 if the line opens with a comment or whitespace. This builds on work by Batuhan Taşkaya.
