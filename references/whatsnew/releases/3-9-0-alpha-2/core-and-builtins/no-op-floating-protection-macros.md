# Python 3.9.0 alpha 2 / core and builtins / pyfpe start protect pyfpe end protect macros expand nothing they had no effect

[bpo-38835](https://bugs.python.org/issue?@action=redirect&bpo=38835): The `PyFPE_START_PROTECT()` and `PyFPE_END_PROTECT()` macros now expand to nothing: they have had no effect for the past year, so their use was dropped.
