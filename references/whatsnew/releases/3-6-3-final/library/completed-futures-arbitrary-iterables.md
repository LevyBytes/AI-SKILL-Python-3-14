# Python 3.6.3 final / library / permit arbitrary iterables once more concurrent futures as completed

[bpo-31641](https://bugs.python.org/issue?@action=redirect&bpo=31641): Permit arbitrary iterables once more in `concurrent.futures.as_completed()`. This corrects a regression introduced by 3.6.3rc1.
