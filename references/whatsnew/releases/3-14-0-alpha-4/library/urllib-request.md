# Python 3.14.0 alpha 4 / library / urllib request

[gh-128192](https://github.com/python/cpython/issues/128192): Strengthen the HTTP digest authentication scheme used by [`urllib.request`](https://docs.python.org/3.14/library/urllib.request.html#module-urllib.request) so it now also handles SHA-256 digest auth, following the rules laid out in [**RFC 7616**](https://datatracker.ietf.org/doc/html/rfc7616.html).
