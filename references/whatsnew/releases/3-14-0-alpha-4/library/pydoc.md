# Python 3.14.0 alpha 4 / library / pydoc

[gh-41872](https://github.com/python/cpython/issues/41872): Repaired the speedy pulling of module docstrings out of a file inside [`pydoc`](https://docs.python.org/3.14/library/pydoc.html#module-pydoc). Docstrings written with single quotes, escape sequences, raw string literals, and further Python syntax now work.
