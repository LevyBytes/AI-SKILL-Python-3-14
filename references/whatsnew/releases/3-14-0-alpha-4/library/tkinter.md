# Python 3.14.0 alpha 4 / library / tkinter

[gh-128562](https://github.com/python/cpython/issues/128562): Resolved possible clashes among generated [`tkinter`](https://docs.python.org/3.14/library/tkinter.html#module-tkinter) widget names when a widget's class name finishes with a digit.

[gh-128014](https://github.com/python/cpython/issues/128014): Made resetting the default window icon work by handing `default=''` to the [`tkinter`](https://docs.python.org/3.14/library/tkinter.html#module-tkinter) method `wm_iconbitmap()`.
