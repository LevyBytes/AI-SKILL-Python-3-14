# Python 3.14.0 alpha 4 / library / build and platforms

[gh-128388](https://github.com/python/cpython/issues/128388): Extended `PyREPL` on Windows so it recognizes more keybindings, among them the Control-" and Control-" word-skipping ones plus those carrying meta (that is, Alt), such as Alt-d for `kill-word` or Alt-Backspace for `backward-kill-word`.
