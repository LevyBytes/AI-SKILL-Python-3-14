# Python 3.10.0 alpha 7 / core and builtins / numbers

[bpo-39316](https://bugs.python.org/issue?@action=redirect&bpo=39316): Attribute accesses are now traced with correct line numbers even when the attribute sits on a line apart from the object. This aids debugging and profiling of multi-line method chains.
