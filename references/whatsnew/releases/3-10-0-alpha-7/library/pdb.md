# Python 3.10.0 alpha 7 / library / pdb

[bpo-24160](https://bugs.python.org/issue?@action=redirect&bpo=24160): Resolved a defect in [`pdb`](https://docs.python.org/3.14/library/pdb.html#module-pdb)'s interactive mode where breakpoints failed to carry over between separate debugger sessions.

[bpo-26053](https://bugs.python.org/issue?@action=redirect&bpo=26053): Resolved a defect in which the [`pdb`](https://docs.python.org/3.14/library/pdb.html#module-pdb) interactive run command repeated the args from the shell command line even after they had been replaced at the pdb prompt.
