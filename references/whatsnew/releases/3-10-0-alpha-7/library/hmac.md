# Python 3.10.0 alpha 7 / library / hmac

[bpo-40645](https://bugs.python.org/issue?@action=redirect&bpo=40645): Whenever the digestmod argument names a hash or is a builtin hash function, the [`hmac`](https://docs.python.org/3.14/library/hmac.html#module-hmac) module now relies on OpenSSL's HMAC implementation.
