# Python 3.10.0 alpha 7 / library / pprint

[bpo-42914](https://bugs.python.org/issue?@action=redirect&bpo=42914): [`pprint.pprint()`](https://docs.python.org/3.14/library/pprint.html#pprint.pprint) picks up a fresh boolean `underscore_numbers` optional argument that prints integers with their thousands grouped by an underscore for easier reading (so `1_000_000` rather than `1000000`).
