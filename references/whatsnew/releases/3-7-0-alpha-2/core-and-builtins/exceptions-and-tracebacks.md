# Python 3.7.0 alpha 2 / core and builtins / exceptions and tracebacks

[bpo-31588](https://bugs.python.org/issue?@action=redirect&bpo=31588): Emit a `TypeError` carrying a useful error message whenever class creation breaks because a metaclass has a faulty `__prepare__()` method. Oren Milman wrote the patch.

[bpo-31506](https://bugs.python.org/issue?@action=redirect&bpo=31506): The error message logic for `object.__new__` and `object.__init__` was improved.
