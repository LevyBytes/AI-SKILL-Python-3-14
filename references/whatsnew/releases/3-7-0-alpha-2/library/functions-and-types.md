# Python 3.7.0 alpha 2 / library / functions and types

[bpo-31389](https://bugs.python.org/issue?@action=redirect&bpo=31389): `pdb.set_trace()` now accepts an optional keyword-only `header` argument. When supplied, its value prints to the console immediately before debugging starts.

[bpo-31673](https://bugs.python.org/issue?@action=redirect&bpo=31673): Corrected a typo in the name of Tkinter’s adderrorinfo() method.
