# Python 3.7.0 alpha 2 / idle / python

[bpo-31460](https://bugs.python.org/issue?@action=redirect&bpo=31460): The API for IDLE's Module Browser was streamlined. Handing it a widget rather than an flist plus root widget makes it possible to build a browser frame occupying just a portion of a window. And accepting a complete file name in place of fragments presumed to originate from a .py file makes it feasible to browse python sources whose names don't finish in .py.
