# Python 3.7.0 alpha 2 / idle / dialog

[bpo-31459](https://bugs.python.org/issue?@action=redirect&bpo=31459): What IDLE labeled the Class Browser is now called the Module Browser. That original browser, which listed module-level classes and methods, grew into a module browser years back once module-level functions were folded in. Support for nested classes and functions arrived yesterday. To keep backwards compatibility, the <&lt;open-class-browser&gt;> virtual event shown on the Settings dialog's Keys tab stays as it was. Cheryl Sabella supplied the patch.
