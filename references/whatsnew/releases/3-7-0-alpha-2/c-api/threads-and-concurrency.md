# Python 3.7.0 alpha 2 / c api / threads and concurrency

[bpo-25658](https://bugs.python.org/issue?@action=redirect&bpo=25658): The Thread Specific Storage (TSS) API of [**PEP 539**](https://peps.python.org/pep-0539/) is now implemented: this fresh Thread Local Storage (TLS) API for CPython is meant to replace the TLS API already used inside the CPython interpreter and to deprecate that older one. Erik M. Bray authored the PEP and Masayuki Yamamoto wrote the patch.
