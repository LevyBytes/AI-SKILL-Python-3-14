# Python 3.8.0 beta 1 / documentation / text

[bpo-36686](https://bugs.python.org/issue?@action=redirect&bpo=36686): Sharpened the documentation covering the stdin, stdout, and stderr arguments of the `asyncio.subprocess_exec` function so the supported values are clear. Notes too that decoding to text is unsupported.

Also adds a handful of tests confirming that the assorted values handed to the std* arguments do indeed work.
