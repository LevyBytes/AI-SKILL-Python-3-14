# Python 3.8.0 beta 1 / library / plistlib

[bpo-26707](https://bugs.python.org/issue?@action=redirect&bpo=26707): Lets plistlib both read and write binary plist files originating as a KeyedArchive file. Concretely, plistlib is thereby able to handle 0x80 tokens as UID objects.
