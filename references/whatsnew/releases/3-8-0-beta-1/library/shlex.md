# Python 3.8.0 beta 1 / library / shlex

[bpo-22454](https://bugs.python.org/issue?@action=redirect&bpo=22454): The [`shlex`](https://docs.python.org/3.14/library/shlex.html#module-shlex) module now offers [`shlex.join()`](https://docs.python.org/3.14/library/shlex.html#shlex.join) as the counterpart of [`shlex.split()`](https://docs.python.org/3.14/library/shlex.html#shlex.split). Bo Bayles supplied the patch.
