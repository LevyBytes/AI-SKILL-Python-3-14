# Python 3.8.0 beta 1 / library / math

[bpo-36887](https://bugs.python.org/issue?@action=redirect&bpo=36887): Introduces the [`math.isqrt()`](https://docs.python.org/3.14/library/math.html#math.isqrt) routine for evaluating integer square roots.

[bpo-37128](https://bugs.python.org/issue?@action=redirect&bpo=37128): Adds [`math.perm()`](https://docs.python.org/3.14/library/math.html#math.perm).

[bpo-35431](https://bugs.python.org/issue?@action=redirect&bpo=35431): Adds [`math.comb()`](https://docs.python.org/3.14/library/math.html#math.comb), giving the binomial coefficient — the count of ways to pick k items out of n without repetition and without ordering. Yash Aggarwal and Keller Fuchs wrote the patch.
