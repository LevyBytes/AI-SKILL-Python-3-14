# Python 3.8.0 beta 1 / library / symtable

[bpo-37001](https://bugs.python.org/issue?@action=redirect&bpo=37001): [`symtable.symtable()`](https://docs.python.org/3.14/library/symtable.html#symtable.symtable) henceforth takes the very same source-code input types as the built-in [`compile()`](https://docs.python.org/3.14/library/functions.html#compile) function. Dino Viehland wrote the patch.
