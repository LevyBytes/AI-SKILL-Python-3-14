# Python 3.8.0 beta 1 / library / ssl

[bpo-34271](https://bugs.python.org/issue?@action=redirect&bpo=34271): Adds debugging aids to the ssl module. Dumping key material and tracing the TLS protocol are now feasible. The SSLKEYLOGFILE env var is also honored by the default and stdlib contexts.
