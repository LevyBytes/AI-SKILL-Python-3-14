# Python 3.8.0 beta 1 / core and builtins / text and unicode

[bpo-36861](https://bugs.python.org/issue?@action=redirect&bpo=36861): Bumps the Unicode database up to version 12.1.0.

[bpo-36594](https://bugs.python.org/issue?@action=redirect&bpo=36594): Repairs a wrong use of `%p` within format strings. Zackery Spytz wrote the patch.

[bpo-36878](https://bugs.python.org/issue?@action=redirect&bpo=36878): Text trailing a `# type: ignore` is admitted only when its leading character is ASCII. The intent is to forbid constructs such as `# type: ignoreé`.
