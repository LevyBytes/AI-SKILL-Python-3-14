# Python 3.8.0 beta 1 / core and builtins / collections and iteration

[bpo-35814](https://bugs.python.org/issue?@action=redirect&bpo=35814): Unpacking is now permitted on the right-hand side of annotated assignments. As a concrete case, `t: Tuple[int, ...] = x, y, *z` now passes.
