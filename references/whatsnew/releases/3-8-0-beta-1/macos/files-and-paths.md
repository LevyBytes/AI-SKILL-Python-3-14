# Python 3.8.0 beta 1 / macos / files and paths

[bpo-36231](https://bugs.python.org/issue?@action=redirect&bpo=36231): Enables building Python on macOS even when /usr/include is absent. Beginning with macOS 10.14, system header files ship only inside an SDK delivered through either the Command Line Tools or the Xcode app.
