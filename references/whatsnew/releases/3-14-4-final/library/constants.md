# Python 3.14.4 final / library / constants

[gh-143698](https://github.com/python/cpython/issues/143698): Permits the *scheduler* and *setpgroup* arguments to be explicitly [`None`](https://docs.python.org/3.14/library/constants.html#None) while calling [`os.posix_spawn()`](https://docs.python.org/3.14/library/os.html#os.posix_spawn) or [`os.posix_spawnp()`](https://docs.python.org/3.14/library/os.html#os.posix_spawnp). Bénédikt Tran supplied the patch.
