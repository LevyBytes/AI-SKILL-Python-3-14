# Python 3.11.0 alpha 7 / build / soabi values added wasm32 emscripten emscripten wasm32 wasi wasi bit wasm

[bpo-40280](https://bugs.python.org/issue?@action=redirect&bpo=40280): SOABI values are added — `wasm32-emscripten` for Emscripten and `wasm32-wasi` for WASI on 32bit WASM, plus their `wasm64` counter parts.
