# Python 3.11.0 alpha 7 / windows / files and paths

[bpo-47086](https://bugs.python.org/issue?@action=redirect&bpo=47086): Rather than one compiled `.chm` file, the Windows installer now ships documentation as loose HTML files.

[bpo-46948](https://bugs.python.org/issue?@action=redirect&bpo=46948): [**CVE 2022-26488**](https://www.cve.org/CVERecord?id=CVE-2022-26488) is prevented by making sure the Add to PATH option in the Windows installer applies the correct path during a repair.
