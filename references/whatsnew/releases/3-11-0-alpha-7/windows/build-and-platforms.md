# Python 3.11.0 alpha 7 / windows / build and platforms

[bpo-47171](https://bugs.python.org/issue?@action=redirect&bpo=47171): Installing the `py.exe` launcher is now enabled on Windows ARM64.

[bpo-46907](https://bugs.python.org/issue?@action=redirect&bpo=46907): The Windows installer is updated to use SQLite 3.38.1.

[bpo-44549](https://bugs.python.org/issue?@action=redirect&bpo=44549): bzip2 is updated to 1.0.8 across Windows builds to guard against [**CVE 2016-3189**](https://www.cve.org/CVERecord?id=CVE-2016-3189) and [**CVE 2019-12900**](https://www.cve.org/CVERecord?id=CVE-2019-12900).
