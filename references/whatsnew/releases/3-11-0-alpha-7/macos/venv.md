# Python 3.11.0 alpha 7 / macos / venv

[bpo-46890](https://bugs.python.org/issue?@action=redirect&bpo=46890): A regression in how `sys._base_executable` was set for framework builds is fixed, which in turn fixes a regression affecting [`venv`](https://docs.python.org/3.14/library/venv.html#module-venv) virtual environments produced from such builds.
