# Python 3.11.0 alpha 7 / library / sys

[bpo-47099](https://bugs.python.org/issue?@action=redirect&bpo=47099): The exception-chaining mechanism moved away from `Exception.with_traceback()`/[`sys.exc_info()`](https://docs.python.org/3.14/library/sys.html#sys.exc_info) toward [**PEP 3134**](https://peps.python.org/pep-3134/). Oleg Iarygin supplied the patch.
