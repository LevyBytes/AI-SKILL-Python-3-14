# Python 3.11.0 alpha 7 / library / global inline flags such i valid only very beginning

[bpo-47066](https://bugs.python.org/issue?@action=redirect&bpo=47066): Global inline flags such as `(?i)` are now valid only at the very beginning of a regular expression. Placing them elsewhere had carried a deprecation since Python 3.6.
