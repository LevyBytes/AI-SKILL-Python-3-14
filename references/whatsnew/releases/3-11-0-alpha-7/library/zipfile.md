# Python 3.11.0 alpha 7 / library / zipfile

[bpo-28080](https://bugs.python.org/issue?@action=redirect&bpo=28080): A *metadata_encoding* parameter joins the [`zipfile.ZipFile`](https://docs.python.org/3.14/library/zipfile.html#zipfile.ZipFile) constructor, alongside a `--metadata-encoding` option in the [`zipfile`](https://docs.python.org/3.14/library/zipfile.html#module-zipfile) CLI, so zipfiles whose archived filenames use non-standard codecs can be read.
