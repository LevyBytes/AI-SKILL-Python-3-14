# Python 3.11.0 alpha 7 / library / asyncio

[bpo-39622](https://bugs.python.org/issue?@action=redirect&bpo=39622): Within asyncio programs, Ctrl+C is now handled so the main task gets interrupted.

[bpo-46805](https://bugs.python.org/issue?@action=redirect&bpo=46805): asyncio gains raw datagram socket functions: `sock_sendto()`, `sock_recvfrom()` and `sock_recvfrom_into()`.

[bpo-47039](https://bugs.python.org/issue?@action=redirect&bpo=47039): Bring the `repr()` of asyncio future and task objects into a consistent form.
