# Python 3.11.0 alpha 7 / library / ctypes

[bpo-33178](https://bugs.python.org/issue?@action=redirect&bpo=33178): The [`ctypes.BigEndianUnion`](https://docs.python.org/3.14/library/ctypes.html#ctypes.BigEndianUnion) and [`ctypes.LittleEndianUnion`](https://docs.python.org/3.14/library/ctypes.html#ctypes.LittleEndianUnion) classes are now added — they were described in the library docs all along but had never been implemented.
