# Python 3.11.0 alpha 7 / library / pwd

[bpo-46933](https://bugs.python.org/issue?@action=redirect&bpo=46933): The [`pwd`](https://docs.python.org/3.14/library/pwd.html#module-pwd) module becomes optional. Where `pwd` is unavailable, [`os.path.expanduser()`](https://docs.python.org/3.14/library/os.path.html#os.path.expanduser) hands back the path unchanged.
