# Python 3.11.0 alpha 7 / library / warnings

[bpo-46557](https://bugs.python.org/issue?@action=redirect&bpo=46557): The logging module now records warnings it captures without a format string, so that any system grouping logs by the msg argument no longer lumps all captured warnings into one bucket.
