# Python 3.11.0 alpha 7 / library / asynchat

[bpo-47022](https://bugs.python.org/issue?@action=redirect&bpo=47022): For a stretch reaching back to at least Python 3.6, the `asynchat`, `asyncore` and `smtpd` modules have been deprecated. Their documentation and deprecation warnings now state that removal will land in Python 3.12 ([**PEP 594**](https://peps.python.org/pep-0594/)).
