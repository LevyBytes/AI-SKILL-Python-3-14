# Python 3.11.0 alpha 7 / library / collections and iteration

[bpo-43224](https://bugs.python.org/issue?@action=redirect&bpo=43224): types.GenericAlias objects can now be unpacked, for instance `*tuple[int, str]`.

[bpo-47208](https://bugs.python.org/issue?@action=redirect&bpo=47208): Permit vendors to set their own `CTYPES_MAX_ARGCOUNT`.

[bpo-46981](https://bugs.python.org/issue?@action=redirect&bpo=46981): `typing.get_args(typing.Tuple[()])` hands back `()` these days instead of `((),)`.
