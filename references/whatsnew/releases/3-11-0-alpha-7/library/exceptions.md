# Python 3.11.0 alpha 7 / library / exceptions

[bpo-46607](https://bugs.python.org/issue?@action=redirect&bpo=46607): A [`DeprecationWarning`](https://docs.python.org/3.14/library/exceptions.html#DeprecationWarning) is now attached to `LegacyInterpolation`, which the docstring had already marked deprecated back in Python 3.2. Removal is slated for Python 3.13. Reach for `BasicInterpolation` or `ExtendedInterpolation` as the replacement.
