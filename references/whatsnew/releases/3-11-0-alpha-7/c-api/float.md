# Python 3.11.0 alpha 7 / c api / float

[bpo-46906](https://bugs.python.org/issue?@action=redirect&bpo=46906): New functions for packing and unpacking a C double (serialize and deserialize) are added: [`PyFloat_Pack2()`](https://docs.python.org/3.14/c-api/float.html#c.PyFloat_Pack2), [`PyFloat_Pack4()`](https://docs.python.org/3.14/c-api/float.html#c.PyFloat_Pack4), [`PyFloat_Pack8()`](https://docs.python.org/3.14/c-api/float.html#c.PyFloat_Pack8), [`PyFloat_Unpack2()`](https://docs.python.org/3.14/c-api/float.html#c.PyFloat_Unpack2), [`PyFloat_Unpack4()`](https://docs.python.org/3.14/c-api/float.html#c.PyFloat_Unpack4) and [`PyFloat_Unpack8()`](https://docs.python.org/3.14/c-api/float.html#c.PyFloat_Unpack8). Victor Stinner wrote the patch.
