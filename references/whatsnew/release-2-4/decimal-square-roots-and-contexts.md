# What’s New in Python 2.4 / The `Decimal` type

There’s a `sqrt()` method on `Decimal` instances that yields a `Decimal`, but should you require other things like trigonometric functions, you’ll need to write them yourself.

```python
>>> d.sqrt()
Decimal("351364.1828820134592177245001")

```
