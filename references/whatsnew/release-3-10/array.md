# What's New In Python 3.10 / array — array

### array

On [`array.array`](https://docs.python.org/3.14/library/array.html#array.array), optional *start* and *stop* parameters are now accepted by its [`index()`](https://docs.python.org/3.14/library/array.html#array.array.index) method. (Anders Lorentsen along with Zackery Spytz contributed this in [bpo-31956](https://bugs.python.org/issue?@action=redirect&bpo=31956).)
