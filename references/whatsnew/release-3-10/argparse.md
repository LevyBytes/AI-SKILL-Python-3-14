# What's New In Python 3.10 / argparse

### argparse

Within argparse help, the confusing wording “optional arguments” gave way to “options”. A handful of tests may need tweaking should they depend on matching the output exactly. (Contributed by Raymond Hettinger in [bpo-9694](https://bugs.python.org/issue?@action=redirect&bpo=9694).)
