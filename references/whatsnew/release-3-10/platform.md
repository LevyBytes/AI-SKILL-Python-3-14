# What's New In Python 3.10 / platform — platform

### platform

Add [`platform.freedesktop_os_release()`](https://docs.python.org/3.14/library/platform.html#platform.freedesktop_os_release) to pull operating system identification out of the [freedesktop.org os-release](https://www.freedesktop.org/software/systemd/man/os-release.html) standard file. (Contributed by Christian Heimes in [bpo-28468](https://bugs.python.org/issue?@action=redirect&bpo=28468).)
