# What's New In Python 3.10 / importlib.metadata - importlib.metadata

Reaches feature parity with `importlib_metadata` 4.6 ([history](https://importlib-metadata.readthedocs.io/en/latest/history.html)).

A new [importlib.metadata.EntryPoints](https://docs.python.org/3.14/library/importlib.metadata.html#entry-points) class gives [importlib.metadata entry points](https://docs.python.org/3.14/library/importlib.metadata.html#entry-points) a smoother way to pick entry points by group plus name. Consult the Compatibility Note in the documentation for further detail on the deprecation and how to use it.

Introduced [importlib.metadata.packages_distributions()](https://docs.python.org/3.14/library/importlib.metadata.html#package-distributions), which maps top-level Python packages and modules back to their [importlib.metadata.Distribution](https://docs.python.org/3.14/library/importlib.metadata.html#distributions).
