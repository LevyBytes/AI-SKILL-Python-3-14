### C API Changes

### PEP 652: Maintaining the Stable ABI

The Stable ABI (Application Binary Interface) covering extension modules or Python embedding now carries an explicit definition. [C API Stability](https://docs.python.org/3.14/c-api/stable.html#stable) lays out the C API and ABI stability guarantees as well as recommended practices for working with the Stable ABI.

(Contributed by Petr Viktorin in [**PEP 652**](https://peps.python.org/pep-0652/) and [bpo-43795](https://bugs.python.org/issue?@action=redirect&bpo=43795).)
