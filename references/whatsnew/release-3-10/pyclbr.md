# What's New In Python 3.10 / pyclbr - pyclbr

### pyclbr

Add an `end_lineno` attribute on the `Function` and `Class` objects within the tree handed back by [`pyclbr.readmodule()`](https://docs.python.org/3.14/library/pyclbr.html#pyclbr.readmodule) and [`pyclbr.readmodule_ex()`](https://docs.python.org/3.14/library/pyclbr.html#pyclbr.readmodule_ex). It pairs with the already-present (start) `lineno`. (Contributed by Aviral Srivastava in [bpo-38307](https://bugs.python.org/issue?@action=redirect&bpo=38307).)
