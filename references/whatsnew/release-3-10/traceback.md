# What's New In Python 3.10 / traceback — traceback

### traceback

The [`format_exception()`](https://docs.python.org/3.14/library/traceback.html#traceback.format_exception), [`format_exception_only()`](https://docs.python.org/3.14/library/traceback.html#traceback.format_exception_only), and [`print_exception()`](https://docs.python.org/3.14/library/traceback.html#traceback.print_exception) functions are now able to accept, as a positional-only argument, an exception object. (Contributed by Zackery Spytz and Matthias Bussonnier in [bpo-26389](https://bugs.python.org/issue?@action=redirect&bpo=26389).)
