# What's New In Python 3.10 / PEP 647: User-Defined Type Guards - typing

### PEP 647: User-Defined Type Guards

The [`typing`](https://docs.python.org/3.14/library/typing.html#module-typing) module gained [`TypeGuard`](https://docs.python.org/3.14/library/typing.html#typing.TypeGuard), which annotates type guard functions and feeds richer detail to static type checkers while they narrow types. To dig deeper, consult `TypeGuard`‘s documentation, plus [**PEP 647**](https://peps.python.org/pep-0647/).

(Ken Jin together with Guido van Rossum contributed this in [bpo-43766](https://bugs.python.org/issue?@action=redirect&bpo=43766). Eric Traut authored the PEP.)
