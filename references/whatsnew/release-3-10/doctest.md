# What's New In Python 3.10 / doctest

### doctest

Where a module supplies no `__loader__`, the code now falls back to `__spec__.loader`. (Contributed by Brett Cannon in [bpo-42133](https://bugs.python.org/issue?@action=redirect&bpo=42133).)
