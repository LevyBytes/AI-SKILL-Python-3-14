# What's New In Python 3.10 / glob — glob

### glob

Add *root_dir* and *dir_fd* parameters to [`glob()`](https://docs.python.org/3.14/library/glob.html#glob.glob) and [`iglob()`](https://docs.python.org/3.14/library/glob.html#glob.iglob), letting you point the search at a chosen root directory. (Contributed by Serhiy Storchaka in [bpo-38144](https://bugs.python.org/issue?@action=redirect&bpo=38144).)
