# What's New In Python 3.10 / base64 - base64

### base64

Add [`base64.b32hexencode()`](https://docs.python.org/3.14/library/base64.html#base64.b32hexencode) and [`base64.b32hexdecode()`](https://docs.python.org/3.14/library/base64.html#base64.b32hexdecode) so that Base32 Encoding with Extended Hex Alphabet is supported.
