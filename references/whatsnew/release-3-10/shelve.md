# What's New In Python 3.10 / shelve - pickle, shelve

### shelve

When making shelves, the [`shelve`](https://docs.python.org/3.14/library/shelve.html#module-shelve) module now defaults to [`pickle.DEFAULT_PROTOCOL`](https://docs.python.org/3.14/library/pickle.html#pickle.DEFAULT_PROTOCOL) rather than [`pickle`](https://docs.python.org/3.14/library/pickle.html#module-pickle) protocol `3`. (Contributed by Zackery Spytz in [bpo-34204](https://bugs.python.org/issue?@action=redirect&bpo=34204).)
