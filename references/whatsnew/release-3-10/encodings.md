# What's New In Python 3.10 / encodings — codecs

### encodings

Non-ASCII characters are now disregarded by [`encodings.normalize_encoding()`](https://docs.python.org/3.14/library/codecs.html#encodings.normalize_encoding). (Contributed by Hai Shi in [bpo-39337](https://bugs.python.org/issue?@action=redirect&bpo=39337).)
