# What's New In Python 3.10 / types — types

### types

Reintroduce the [`types.EllipsisType`](https://docs.python.org/3.14/library/types.html#types.EllipsisType), [`types.NoneType`](https://docs.python.org/3.14/library/types.html#types.NoneType) and [`types.NotImplementedType`](https://docs.python.org/3.14/library/types.html#types.NotImplementedType) classes, supplying a fresh set of types that type checkers can readily interpret. (Contributed by Bas van Beek in [bpo-41810](https://bugs.python.org/issue?@action=redirect&bpo=41810).)
