# What's New In Python 3.10 / PEP 634: Structural Pattern Matching

### PEP 634: Structural Pattern Matching

Structural pattern matching arrives as a *match statement* paired with *case statements* holding patterns and their attached actions. A pattern may be built from sequences, mappings, primitive data types, and also class instances. With pattern matching, programs can pull data out of intricate data types, branch according to how data is structured, and run targeted actions depending on the various shapes the data takes.
