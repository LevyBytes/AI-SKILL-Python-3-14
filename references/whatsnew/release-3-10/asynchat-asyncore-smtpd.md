# What's New In Python 3.10 / asynchat, asyncore, smtpd

### asynchat, asyncore, smtpd

Since Python 3.6 these modules have been flagged as deprecated within their module documentation. All three now also emit an import-time [`DeprecationWarning`](https://docs.python.org/3.14/library/exceptions.html#DeprecationWarning).
