# What's New In Python 3.10 / unittest — unittest

### unittest

Add new method [`assertNoLogs()`](https://docs.python.org/3.14/library/unittest.html#unittest.TestCase.assertNoLogs), a counterpart that rounds out the already-present [`assertLogs()`](https://docs.python.org/3.14/library/unittest.html#unittest.TestCase.assertLogs). (Contributed by Kit Yan Choi in [bpo-39385](https://bugs.python.org/issue?@action=redirect&bpo=39385).)
