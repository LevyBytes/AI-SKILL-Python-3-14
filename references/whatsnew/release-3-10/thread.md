# What's New In Python 3.10 / _thread - _thread, signal

### _thread

[`_thread.interrupt_main()`](https://docs.python.org/3.14/library/_thread.html#thread.interrupt_main) now accepts an optional signal number to simulate (with [`signal.SIGINT`](https://docs.python.org/3.14/library/signal.html#signal.SIGINT) staying the default). (Contributed by Antoine Pitrou in [bpo-43356](https://bugs.python.org/issue?@action=redirect&bpo=43356).)
