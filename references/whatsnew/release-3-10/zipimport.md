# What's New In Python 3.10 / zipimport - zipimport

### zipimport

Add methods related to [**PEP 451**](https://peps.python.org/pep-0451/): [`find_spec()`](https://docs.python.org/3.14/library/zipimport.html#zipimport.zipimporter.find_spec), [`zipimport.zipimporter.create_module()`](https://docs.python.org/3.14/library/zipimport.html#zipimport.zipimporter.create_module), and [`zipimport.zipimporter.exec_module()`](https://docs.python.org/3.14/library/zipimport.html#zipimport.zipimporter.exec_module). (Contributed by Brett Cannon in [bpo-42131](https://bugs.python.org/issue?@action=redirect&bpo=42131).)

Add [`invalidate_caches()`](https://docs.python.org/3.14/library/zipimport.html#zipimport.zipimporter.invalidate_caches) method. (Contributed by Desmond Cheong in [bpo-14678](https://bugs.python.org/issue?@action=redirect&bpo=14678).)
