# What's New In Python 3.10 / Porting to Python 3.10 / Changes in the C API / CPython bytecode changes

### CPython bytecode changes

- The `MAKE_FUNCTION` instruction will now take either a dict or a tuple of strings to supply the function's annotations. (Contributed by Yurii Karabas and Inada Naoki in [bpo-42202](https://bugs.python.org/issue?@action=redirect&bpo=42202).)
