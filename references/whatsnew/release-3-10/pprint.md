# What's New In Python 3.10 / pprint — dataclasses, pprint

### pprint

[`pprint.pprint()`](https://docs.python.org/3.14/library/pprint.html#pprint.pprint) now takes a new `underscore_numbers` keyword argument. (Contributed by sblondon in [bpo-42914](https://bugs.python.org/issue?@action=redirect&bpo=42914).)

[`pprint`](https://docs.python.org/3.14/library/pprint.html#module-pprint) gains the ability to pretty-print [`dataclasses.dataclass`](https://docs.python.org/3.14/library/dataclasses.html#dataclasses.dataclass) instances. (Contributed by Lewis Gaul in [bpo-43080](https://bugs.python.org/issue?@action=redirect&bpo=43080).)
