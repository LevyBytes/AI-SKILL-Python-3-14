# What's New In Python 3.10 / faulthandler — faulthandler

### faulthandler

Should a fatal error strike in the middle of a garbage collector collection, the [`faulthandler`](https://docs.python.org/3.14/library/faulthandler.html#module-faulthandler) module now notices it. (Contributed by Victor Stinner in [bpo-44466](https://bugs.python.org/issue?@action=redirect&bpo=44466).)
