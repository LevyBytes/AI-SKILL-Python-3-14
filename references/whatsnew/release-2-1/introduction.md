### Introduction

Here we walk through what Python 2.1 brings to the table. The count of changes is smaller than what Python 2.0 delivered, yet a few welcome additions are waiting for you nonetheless. This marks the very first release guided by Python Enhancement Proposals (the PEPs), and as a result nearly every substantial change ships alongside a PEP that supplies fuller documentation plus the reasoning behind the design decision. The intent here isn’t exhaustive coverage of each addition; rather, it offers Python programmers a high-level tour. When a particular feature catches your interest, consult either the Python 2.1 documentation or the relevant PEP for the finer points.

A goal the Python developers have pursued lately is shortening the interval between releases, aiming for a fresh release roughly every 6 to 9 months. 2.1 is the inaugural release to follow this quicker cadence; its first alpha surfaced in January, just 3 months after 2.0 reached its final form.

Python 2.1 reached its final release on April 17, 2001.
