# What's New In Python 3.7 / decimal — decimal

### decimal

To hold the decimal context, the [`decimal`](https://docs.python.org/3.14/library/decimal.html#module-decimal) module now leans on context variables. (Contributed by Yury Selivanov in [bpo-32630](https://bugs.python.org/issue?@action=redirect&bpo=32630).)
