# What's New In Python 3.7 / hmac — hmac

### hmac

An optimized one-shot [`digest()`](https://docs.python.org/3.14/library/hmac.html#hmac.digest) function now lives in the [`hmac`](https://docs.python.org/3.14/library/hmac.html#module-hmac) module, running as much as three times quicker than [`HMAC()`](https://docs.python.org/3.14/library/hmac.html#hmac.HMAC). (Contributed by Christian Heimes in [bpo-32433](https://bugs.python.org/issue?@action=redirect&bpo=32433).)
