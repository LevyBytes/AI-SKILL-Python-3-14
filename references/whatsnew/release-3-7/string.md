# What's New In Python 3.7 / string — string

### string

[`string.Template`](https://docs.python.org/3.14/library/string.html#string.Template) now permits you to separately adjust, if you wish, the regular expression pattern used for braced placeholders versus non-braced placeholders. (Contributed by Barry Warsaw in [bpo-1198569](https://bugs.python.org/issue?@action=redirect&bpo=1198569).)
