# What's New In Python 3.7 / pdb — pdb

### pdb

[`pdb.set_trace()`](https://docs.python.org/3.14/library/pdb.html#pdb.set_trace) now accepts an optional *header* keyword-only argument. Supply it and it prints to the console right as debugging starts. (Contributed by Barry Warsaw in [bpo-31389](https://bugs.python.org/issue?@action=redirect&bpo=31389).)

The [`pdb`](https://docs.python.org/3.14/library/pdb.html#module-pdb) command line now recognizes `-m module_name` as a substitute for naming a script file. (Contributed by Mario Corchero in [bpo-32206](https://bugs.python.org/issue?@action=redirect&bpo=32206).)
