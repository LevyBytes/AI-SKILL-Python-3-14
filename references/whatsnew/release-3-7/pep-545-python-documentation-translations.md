# What's New In Python 3.7 / PEP 545: Python Documentation Translations

### PEP 545: Python Documentation Translations

[**PEP 545**](https://peps.python.org/pep-0545/) lays out how Python documentation translations get created and kept current.

Three fresh translations have joined:

- Japanese: [https://docs.python.org/ja/](https://docs.python.org/ja/)

- French: [https://docs.python.org/fr/](https://docs.python.org/fr/)

- Korean: [https://docs.python.org/ko/](https://docs.python.org/ko/)
