# What's New In Python 3.7 / pathlib — pathlib

### pathlib

A new [`Path.is_mount()`](https://docs.python.org/3.14/library/pathlib.html#pathlib.Path.is_mount) method now exists on POSIX systems, letting you check whether a given path is a mount point. (Contributed by Cooper Ry Lees in [bpo-30897](https://bugs.python.org/issue?@action=redirect&bpo=30897).)
