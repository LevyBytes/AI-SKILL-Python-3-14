# What's New In Python 3.7 / io - io

### io

A new [`TextIOWrapper.reconfigure()`](https://docs.python.org/3.14/library/io.html#io.TextIOWrapper.reconfigure) method lets you reconfigure the text stream so it adopts fresh settings. (Contributed by Antoine Pitrou in [bpo-30526](https://bugs.python.org/issue?@action=redirect&bpo=30526) and INADA Naoki in [bpo-15216](https://bugs.python.org/issue?@action=redirect&bpo=15216).)
