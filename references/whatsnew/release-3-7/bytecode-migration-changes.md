# What's New In Python 3.7 / Porting to Python 3.7 / Changes in the C API / CPython bytecode changes

### CPython bytecode changes

A pair of new opcodes have arrived: `LOAD_METHOD` and `CALL_METHOD`. Yury Selivanov and INADA Naoki contributed these through [bpo-26110](https://bugs.python.org/issue?@action=redirect&bpo=26110).

The `STORE_ANNOTATION` opcode was dropped. Mark Shannon contributed this through [bpo-32550](https://bugs.python.org/issue?@action=redirect&bpo=32550).
