# What's New In Python 3.7 / threading - threading

### threading

The `dummy_threading` and `_dummy_thread` modules are now deprecated. Building Python with threading turned off is no longer feasible. Use [`threading`](https://docs.python.org/3.14/library/threading.html#module-threading) instead. (Contributed by Antoine Pitrou in [bpo-31370](https://bugs.python.org/issue?@action=redirect&bpo=31370).)
