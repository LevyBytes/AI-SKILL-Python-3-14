# What's New In Python 3.7 / pydoc

### pydoc

The new `-n` command-line argument lets the pydoc server bind to whatever hostname you choose. (Contributed by Feanil Patel in [bpo-31128](https://bugs.python.org/issue?@action=redirect&bpo=31128).)
