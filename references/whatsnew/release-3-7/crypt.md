# What's New In Python 3.7 / crypt

### crypt

Blowfish hashing is now among the methods the `crypt` module handles. (Contributed by Serhiy Storchaka in [bpo-31664](https://bugs.python.org/issue?@action=redirect&bpo=31664).)

You can now tell the `mksalt()` function how many rounds to use for hashing. (Contributed by Serhiy Storchaka in [bpo-31702](https://bugs.python.org/issue?@action=redirect&bpo=31702).)
