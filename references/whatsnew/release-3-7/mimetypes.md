# What's New In Python 3.7 / mimetypes

### mimetypes

For .bmp, the MIME type was switched away from `'image/x-ms-bmp'` over to `'image/bmp'`. (Contributed by Nitish Chandra in [bpo-22589](https://bugs.python.org/issue?@action=redirect&bpo=22589).)
