# What's New In Python 3.7 / dis — dis

### dis

Nested code objects can now be taken apart by the [`dis()`](https://docs.python.org/3.14/library/dis.html#dis.dis) function (covering the code of comprehensions, generator expressions, and nested functions, plus the code that builds nested classes). A fresh *depth* parameter governs how far the disassembly recursion is allowed to descend. (Contributed by Serhiy Storchaka in [bpo-11822](https://bugs.python.org/issue?@action=redirect&bpo=11822).)
