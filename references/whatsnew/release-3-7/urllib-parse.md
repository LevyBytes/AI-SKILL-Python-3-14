# What's New In Python 3.7 / urllib.parse — urllib.parse

### urllib.parse

Moving from [**RFC 2396**](https://datatracker.ietf.org/doc/html/rfc2396.html) to [**RFC 3986**](https://datatracker.ietf.org/doc/html/rfc3986.html), [`urllib.parse.quote()`](https://docs.python.org/3.14/library/urllib.parse.html#urllib.parse.quote) now adds `~` to the characters that go unquoted by default. (Contributed by Christian Theune and Ratnadeep Debnath in [bpo-16285](https://bugs.python.org/issue?@action=redirect&bpo=16285).)
