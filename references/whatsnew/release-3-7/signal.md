# What's New In Python 3.7 / signal - signal

### signal

A new *warn_on_full_buffer* argument on the [`signal.set_wakeup_fd()`](https://docs.python.org/3.14/library/signal.html#signal.set_wakeup_fd) function lets you decide whether Python writes a warning to stderr once the wakeup buffer fills past capacity. (Contributed by Nathaniel J. Smith in [bpo-30050](https://bugs.python.org/issue?@action=redirect&bpo=30050).)
