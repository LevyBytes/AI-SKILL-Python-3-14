# What's New In Python 3.7 / collections

### collections

Default values are now accepted by `collections.namedtuple()`. (Contributed by Raymond Hettinger in [bpo-32320](https://bugs.python.org/issue?@action=redirect&bpo=32320).)

### collections

Starting with Python 3.8, the abstract base classes living in [`collections.abc`](https://docs.python.org/3.14/library/collections.abc.html#module-collections.abc) will cease to appear inside the ordinary [`collections`](https://docs.python.org/3.14/library/collections.html#module-collections) module. The goal is to draw a sharper line separating the concrete classes from the abstract base classes. (Contributed by Serhiy Storchaka in [bpo-25988](https://bugs.python.org/issue?@action=redirect&bpo=25988).)
