# What's New In Python 3.7 / Python Development Mode (-X dev) — devmode

### Python Development Mode (-X dev)

The new [`-X`](https://docs.python.org/3.14/using/cmdline.html#cmdoption-X) `dev` command line option, or alternatively the new [`PYTHONDEVMODE`](https://docs.python.org/3.14/using/cmdline.html#envvar-PYTHONDEVMODE) environment variable, switches on [Python Development Mode](https://docs.python.org/3.14/library/devmode.html#devmode). Under development mode Python runs extra runtime checks that would be too costly to leave on by default. The complete description appears in the [Python Development Mode](https://docs.python.org/3.14/library/devmode.html#devmode) documentation.
