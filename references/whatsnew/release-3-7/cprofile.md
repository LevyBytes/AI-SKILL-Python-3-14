# What's New In Python 3.7 / cProfile — profile

### cProfile

As an option besides a script path, the [`cProfile`](https://docs.python.org/3.14/library/profile.html#module-cProfile) command line will now take `-m module_name`. (Contributed by Sanyam Khurana in [bpo-21862](https://bugs.python.org/issue?@action=redirect&bpo=21862).)
