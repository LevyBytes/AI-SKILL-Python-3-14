# What's New In Python 3.7 / gettext — gettext

### gettext

Passing a non-integer value to pick a plural form in [`gettext`](https://docs.python.org/3.14/library/gettext.html#module-gettext) is now deprecated. That behavior never functioned properly. (Contributed by Serhiy Storchaka in [bpo-28692](https://bugs.python.org/issue?@action=redirect&bpo=28692).)
