# What's New In Python 3.7 / itertools — itertools

### itertools

[`itertools.islice()`](https://docs.python.org/3.14/library/itertools.html#itertools.islice) will now take [`integer-like objects`](https://docs.python.org/3.14/reference/datamodel.html#object.__index__) for its start, stop, and slice arguments. (Contributed by Will Roberts in [bpo-30537](https://bugs.python.org/issue?@action=redirect&bpo=30537).)
