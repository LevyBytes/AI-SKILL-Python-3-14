# What's New In Python 3.7 / aifc

### Deprecated Python modules, functions and methods

### aifc

The `aifc.openfp()` call is now deprecated and will go away in Python 3.9. Switch to `aifc.open()` instead. (Contributed by Brian Curtin in [bpo-31985](https://bugs.python.org/issue?@action=redirect&bpo=31985).)
