# What's New In Python 3.7 / macpath

### macpath

`macpath` is now deprecated and is slated for removal in Python 3.8. (Contributed by Chi Hsuan Yen in [bpo-9850](https://bugs.python.org/issue?@action=redirect&bpo=9850).)
