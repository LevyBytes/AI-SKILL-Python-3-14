# What's New In Python 3.7 / compileall - compileall

### compileall

The [`compileall.compile_dir()`](https://docs.python.org/3.14/library/compileall.html#compileall.compile_dir) function gained a fresh *invalidation_mode* parameter for switching on hash-based .pyc invalidation. You can also pick the invalidation mode from the command line through the fresh `--invalidation-mode` argument. (Contributed by Benjamin Peterson in [bpo-31650](https://bugs.python.org/issue?@action=redirect&bpo=31650).)
