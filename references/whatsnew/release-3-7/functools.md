# What's New In Python 3.7 / functools - functools

### functools

Registering implementations through type annotations is now supported by [`functools.singledispatch()`](https://docs.python.org/3.14/library/functools.html#functools.singledispatch). (Contributed by ?ukasz Langa in [bpo-32227](https://bugs.python.org/issue?@action=redirect&bpo=32227).)
