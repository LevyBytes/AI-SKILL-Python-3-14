# What's New In Python 3.7 / wave - wave

### wave

The `wave.openfp()` call is now deprecated and will go away in Python 3.9. Switch to [`wave.open()`](https://docs.python.org/3.14/library/wave.html#wave.open) instead. (Contributed by Brian Curtin in [bpo-31985](https://bugs.python.org/issue?@action=redirect&bpo=31985).)
