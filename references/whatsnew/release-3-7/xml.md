# What's New In Python 3.7 / xml - xml.dom.minidom, xml.sax

### xml

To guard against DTD and external entity retrieval, external entities are no longer processed by default in the [`xml.dom.minidom`](https://docs.python.org/3.14/library/xml.dom.minidom.html#module-xml.dom.minidom) and [`xml.sax`](https://docs.python.org/3.14/library/xml.sax.html#module-xml.sax) modules. (Contributed by Christian Heimes in [gh-61441](https://github.com/python/cpython/issues/61441).)
