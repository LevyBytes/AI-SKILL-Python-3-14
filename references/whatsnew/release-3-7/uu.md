# What's New In Python 3.7 / uu

### uu

An optional *backtick* keyword argument is now accepted by the `uu.encode()` function. With it set true, `'`'` stands in for zeros rather than spaces. (Contributed by Xiang Zhang in [bpo-30103](https://bugs.python.org/issue?@action=redirect&bpo=30103).)
