# What's New In Python 3.7 / binascii — binascii

### binascii

An optional *backtick* keyword argument is now taken by the [`b2a_uu()`](https://docs.python.org/3.14/library/binascii.html#binascii.b2a_uu) function. Set it true and zeros come out as `'`'` rather than spaces. (Contributed by Xiang Zhang in [bpo-30103](https://bugs.python.org/issue?@action=redirect&bpo=30103).)
