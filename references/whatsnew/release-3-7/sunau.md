# What's New In Python 3.7 / sunau

### sunau

The `sunau.openfp()` call is now deprecated and will go away in Python 3.9. Switch to `sunau.open()` instead. (Contributed by Brian Curtin in [bpo-31985](https://bugs.python.org/issue?@action=redirect&bpo=31985).)
