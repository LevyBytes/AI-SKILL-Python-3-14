# What's New In Python 3.7 / calendar — calendar

### calendar

Fresh class attributes on the [`HTMLCalendar`](https://docs.python.org/3.14/library/calendar.html#calendar.HTMLCalendar) class make it simpler to tailor the CSS classes within the generated HTML calendar. (Contributed by Oz Tiram in [bpo-30095](https://bugs.python.org/issue?@action=redirect&bpo=30095).)
