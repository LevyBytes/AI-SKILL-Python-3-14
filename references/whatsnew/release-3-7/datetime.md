# What's New In Python 3.7 / datetime - datetime

### datetime

A fresh [`datetime.fromisoformat()`](https://docs.python.org/3.14/library/datetime.html#datetime.datetime.fromisoformat) method assembles a [`datetime`](https://docs.python.org/3.14/library/datetime.html#datetime.datetime) object out of a string written in one of the layouts produced by [`datetime.isoformat()`](https://docs.python.org/3.14/library/datetime.html#datetime.datetime.isoformat). (Contributed by Paul Ganssle in [bpo-15873](https://bugs.python.org/issue?@action=redirect&bpo=15873).)

Sub-minute offsets are now handled by the [`tzinfo`](https://docs.python.org/3.14/library/datetime.html#datetime.tzinfo) class. (Contributed by Alexander Belopolsky in [bpo-5288](https://bugs.python.org/issue?@action=redirect&bpo=5288).)
