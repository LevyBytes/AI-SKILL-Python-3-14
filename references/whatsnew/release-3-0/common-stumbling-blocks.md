# What's New In Python 3.0 / Common Stumbling Blocks

### What's New In Python 3.0

Author:

Guido van Rossum

Here we walk through what is fresh in Python 3.0 relative to 2.6. Carrying the nicknames ?Python 3000? and ?Py3K?, this was the very first Python edition designed to be *intentionally backwards incompatible*. Python 3.0 was released on December 3, 2008. The volume of changes exceeds the usual release, and a larger share of them matters to everyone who writes Python. Still, once the dust settles you'll see that the language hasn't really shifted dramatically; mostly we cleaned up familiar irritations and quirks and stripped away a heap of aging cruft.

Rather than serving as an exhaustive specification of every new capability, this writeup aims to deliver a handy summary. To get the whole picture, consult the Python 3.0 documentation along with the numerous PEPs cited throughout. When you're after the full implementation and the reasoning behind a given feature, a PEP typically carries deeper detail than the standard docs; keep in mind, though, that a PEP often stops being maintained after its feature ships in full.

Owing to a shortage of time, this writeup falls short of the coverage it deserves. As is true for any release, the `Misc/NEWS` file shipped in the source distribution holds a trove of granular notes covering each tiny adjustment.
