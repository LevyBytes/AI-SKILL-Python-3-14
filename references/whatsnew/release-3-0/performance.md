# What's New In Python 3.0 / Performance

### Performance

Taken together, the broadening changes in 3.0 leave Python 3.0 executing the pystone benchmark roughly 10% behind Python 2.5. The leading suspect is almost certainly that small integers no longer receive special-case treatment. Improvements are possible, but they will land only once 3.0 has shipped!
