# What's New In Python 3.0 / **PEP 3101**: A New Approach To String Formatting

### [**PEP 3101**](https://peps.python.org/pep-3101/): A New Approach To String Formatting

- A fresh mechanism for native string-formatting work supersedes the `%` string-formatting operator. (That said, `%` continues to function for now; it is slated for deprecation in Python 3.1 and eventual removal from the language down the road.) Consult [**PEP 3101**](https://peps.python.org/pep-3101/) for every detail.
