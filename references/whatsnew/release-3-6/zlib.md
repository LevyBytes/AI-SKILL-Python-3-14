# What's New In Python 3.6 / zlib - zlib

### zlib

The [`compress()`](https://docs.python.org/3.14/library/zlib.html#zlib.compress) and [`decompress()`](https://docs.python.org/3.14/library/zlib.html#zlib.decompress) functions take keyword arguments now. (Contributed by Aviv Palivoda in [bpo-26243](https://bugs.python.org/issue?@action=redirect&bpo=26243) and Xiang Zhang in [bpo-16764](https://bugs.python.org/issue?@action=redirect&bpo=16764) respectively.)
