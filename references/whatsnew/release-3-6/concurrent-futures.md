# What's New In Python 3.6 / concurrent.futures — concurrent.futures

### concurrent.futures

The [`ThreadPoolExecutor`](https://docs.python.org/3.14/library/concurrent.futures.html#concurrent.futures.ThreadPoolExecutor) class constructor has gained an optional *thread_name_prefix* argument letting you tailor the names given to the threads the pool spins up. (Contributed by Gregory P. Smith in [bpo-27664](https://bugs.python.org/issue?@action=redirect&bpo=27664).)
