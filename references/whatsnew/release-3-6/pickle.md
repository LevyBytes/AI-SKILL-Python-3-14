# What's New In Python 3.6 / pickle — pickle

### pickle

Using [pickle protocols](https://docs.python.org/3.14/library/pickle.html#pickle-protocols) below protocol version 4, you can now pickle objects whose `__new__` requires keyword arguments. That scenario was already covered by protocol version 4. (Contributed by Serhiy Storchaka in [bpo-24164](https://bugs.python.org/issue?@action=redirect&bpo=24164).)
