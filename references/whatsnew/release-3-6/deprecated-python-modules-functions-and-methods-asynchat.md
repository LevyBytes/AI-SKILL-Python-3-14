# What's New In Python 3.6 / Deprecated Python modules, functions and methods / asynchat — asyncio

### Deprecated Python modules, functions and methods

#### asynchat

`asynchat` has been deprecated, with [`asyncio`](https://docs.python.org/3.14/library/asyncio.html#module-asyncio) being favored instead. (Contributed by Mariatta in [bpo-25002](https://bugs.python.org/issue?@action=redirect&bpo=25002).)
