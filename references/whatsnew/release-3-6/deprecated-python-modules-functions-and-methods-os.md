# What's New In Python 3.6 / Deprecated Python modules, functions and methods / os - os

#### os

Undocumented acceptance of general [bytes-like objects](https://docs.python.org/3.14/glossary.html#term-bytes-like-object) for use as paths across [`os`](https://docs.python.org/3.14/library/os.html#module-os) functions, [`compile()`](https://docs.python.org/3.14/library/functions.html#compile) and comparable functions is now deprecated. (Contributed by Serhiy Storchaka in [bpo-25791](https://bugs.python.org/issue?@action=redirect&bpo=25791) and [bpo-26754](https://bugs.python.org/issue?@action=redirect&bpo=26754).)
