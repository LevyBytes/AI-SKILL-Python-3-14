# What's New In Python 3.6 / Deprecated Python modules, functions and methods / venv

#### venv

Deprecation has landed on the `pyvenv` script, with `python3 -m venv` taking its place. The change removes ambiguity about which interpreter `pyvenv` ties to, and therefore which one the virtual environment ends up running. (Contributed by Brett Cannon in [bpo-25154](https://bugs.python.org/issue?@action=redirect&bpo=25154).)
