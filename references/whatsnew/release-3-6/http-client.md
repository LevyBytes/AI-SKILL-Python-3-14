# What's New In Python 3.6 / http.client - http.client

Chunked encoding request bodies are now accepted by both [`HTTPConnection.request()`](https://docs.python.org/3.14/library/http.client.html#http.client.HTTPConnection.request) and [`endheaders()`](https://docs.python.org/3.14/library/http.client.html#http.client.HTTPConnection.endheaders). (Contributed by Demian Brecht and Rolf Krahl in [bpo-12319](https://bugs.python.org/issue?@action=redirect&bpo=12319).)
