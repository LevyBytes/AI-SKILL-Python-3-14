# What's New In Python 3.6 / pickletools — pickletools

### pickletools

For the `MEMOIZE` opcode, [`pickletools.dis()`](https://docs.python.org/3.14/library/pickletools.html#pickletools.dis) now prints the implicit memo index. (Contributed by Serhiy Storchaka in [bpo-25382](https://bugs.python.org/issue?@action=redirect&bpo=25382).)
