# What's New In Python 3.6 / encodings

### encodings

Under Windows, an `'oem'` encoding was added that taps `CP_OEMCP`, plus an `'ansi'` alias pointing at the existing `'mbcs'` encoding, which draws on the `CP_ACP` code page. (Contributed by Steve Dower in [bpo-27959](https://bugs.python.org/issue?@action=redirect&bpo=27959).)
