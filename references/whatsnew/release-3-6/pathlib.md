# What's New In Python 3.6 / pathlib - pathlib

### pathlib

[path-like objects](https://docs.python.org/3.14/glossary.html#term-path-like-object) are now handled by [`pathlib`](https://docs.python.org/3.14/library/pathlib.html#module-pathlib). (Contributed by Brett Cannon in [bpo-27186](https://bugs.python.org/issue?@action=redirect&bpo=27186).)

Refer to the summary of PEP 519 for specifics.
