# What's New In Python 3.6 / struct - struct

### struct

By way of the `'e'` format specifier, [`struct`](https://docs.python.org/3.14/library/struct.html#module-struct) now handles IEEE 754 half-precision floats. (Contributed by Eli Stevens, Mark Dickinson in [bpo-11734](https://bugs.python.org/issue?@action=redirect&bpo=11734).)
