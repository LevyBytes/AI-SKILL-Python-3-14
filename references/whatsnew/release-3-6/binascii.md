# What's New In Python 3.6 / binascii - binascii

### binascii

The [`b2a_base64()`](https://docs.python.org/3.14/library/binascii.html#binascii.b2a_base64) function has gained an optional *newline* keyword argument that governs whether the newline character gets tacked onto what is returned. (Contributed by Victor Stinner in [bpo-25357](https://bugs.python.org/issue?@action=redirect&bpo=25357).)
