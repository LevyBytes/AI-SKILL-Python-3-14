# What's New In Python 3.6 / multiprocessing - multiprocessing

### multiprocessing

Nesting is now permitted for [Proxy Objects](https://docs.python.org/3.14/library/multiprocessing.html#multiprocessing-proxy-objects) that [`multiprocessing.Manager()`](https://docs.python.org/3.14/library/multiprocessing.html#multiprocessing.Manager) hands back. (Contributed by Davin Potts in [bpo-6766](https://bugs.python.org/issue?@action=redirect&bpo=6766).)
