# What's New In Python 3.6 / readline - readline

### readline

To switch automatic appending of input into the history list on or off, [`set_auto_history()`](https://docs.python.org/3.14/library/readline.html#readline.set_auto_history) was added. (Contributed by Tyler Crompton in [bpo-26870](https://bugs.python.org/issue?@action=redirect&bpo=26870).)
