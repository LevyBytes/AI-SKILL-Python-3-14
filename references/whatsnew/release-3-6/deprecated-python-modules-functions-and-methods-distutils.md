# What's New In Python 3.6 / Deprecated Python modules, functions and methods / distutils

#### distutils

The undocumented `extra_path` argument passed to the `distutils.Distribution` constructor is now regarded as deprecated and triggers a warning when set. This parameter's support disappears in an upcoming Python release. Consult [bpo-27919](https://bugs.python.org/issue?@action=redirect&bpo=27919) for the specifics.
