# What's New In Python 3.6 / ast - ast

### ast

A freshly introduced [`ast.Constant`](https://docs.python.org/3.14/library/ast.html#ast.Constant) AST node now exists. Outside AST optimizers can take advantage of it to perform constant folding.

Contributed by Victor Stinner in [bpo-26146](https://bugs.python.org/issue?@action=redirect&bpo=26146).
