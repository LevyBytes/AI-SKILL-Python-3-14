# What's New In Python 3.6 / xmlrpc.client - xmlrpc.client

### xmlrpc.client

The [`xmlrpc.client`](https://docs.python.org/3.14/library/xmlrpc.client.html#module-xmlrpc.client) module can now unmarshal further data types that the Apache XML-RPC implementation employs for numerics and `None`. (Contributed by Serhiy Storchaka in [bpo-26885](https://bugs.python.org/issue?@action=redirect&bpo=26885).)
