# What's New In Python 3.6 / xml - xml.dom.minidom, xml.sax

### xml

- To harden against DTD plus external entity fetching, the [`xml.dom.minidom`](https://docs.python.org/3.14/library/xml.dom.minidom.html#module-xml.dom.minidom) along with [`xml.sax`](https://docs.python.org/3.14/library/xml.sax.html#module-xml.sax) modules have stopped handling external entities out of the box. (Contributed by Christian Heimes in [gh-61441](https://github.com/python/cpython/issues/61441).)
