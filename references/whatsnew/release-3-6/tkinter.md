# What's New In Python 3.6 / tkinter

### tkinter

Within the `tkinter.Variable` class, the methods `Variable.trace_add()`, `Variable.trace_remove()` and `trace_info()` were added. These supersede the older `trace_variable()`, `trace()`, `trace_vdelete()` and `trace_vinfo()` methods, which lean on outdated Tcl commands and may break under later Tcl releases. (Contributed by Serhiy Storchaka in [bpo-22115](https://bugs.python.org/issue?@action=redirect&bpo=22115)).
