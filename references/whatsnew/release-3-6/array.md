# What's New In Python 3.6 / array - array

### Improved Modules

### array

Once an iterator over an [`array.array`](https://docs.python.org/3.14/library/array.html#array.array) has been depleted it will remain depleted, even should the underlying array later grow. That brings it in line with how the other mutable sequences behave.

Contributed by Serhiy Storchaka in [bpo-26492](https://bugs.python.org/issue?@action=redirect&bpo=26492).
