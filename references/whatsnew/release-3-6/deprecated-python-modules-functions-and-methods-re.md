# What's New In Python 3.6 / Deprecated Python modules, functions and methods / re

#### re

Handling for inline flags `(?letters)` placed in the middle of the regular expression has been deprecated and disappears in an upcoming Python version. Placing flags at the beginning of a regular expression stays permitted. (Contributed by Serhiy Storchaka in [bpo-22493](https://bugs.python.org/issue?@action=redirect&bpo=22493).)
