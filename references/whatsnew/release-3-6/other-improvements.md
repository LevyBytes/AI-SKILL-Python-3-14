# What's New In Python 3.6 / Other Improvements - sys

### Other Improvements

- Supplying [`--version`](https://docs.python.org/3.14/using/cmdline.html#cmdoption-version) (short form: [`-V`](https://docs.python.org/3.14/using/cmdline.html#cmdoption-V)) two times makes Python print [`sys.version`](https://docs.python.org/3.14/library/sys.html#sys.version) for fuller detail.

```shell
$ ./python -VV
Python 3.6.0b4+ (3.6:223967b49e49+, Nov 21 2016, 20:55:04)
[GCC 4.2.1 Compatible Apple LLVM 8.0.0 (clang-800.0.42.1)]

```
