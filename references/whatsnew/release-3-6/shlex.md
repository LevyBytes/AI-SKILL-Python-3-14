# What's New In Python 3.6 / shlex - shlex

### shlex

Thanks to the fresh *punctuation_chars* argument, which decides which characters count as punctuation, the [`shlex`](https://docs.python.org/3.14/library/shlex.html#shlex.shlex) now offers far [improved shell compatibility](https://docs.python.org/3.14/library/shlex.html#improved-shell-compatibility). (Contributed by Vinay Sajip in [bpo-1521950](https://bugs.python.org/issue?@action=redirect&bpo=1521950).)
