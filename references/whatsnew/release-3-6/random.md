# What's New In Python 3.6 / random — random

### random

Given a population, the fresh [`choices()`](https://docs.python.org/3.14/library/random.html#random.choices) function hands back a list of a requested length, optionally honoring weights. (Contributed by Raymond Hettinger in [bpo-18844](https://bugs.python.org/issue?@action=redirect&bpo=18844).)
