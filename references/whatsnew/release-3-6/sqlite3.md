# What's New In Python 3.6 / sqlite3 — sqlite3

### sqlite3

The `REPLACE` statement is now handled by [`sqlite3.Cursor.lastrowid`](https://docs.python.org/3.14/library/sqlite3.html#sqlite3.Cursor.lastrowid). (Contributed by Alex LordThorsen in [bpo-16864](https://bugs.python.org/issue?@action=redirect&bpo=16864).)
