# What's New In Python 3.6 / site - sys

### site

While listing paths for [`sys.path`](https://docs.python.org/3.14/library/sys.html#sys.path) inside a `.pth` file, you can now point at file paths layered over directories (zip files, say). (Contributed by Wolfgang Langner in [bpo-26587](https://bugs.python.org/issue?@action=redirect&bpo=26587)).
