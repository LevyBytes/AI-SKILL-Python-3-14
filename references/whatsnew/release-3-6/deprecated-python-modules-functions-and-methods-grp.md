# What's New In Python 3.6 / Deprecated Python modules, functions and methods / grp - grp

#### grp

Accepting non-integer arguments in [`getgrgid()`](https://docs.python.org/3.14/library/grp.html#grp.getgrgid) has been deprecated. (Contributed by Serhiy Storchaka in [bpo-26129](https://bugs.python.org/issue?@action=redirect&bpo=26129).)
