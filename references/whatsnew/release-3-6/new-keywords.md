### New Keywords

Using `async` and `await` as variable, class, function or module names is discouraged. Brought in by [**PEP 492**](https://peps.python.org/pep-0492/) during Python 3.5, both turn into genuine keywords in Python 3.7. From Python 3.6 onward, employing `async` or `await` as names raises a [`DeprecationWarning`](https://docs.python.org/3.14/library/exceptions.html#DeprecationWarning).
