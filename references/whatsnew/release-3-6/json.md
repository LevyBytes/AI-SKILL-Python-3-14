# What's New In Python 3.6 / json — json

### json

Binary input is now handled by [`json.load()`](https://docs.python.org/3.14/library/json.html#json.load) and [`json.loads()`](https://docs.python.org/3.14/library/json.html#json.loads). Any encoded JSON ought to use UTF-8, UTF-16, or UTF-32. (Contributed by Serhiy Storchaka in [bpo-17909](https://bugs.python.org/issue?@action=redirect&bpo=17909).)
