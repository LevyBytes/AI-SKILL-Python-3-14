# What's New In Python 3.6 / Notable changes in Python 3.6.5 - locale

### Notable changes in Python 3.6.5

Under certain circumstances the [`locale.localeconv()`](https://docs.python.org/3.14/library/locale.html#locale.localeconv) function will, for the moment, switch the `LC_CTYPE` locale over to the `LC_NUMERIC` locale. (Contributed by Victor Stinner in [bpo-31900](https://bugs.python.org/issue?@action=redirect&bpo=31900).)
