# What's New In Python 3.6 / Deprecated Python modules, functions and methods / tkinter - tkinter, tkinter.ttk

#### tkinter

Deprecation now applies to the `tkinter.tix` module. Anyone relying on [`tkinter`](https://docs.python.org/3.14/library/tkinter.html#module-tkinter) ought to switch over to [`tkinter.ttk`](https://docs.python.org/3.14/library/tkinter.ttk.html#module-tkinter.ttk).
