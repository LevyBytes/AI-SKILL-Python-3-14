# What's New In Python 3.6 / logging - logging.handlers

### logging

So you can test whether reopening the log file is warranted, the fresh [`WatchedFileHandler.reopenIfNeeded()`](https://docs.python.org/3.14/library/logging.handlers.html#logging.handlers.WatchedFileHandler.reopenIfNeeded) method was introduced. (Contributed by Marian Horban in [bpo-24884](https://bugs.python.org/issue?@action=redirect&bpo=24884).)
