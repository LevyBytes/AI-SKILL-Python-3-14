# What's New In Python 3.6 / pydoc - pydoc

### pydoc

The `MANPAGER` environment variable is now honored by the [`pydoc`](https://docs.python.org/3.14/library/pydoc.html#module-pydoc) module. (Contributed by Matthias Klose in [bpo-8637](https://bugs.python.org/issue?@action=redirect&bpo=8637).)

Rather than alphabetically, [`help()`](https://docs.python.org/3.14/library/functions.html#help) together with [`pydoc`](https://docs.python.org/3.14/library/pydoc.html#module-pydoc) can now show named tuple fields following their definition order. (Contributed by Raymond Hettinger in [bpo-24879](https://bugs.python.org/issue?@action=redirect&bpo=24879).)
