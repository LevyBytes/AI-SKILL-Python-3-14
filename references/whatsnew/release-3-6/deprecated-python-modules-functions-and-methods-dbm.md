# What's New In Python 3.6 / Deprecated Python modules, functions and methods / dbm - dbm

#### dbm

In contrast to other [`dbm`](https://docs.python.org/3.14/library/dbm.html#module-dbm) implementations, the [`dbm.dumb`](https://docs.python.org/3.14/library/dbm.html#module-dbm.dumb) module builds databases using the `'rw'` mode and permits altering a database that was opened under the `'r'` mode. Such behavior is now deprecated and gets removed in 3.8. (Contributed by Serhiy Storchaka in [bpo-21708](https://bugs.python.org/issue?@action=redirect&bpo=21708).)
