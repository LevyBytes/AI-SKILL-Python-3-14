# What's New In Python 3.6 / venv - venv

### venv

[`venv`](https://docs.python.org/3.14/library/venv.html#module-venv) takes a fresh `--prompt` parameter. That parameter supplies a different prefix for the virtual environment. (Proposed by ??ukasz Balcerzak and ported to 3.6 by Stéphane Wirtel in [bpo-22829](https://bugs.python.org/issue?@action=redirect&bpo=22829).)
