# What's New In Python 3.6 / faulthandler — faulthandler

### faulthandler

Under Windows, the [`faulthandler`](https://docs.python.org/3.14/library/faulthandler.html#module-faulthandler) module now sets up a handler covering Windows exceptions: refer to [`faulthandler.enable()`](https://docs.python.org/3.14/library/faulthandler.html#faulthandler.enable). (Contributed by Victor Stinner in [bpo-23848](https://bugs.python.org/issue?@action=redirect&bpo=23848).)
