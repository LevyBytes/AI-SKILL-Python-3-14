# What's New in Python 2.5 / New, Improved, and Removed Modules — copy, datetime, weakref, webbrowser, xmlrpc.client, zipfile, zlib

- In the [`weakref`](https://docs.python.org/3.14/library/weakref.html#module-weakref) module, the `WeakKeyDictionary` and `WeakValueDictionary` types received new methods for walking over the weak references held inside the dictionary. The `iterkeyrefs()` and `keyrefs()` methods landed on `WeakKeyDictionary`, while `itervaluerefs()` and `valuerefs()` arrived on `WeakValueDictionary`. (Contributed by Fred L. Drake, Jr.)

- The [`webbrowser`](https://docs.python.org/3.14/library/webbrowser.html#module-webbrowser) module gained several improvements. You can now run it as a script via `python -m webbrowser`, passing a URL as the argument; several switches govern its behaviour (`-n` opens a new browser window, `-t` opens a new tab). Backing this, the new module-level functions `open_new()` and `open_new_tab()` were introduced. The module's [`open()`](https://docs.python.org/3.14/library/functions.html#open) function now accepts an extra *autoraise* parameter indicating whether the opened window should be raised where feasible. Several more browsers joined the supported set, among them Firefox, Opera, Konqueror, and elinks. (Contributed by Oleg Broytmann and Georg Brandl.)

- The [`xmlrpclib`](https://docs.python.org/3.14/library/xmlrpc.client.html#module-xmlrpc.client) module can now hand back [`datetime`](https://docs.python.org/3.14/library/datetime.html#datetime.datetime) objects for the XML-RPC date type. Pass `use_datetime=True` to either the [`loads()`](https://docs.python.org/3.14/library/xmlrpc.client.html#xmlrpc.client.loads) function or the `Unmarshaller` class to switch this on. (Contributed by Skip Montanaro.)

- The [`zipfile`](https://docs.python.org/3.14/library/zipfile.html#module-zipfile) module now handles the ZIP64 variant of the format, so a .zip archive can exceed 4 GiB and may hold individual files that are themselves bigger than 4 GiB. (Contributed by Ronald Oussoren.)

- In the [`zlib`](https://docs.python.org/3.14/library/zlib.html#module-zlib) module, the `Compress` and `Decompress` objects now offer a [`copy()`](https://docs.python.org/3.14/library/copy.html#module-copy) method that duplicates the object's internal state and returns a fresh `Compress` or `Decompress` object. (Contributed by Chris AtLee.)
