# What's New In Python 3.9 / signal - signal

### signal

The Linux-only [`signal.pidfd_send_signal()`](https://docs.python.org/3.14/library/signal.html#signal.pidfd_send_signal) was exposed, letting you signal a process through a file descriptor rather than a pid. ([bpo-38712](https://bugs.python.org/issue?@action=redirect&bpo=38712))
