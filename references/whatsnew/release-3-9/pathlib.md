# What's New In Python 3.9 / pathlib — os, pathlib

### pathlib

A new [`pathlib.Path.readlink()`](https://docs.python.org/3.14/library/pathlib.html#pathlib.Path.readlink) was added; it behaves much like [`os.readlink()`](https://docs.python.org/3.14/library/os.html#os.readlink). (Contributed by Girts Folkmanis in [bpo-30618](https://bugs.python.org/issue?@action=redirect&bpo=30618))
