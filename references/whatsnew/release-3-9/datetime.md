# What's New In Python 3.9 / datetime — collections, datetime

### datetime

[`isocalendar()`](https://docs.python.org/3.14/library/datetime.html#datetime.date.isocalendar) on [`datetime.date`](https://docs.python.org/3.14/library/datetime.html#datetime.date) along with [`isocalendar()`](https://docs.python.org/3.14/library/datetime.html#datetime.datetime.isocalendar) on [`datetime.datetime`](https://docs.python.org/3.14/library/datetime.html#datetime.datetime) now hand back a [`namedtuple()`](https://docs.python.org/3.14/library/collections.html#collections.namedtuple) in place of a plain [`tuple`](https://docs.python.org/3.14/library/stdtypes.html#tuple). (Contributed by Donghee Na in [bpo-24416](https://bugs.python.org/issue?@action=redirect&bpo=24416).)
