# What's New In Python 3.9 / pprint — pprint, types

### pprint

[`pprint`](https://docs.python.org/3.14/library/pprint.html#module-pprint) is now able to pretty-print [`types.SimpleNamespace`](https://docs.python.org/3.14/library/types.html#types.SimpleNamespace) values. (Contributed by Carl Bordum Hansen in [bpo-37376](https://bugs.python.org/issue?@action=redirect&bpo=37376).)
