# What's New In Python 3.9 / New String Methods to Remove Prefixes and Suffixes

### New String Methods to Remove Prefixes and Suffixes

The pair [`str.removeprefix(prefix)`](https://docs.python.org/3.14/library/stdtypes.html#str.removeprefix) plus [`str.removesuffix(suffix)`](https://docs.python.org/3.14/library/stdtypes.html#str.removesuffix) arrived to make stripping an unwanted leading prefix or trailing suffix off a string simple. Matching `bytes`, `bytearray`, and `collections.UserString` variants joined too. Consult [**PEP 616**](https://peps.python.org/pep-0616/) for the complete writeup. (Contributed by Dennis Sweeney in [bpo-39939](https://bugs.python.org/issue?@action=redirect&bpo=39939).)
