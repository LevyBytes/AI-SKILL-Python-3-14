# What's New In Python 3.9 / multiprocessing — multiprocessing

### multiprocessing

A new [`close()`](https://docs.python.org/3.14/library/multiprocessing.html#multiprocessing.SimpleQueue.close) method on the [`multiprocessing.SimpleQueue`](https://docs.python.org/3.14/library/multiprocessing.html#multiprocessing.SimpleQueue) class lets you shut the queue explicitly. (Contributed by Victor Stinner in [bpo-30966](https://bugs.python.org/issue?@action=redirect&bpo=30966).)
