# What's New In Python 3.9 / fcntl

### fcntl

The constants `fcntl.F_OFD_GETLK`, `fcntl.F_OFD_SETLK` and `fcntl.F_OFD_SETLKW` were added. (Contributed by Donghee Na in [bpo-38602](https://bugs.python.org/issue?@action=redirect&bpo=38602).)
