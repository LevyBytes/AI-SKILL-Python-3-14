# What's New In Python 3.9 / distutils

### distutils

The **upload** command now produces SHA2-256 plus Blake2b-256 hash digests. On platforms that forbid the MD5 digest it leaves MD5 out. (Contributed by Christian Heimes in [bpo-40698](https://bugs.python.org/issue?@action=redirect&bpo=40698).)
