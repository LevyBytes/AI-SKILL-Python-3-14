# What's New In Python 3.9 / graphlib - graphlib

### graphlib

A freshly added module, [`graphlib`](https://docs.python.org/3.14/library/graphlib.html#module-graphlib), houses the [`graphlib.TopologicalSorter`](https://docs.python.org/3.14/library/graphlib.html#graphlib.TopologicalSorter) class, which supplies the capability to topologically sort graphs. (Contributed by Pablo Galindo, Tim Peters and Larry Hastings in [bpo-17005](https://bugs.python.org/issue?@action=redirect&bpo=17005).)
