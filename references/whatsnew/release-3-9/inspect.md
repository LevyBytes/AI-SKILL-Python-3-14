# What's New In Python 3.9 / inspect - inspect

### inspect

The type of [`inspect.BoundArguments.arguments`](https://docs.python.org/3.14/library/inspect.html#inspect.BoundArguments.arguments) was switched away from `OrderedDict` to a plain dict. (Contributed by Inada Naoki in [bpo-36350](https://bugs.python.org/issue?@action=redirect&bpo=36350) and [bpo-39775](https://bugs.python.org/issue?@action=redirect&bpo=39775).)
