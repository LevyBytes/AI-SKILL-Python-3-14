# What's New In Python 3.9 / pydoc

### pydoc

The docstring now appears not only for classes, functions, methods and the like, but for every object that carries its own [`__doc__`](https://docs.python.org/3.14/library/stdtypes.html#definition.__doc__) attribute. (Contributed by Serhiy Storchaka in [bpo-40257](https://bugs.python.org/issue?@action=redirect&bpo=40257).)
