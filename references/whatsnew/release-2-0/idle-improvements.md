# What’s New in Python 2.0 / IDLE Improvements

### IDLE Improvements

Built on top of Tkinter, IDLE is Python’s official cross-platform IDE. Bundled into Python 2.0 is IDLE 0.6, which brings several fresh features and refinements. Here is a sampling:

- Refinements and speed-ups to the interface, most of all around syntax highlighting and auto-indentation.

- More detail now appears in the class browser, the module-level functions of a module among it.

- You can now configure the tab width yourself. On loading an existing Python file, IDLE works out the indentation style in use and falls in line with it.

- Launching browsers across assorted platforms is now handled, the point being to bring up the Python documentation inside a browser.

- A command line has been added to IDLE, behaving much like the plain Python interpreter does.

- Call tips now show up across numerous spots.

- It is now possible to set up IDLE as a package.

- The editor window now carries a line/column indicator along its bottom edge.

- A trio of new keystroke commands arrived: Check module (Alt-F5), Import module (F5) and Run script (Ctrl-F5).
