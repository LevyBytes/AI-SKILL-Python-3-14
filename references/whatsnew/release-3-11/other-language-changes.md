# What's New In Python 3.11 / Other Language Changes — collections, contextlib, copy, datetime, pickle, string, sys, weakref

### Other Language Changes

- Starred unpacking expressions are now permitted within [`for`](https://docs.python.org/3.14/reference/compound_stmts.html#for) statements. (See [bpo-46725](https://bugs.python.org/issue?@action=redirect&bpo=46725) for more details.)

- > Asynchronous [comprehensions](https://docs.python.org/3.14/reference/expressions.html#comprehensions) may now appear nested inside comprehensions within [asynchronous functions](https://docs.python.org/3.14/reference/compound_stmts.html#async-def). In that situation the enclosing comprehensions quietly turn asynchronous. (Contributed by Serhiy Storchaka in [bpo-33346](https://bugs.python.org/issue?@action=redirect&bpo=33346).)

- > A [`TypeError`](https://docs.python.org/3.14/library/exceptions.html#TypeError) now surfaces in place of an [`AttributeError`](https://docs.python.org/3.14/library/exceptions.html#AttributeError) within [`with`](https://docs.python.org/3.14/reference/compound_stmts.html#with) statements and [`contextlib.ExitStack.enter_context()`](https://docs.python.org/3.14/library/contextlib.html#contextlib.ExitStack.enter_context) when an object lacks the [context manager](https://docs.python.org/3.14/glossary.html#term-context-manager) protocol, and equally within [`async with`](https://docs.python.org/3.14/reference/compound_stmts.html#async-with) statements and [`contextlib.AsyncExitStack.enter_async_context()`](https://docs.python.org/3.14/library/contextlib.html#contextlib.AsyncExitStack.enter_async_context) when an object lacks the [asynchronous context manager](https://docs.python.org/3.14/glossary.html#term-asynchronous-context-manager) protocol. (Contributed by Serhiy Storchaka in [bpo-12022](https://bugs.python.org/issue?@action=redirect&bpo=12022) and [bpo-44471](https://bugs.python.org/issue?@action=redirect&bpo=44471).)

- > Introduced [`object.__getstate__()`](https://docs.python.org/3.14/library/pickle.html#object.__getstate__), supplying the stock implementation of the `__getstate__()` method. [`copy`](https://docs.python.org/3.14/library/copy.html#module-copy)ing and [`pickle`](https://docs.python.org/3.14/library/pickle.html#module-pickle)ing instances of subclasses of builtin types [`bytearray`](https://docs.python.org/3.14/library/stdtypes.html#bytearray), [`set`](https://docs.python.org/3.14/library/stdtypes.html#set), [`frozenset`](https://docs.python.org/3.14/library/stdtypes.html#frozenset), [`collections.OrderedDict`](https://docs.python.org/3.14/library/collections.html#collections.OrderedDict), [`collections.deque`](https://docs.python.org/3.14/library/collections.html#collections.deque), [`weakref.WeakSet`](https://docs.python.org/3.14/library/weakref.html#weakref.WeakSet), and [`datetime.tzinfo`](https://docs.python.org/3.14/library/datetime.html#datetime.tzinfo) now copies and pickles instance attributes held in [slots](https://docs.python.org/3.14/glossary.html#term-__slots__). One unplanned consequence followed: it disrupts a handful of existing Python projects that did not anticipate `object.__getstate__()` being present. Browse the follow-up notes on [gh-70766](https://github.com/python/cpython/issues/70766) to see what fixes affected code might require. (Contributed by Serhiy Storchaka in [bpo-26579](https://bugs.python.org/issue?@action=redirect&bpo=26579).)

- > Introduced a [`-P`](https://docs.python.org/3.14/using/cmdline.html#cmdoption-P) command line option plus a [`PYTHONSAFEPATH`](https://docs.python.org/3.14/using/cmdline.html#envvar-PYTHONSAFEPATH) environment variable; both switch off the automatic prepending onto [`sys.path`](https://docs.python.org/3.14/library/sys.html#sys.path) of a script's own directory while running a script, or the working directory while using [`-c`](https://docs.python.org/3.14/using/cmdline.html#cmdoption-c) and [`-m`](https://docs.python.org/3.14/using/cmdline.html#cmdoption-m). This guarantees that [`import`](https://docs.python.org/3.14/reference/simple_stmts.html#import) only finds stdlib and installed modules, and it heads off accidental or malicious shadowing of modules by ones in a local (commonly user-writable) directory. (Contributed by Victor Stinner in [gh-57684](https://github.com/python/cpython/issues/57684).)

- > A `"z"` option joined the [Format specification mini-language](https://docs.python.org/3.14/library/string.html#formatspec); it nudges a negative zero up to positive zero once the value has been rounded to the format precision. See [**PEP 682**](https://peps.python.org/pep-0682/) for more details. (Contributed by John Belmonte in [gh-90153](https://github.com/python/cpython/issues/90153).)
