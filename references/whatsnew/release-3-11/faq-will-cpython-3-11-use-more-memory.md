# What's New In Python 3.11 / FAQ / Will CPython 3.11 use more memory?

#### Will CPython 3.11 use more memory?

Probably not; the expectation is that consumption stays within 20% of 3.10's figure. Savings from the frame-object and object-dictionary work covered earlier balance it out.
