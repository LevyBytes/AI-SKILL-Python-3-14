# What's New In Python 3.11 / pathlib — os, pathlib

### pathlib

- [`glob()`](https://docs.python.org/3.14/library/pathlib.html#pathlib.Path.glob) and [`rglob()`](https://docs.python.org/3.14/library/pathlib.html#pathlib.Path.rglob) yield directories alone when *pattern* finishes with a pathname component separator: [`sep`](https://docs.python.org/3.14/library/os.html#os.sep) or [`altsep`](https://docs.python.org/3.14/library/os.html#os.altsep). (Contributed by Eisuke Kawasima in [bpo-22276](https://bugs.python.org/issue?@action=redirect&bpo=22276) and [bpo-33392](https://bugs.python.org/issue?@action=redirect&bpo=33392).)
