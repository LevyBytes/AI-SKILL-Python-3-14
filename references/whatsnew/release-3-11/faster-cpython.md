# What's New In Python 3.11 / Faster CPython

### Faster CPython

Built with GCC on Ubuntu Linux and gauged via the [pyperformance](https://github.com/python/pyperformance) benchmark suite, CPython 3.11 averages [25% faster](https://github.com/faster-cpython/ideas#published-results) than CPython 3.10. Your particular workload determines whether the total speedup lands somewhere in the 10-60% band.

The effort zeroes in on a pair of major Python fronts: Faster Startup and Faster Runtime. Anything this project leaves out is enumerated on its own beneath Optimizations.
