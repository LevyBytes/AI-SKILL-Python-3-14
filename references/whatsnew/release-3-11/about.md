# What's New In Python 3.11 / About

### About

The Faster CPython initiative looks into ways to speed up [CPython](https://docs.python.org/3.14/glossary.html#term-CPython). Microsoft bankrolls the core group to pursue it full-time. On a part-time basis, Bloomberg LP funds Pablo Galindo Salgado's work here too. Beyond that, plenty of the contributors give their time as community volunteers.
