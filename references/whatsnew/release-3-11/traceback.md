# What's New In Python 3.11 / traceback - traceback

### traceback

- [`traceback.StackSummary.format_frame_summary()`](https://docs.python.org/3.14/library/traceback.html#traceback.StackSummary.format_frame_summary) was added so that users may control which frames land in the traceback, plus their formatting. (Contributed by Ammar Askar in [bpo-44569](https://bugs.python.org/issue?@action=redirect&bpo=44569).)

- [`traceback.TracebackException.print()`](https://docs.python.org/3.14/library/traceback.html#traceback.TracebackException.print) was added; it writes the formatted [`TracebackException`](https://docs.python.org/3.14/library/traceback.html#traceback.TracebackException) instance out to a file. (Contributed by Irit Katriel in [bpo-33809](https://bugs.python.org/issue?@action=redirect&bpo=33809).)
