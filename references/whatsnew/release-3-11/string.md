# What's New In Python 3.11 / string - string

### string

- [`get_identifiers()`](https://docs.python.org/3.14/library/string.html#string.Template.get_identifiers) plus [`is_valid()`](https://docs.python.org/3.14/library/string.html#string.Template.is_valid) were added onto [`string.Template`](https://docs.python.org/3.14/library/string.html#string.Template); the former lists every legal placeholder while the latter reports whether any illegal placeholder shows up. (Contributed by Ben Kehoe in [gh-90465](https://github.com/python/cpython/issues/90465).)
