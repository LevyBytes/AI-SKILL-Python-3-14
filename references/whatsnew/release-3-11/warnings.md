# What's New In Python 3.11 / warnings - warnings

### warnings

- [`warnings.catch_warnings()`](https://docs.python.org/3.14/library/warnings.html#warnings.catch_warnings) now takes the arguments belonging to [`warnings.simplefilter()`](https://docs.python.org/3.14/library/warnings.html#warnings.simplefilter), giving a tighter route to either ignore warnings locally or turn them into errors. (Contributed by Zac Hatfield-Dodds in [bpo-47074](https://bugs.python.org/issue?@action=redirect&bpo=47074).)
