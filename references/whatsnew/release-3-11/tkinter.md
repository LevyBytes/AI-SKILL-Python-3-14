### tkinter

- A method `info_patchlevel()` was added; it returns the precise Tcl library version as a named tuple resembling [`sys.version_info`](https://docs.python.org/3.14/library/sys.html#sys.version_info). (Contributed by Serhiy Storchaka in [gh-91827](https://github.com/python/cpython/issues/91827).)
