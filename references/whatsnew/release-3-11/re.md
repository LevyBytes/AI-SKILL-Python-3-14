# What's New In Python 3.11 / re

### re

- Regular expressions now accept atomic grouping (`(?>...)`) along with possessive quantifiers (`*+`, `++`, `?+`, `{m,n}+`). (Contributed by Jeffrey C. Jacobs and Serhiy Storchaka in [bpo-433030](https://bugs.python.org/issue?@action=redirect&bpo=433030).)
