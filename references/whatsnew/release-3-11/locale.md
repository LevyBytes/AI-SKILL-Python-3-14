# What's New In Python 3.11 / locale - locale, os

### locale

- [`locale.getencoding()`](https://docs.python.org/3.14/library/locale.html#locale.getencoding) was added to fetch the encoding of the current locale. It resembles `locale.getpreferredencoding(False)` yet disregards the [Python UTF-8 Mode](https://docs.python.org/3.14/library/os.html#utf8-mode).
