# What's New In Python 3.11 / fcntl

### fcntl

- Under FreeBSD, the `F_DUP2FD` and `F_DUP2FD_CLOEXEC` flags are each available; the first matches what `dup2` does, and the second additionally turns on the `FD_CLOEXEC` flag.
