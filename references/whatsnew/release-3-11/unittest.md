# What's New In Python 3.11 / unittest - unittest

### unittest

- Several additions arrived: [`enterContext()`](https://docs.python.org/3.14/library/unittest.html#unittest.TestCase.enterContext) and [`enterClassContext()`](https://docs.python.org/3.14/library/unittest.html#unittest.TestCase.enterClassContext) on class [`TestCase`](https://docs.python.org/3.14/library/unittest.html#unittest.TestCase), the [`enterAsyncContext()`](https://docs.python.org/3.14/library/unittest.html#unittest.IsolatedAsyncioTestCase.enterAsyncContext) method on class [`IsolatedAsyncioTestCase`](https://docs.python.org/3.14/library/unittest.html#unittest.IsolatedAsyncioTestCase), and the [`unittest.enterModuleContext()`](https://docs.python.org/3.14/library/unittest.html#unittest.enterModuleContext) function. (Contributed by Serhiy Storchaka in [bpo-45046](https://bugs.python.org/issue?@action=redirect&bpo=45046).)
