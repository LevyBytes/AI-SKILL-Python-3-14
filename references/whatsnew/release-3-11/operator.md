# What's New In Python 3.11 / operator

### operator

- A new `operator.call` function arrived, so that `operator.call(obj, *args, **kwargs) == obj(*args, **kwargs)`. (Contributed by Antony Lee in [bpo-44019](https://bugs.python.org/issue?@action=redirect&bpo=44019).)
