# What's New In Python 3.11 / IDLE and idlelib

### IDLE and idlelib

- Syntax highlighting is now applied to `.pyi` files. (Contributed by Alex Waygood and Terry Jan Reedy in [bpo-45447](https://bugs.python.org/issue?@action=redirect&bpo=45447).)

- Prompts are now kept when you save the Shell together with its inputs and outputs. (Contributed by Terry Jan Reedy in [gh-95191](https://github.com/python/cpython/issues/95191).)
