# What's new in Python 3.14 / struct — struct

### struct

- The [`struct`](https://docs.python.org/3.14/library/struct.html#module-struct) module now handles the C float complex and double complex types, mapped to the formatting characters `'F'` and `'D'` respectively. (Contributed by Sergey B Kirpichev in [gh-121249](https://github.com/python/cpython/issues/121249).)
