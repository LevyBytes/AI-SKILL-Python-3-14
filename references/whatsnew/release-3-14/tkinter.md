# What's new in Python 3.14 / tkinter

### tkinter

-

Allow the [`tkinter`](https://docs.python.org/3.14/library/tkinter.html#module-tkinter) widget routines `after()` and `after_idle()` to take keyword arguments. (Contributed by Zhikang Yan in [gh-126899](https://github.com/python/cpython/issues/126899).)

- Provide a way to assign a name to `tkinter.OptionMenu` as well as `tkinter.ttk.OptionMenu`. (Contributed by Zhikang Yan in [gh-130482](https://github.com/python/cpython/issues/130482).)
