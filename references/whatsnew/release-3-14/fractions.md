# What's new in Python 3.14 / fractions - fractions

### fractions

- You can now build a [`Fraction`](https://docs.python.org/3.14/library/fractions.html#fractions.Fraction) object out of any object that exposes the `as_integer_ratio()` method. (Contributed by Serhiy Storchaka in [gh-82017](https://github.com/python/cpython/issues/82017).)

- The new [`Fraction.from_number()`](https://docs.python.org/3.14/library/fractions.html#fractions.Fraction.from_number) acts as a secondary constructor for [`Fraction`](https://docs.python.org/3.14/library/fractions.html#fractions.Fraction). (Contributed by Serhiy Storchaka in [gh-121797](https://github.com/python/cpython/issues/121797).)
