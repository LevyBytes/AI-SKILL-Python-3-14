# What's new in Python 3.14 / getpass - getpass

### getpass

- Keyboard feedback within the [`getpass()`](https://docs.python.org/3.14/library/getpass.html#getpass.getpass) function is now available via the keyword-only optional argument *echo_char*. A placeholder character appears as each character gets typed, then disappears when a character gets removed. (Contributed by Semyon Moroz in [gh-77065](https://github.com/python/cpython/issues/77065).)
