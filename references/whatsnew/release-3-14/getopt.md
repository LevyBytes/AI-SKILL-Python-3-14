# What's new in Python 3.14 / getopt

### getopt

- Options carrying optional arguments are now supported. (Contributed by Serhiy Storchaka in [gh-126374](https://github.com/python/cpython/issues/126374).)

- Returning options interleaved with non-option arguments in their original order is now supported. (Contributed by Serhiy Storchaka in [gh-126390](https://github.com/python/cpython/issues/126390).)
