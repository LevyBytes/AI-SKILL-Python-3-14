# What's new in Python 3.14 / decimal - decimal

### decimal

- The new [`Decimal.from_number()`](https://docs.python.org/3.14/library/decimal.html#decimal.Decimal.from_number) serves as a secondary constructor for [`Decimal`](https://docs.python.org/3.14/library/decimal.html#decimal.Decimal). (Contributed by Serhiy Storchaka in [gh-121798](https://github.com/python/cpython/issues/121798).)

- Surface [`IEEEContext()`](https://docs.python.org/3.14/library/decimal.html#decimal.IEEEContext) so contexts that align with the IEEE 754 (2008) decimal interchange formats can be built. (Contributed by Sergey B Kirpichev in [gh-53032](https://github.com/python/cpython/issues/53032).)
