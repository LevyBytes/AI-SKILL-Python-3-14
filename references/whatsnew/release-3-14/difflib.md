# What's new in Python 3.14 / difflib - difflib

### difflib

- Pages comparing content with highlighted changes that the [`HtmlDiff`](https://docs.python.org/3.14/library/difflib.html#difflib.HtmlDiff) class produces now honor "dark mode". (Contributed by Jiahao Li in [gh-129939](https://github.com/python/cpython/issues/129939).)

### difflib

- The [`IS_LINE_JUNK()`](https://docs.python.org/3.14/library/difflib.html#difflib.IS_LINE_JUNK) function now runs as much as twice as fast. (Contributed by Adam Turner and Semyon Moroz in [gh-130167](https://github.com/python/cpython/issues/130167).)
