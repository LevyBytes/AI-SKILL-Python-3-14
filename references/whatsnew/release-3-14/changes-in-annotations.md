# What's new in Python 3.14 / Changes in annotations (**PEP 649** and **PEP 749**)

### Changes in annotations ([**PEP 649**](https://peps.python.org/pep-0649/) and [**PEP 749**](https://peps.python.org/pep-0749/))

This part offers guidance about adjustments you might have to make to annotations, or to Python code that introspects or otherwise works with annotations, owing to the move to deferred evaluation of annotations.

For the vast majority of situations, code that worked on older Python releases needs no modification.
