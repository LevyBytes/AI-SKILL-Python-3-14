# What's new in Python 3.14 / calendar - calendar

### calendar

- By default the current day gets highlighted with color within the [command-line](https://docs.python.org/3.14/library/calendar.html#calendar-cli) text output of [`calendar`](https://docs.python.org/3.14/library/calendar.html#module-calendar). You can govern this through [environment variables](https://docs.python.org/3.14/using/cmdline.html#using-on-controlling-color). (Contributed by Hugo van Kemenade in [gh-128317](https://github.com/python/cpython/issues/128317).)
