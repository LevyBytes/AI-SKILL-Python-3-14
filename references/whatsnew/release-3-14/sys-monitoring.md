# What's new in Python 3.14 / sys.monitoring — sys.monitoring

### sys.monitoring

- Add two new monitoring events, [`BRANCH_LEFT`](https://docs.python.org/3.14/library/sys.monitoring.html#monitoring-event-BRANCH_LEFT) and [`BRANCH_RIGHT`](https://docs.python.org/3.14/library/sys.monitoring.html#monitoring-event-BRANCH_RIGHT). The pair supersedes and deprecates the `BRANCH` event. (Contributed by Mark Shannon in [gh-122548](https://github.com/python/cpython/issues/122548).)
