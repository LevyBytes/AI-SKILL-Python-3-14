# What's new in Python 3.14 / pickle — pickle

### pickle

- The [`pickle`](https://docs.python.org/3.14/library/pickle.html#module-pickle) module now ships with its default protocol version raised to 5. Further information lives under [pickle protocols](https://docs.python.org/3.14/library/pickle.html#pickle-protocols).

- Attach exception notes to pickle serialization failures so the origin of the problem can be pinpointed. (Contributed by Serhiy Storchaka in [gh-122213](https://github.com/python/cpython/issues/122213).)
