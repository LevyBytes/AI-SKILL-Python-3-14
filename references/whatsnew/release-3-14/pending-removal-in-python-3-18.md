# What's new in Python 3.14 / Pending removal in Python 3.18 — decimal

### Pending removal in Python 3.18

- [`decimal`](https://docs.python.org/3.14/library/decimal.html#module-decimal):

  - Available only within the C implementation of the `decimal` module, the non-standard and undocumented [`Decimal`](https://docs.python.org/3.14/library/decimal.html#decimal.Decimal) format specifier `'N'` has carried a deprecation since Python 3.13. (Contributed by Serhiy Storchaka in [gh-89902](https://github.com/python/cpython/issues/89902).)
