# What's new in Python 3.14 / Optimizations

### Optimizations

- Import time dropped for a range of standard library modules, among them [`annotationlib`](https://docs.python.org/3.14/library/annotationlib.html#module-annotationlib), [`ast`](https://docs.python.org/3.14/library/ast.html#module-ast), [`asyncio`](https://docs.python.org/3.14/library/asyncio.html#module-asyncio), [`base64`](https://docs.python.org/3.14/library/base64.html#module-base64), [`cmd`](https://docs.python.org/3.14/library/cmd.html#module-cmd), [`csv`](https://docs.python.org/3.14/library/csv.html#module-csv), [`gettext`](https://docs.python.org/3.14/library/gettext.html#module-gettext), [`importlib.util`](https://docs.python.org/3.14/library/importlib.html#module-importlib.util), [`locale`](https://docs.python.org/3.14/library/locale.html#module-locale), [`mimetypes`](https://docs.python.org/3.14/library/mimetypes.html#module-mimetypes), [`optparse`](https://docs.python.org/3.14/library/optparse.html#module-optparse), [`pickle`](https://docs.python.org/3.14/library/pickle.html#module-pickle), [`pprint`](https://docs.python.org/3.14/library/pprint.html#module-pprint), [`pstats`](https://docs.python.org/3.14/library/profile.html#module-pstats), [`shlex`](https://docs.python.org/3.14/library/shlex.html#module-shlex), [`socket`](https://docs.python.org/3.14/library/socket.html#module-socket), [`string`](https://docs.python.org/3.14/library/string.html#module-string), [`subprocess`](https://docs.python.org/3.14/library/subprocess.html#module-subprocess), [`threading`](https://docs.python.org/3.14/library/threading.html#module-threading), [`tomllib`](https://docs.python.org/3.14/library/tomllib.html#module-tomllib), [`types`](https://docs.python.org/3.14/library/types.html#module-types), and [`zipfile`](https://docs.python.org/3.14/library/zipfile.html#module-zipfile).

> (Contributed by Adam Turner, Bénédikt Tran, Chris Markiewicz, Eli Schwartz, Hugo van Kemenade, Jelle Zijlstra, and others in [gh-118761](https://github.com/python/cpython/issues/118761).)

- Where it is safe, the interpreter now skips certain internal reference count changes. As a result, the values handed back by [`sys.getrefcount()`](https://docs.python.org/3.14/library/sys.html#sys.getrefcount) and [`Py_REFCNT()`](https://docs.python.org/3.14/c-api/refcounting.html#c.Py_REFCNT) can differ from earlier Python releases. Particulars follow lower down.
