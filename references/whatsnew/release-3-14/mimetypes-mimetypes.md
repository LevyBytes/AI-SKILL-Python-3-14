# What's new in Python 3.14 / mimetypes - mimetypes

### mimetypes

- A public [command-line](https://docs.python.org/3.14/library/mimetypes.html#mimetypes-cli) for the module now exists, reached by way of **python -m mimetypes**. (Contributed by Oleg Iarygin and Hugo van Kemenade in [gh-93096](https://github.com/python/cpython/issues/93096).)

- Several fresh MIME types grounded in RFCs and everyday usage were added:

Microsoft and [**RFC 8081**](https://datatracker.ietf.org/doc/html/rfc8081.html) MIME types for fonts

  - Embedded OpenType: `application/vnd.ms-fontobject`
