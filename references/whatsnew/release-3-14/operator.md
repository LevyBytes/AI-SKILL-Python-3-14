# What's new in Python 3.14 / operator - operator

### operator

- Add [`is_none()`](https://docs.python.org/3.14/library/operator.html#operator.is_none) and [`is_not_none()`](https://docs.python.org/3.14/library/operator.html#operator.is_not_none) as a matched pair, where `operator.is_none(obj)` behaves the same as `obj is None` and `operator.is_not_none(obj)` behaves the same as `obj is not None`. (Contributed by Raymond Hettinger and Nico Mexis in [gh-115808](https://github.com/python/cpython/issues/115808).)
