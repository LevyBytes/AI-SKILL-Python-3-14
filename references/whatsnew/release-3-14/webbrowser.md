# What's new in Python 3.14 / webbrowser - webbrowser

### webbrowser

- Entries inside the `BROWSER` environment variable may now point at browsers already registered with the [`webbrowser`](https://docs.python.org/3.14/library/webbrowser.html#module-webbrowser) module, rather than forever spawning a brand-new browser command.

This lets you assign `BROWSER` to one of the browsers that macOS supports.
