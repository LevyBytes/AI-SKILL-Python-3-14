# What's new in Python 3.14 / Discontinuation of PGP signatures

### Discontinuation of PGP signatures

No PGP (Pretty Good Privacy) signatures will accompany releases of Python 3.14 or any later version. Verifying CPython artifacts now requires the [Sigstore verification materials](https://www.python.org/downloads/metadata/sigstore/). Since Python 3.11, releases have carried a signature produced with [Sigstore](https://www.sigstore.dev/).

[**PEP 761**](https://peps.python.org/pep-0761/) laid out this adjustment to the release process.
