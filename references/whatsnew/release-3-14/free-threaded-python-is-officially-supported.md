# What's new in Python 3.14 / Free-threaded Python is officially supported

### Free-threaded Python is officially supported

Python's free-threaded build has graduated from experimental status and is now supported. This marks the beginning of [phase II](https://discuss.python.org/t/37075), in which free-threaded Python carries official support while remaining optional.

Confident that the effort is heading the right way, the free-threading team values the ongoing commitment of everyone helping ready free-threading for wider uptake throughout the Python community.

Given these recommendations and the PEP's acceptance, the Python developer community ought to widely communicate that free-threading is now and going forward a supported build choice, one that will not be dropped absent a proper deprecation schedule.

Whether to move to [phase III](https://discuss.python.org/t/37075), making free-threading the default or the only build of Python, stays open and hinges on numerous factors inside CPython and across the community alike. That call belongs to the future.
