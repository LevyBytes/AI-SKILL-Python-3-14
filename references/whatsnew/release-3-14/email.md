# What's new in Python 3.14 / email - email.utils

### email

- The *isdst* parameter of [`email.utils.localtime()`](https://docs.python.org/3.14/library/email.utils.html#email.utils.localtime) is gone; it had been deprecated and disregarded as of Python 3.12. (Contributed by Hugo van Kemenade in [gh-118798](https://github.com/python/cpython/issues/118798).)
