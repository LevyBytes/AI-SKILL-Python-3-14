# What's new in Python 3.14 / pkgutil

### pkgutil

- The `get_loader()` plus `find_loader()` functions are gone, both having carried a deprecation since Python 3.12. (Contributed by Bénédikt Tran in [gh-97850](https://github.com/python/cpython/issues/97850).)
