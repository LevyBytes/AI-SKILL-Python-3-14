# What's new in Python 3.14 / itertools - itertools

### itertools

- Copy, deepcopy, and pickle behavior is no longer offered by [`itertools`](https://docs.python.org/3.14/library/itertools.html#module-itertools) iterators. A [`DeprecationWarning`](https://docs.python.org/3.14/library/exceptions.html#DeprecationWarning) had flagged these starting with Python 3.12. (Contributed by Raymond Hettinger in [gh-101588](https://github.com/python/cpython/issues/101588).)
