# What's new in Python 3.14 / bdb - bdb, sys.monitoring

### bdb

- The basic debugger gains a [`sys.monitoring`](https://docs.python.org/3.14/library/sys.monitoring.html#module-sys.monitoring)-based backend, selectable by handing `'monitoring'` to the new *backend* parameter on the [`Bdb`](https://docs.python.org/3.14/library/bdb.html#bdb.Bdb) class. (Contributed by Tian Gao in [gh-124533](https://github.com/python/cpython/issues/124533).)
