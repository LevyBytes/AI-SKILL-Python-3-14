# What's new in Python 3.14 / curses - curses

### curses

- The new [`assume_default_colors()`](https://docs.python.org/3.14/library/curses.html#curses.assume_default_colors) function refines [`use_default_colors()`](https://docs.python.org/3.14/library/curses.html#curses.use_default_colors) by letting you alter the color pair `0`. (Contributed by Serhiy Storchaka in [gh-133139](https://github.com/python/cpython/issues/133139).)
