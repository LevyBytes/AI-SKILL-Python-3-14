# What’s New In Python 3.5 / Other module-level changes — codecs, mmap, socket, ssl

### Other module-level changes

A great many functions across the [`mmap`](https://docs.python.org/3.14/library/mmap.html#module-mmap), `ossaudiodev`, [`socket`](https://docs.python.org/3.14/library/socket.html#module-socket), [`ssl`](https://docs.python.org/3.14/library/ssl.html#module-ssl), and [`codecs`](https://docs.python.org/3.14/library/codecs.html#module-codecs) modules will now take writable [bytes-like objects](https://docs.python.org/3.14/glossary.html#term-bytes-like-object). (Contributed by Serhiy Storchaka in [bpo-23001](https://bugs.python.org/issue?@action=redirect&bpo=23001).)
