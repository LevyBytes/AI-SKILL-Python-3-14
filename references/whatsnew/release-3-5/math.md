# What’s New In Python 3.5 / math - math

### math

The [`math`](https://docs.python.org/3.14/library/math.html#module-math) module gained two fresh constants: [`inf`](https://docs.python.org/3.14/library/math.html#math.inf) and [`nan`](https://docs.python.org/3.14/library/math.html#math.nan). (Contributed by Mark Dickinson in [bpo-23185](https://bugs.python.org/issue?@action=redirect&bpo=23185).)

Testing for approximate equality is now possible with a new [`isclose()`](https://docs.python.org/3.14/library/math.html#math.isclose) function. (Contributed by Chris Barker and Tal Einat in [bpo-24270](https://bugs.python.org/issue?@action=redirect&bpo=24270).)

A new [`gcd()`](https://docs.python.org/3.14/library/math.html#math.gcd) function has arrived. Consequently `fractions.gcd()` now carries a deprecation. (Contributed by Mark Dickinson and Serhiy Storchaka in [bpo-22486](https://bugs.python.org/issue?@action=redirect&bpo=22486).)
