# What’s New In Python 3.5 / Unsupported Operating Systems

### Unsupported Operating Systems

Since Microsoft has dropped support for Windows XP, under [**PEP 11**](https://peps.python.org/pep-0011/) this OS no longer carries official CPython 3.5 support.
