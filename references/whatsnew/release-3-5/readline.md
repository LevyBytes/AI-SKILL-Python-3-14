# What’s New In Python 3.5 / readline - readline

### readline

A freshly added [`append_history_file()`](https://docs.python.org/3.14/library/readline.html#readline.append_history_file) function lets you append a chosen count of the most recent history entries onto a target file. Bruno Cauet built this (see [bpo-22940](https://bugs.python.org/issue?@action=redirect&bpo=22940)).
