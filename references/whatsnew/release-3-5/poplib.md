# What’s New In Python 3.5 / poplib — poplib

### poplib

When a POP server offers it, the freshly added [`POP3.utf8()`](https://docs.python.org/3.14/library/poplib.html#poplib.POP3.utf8) command turns on [**RFC 6856**](https://datatracker.ietf.org/doc/html/rfc6856.html) (Internationalized Email) handling. Milan OberKirch landed this addition (see [bpo-21804](https://bugs.python.org/issue?@action=redirect&bpo=21804)).
