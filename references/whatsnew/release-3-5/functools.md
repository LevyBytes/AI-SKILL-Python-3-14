# What’s New In Python 3.5 / functools - functools

### functools

A large portion of the [`lru_cache()`](https://docs.python.org/3.14/library/functools.html#functools.lru_cache) internals has moved to C, yielding a substantial speedup. (Contributed by Matt Joiner, Alexey Kachayev, and Serhiy Storchaka in [bpo-14373](https://bugs.python.org/issue?@action=redirect&bpo=14373).)
