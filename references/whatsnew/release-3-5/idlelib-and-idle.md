# What’s New In Python 3.5 / idlelib and IDLE

### idlelib and IDLE

Because idlelib provides the IDLE shell and editor and is not meant to be imported by outside programs, every release brings it enhancements. For a running list of everything changed after 3.4.0, plus edits made across later 3.5.x releases, consult `Lib/idlelib/NEWS.txt`. The IDLE Help ? About IDLE dialog also offers this file.
