# What’s New In Python 3.5 / glob — glob

### glob

Using the `"**"` pattern, the [`iglob()`](https://docs.python.org/3.14/library/glob.html#glob.iglob) and [`glob()`](https://docs.python.org/3.14/library/glob.html#glob.glob) functions can now descend recursively through subdirectories. (Contributed by Serhiy Storchaka in [bpo-13968](https://bugs.python.org/issue?@action=redirect&bpo=13968).)
