# What’s New In Python 3.5 / curses - curses

### curses

The fresh [`update_lines_cols()`](https://docs.python.org/3.14/library/curses.html#curses.update_lines_cols) function refreshes the [`LINES`](https://docs.python.org/3.14/library/curses.html#curses.LINES) and [`COLS`](https://docs.python.org/3.14/library/curses.html#curses.COLS) module variables. That comes in handy when spotting a manual screen resize. (Contributed by Arnon Yaari in [bpo-4254](https://bugs.python.org/issue?@action=redirect&bpo=4254).)
