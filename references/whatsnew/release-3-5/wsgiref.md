# What’s New In Python 3.5 / wsgiref - wsgiref

### wsgiref

For the [`headers.Headers`](https://docs.python.org/3.14/library/wsgiref.html#wsgiref.headers.Headers) class constructor, supplying the *headers* argument is now optional. (Contributed by Pablo Torres Navarrete and SilentGhost in [bpo-5800](https://bugs.python.org/issue?@action=redirect&bpo=5800).)
