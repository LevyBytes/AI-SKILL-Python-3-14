# What’s New In Python 3.5 / xml.sax — xml.sax, xml.sax.reader

### xml.sax

A character stream belonging to the [`xmlreader.InputSource`](https://docs.python.org/3.14/library/xml.sax.reader.html#xml.sax.xmlreader.InputSource) object is now usable by SAX parsers. (Contributed by Serhiy Storchaka in [bpo-2175](https://bugs.python.org/issue?@action=redirect&bpo=2175).)

A [`str`](https://docs.python.org/3.14/library/stdtypes.html#str) instance is now an acceptable argument to [`parseString()`](https://docs.python.org/3.14/library/xml.sax.html#xml.sax.parseString). (Contributed by Serhiy Storchaka in [bpo-10590](https://bugs.python.org/issue?@action=redirect&bpo=10590).)
