# What’s New In Python 3.5 / lzma — lzma

### lzma

To cap how much decompressed data is produced, the [`LZMADecompressor.decompress()`](https://docs.python.org/3.14/library/lzma.html#lzma.LZMADecompressor.decompress) method now takes an optional *max_length* argument. (Contributed by Martin Panter in [bpo-15955](https://bugs.python.org/issue?@action=redirect&bpo=15955).)
