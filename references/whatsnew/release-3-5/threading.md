# What’s New In Python 3.5 / threading - threading

### threading

For managing their timeouts, the [`Lock.acquire()`](https://docs.python.org/3.14/library/threading.html#threading.Lock.acquire) and [`RLock.acquire()`](https://docs.python.org/3.14/library/threading.html#threading.RLock.acquire) methods both now turn to a monotonic clock. Victor Stinner landed this (see [bpo-22043](https://bugs.python.org/issue?@action=redirect&bpo=22043)).
