# What’s New In Python 3.5 / bz2 - bz2

### bz2

The [`BZ2Decompressor.decompress`](https://docs.python.org/3.14/library/bz2.html#bz2.BZ2Decompressor.decompress) method will henceforth take an optional *max_length* argument that caps how large the decompressed data may grow. (Contributed by Nikolaus Rath in [bpo-15955](https://bugs.python.org/issue?@action=redirect&bpo=15955).)
