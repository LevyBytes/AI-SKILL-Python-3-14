# What’s New In Python 3.5 / code — code

### code

The [`InteractiveInterpreter.showtraceback()`](https://docs.python.org/3.14/library/code.html#code.InteractiveInterpreter.showtraceback) method now emits the complete chained traceback, exactly as the interactive interpreter does. (Contributed by Claudiu Popa in [bpo-17442](https://bugs.python.org/issue?@action=redirect&bpo=17442).)
