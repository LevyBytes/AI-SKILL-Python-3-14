# What’s New In Python 3.5 / sysconfig

### sysconfig

On Windows the user scripts directory is now named with the leading two pieces of the Python version folded in. Paul Moore contributed this (see [bpo-23437](https://bugs.python.org/issue?@action=redirect&bpo=23437)).
