# What’s New In Python 3.5 / operator — operator

### operator

Pickling is now available for [`attrgetter()`](https://docs.python.org/3.14/library/operator.html#operator.attrgetter), [`itemgetter()`](https://docs.python.org/3.14/library/operator.html#operator.itemgetter), and [`methodcaller()`](https://docs.python.org/3.14/library/operator.html#operator.methodcaller) objects. (Contributed by Josh Rosenberg and Serhiy Storchaka in [bpo-22955](https://bugs.python.org/issue?@action=redirect&bpo=22955).)

For carrying out matrix multiplication there are new [`matmul()`](https://docs.python.org/3.14/library/operator.html#operator.matmul) and [`imatmul()`](https://docs.python.org/3.14/library/operator.html#operator.imatmul) functions. (Contributed by Benjamin Peterson in [bpo-21176](https://bugs.python.org/issue?@action=redirect&bpo=21176).)
