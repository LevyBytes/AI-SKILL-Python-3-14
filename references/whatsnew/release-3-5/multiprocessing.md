# What’s New In Python 3.5 / multiprocessing - multiprocessing

### multiprocessing

The [context manager](https://docs.python.org/3.14/glossary.html#term-context-manager) protocol is now honored by [`sharedctypes.synchronized()`](https://docs.python.org/3.14/library/multiprocessing.html#multiprocessing.sharedctypes.synchronized) objects. (Contributed by Charles-François Natali in [bpo-21565](https://bugs.python.org/issue?@action=redirect&bpo=21565).)
