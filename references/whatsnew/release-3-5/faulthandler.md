# What’s New In Python 3.5 / faulthandler — faulthandler

### faulthandler

Beyond file-like objects, file descriptors are now valid inputs for the [`enable()`](https://docs.python.org/3.14/library/faulthandler.html#faulthandler.enable), [`register()`](https://docs.python.org/3.14/library/faulthandler.html#faulthandler.register), [`dump_traceback()`](https://docs.python.org/3.14/library/faulthandler.html#faulthandler.dump_traceback) and [`dump_traceback_later()`](https://docs.python.org/3.14/library/faulthandler.html#faulthandler.dump_traceback_later) functions. (Contributed by Wei Wu in [bpo-23566](https://bugs.python.org/issue?@action=redirect&bpo=23566).)
