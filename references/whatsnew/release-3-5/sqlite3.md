# What’s New In Python 3.5 / sqlite3 - sqlite3

### sqlite3

Full support for the sequence protocol — notably [`reversed()`](https://docs.python.org/3.14/library/functions.html#reversed) iteration together with slice indexing — now lives in the [`Row`](https://docs.python.org/3.14/library/sqlite3.html#sqlite3.Row) class. Claudiu Popa landed it (see [bpo-10203](https://bugs.python.org/issue?@action=redirect&bpo=10203)); Lucas Sinclair, Jessica McKellar, and Serhiy Storchaka added more (see [bpo-13583](https://bugs.python.org/issue?@action=redirect&bpo=13583)).
