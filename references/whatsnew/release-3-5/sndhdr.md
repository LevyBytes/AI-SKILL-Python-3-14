# What’s New In Python 3.5 / sndhdr - collections

### sndhdr

A [`namedtuple()`](https://docs.python.org/3.14/library/collections.html#collections.namedtuple) is now what both the `what()` and `whathdr()` functions hand back. Claudiu Popa contributed this (see [bpo-18615](https://bugs.python.org/issue?@action=redirect&bpo=18615)).
