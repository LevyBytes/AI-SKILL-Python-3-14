# What’s New In Python 3.5 / time - time

### time

On every platform, the [`monotonic()`](https://docs.python.org/3.14/library/time.html#time.monotonic) function can now be relied upon. Victor Stinner contributed this (see [bpo-22043](https://bugs.python.org/issue?@action=redirect&bpo=22043)).
