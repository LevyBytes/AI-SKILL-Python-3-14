# What’s New In Python 3.5 / gzip - gzip

### gzip

To ask for exclusive creation, the *mode* argument of the [`GzipFile`](https://docs.python.org/3.14/library/gzip.html#gzip.GzipFile) constructor now permits `"x"`. (Contributed by Tim Heaney in [bpo-19222](https://bugs.python.org/issue?@action=redirect&bpo=19222).)
