# What’s New In Python 3.5 / tkinter

### tkinter

For configuring the Tcl/Tk environment under Windows, the `tkinter._fix` module has given way to a private function within the `_tkinter` module, one that leaves environment variables permanently untouched. Zachary Ware landed this (see [bpo-20035](https://bugs.python.org/issue?@action=redirect&bpo=20035)).
