# What’s New In Python 3.5 / http — http

### http

There is now an [`HTTPStatus`](https://docs.python.org/3.14/library/http.html#http.HTTPStatus) enum supplying a collection of HTTP status codes together with reason phrases and lengthy English descriptions. (Contributed by Demian Brecht in [bpo-21793](https://bugs.python.org/issue?@action=redirect&bpo=21793).)
