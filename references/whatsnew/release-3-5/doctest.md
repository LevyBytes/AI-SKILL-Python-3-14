# What’s New In Python 3.5 / doctest — doctest, unittest

### doctest

When *module* holds no docstrings, the [`DocTestSuite()`](https://docs.python.org/3.14/library/doctest.html#doctest.DocTestSuite) function hands back an empty [`unittest.TestSuite`](https://docs.python.org/3.14/library/unittest.html#unittest.TestSuite) instead of raising [`ValueError`](https://docs.python.org/3.14/library/exceptions.html#ValueError). (Contributed by Glenn Jones in [bpo-15916](https://bugs.python.org/issue?@action=redirect&bpo=15916).)
