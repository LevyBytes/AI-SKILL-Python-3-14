# What’s New In Python 3.5 / argparse — argparse

### Improved Modules

### argparse

By setting [allow_abbrev](https://docs.python.org/3.14/library/argparse.html#allow-abbrev) to `False`, you can henceforth turn off [abbreviated usage](https://docs.python.org/3.14/library/argparse.html#prefix-matching) of long options on the [`ArgumentParser`](https://docs.python.org/3.14/library/argparse.html#argparse.ArgumentParser) class. (Contributed by Jonathan Paugh, Steven Bethard, paul j3 and Daniel Eriksson in [bpo-14910](https://bugs.python.org/issue?@action=redirect&bpo=14910).)
