# What’s New In Python 3.8 / venv — venv

### venv

On every platform, [`venv`](https://docs.python.org/3.14/library/venv.html#module-venv) henceforth ships an `Activate.ps1` script for bringing up virtual environments inside PowerShell Core 6.1. (Contributed by Brett Cannon in [bpo-32718](https://bugs.python.org/issue?@action=redirect&bpo=32718).)
