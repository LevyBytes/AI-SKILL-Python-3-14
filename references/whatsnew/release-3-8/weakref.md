# What’s New In Python 3.8 / weakref — weakref

### weakref

The proxy objects that [`weakref.proxy()`](https://docs.python.org/3.14/library/weakref.html#weakref.proxy) hands back henceforth handle the matrix multiplication operators `@` and `@=` on top of the remaining numeric operators. (Contributed by Mark Dickinson in [bpo-36669](https://bugs.python.org/issue?@action=redirect&bpo=36669).)
