# What’s New In Python 3.8 / tkinter

### tkinter

Four methods, `selection_from()`, `selection_present()`, `selection_range()` and `selection_to()`, were added to the `tkinter.Spinbox` class. (Contributed by Juliette Monsel in [bpo-34829](https://bugs.python.org/issue?@action=redirect&bpo=34829).)

A `moveto()` method was added to the `tkinter.Canvas` class. (Contributed by Juliette Monsel in [bpo-23831](https://bugs.python.org/issue?@action=redirect&bpo=23831).)

The `tkinter.PhotoImage` class henceforth carries `transparency_get()` and `transparency_set()` methods. (Contributed by Zackery Spytz in [bpo-25451](https://bugs.python.org/issue?@action=redirect&bpo=25451).)
