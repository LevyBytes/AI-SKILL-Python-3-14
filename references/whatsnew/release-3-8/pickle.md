# What’s New In Python 3.8 / pickle - pickle

### pickle

[`pickle`](https://docs.python.org/3.14/library/pickle.html#module-pickle) extensions that subclass the C-optimized [`Pickler`](https://docs.python.org/3.14/library/pickle.html#pickle.Pickler) can henceforth replace how functions and classes get pickled by supplying the dedicated [`reducer_override()`](https://docs.python.org/3.14/library/pickle.html#pickle.Pickler.reducer_override) method. (Contributed by Pierre Glaser and Olivier Grisel in [bpo-35900](https://bugs.python.org/issue?@action=redirect&bpo=35900).)
