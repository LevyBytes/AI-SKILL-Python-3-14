# What’s New In Python 3.8 / tokenize - tokenize

### tokenize

The [`tokenize`](https://docs.python.org/3.14/library/tokenize.html#module-tokenize) module henceforth emits a `NEWLINE` token implicitly whenever its input lacks a trailing new line. That conduct now lines up with how the C tokenizer behaves under the hood. (Contributed by Ammar Askar in [bpo-33899](https://bugs.python.org/issue?@action=redirect&bpo=33899).)
