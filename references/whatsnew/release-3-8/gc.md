# What’s New In Python 3.8 / gc — gc

> (Contributed by Ethan Smith in [bpo-32380](https://bugs.python.org/issue?@action=redirect&bpo=32380))

### gc

An optional *generation* parameter may now be handed to [`get_objects()`](https://docs.python.org/3.14/library/gc.html#gc.get_objects), naming which generation to collect objects from.
