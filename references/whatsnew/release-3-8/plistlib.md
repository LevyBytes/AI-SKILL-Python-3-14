# What’s New In Python 3.8 / plistlib - plistlib

### plistlib

A fresh [`plistlib.UID`](https://docs.python.org/3.14/library/plistlib.html#plistlib.UID) arrived, alongside support for both reading and writing NSKeyedArchiver-encoded binary plists. (Contributed by Jon Janzen in [bpo-26707](https://bugs.python.org/issue?@action=redirect&bpo=26707).)
