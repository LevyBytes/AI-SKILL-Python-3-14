# What’s New In Python 3.8 / PEP 578: Python Runtime Audit Hooks

### PEP 578: Python Runtime Audit Hooks

This PEP introduces an Audit Hook together with a Verified Open Hook. Both can be reached from Python as well as native code, so that pure-Python applications and frameworks gain access to additional notifications, while embedders or system administrators can ship Python builds in which auditing is permanently on.

The full details live in [**PEP 578**](https://peps.python.org/pep-0578/).
