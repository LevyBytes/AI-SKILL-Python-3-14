# What’s New In Python 3.8 / xmlrpc - xmlrpc.client

### xmlrpc

[`xmlrpc.client.ServerProxy`](https://docs.python.org/3.14/library/xmlrpc.client.html#xmlrpc.client.ServerProxy) henceforth accepts an optional *headers* keyword argument carrying a sequence of HTTP headers to accompany each request. This, among its other uses, opens the door to moving up from the default basic authentication to quicker session authentication. (Contributed by Cédric Krier in [bpo-35153](https://bugs.python.org/issue?@action=redirect&bpo=35153).)
