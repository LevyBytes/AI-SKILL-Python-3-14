# codecs - Python Specific Encodings

### Python Specific Encodings

Several predefined codecs belong to Python alone, so their codec names mean nothing beyond Python. The tables further down catalog these, grouped by the input and output types each expects (keep in mind that although text encodings are the most frequent application of codecs, the codec infrastructure underneath accommodates arbitrary data transforms, not text encodings alone). With asymmetric codecs, the meaning given describes the encoding direction.
