# sys._is_interned

sys._is_interned(*string*)

Return [`True`](https://docs.python.org/3.14/library/constants.html#True) when the supplied string has been “interned”, and [`False`](https://docs.python.org/3.14/library/constants.html#False) otherwise.

Added in version 3.13.

**CPython implementation detail:** There is no guarantee that it exists across every Python implementation.
