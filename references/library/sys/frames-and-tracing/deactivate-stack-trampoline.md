# sys.deactivate_stack_trampoline

sys.deactivate_stack_trampoline()

Turns off whichever stack profiler trampoline backend is currently in use.

Should no stack profiler be turned on, calling this does nothing.

[Availability](https://docs.python.org/3.14/library/intro.html#availability): Linux.

Added in version 3.12.
