# sys.is_finalizing

sys.is_finalizing()

Return [`True`](https://docs.python.org/3.14/library/constants.html#True) when the principal Python interpreter is in the process of [shutting down](https://docs.python.org/3.14/glossary.html#term-interpreter-shutdown); otherwise return [`False`](https://docs.python.org/3.14/library/constants.html#False).

Consult as well the [`PythonFinalizationError`](https://docs.python.org/3.14/library/exceptions.html#PythonFinalizationError) exception.

Added in version 3.5.
