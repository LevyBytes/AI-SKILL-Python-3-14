# sys.winver

sys.winver

The version number that shapes registry keys under Windows. It lives as string resource 1000 inside the Python DLL. Ordinarily its value is the major and minor versions of the Python interpreter in use. The `sys` module exposes it purely for information; changing it does nothing to the registry keys Python actually uses.

[Availability](https://docs.python.org/3.14/library/intro.html#availability): Windows.
