# sys.version

sys.version

A string carrying the Python interpreter’s version number along with extra notes on the build number and the compiler that was used. This is the string shown when the interactive interpreter starts up. Rather than pulling version details out of it, turn to `version_info` and the functions the [`platform`](https://docs.python.org/3.14/library/platform.html#module-platform) module supplies.
