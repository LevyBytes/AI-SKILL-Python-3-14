# sys.getdlopenflags

sys.getdlopenflags()

Report the flags currently in effect for `dlopen()` calls. You can find symbolic names for those flag values inside the [`os`](https://docs.python.org/3.14/library/os.html#module-os) module (the `RTLD_*xxx*` constants, e.g. [`os.RTLD_LAZY`](https://docs.python.org/3.14/library/os.html#os.RTLD_LAZY)).

[Availability](https://docs.python.org/3.14/library/intro.html#availability): Unix.
