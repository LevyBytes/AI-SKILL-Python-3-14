# sys.getandroidapilevel

sys.getandroidapilevel()

Report Android's build-time API level as an integer. It marks the lowest Android version on which this build of Python is able to run. To get runtime version data, refer to [`platform.android_ver()`](https://docs.python.org/3.14/library/platform.html#platform.android_ver).

[Availability](https://docs.python.org/3.14/library/intro.html#availability): Android.

Added in version 3.7.
