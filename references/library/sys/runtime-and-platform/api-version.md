# sys.api_version

sys.api_version

The C API version, matching the C macro [`PYTHON_API_VERSION`](https://docs.python.org/3.14/c-api/module.html#c.PYTHON_API_VERSION). It exists for backwards compatibility.

As things stand, fresh Python releases leave this constant unchanged, so it serves no purpose for versioning. That could shift down the road.
