# sys.abiflags

sys.abiflags

On POSIX platforms where Python was compiled using the regular `configure` script, this holds the ABI flags described by [**PEP 3149**](https://peps.python.org/pep-3149/).

Added in version 3.2.

Changed in version 3.8: The default became an empty string once the `m` flag for pymalloc was dropped.

[Availability](https://docs.python.org/3.14/library/intro.html#availability): Unix.
