# sys.get_coroutine_origin_tracking_depth

sys.get_coroutine_origin_tracking_depth()

Fetch the coroutine origin tracking depth as it currently stands, the value put in place by `set_coroutine_origin_tracking_depth()`.

Added in version 3.7.

Note

This function is provided provisionally for now (refer to [**PEP 411**](https://peps.python.org/pep-0411/) for the details.) Restrict its use to debugging alone.
