# sys.maxunicode

sys.maxunicode

An integer reporting the value of the highest Unicode code point, namely `1114111` (`0x10FFFF` written in hexadecimal).

Changed in version 3.3: Prior to [**PEP 393**](https://peps.python.org/pep-0393/), `sys.maxunicode` would be either `0xFFFF` or `0x10FFFF`, according to the configuration option choosing whether Unicode characters were held as UCS-2 or UCS-4.
