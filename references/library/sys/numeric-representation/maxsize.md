# sys.maxsize

sys.maxsize

An integer reporting the largest value a variable of type [`Py_ssize_t`](https://docs.python.org/3.14/c-api/intro.html#c.Py_ssize_t) is able to hold. On a 32-bit platform this is normally `2**31 - 1`, and on a 64-bit platform it is normally `2**63 - 1`.
