# sys.get_int_max_str_digits

sys.get_int_max_str_digits()

Hands back the current setting of the [integer string conversion length limitation](https://docs.python.org/3.14/library/stdtypes.html#int-max-str-digits). See also `set_int_max_str_digits()`.

Added in version 3.11.
