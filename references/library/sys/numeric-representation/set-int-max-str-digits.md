# sys.set_int_max_str_digits

sys.set_int_max_str_digits(*maxdigits*)

Set the [integer string conversion length limitation](https://docs.python.org/3.14/library/stdtypes.html#int-max-str-digits) that this interpreter uses. See also `get_int_max_str_digits()`.

Added in version 3.11.
