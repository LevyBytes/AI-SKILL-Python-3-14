# ast: `ast.Match`

### Pattern matching

 *class *ast.Match(*subject*, *cases*)

Represents a `match` statement. The `subject` field holds the match's subject (the object being matched against each case), while `cases` holds an iterable of `match_case` nodes covering the various cases.

Added in version 3.10.
