### `telnetlib` - Telnet client

Deprecated since version 3.11, removed in version 3.13.

You will no longer find this module in the Python standard library. Having been deprecated back in Python 3.11, it was [removed in Python 3.13](https://docs.python.org/3.14/whatsnew/3.13.html#whatsnew313-pep594). That removal was settled in [**PEP 594**](https://peps.python.org/pep-0594/).

For a substitute, look to third-party PyPI libraries such as [telnetlib3](https://pypi.org/project/telnetlib3/) or [Exscript](https://pypi.org/project/Exscript/). Neither is supported nor maintained by Python's core team.

The final Python release that still shipped the `telnetlib` module was [Python 3.12](https://docs.python.org/3.12/library/telnetlib.html).
