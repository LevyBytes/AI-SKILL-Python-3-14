# uuid: UUID multiprocessing-safety classifications

safe

The UUID was generated by the platform in a multiprocessing-safe way.

 unsafe

The UUID was not generated in a multiprocessing-safe way.

 unknown

The platform gives no indication as to whether or not the UUID was generated safely.
