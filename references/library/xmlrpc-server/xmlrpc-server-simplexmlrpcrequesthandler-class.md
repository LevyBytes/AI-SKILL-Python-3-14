# xmlrpc.server: `xmlrpc.server.SimpleXMLRPCRequestHandler`

`*class *xmlrpc.server.SimpleXMLRPCRequestHandler`

Spin up a fresh request handler instance. This request handler handles `POST` requests and tweaks logging so that the *logRequests* parameter given to the `SimpleXMLRPCServer` constructor is respected.
