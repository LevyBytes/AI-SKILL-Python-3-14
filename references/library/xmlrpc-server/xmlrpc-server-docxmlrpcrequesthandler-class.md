# xmlrpc.server: `xmlrpc.server.DocXMLRPCRequestHandler`

`*class *xmlrpc.server.DocXMLRPCRequestHandler`

Spin up a fresh request handler instance. This request handler handles XML-RPC POST requests along with documentation GET requests, and tweaks logging so that the *logRequests* parameter given to the `DocXMLRPCServer` constructor is respected.
