# io: `io.IncrementalNewlineDecoder`

*class *io.IncrementalNewlineDecoder

A helper codec for decoding newlines under [universal newlines](https://docs.python.org/3.14/glossary.html#term-universal-newlines) mode. It derives from [`codecs.IncrementalDecoder`](https://docs.python.org/3.14/library/codecs.html#codecs.IncrementalDecoder).
