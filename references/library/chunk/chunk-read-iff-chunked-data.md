### `chunk` — Read IFF chunked data

Deprecated since version 3.11, removed in version 3.13.

This module no longer belongs to the Python standard library. It was [removed in Python 3.13](https://docs.python.org/3.14/whatsnew/3.13.html#whatsnew313-pep594) after a deprecation in Python 3.11. That removal was settled in [**PEP 594**](https://peps.python.org/pep-0594/).

The most recent Python release to ship the `chunk` module was [Python 3.12](https://docs.python.org/3.12/library/chunk.html).
