# urllib.parse: `urllib.parse.quote()`

### URL Quoting

The URL quoting functions are about taking program data and rendering it safe for use as URL components, by quoting special characters and suitably encoding non-ASCII text. They also let you undo these operations to rebuild the original data from a URL component’s contents, when the URL parsing functions above haven’t already handled that.

 urllib.parse.quote(*string*, *safe='/'*, *encoding=None*, *errors=None*)
