# urllib.parse: `urllib.parse.DefragResultBytes`

*class *urllib.parse.DefragResultBytes(*url*, *fragment*)

Concrete class for `urldefrag()` results containing [`bytes`](https://docs.python.org/3.14/library/stdtypes.html#bytes) data. The `decode()` method returns a `DefragResult` instance.

Added in version 3.2.
