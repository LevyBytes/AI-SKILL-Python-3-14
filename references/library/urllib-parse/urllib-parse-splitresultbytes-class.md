# urllib.parse: `urllib.parse.SplitResultBytes`

*class *urllib.parse.SplitResultBytes(*scheme*, *netloc*, *path*, *query*, *fragment*)

Concrete class for `urlsplit()` results containing [`bytes`](https://docs.python.org/3.14/library/stdtypes.html#bytes) data. The `decode()` method returns a `SplitResult` instance.

Added in version 3.2.
