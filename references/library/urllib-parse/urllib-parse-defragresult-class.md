# urllib.parse: `urllib.parse.DefragResult`

*class *urllib.parse.DefragResult(*url*, *fragment*)

Concrete class for `urldefrag()` results containing [`str`](https://docs.python.org/3.14/library/stdtypes.html#str) data. The `encode()` method returns a `DefragResultBytes` instance.

Added in version 3.2.
