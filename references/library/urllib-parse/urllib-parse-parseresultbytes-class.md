# urllib.parse: `urllib.parse.ParseResultBytes`

*class *urllib.parse.ParseResultBytes(*scheme*, *netloc*, *path*, *params*, *query*, *fragment*)

Concrete class for `urlparse()` results containing [`bytes`](https://docs.python.org/3.14/library/stdtypes.html#bytes) data. The `decode()` method returns a `ParseResult` instance.

Added in version 3.2.
