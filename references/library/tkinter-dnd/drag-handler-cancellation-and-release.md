# tkinter.dnd.DndHandler: `cancel()`, `finish()`, `on_motion()`, `on_release()`

cancel(*event=None*)

Abort the drag-and-drop process.

 finish(*event*, *commit=0*)

Run end-of-drag-and-drop functions.

 on_motion(*event*)

While dragging, examine the region beneath the mouse for target objects.

 on_release(*event*)

Mark the drag as finished once the release pattern fires.
