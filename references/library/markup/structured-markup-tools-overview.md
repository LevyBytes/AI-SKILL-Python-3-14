## Structured Markup Processing Tools

### Structured Markup Processing Tools

Python ships a range of modules for handling the various kinds of structured data markup. Among them are modules covering the Standard Generalized Markup Language (SGML) and the Hypertext Markup Language (HTML), together with a number of interfaces aimed at the Extensible Markup Language (XML).
