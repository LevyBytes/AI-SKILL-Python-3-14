# Gettext

### `gettext` — Multilingual internationalization services

**Source code:** [Lib/gettext.py](https://github.com/python/cpython/tree/3.14/Lib/gettext.py)

---

For your Python modules and applications, the `gettext` module supplies internationalization (I18N) and localization (L10N) facilities. Two styles are offered: the GNU **gettext** message catalog API, plus a higher level, class-based API that often fits Python files better. With the interface documented here you can author your module and application messages in a single natural language, then supply a catalog of translated messages so the program runs under other natural languages.

A handful of tips on localizing your Python modules and applications appear here as well.
