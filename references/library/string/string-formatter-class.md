# string: `string.Formatter`

### Custom string formatting

Through the [`format()`](https://docs.python.org/3.14/library/stdtypes.html#str.format) method laid out in [**PEP 3101**](https://peps.python.org/pep-3101/), the built-in string class can perform elaborate variable substitution and value formatting. By drawing on the same machinery as the built-in `format()` method, the `Formatter` class within the `string` module lets you build and tailor your own string-formatting behaviors.
