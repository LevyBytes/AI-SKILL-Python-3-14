# zoneinfo — Runtime configuration

#### Runtime configuration

You may likewise adjust the TZ search path while the program runs by calling the `reset_tzpath()` function. As a rule this isn't a wise thing to do, yet it makes sense within test functions that need a particular time zone path (or need to shut off access to the system time zones).
