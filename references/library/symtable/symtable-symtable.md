# symtable — Generating Symbol Tables

### Generating Symbol Tables

 symtable.symtable(*code*, *filename*, *compile_type*)

Hands back the toplevel `SymbolTable` built from the Python source *code*. The file that holds that code is named by *filename*, while *compile_type* plays the role that the *mode* argument plays for [`compile()`](https://docs.python.org/3.14/library/functions.html#compile).
