# symtable - Command-Line Usage

### Command-Line Usage

Added in version 3.13.

You can run the `symtable` module directly as a script straight from the command line.

```sh
python -m symtable [infile...]

```

For each Python source file you name, a symbol table is built and written out to stdout. When you supply no input file, the content is taken from stdin instead.
