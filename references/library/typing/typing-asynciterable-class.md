# typing: `typing.AsyncIterable`

*class *typing.AsyncIterable(*Generic[T_co]*)

Deprecated alias to [`collections.abc.AsyncIterable`](https://docs.python.org/3.14/library/collections.abc.html#collections.abc.AsyncIterable).

Added in version 3.5.2.

Deprecated since version 3.9: [`collections.abc.AsyncIterable`](https://docs.python.org/3.14/library/collections.abc.html#collections.abc.AsyncIterable) now supports subscripting (`[]`). See [**PEP 585**](https://peps.python.org/pep-0585/) and [Generic Alias Type](https://docs.python.org/3.14/library/stdtypes.html#types-genericalias).
