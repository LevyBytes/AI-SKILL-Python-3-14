# typing: `typing.Dict`

#### Aliases to built-in types

 *class *typing.Dict(*dict, MutableMapping[KT, VT]*)

Deprecated alias to [`dict`](https://docs.python.org/3.14/library/stdtypes.html#dict).

When annotating arguments, keep in mind that an abstract collection type like [`Mapping`](https://docs.python.org/3.14/library/collections.abc.html#collections.abc.Mapping) is the preferred choice over [`dict`](https://docs.python.org/3.14/library/stdtypes.html#dict) or `typing.Dict`.

Deprecated since version 3.9: [`builtins.dict`](https://docs.python.org/3.14/library/stdtypes.html#dict) now supports subscripting (`[]`). See [**PEP 585**](https://peps.python.org/pep-0585/) and [Generic Alias Type](https://docs.python.org/3.14/library/stdtypes.html#types-genericalias).
