# typing: `typing.FrozenSet`

*class *typing.FrozenSet(*frozenset, AbstractSet[T_co]*)

Deprecated alias to [`builtins.frozenset`](https://docs.python.org/3.14/library/stdtypes.html#frozenset).

Deprecated since version 3.9: [`builtins.frozenset`](https://docs.python.org/3.14/library/stdtypes.html#frozenset) now supports subscripting (`[]`). See [**PEP 585**](https://peps.python.org/pep-0585/) and [Generic Alias Type](https://docs.python.org/3.14/library/stdtypes.html#types-genericalias).
