# typing: `typing.List`

*class *typing.List(*list, MutableSequence[T]*)

Deprecated alias to [`list`](https://docs.python.org/3.14/library/stdtypes.html#list).

When annotating arguments, keep in mind that an abstract collection type such as [`Sequence`](https://docs.python.org/3.14/library/collections.abc.html#collections.abc.Sequence) or [`Iterable`](https://docs.python.org/3.14/library/collections.abc.html#collections.abc.Iterable) is the preferred choice over [`list`](https://docs.python.org/3.14/library/stdtypes.html#list) or `typing.List`.

Deprecated since version 3.9: [`builtins.list`](https://docs.python.org/3.14/library/stdtypes.html#list) now supports subscripting (`[]`). See [**PEP 585**](https://peps.python.org/pep-0585/) and [Generic Alias Type](https://docs.python.org/3.14/library/stdtypes.html#types-genericalias).
