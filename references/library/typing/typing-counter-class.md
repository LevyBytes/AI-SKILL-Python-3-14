# typing: `typing.Counter`

*class *typing.Counter(*collections.Counter, Dict[T, int]*)

Deprecated alias to [`collections.Counter`](https://docs.python.org/3.14/library/collections.html#collections.Counter).

Added in version 3.6.1.

Deprecated since version 3.9: [`collections.Counter`](https://docs.python.org/3.14/library/collections.html#collections.Counter) now supports subscripting (`[]`). See [**PEP 585**](https://peps.python.org/pep-0585/) and [Generic Alias Type](https://docs.python.org/3.14/library/stdtypes.html#types-genericalias).
