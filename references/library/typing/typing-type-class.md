# typing: `typing.Type`

*class *typing.Type(*Generic[CT_co]*)

Deprecated alias to [`type`](https://docs.python.org/3.14/library/functions.html#type).

For guidance on applying [`type`](https://docs.python.org/3.14/library/functions.html#type) or `typing.Type` within type annotations, refer to The type of class objects.

Added in version 3.5.2.

Deprecated since version 3.9: [`builtins.type`](https://docs.python.org/3.14/library/functions.html#type) now supports subscripting (`[]`). See [**PEP 585**](https://peps.python.org/pep-0585/) and [Generic Alias Type](https://docs.python.org/3.14/library/stdtypes.html#types-genericalias).
