# typing: `typing.Tuple`

typing.Tuple

Deprecated alias for [`tuple`](https://docs.python.org/3.14/library/stdtypes.html#tuple).

Within the type system, [`tuple`](https://docs.python.org/3.14/library/stdtypes.html#tuple) and `Tuple` receive special-case handling; consult Annotating tuples for further detail.

Deprecated since version 3.9: [`builtins.tuple`](https://docs.python.org/3.14/library/stdtypes.html#tuple) now supports subscripting (`[]`). See [**PEP 585**](https://peps.python.org/pep-0585/) and [Generic Alias Type](https://docs.python.org/3.14/library/stdtypes.html#types-genericalias).
