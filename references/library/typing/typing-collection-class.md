# typing: `typing.Collection`

*class *typing.Collection(*Sized, Iterable[T_co], Container[T_co]*)

Deprecated alias to [`collections.abc.Collection`](https://docs.python.org/3.14/library/collections.abc.html#collections.abc.Collection).

Added in version 3.6.

Deprecated since version 3.9: [`collections.abc.Collection`](https://docs.python.org/3.14/library/collections.abc.html#collections.abc.Collection) now supports subscripting (`[]`). See [**PEP 585**](https://peps.python.org/pep-0585/) and [Generic Alias Type](https://docs.python.org/3.14/library/stdtypes.html#types-genericalias).
