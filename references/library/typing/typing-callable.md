# typing: `typing.Callable`

typing.Callable

Deprecated alias to [`collections.abc.Callable`](https://docs.python.org/3.14/library/collections.abc.html#collections.abc.Callable).

For guidance on applying [`collections.abc.Callable`](https://docs.python.org/3.14/library/collections.abc.html#collections.abc.Callable) and `typing.Callable` within type annotations, refer to Annotating callable objects.

Deprecated since version 3.9: [`collections.abc.Callable`](https://docs.python.org/3.14/library/collections.abc.html#collections.abc.Callable) now supports subscripting (`[]`). See [**PEP 585**](https://peps.python.org/pep-0585/) and [Generic Alias Type](https://docs.python.org/3.14/library/stdtypes.html#types-genericalias).

Changed in version 3.10: `Callable` now supports `ParamSpec` and `Concatenate`. See [**PEP 612**](https://peps.python.org/pep-0612/) for more details.
