# typing: `typing.Set`

*class *typing.Set(*set, MutableSet[T]*)

Deprecated alias to [`builtins.set`](https://docs.python.org/3.14/library/stdtypes.html#set).

When annotating arguments, keep in mind that an abstract collection type like [`collections.abc.Set`](https://docs.python.org/3.14/library/collections.abc.html#collections.abc.Set) is the preferred choice over [`set`](https://docs.python.org/3.14/library/stdtypes.html#set) or `typing.Set`.

Deprecated since version 3.9: [`builtins.set`](https://docs.python.org/3.14/library/stdtypes.html#set) now supports subscripting (`[]`). See [**PEP 585**](https://peps.python.org/pep-0585/) and [Generic Alias Type](https://docs.python.org/3.14/library/stdtypes.html#types-genericalias).
