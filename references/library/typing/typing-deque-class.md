# typing: `typing.Deque`

*class *typing.Deque(*deque, MutableSequence[T]*)

Deprecated alias to [`collections.deque`](https://docs.python.org/3.14/library/collections.html#collections.deque).

Added in version 3.6.1.

Deprecated since version 3.9: [`collections.deque`](https://docs.python.org/3.14/library/collections.html#collections.deque) now supports subscripting (`[]`). See [**PEP 585**](https://peps.python.org/pep-0585/) and [Generic Alias Type](https://docs.python.org/3.14/library/stdtypes.html#types-genericalias).
