# idlelib - implementation of IDLE application

### idlelib - implementation of IDLE application

**Source code:** [Lib/idlelib](https://github.com/python/cpython/tree/3.14/Lib/idlelib)

---

The IDLE application is implemented by the Lib/idlelib package. For instructions on using IDLE, refer to the remainder of this page.

A rundown of the files within idlelib lives in idlelib/README.txt. You can open it from idlelib directly or by choosing Help => About IDLE on the IDLE menu. That file additionally ties each IDLE menu item to the code behind it. Apart from the files grouped under ‘Startup’, the idlelib code counts as ‘private’, in the sense that feature changes are eligible for backporting (see [**PEP 434**](https://peps.python.org/pep-0434/)).
