## xmlrpc — XMLRPC server and client modules

### `xmlrpc` — XMLRPC server and client modules

As a Remote Procedure Call mechanism, XML-RPC carries XML over HTTP as its transport. Through it, a client invokes parameterized methods on a far server (named by a URI) and gets structured data in return.

The `xmlrpc` package gathers together the server and client modules that put XML-RPC into practice. Its modules are:

- [`xmlrpc.client`](https://docs.python.org/3.14/library/xmlrpc.client.html#module-xmlrpc.client)

- [`xmlrpc.server`](https://docs.python.org/3.14/library/xmlrpc.server.html#module-xmlrpc.server)
