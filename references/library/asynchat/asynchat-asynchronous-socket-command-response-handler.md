### `asynchat` — Asynchronous socket command/response handler

Deprecated since version 3.6, removed in version 3.12.

You won’t find this module in the Python standard library anymore. Having been deprecated back in Python 3.6, it was eventually [removed in Python 3.12](https://docs.python.org/3.14/whatsnew/3.12.html#whatsnew312-removed). That removal was settled by [**PEP 594**](https://peps.python.org/pep-0594/).

Reach for the [`asyncio`](https://docs.python.org/3.14/library/asyncio.html#module-asyncio) module in its place.

[Python 3.11](https://docs.python.org/3.11/library/asynchat.html) was the final Python release to ship the `asynchat` module.
