# xml.sax.xmlreader: `xml.sax.xmlreader.Locator`

*class *xml.sax.xmlreader.Locator

Interface for tying a SAX event to a document location. A locator object will hand back valid results solely during calls to DocumentHandler methods; at any other moment, the results are unpredictable. Where information is unavailable, methods may return `None`.
