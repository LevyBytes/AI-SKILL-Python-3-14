# xml.sax.xmlreader: `xml.sax.xmlreader.AttributesImpl`

*class *xml.sax.xmlreader.AttributesImpl(*attrs*)

This is an implementation of the `Attributes` interface (see section The Attributes Interface). It is a dictionary-like object representing the element attributes in a `startElement()` call. Alongside the most useful dictionary operations, it backs a number of further methods as the interface describes. Readers should instantiate objects of this class; *attrs* has to be a dictionary-like object that maps attribute names onto attribute values.
