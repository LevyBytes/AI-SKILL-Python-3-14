# Options menu (Shell and Editor)

### Options menu (Shell and Editor)

Configure IDLE

Bring up a configuration dialog to adjust preferences covering: fonts, indentation, keybindings, text color themes, startup windows and size, extra help sources, and extensions. Under macOS, reach the configuration dialog by choosing Preferences from the application menu. See Setting preferences under Help and preferences for fuller detail.

The majority of configuration options affect all windows or every future window. The option entries below act only on the active window.

Show/Hide Code Context (Editor Window only)

Open a pane along the top of the edit window that displays the block context of code which has scrolled past the window’s top edge. Refer to Code Context within the Editing and Navigation section that follows.

Show/Hide Line Numbers (Editor Window only)

Open a column at the left of the edit window that displays each text line’s number. By default it is off, which the preferences can change (see Setting preferences).

Zoom/Restore Height

Switch the window between its normal size and maximum height. Unless altered on the General tab of the Configure IDLE dialog, the initial size defaults to 40 lines by 80 chars. A screen’s maximum height is found by briefly maximizing a window the first time any window is zoomed on that screen. Altering screen settings can invalidate the stored height. While a window is maximized this toggle does nothing.
