### Help sources

The Help menu's “IDLE Help” item shows a formatted html rendering of the IDLE chapter from the Library Reference. Presented in a read-only tkinter text window, it looks much like what a web browser would give you. Move through the text using a mousewheel, the scrollbar, or by holding down the up and down arrow keys. Alternatively, press the TOC (Table of Contents) button and choose a section header from the box that opens.

The Help menu's “Python Docs” item brings up the broad help resources, tutorials among them, found at `docs.python.org/x.y`, where ‘x.y’ denotes the Python version currently in use. Should your system hold an off-line copy of the docs — possibly chosen during installation — that copy opens instead.

At any point you can add or drop particular URLs from the help menu through the General tab of the Configure IDLE dialog.
