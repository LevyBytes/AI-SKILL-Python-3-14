# Shell menu (Shell window only)

### Shell menu (Shell window only)

View Last Restart

Scroll the shell window to the last Shell restart.

Restart Shell

Restart the shell to wipe the environment and reset display together with exception handling.

Previous History

Step backward through earlier history commands that match the current entry.

Next History

Step forward through later history commands that match the current entry.

Interrupt Execution

Stop a running program.
