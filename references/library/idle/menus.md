# Menus

### Menus

There are two principal window kinds in IDLE: the Shell window and the Editor window. Several editor windows may be open at once. Under Windows and Linux, every window carries its own top menu. The documentation for each menu below notes which window kind it belongs to.

Output windows — for instance the one produced by Edit => Find in Files — count as a variety of editor window. For now they share the same top menu yet use a distinct default title and context menu.

Under macOS there is a single application menu. That menu shifts dynamically based on whichever window is active. It includes an IDLE menu, and certain entries listed below are relocated to follow Apple guidelines.
