# Extensions

### Extensions

IDLE ships with an extension facility. You change extension preferences from the Extensions tab of the preferences dialog. For more detail, look at the top of config-extensions.def in the idlelib directory. At present the sole default extension is zzdummy, a sample that doubles as a testing aid.
