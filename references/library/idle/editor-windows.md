### Editor windows

Depending on your settings and how IDLE was launched, it may open editor windows at startup. After that, rely on the File menu. A given file can have at most one editor window open.

The title bar holds the file’s name, the full path, and the Python and IDLE version powering the window. The status bar holds the line number (‘Ln’) and column number (‘Col’). Line numbering begins at 1; column numbering at 0.

IDLE treats files bearing a recognized .py* extension as Python code and everything else as not. Use the Run menu to run Python code.
