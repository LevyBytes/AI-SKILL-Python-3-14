# IDLE on macOS

### IDLE on macOS

In System Preferences: Dock, you have the option to set “Prefer tabs when opening documents” to “Always”. That choice doesn't play well with the tk/tkinter GUI framework IDLE depends on, and it ends up breaking a handful of IDLE features.
