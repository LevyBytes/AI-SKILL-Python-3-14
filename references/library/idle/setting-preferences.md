# Setting preferences

### Setting preferences

You adjust the font preferences, highlighting, keys, and general preferences through Configure IDLE on the Option menu. Settings that differ from the defaults get written to a `.idlerc` directory inside the user's home directory. When a bad user configuration file causes trouble, the cure is to edit or delete one or more files within `.idlerc`.

The Font tab's text sample lets you preview how font face and size affect a range of characters across several languages. Feel free to edit that sample to include other characters you care about, and use it to pick monospaced fonts. If certain characters misbehave in Shell or an editor, drop them at the top of the sample and experiment first with size, then with font.

Over on the Highlights and Keys tab, pick a built-in or custom color theme along with a key set. To carry a newer built-in color theme or key set into older IDLEs, store it as a fresh custom theme or key set, and older IDLEs will then be able to reach it.
