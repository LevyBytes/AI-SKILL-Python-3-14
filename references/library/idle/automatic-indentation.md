# Automatic indentation

### Automatic indentation

Following a block-opening statement, the subsequent line gains 4 spaces of indent (one tab inside the Python Shell window). Following particular keywords (break, return etc.) the subsequent line is dedented. Within leading indentation, Backspace removes up to 4 spaces when present. Tab adds spaces (one tab inside the Python Shell window), the count depending on Indent width. For now, tabs are limited to four spaces because of Tcl/Tk limitations.

Refer as well to the indent/dedent region commands on the Format menu.
