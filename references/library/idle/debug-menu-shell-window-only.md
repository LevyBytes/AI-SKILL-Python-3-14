# Debug menu (Shell window only)

### Debug menu (Shell window only)

Go to File/Line

Inspect the current line under the cursor, along with the line above it, for a filename and line number. When one is found, open the file unless it is already open, and reveal the line. Use this to inspect source lines named in an exception traceback and lines surfaced by Find in Files. It is also offered in the context menu of the Shell window and Output windows.

Debugger (toggle)

Once enabled, code typed in the Shell or launched from an Editor runs beneath the debugger. Within the Editor, the context menu can place breakpoints. This capability remains unfinished and rather experimental.

Stack Viewer

Display, within a tree widget granting access to locals and globals, the stack traceback belonging to the most recent exception.

Auto-open Stack Viewer

Toggle whether the stack viewer opens automatically when an exception goes unhandled.
