# IDLE — Python editor and shell

### IDLE — Python editor and shell

**Source code:** [Lib/idlelib/](https://github.com/python/cpython/tree/3.14/Lib/idlelib/)

---

IDLE is Python’s Integrated Development and Learning Environment.

The capabilities IDLE provides include:

- cross-platform: behaves nearly identically across Windows, Unix, and macOS

- a Python shell window (interactive interpreter) that colorizes code input, output, and error messages

- a multi-window text editor offering multiple undo, Python colorizing, smart indent, call tips, auto completion, and more

- searching inside any window, replacing within editor windows, plus searching across several files at once (grep)

- a debugger supporting persistent breakpoints, stepping, and inspection of global and local namespaces

- configuration, browsers, and assorted dialogs

The `idlelib` package contains the implementation of the IDLE application.

This is an [optional module](https://docs.python.org/3.14/glossary.html#term-optional-module). Should it be absent from your CPython build, consult the documentation supplied by your distributor (in other words, whoever handed Python to you). Distributors themselves should refer to [Requirements for optional modules](https://docs.python.org/3.14/using/configure.html#optional-module-requirements).
