# Format block

### Format block

Reformat Paragraph rewraps a block (‘paragraph’) made of contiguous, equally indented, non-blank comments, a comparable block of text inside a multiline string, or a chosen portion of either. When required, it inserts a blank line to part string from code. Partial lines within a selection grow to whole lines. The produced lines keep the prior indent yet hold a maximum total length of N columns (characters). Adjust the default N of 72 on the Window tab of IDLE Settings.
