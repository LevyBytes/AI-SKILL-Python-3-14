# Context menus

### Context menus

Bring up a context menu by right-clicking inside a window (Control-click on macOS). Context menus carry the standard clipboard operations found on the Edit menu as well.

Cut

Place the selection on the system-wide clipboard, then remove that selection.

Copy

Copy selection into the system-wide clipboard.

Paste

Insert contents of the system-wide clipboard into the current window.

Breakpoint operations also live on editor windows. A line carrying a set breakpoint is distinctly marked. Breakpoints take effect solely while running under the debugger. A file’s breakpoints are stored in the user’s `.idlerc` directory.

Set Breakpoint

Set a breakpoint on the current line.

Clear Breakpoint

Clear the breakpoint on that line.

The following also appear on Shell and Output windows.

Go to file/line

Same as in Debug menu.

The Shell window additionally provides an output squeezing feature described in the *Python Shell window* subsection that follows.

Squeeze

When the cursor sits over an output line, collapse all the output between the code above and the prompt below into a ‘Squeezed text’ label.
