# Help menu (Shell and Editor)

### Help menu (Shell and Editor)

About IDLE

Display version, copyright, license, credits, and more.

IDLE Help

Show this IDLE document, which describes the menu choices, fundamental editing and navigation, plus other pointers.

Python Docs

Reach local Python documentation when it is installed, otherwise launch a web browser onto docs.python.org displaying the most recent Python documentation.

Turtle Demo

Run the turtledemo module with example Python code and turtle drawings.

Extra help sources can be added here via the Configure IDLE dialog on the General tab. Consult the Help sources subsection below for more about Help menu choices.
