# Edit menu (Shell and Editor)

### Edit menu (Shell and Editor)

Undo

Reverse the most recent change made to the current window. Up to 1000 changes can be reversed.

Redo

Redo the last undone change to the current window.

Select All

Select the entire contents of the current window.

Cut

Place the selection on the system-wide clipboard, then remove that selection.

Copy

Copy selection into the system-wide clipboard.

Paste

Insert contents of the system-wide clipboard into the current window.

The clipboard operations appear in context menus too.

Find…

Open a search dialog with many options

Find Again

Repeat the last search, if there is one.

Find Selection

Search for the currently selected string, if there is one.

Find in Files…

Open a file search dialog. Put results in a new output window.

Replace…

Open a search-and-replace dialog.

Go to Line

Shift the cursor to the start of the requested line and bring that line into view. A request beyond the file’s end lands at the end. Drop any selection and refresh the line and column status.

Show Completions

Bring up a scrollable list for choosing among existing names. Refer to Completions within the Editing and Navigation section that follows.

Expand Word

Grow a prefix you have entered into a complete word found in the same window; repeat to obtain a different expansion.

Show Call Tip

Following an unclosed parenthesis after a function, bring up a small window showing function parameter hints. Refer to Calltips within the Editing and Navigation section that follows.

Show Surrounding Parens

Highlight the surrounding parenthesis.
