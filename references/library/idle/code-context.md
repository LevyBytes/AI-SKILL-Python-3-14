# Code Context

### Code Context

Inside an editor window holding Python code, code context can be toggled to reveal or conceal a pane along the window’s top. While shown, that pane locks in place the opening lines of block code — for example lines starting with the `class`, `def`, or `if` keywords — that would otherwise have scrolled out of sight. The pane grows and shrinks as required to reveal all present context levels, up to the line maximum set in the Configure IDLE dialog (which defaults to 15). When no current context lines exist and the feature is toggled on, one blank line is shown. Clicking a line in the context pane moves that line to the editor’s top.

The pane’s text and background colors are configurable on the Highlights tab of the Configure IDLE dialog.
