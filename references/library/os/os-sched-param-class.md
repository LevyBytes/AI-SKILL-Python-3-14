# os: `os.sched_param`

*class *os.sched_param(*sched_priority*)

This class stands for the tunable scheduling parameters that `sched_setparam()`, `sched_setscheduler()`, and `sched_getparam()` use. It is immutable.

For now, just one parameter exists:

 sched_priority

The scheduling priority belonging to a scheduling policy.
