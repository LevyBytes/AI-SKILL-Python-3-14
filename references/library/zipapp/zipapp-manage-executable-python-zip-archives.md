# Zipapp

### `zipapp` - Manage executable Python zip archives

Added in version 3.5.

**Source code:** [Lib/zipapp.py](https://github.com/python/cpython/tree/3.14/Lib/zipapp.py)

---

Here you get tools for overseeing the building of zip files that hold Python code and that the [Python interpreter can run directly](https://docs.python.org/3.14/using/cmdline.html#using-on-interface-options). Both a Command-Line Interface and a Python API ship with the module.
