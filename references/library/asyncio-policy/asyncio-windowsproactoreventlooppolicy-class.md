# asyncio.policy: `asyncio.WindowsProactorEventLoopPolicy`

*class *asyncio.WindowsProactorEventLoopPolicy

An alternative event loop policy that uses the [`ProactorEventLoop`](https://docs.python.org/3.14/library/asyncio-eventloop.html#asyncio.ProactorEventLoop) event loop implementation.

[Availability](https://docs.python.org/3.14/library/intro.html#availability): Windows.

Deprecated since version 3.14: Now deprecated, the `WindowsProactorEventLoopPolicy` class is going to be removed in Python 3.16.
