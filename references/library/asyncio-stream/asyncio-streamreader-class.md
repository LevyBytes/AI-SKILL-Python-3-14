# StreamReader: `asyncio.StreamReader`

### StreamReader

 `*class *asyncio.StreamReader`

Stands for a reader object whose APIs pull data out of the IO stream. Being an [asynchronous iterable](https://docs.python.org/3.14/glossary.html#term-asynchronous-iterable), it works with the [`async for`](https://docs.python.org/3.14/reference/compound_stmts.html#async-for) statement.

Creating *StreamReader* objects yourself is discouraged; lean on `open_connection()` and `start_server()` instead.
