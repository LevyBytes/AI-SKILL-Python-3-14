# StreamWriter: `asyncio.StreamWriter`

### StreamWriter

 `*class *asyncio.StreamWriter`

Stands for a writer object whose APIs push data into the IO stream.

Creating *StreamWriter* objects yourself is discouraged; lean on `open_connection()` and `start_server()` instead.
