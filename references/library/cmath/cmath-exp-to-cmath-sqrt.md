# cmath - Power and logarithmic functions

### Power and logarithmic functions

 cmath.exp(*z*)

Return *e* raised to the power *z*, with *e* being the base of natural logarithms.

 cmath.log(*z*[, *base*])

Return the logarithm of *z* to the given *base*. When no *base* is provided, the natural logarithm of *z* is returned. A single branch cut runs from 0 down the negative real axis to -∞.

 cmath.log10(*z*)

Return the base-10 logarithm of *z*. It shares the branch cut of `log()`.

 cmath.sqrt(*z*)

Return the square root of *z*. It shares the branch cut of `log()`.
