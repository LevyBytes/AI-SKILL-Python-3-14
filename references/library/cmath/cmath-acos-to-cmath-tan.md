# cmath - Trigonometric functions

### Trigonometric functions

 cmath.acos(*z*)

Return the arc cosine of *z*. Two branch cuts apply: one runs rightward from 1 along the real axis to ∞, the other runs leftward from -1 along the real axis to -∞.

 cmath.asin(*z*)

Return the arc sine of *z*. It shares the branch cuts of `acos()`.

 cmath.atan(*z*)

Return the arc tangent of *z*. Two branch cuts apply: one runs from `1j` along the imaginary axis to `∞j`, the other runs from `-1j` along the imaginary axis to `-∞j`.

 cmath.cos(*z*)

Return the cosine of *z*.

 cmath.sin(*z*)

Return the sine of *z*.

 cmath.tan(*z*)

Return the tangent of *z*.
