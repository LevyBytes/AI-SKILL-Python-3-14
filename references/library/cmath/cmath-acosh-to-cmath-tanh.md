# cmath — Hyperbolic functions

### Hyperbolic functions

 cmath.acosh(*z*)

Return the inverse hyperbolic cosine of *z*. A single branch cut runs leftward from 1 along the real axis to -∞.

 cmath.asinh(*z*)

Return the inverse hyperbolic sine of *z*. Two branch cuts apply: one runs from `1j` along the imaginary axis to `∞j`, the other runs from `-1j` along the imaginary axis to `-∞j`.

 cmath.atanh(*z*)

Return the inverse hyperbolic tangent of *z*. Two branch cuts apply: one runs from `1` along the real axis to `∞`, the other runs from `-1` along the real axis to `-∞`.

 cmath.cosh(*z*)

Return the hyperbolic cosine of *z*.

 cmath.sinh(*z*)

Return the hyperbolic sine of *z*.

 cmath.tanh(*z*)

Return the hyperbolic tangent of *z*.
