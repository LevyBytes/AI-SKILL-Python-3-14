# Timeit

### `timeit` - Measure execution time of small code snippets

**Source code:** [Lib/timeit.py](https://github.com/python/cpython/tree/3.14/Lib/timeit.py)

---

This module offers an easy way to time short fragments of Python code. It comes with both a Command-Line Interface and a callable one. A number of the common traps in measuring execution times are sidestepped. For background, look at the “Algorithms” chapter's opening written by Tim Peters, found in *Python Cookbook* (2nd edition) from O'Reilly.
