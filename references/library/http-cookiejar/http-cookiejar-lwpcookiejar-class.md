# http.cookiejar: `http.cookiejar.LWPCookieJar`

*class *http.cookiejar.LWPCookieJar(*filename=None*, *delayload=None*, *policy=None*)

A `FileCookieJar` capable of loading from and saving cookies to disk in a format compatible with the libwww-perl library's `Set-Cookie3` file format. That is handy when you'd like to keep your cookies in a file a person can read.

Changed in version 3.8: The filename parameter supports a [path-like object](https://docs.python.org/3.14/glossary.html#term-path-like-object).
