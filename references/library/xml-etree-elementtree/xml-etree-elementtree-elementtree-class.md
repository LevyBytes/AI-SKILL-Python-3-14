# xml.etree.ElementTree: `xml.etree.ElementTree.ElementTree`

### ElementTree Objects

 *class *xml.etree.ElementTree.ElementTree(*element=None*, *file=None*)

ElementTree wrapper class. This class stands for a whole element hierarchy and layers on some extra support for serialization to and from standard XML.

*element* is the root element. When an XML *file* is supplied, the tree starts out holding that file's contents.
