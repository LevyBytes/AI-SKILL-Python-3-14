# xml.etree.ElementTree - XInclude support

### XInclude support

The module offers partial handling of [XInclude directives](https://www.w3.org/TR/xinclude/) through the `xml.etree.ElementInclude` helper module. With it you can splice subtrees and text fragments into element trees, driven by data already present in the tree.
