# xml.etree.ElementTree: `xml.etree.ElementTree.Element`

### Element Objects

 *class *xml.etree.ElementTree.Element(*tag*, *attrib={}*, ***extra*)

Element class. This class lays out the Element interface and also supplies a reference implementation for it.

Each of the element name, the attribute names, and the attribute values may be given as bytestrings or as Unicode strings. *tag* supplies the element name. *attrib*, an optional dictionary, carries element attributes. *extra* gathers further attributes passed as keyword arguments.
