# xml.etree.ElementTree — XPath support

### XPath support

To find elements within a tree, this module gives you partial support for [XPath expressions](https://www.w3.org/TR/xpath). Its intent is to cover a modest portion of the abbreviated syntax; building a complete XPath engine lies beyond what the module sets out to do.
