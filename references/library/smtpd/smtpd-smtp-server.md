## smtpd - SMTP Server

### `smtpd` - SMTP Server

Deprecated since version 3.6, removed in version 3.12.

The Python standard library no longer contains this module. Having been deprecated back in Python 3.6, it was [removed in Python 3.12](https://docs.python.org/3.14/whatsnew/3.12.html#whatsnew312-removed). [**PEP 594**](https://peps.python.org/pep-0594/) settled the decision to drop it.

One candidate to take its place is the third-party [aiosmtpd](https://pypi.org/project/aiosmtpd/) library. The Python core team neither maintains nor supports that library.

[Python 3.11](https://docs.python.org/3.11/library/smtpd.html) was the final release in which the `smtpd` module shipped.
