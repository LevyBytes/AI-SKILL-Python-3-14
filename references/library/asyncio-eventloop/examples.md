# Examples

### Examples

Be aware that every example here **purposefully** demonstrates the low-level event loop APIs, including `loop.run_forever()` and `loop.call_soon()`. Today's asyncio programs seldom have to be built like this; lean toward high-level functions such as [`asyncio.run()`](https://docs.python.org/3.14/library/asyncio-runner.html#asyncio.run).
