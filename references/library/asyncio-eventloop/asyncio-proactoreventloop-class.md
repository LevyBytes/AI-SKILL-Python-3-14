# asyncio.eventloop: `asyncio.ProactorEventLoop`

*class *asyncio.ProactorEventLoop

A `AbstractEventLoop` subclass meant for Windows, built on “I/O Completion Ports” (IOCP).

[Availability](https://docs.python.org/3.14/library/intro.html#availability): Windows.

See also

[MSDN documentation on I/O Completion Ports](https://learn.microsoft.com/windows/win32/fileio/i-o-completion-ports).
