## __main__ - Top-level code environment

### `__main__` - Top-level code environment

---

Within Python, the reserved name `__main__` serves two significant roles:

1.

it names the program's top-level environment, something you can test with the `__name__ == '__main__'` expression; and

2.

it labels the `__main__.py` file found in Python packages.

Both roles tie back to Python modules — how people work with them and how they relate to one another. The sections that follow cover each in depth. Should Python modules be new to you, the tutorial section [Modules](https://docs.python.org/3.14/tutorial/modules.html#tut-modules) offers a starting point.
