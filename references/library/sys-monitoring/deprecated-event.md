# sys.monitoring — Deprecated event

### Deprecated event

- `BRANCH`

As of 3.14, the `BRANCH` event is deprecated. Reaching for the `BRANCH_LEFT` and `BRANCH_RIGHT` events delivers much better performance, since each one can be switched off on its own.
