# sys.monitoring - Other events

### Other events

Other events do not necessarily attach to a particular spot in the program and cannot each be switched off individually through `DISABLE`.

The other events open to monitoring are:

- `PY_THROW`

- `PY_UNWIND`

- `RAISE`

- `EXCEPTION_HANDLED`
