# sys.monitoring — Turning events on and off

### Turning events on and off

To watch an event, you have to switch it on and register a matching callback. You toggle events on or off by establishing the events globally, locally for a particular code object, or both. An event fires only a single time, even when it is switched on both globally and locally.
