# sys.monitoring — Local events

### Local events

Local events go hand in hand with ordinary execution of the program and land at clearly defined spots. Every local event can be switched off. The local events are:

- `PY_START`

- `PY_RESUME`

- `PY_RETURN`

- `PY_YIELD`

- `CALL`

- `LINE`

- `INSTRUCTION`

- `JUMP`

- `BRANCH_LEFT`

- `BRANCH_RIGHT`

- `STOP_ITERATION`
