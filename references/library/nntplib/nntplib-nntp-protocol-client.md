## nntplib - NNTP protocol client

### `nntplib` - NNTP protocol client

Deprecated since version 3.11, removed in version 3.13.

The standard library of Python ships this module no more. After being marked deprecated in Python 3.11, it saw its [removal in Python 3.13](https://docs.python.org/3.14/whatsnew/3.13.html#whatsnew313-pep594), a decision rooted in [**PEP 594**](https://peps.python.org/pep-0594/).

The `nntplib` module last appeared in [Python 3.12](https://docs.python.org/3.12/library/nntplib.html).
