# xml.sax.handler - EntityResolver Objects

### EntityResolver Objects

 EntityResolver.resolveEntity(*publicId*, *systemId*)

Resolve an entity's system identifier, returning either the system identifier to read from (as a string) or else an InputSource to read from. By default the implementation gives back *systemId*.
