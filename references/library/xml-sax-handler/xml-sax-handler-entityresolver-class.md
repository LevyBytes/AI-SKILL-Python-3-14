# xml.sax.handler: `xml.sax.handler.EntityResolver`

*class *xml.sax.handler.EntityResolver

Basic interface for resolving entities. Should you build an object that implements this interface and then register it with your Parser, the parser will invoke the method on your object to resolve every external entity.
