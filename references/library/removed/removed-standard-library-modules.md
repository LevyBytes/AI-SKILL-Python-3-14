# Removed standard-library modules

## Removed Modules

### Removed Modules

The modules listed in this chapter no longer ship with the Python standard library. Their documentation appears here so that people can track down replacements.

- [`aifc` — Read and write AIFF and AIFC files](https://docs.python.org/3.14/library/aifc.html)
- [`asynchat` — Asynchronous socket command/response handler](https://docs.python.org/3.14/library/asynchat.html)
- [`asyncore` — Asynchronous socket handler](https://docs.python.org/3.14/library/asyncore.html)
- [`audioop` — Manipulate raw audio data](https://docs.python.org/3.14/library/audioop.html)
- [`cgi` — Common Gateway Interface support](https://docs.python.org/3.14/library/cgi.html)
- [`cgitb` — Traceback manager for CGI scripts](https://docs.python.org/3.14/library/cgitb.html)
- [`chunk` — Read IFF chunked data](https://docs.python.org/3.14/library/chunk.html)
- [`crypt` — Function to check Unix passwords](https://docs.python.org/3.14/library/crypt.html)
- [`distutils` — Building and installing Python modules](https://docs.python.org/3.14/library/distutils.html)
- [`imghdr` — Determine the type of an image](https://docs.python.org/3.14/library/imghdr.html)
- [`imp` — Access the import internals](https://docs.python.org/3.14/library/imp.html)
- [`mailcap` — Mailcap file handling](https://docs.python.org/3.14/library/mailcap.html)
- [`msilib` — Read and write Microsoft Installer files](https://docs.python.org/3.14/library/msilib.html)
- [`nis` — Interface to Sun’s NIS (Yellow Pages)](https://docs.python.org/3.14/library/nis.html)
- [`nntplib` — NNTP protocol client](https://docs.python.org/3.14/library/nntplib.html)
- [`ossaudiodev` — Access to OSS-compatible audio devices](https://docs.python.org/3.14/library/ossaudiodev.html)
- [`pipes` — Interface to shell pipelines](https://docs.python.org/3.14/library/pipes.html)
- [`smtpd` — SMTP Server](https://docs.python.org/3.14/library/smtpd.html)
- [`sndhdr` — Determine type of sound file](https://docs.python.org/3.14/library/sndhdr.html)
- [`spwd` — The shadow password database](https://docs.python.org/3.14/library/spwd.html)
- [`sunau` — Read and write Sun AU files](https://docs.python.org/3.14/library/sunau.html)
- [`telnetlib` — Telnet client](https://docs.python.org/3.14/library/telnetlib.html)
- [`uu` — Encode and decode uuencode files](https://docs.python.org/3.14/library/uu.html)
- [`xdrlib` — Encode and decode XDR data](https://docs.python.org/3.14/library/xdrlib.html)
