# pickletools — Command-line options

### Command-line options

 -a, --annotate

Attaches a brief opcode note to every line.

 -o, --output=&lt;file&gt;

The name of the file that should receive the output.

 -l, --indentlevel=&lt;num&gt;

How many spaces to use when indenting each fresh MARK level.

 -m, --memo

Keeps the memo intact from one disassembly to the next when several objects get taken apart.

 -p, --preamble=&lt;preamble&gt;

Should you name several pickle files, emit the supplied preamble ahead of every disassembly.

 pickle_file

The pickle file to read; pass `-` to pull from standard input instead.
