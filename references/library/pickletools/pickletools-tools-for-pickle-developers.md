### `pickletools` — Tools for pickle developers

**Source code:** [Lib/pickletools.py](https://github.com/python/cpython/tree/3.14/Lib/pickletools.py)

---

Inside this module you'll find an assortment of constants that touch the inner workings of the [`pickle`](https://docs.python.org/3.14/library/pickle.html#module-pickle) module, several substantial implementation notes, and a handful of handy routines for inspecting pickled data. What this module offers tends to matter to Python core developers building the `pickle`; everyday users of the `pickle` module are unlikely to have much need for the `pickletools` module.
