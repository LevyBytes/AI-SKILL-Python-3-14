### `sysconfig` - Provide access to Python’s configuration information

Added in version 3.2.

**Source code:** [Lib/sysconfig](https://github.com/python/cpython/tree/3.14/Lib/sysconfig)

---

The `sysconfig` module opens up Python's configuration details — among them the roster of installation paths together with the configuration variables that apply to the platform you are on.
