## Custom Python Interpreters

### Custom Python Interpreters

With the modules covered here you can build interfaces that behave much like Python's own interactive interpreter. When you'd like an interpreter that layers some extra capability on top of the plain Python language, turn to the [`code`](https://docs.python.org/3.14/library/code.html#module-code) module. (For something more low-level, the [`codeop`](https://docs.python.org/3.14/library/codeop.html#module-codeop) module exists to help compile a chunk of Python source that may not yet be complete.)

Here is the complete set of modules this chapter documents:

- [`code` - Interpreter base classes](https://docs.python.org/3.14/library/code.html)
  - [Interactive Interpreter Objects](https://docs.python.org/3.14/library/code.html#interactive-interpreter-objects)
  - [Interactive Console Objects](https://docs.python.org/3.14/library/code.html#interactive-console-objects)

- [`codeop` - Compile Python code](https://docs.python.org/3.14/library/codeop.html)
