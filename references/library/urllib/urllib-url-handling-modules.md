## urllib - URL handling modules

### `urllib` - URL handling modules

**Source code:** [Lib/urllib/](https://github.com/python/cpython/tree/3.14/Lib/urllib/)

---

`urllib` is a package gathering together a handful of modules for handling URLs:

- [`urllib.request`](https://docs.python.org/3.14/library/urllib.request.html#module-urllib.request) used to open URLs and read from them

- [`urllib.error`](https://docs.python.org/3.14/library/urllib.error.html#module-urllib.error) which holds the exceptions thrown by [`urllib.request`](https://docs.python.org/3.14/library/urllib.request.html#module-urllib.request)

- [`urllib.parse`](https://docs.python.org/3.14/library/urllib.parse.html#module-urllib.parse) used to parse URLs apart

- [`urllib.robotparser`](https://docs.python.org/3.14/library/urllib.robotparser.html#module-urllib.robotparser) used to parse `robots.txt` files
