## crypt - Function to check Unix passwords

### `crypt` - Function to check Unix passwords

Deprecated since version 3.11, removed in version 3.13.

This module belongs to the Python standard library no longer. Having been deprecated back in Python 3.11, it then saw its [removal in Python 3.13](https://docs.python.org/3.14/whatsnew/3.13.html#whatsnew313-pep594); [**PEP 594**](https://peps.python.org/pep-0594/) is where that decision was reached.

For their needs, applications may turn to the standard library's [`hashlib`](https://docs.python.org/3.14/library/hashlib.html#module-hashlib) module. Among the alternatives are third-party PyPI packages such as [legacycrypt](https://pypi.org/project/legacycrypt/), [bcrypt](https://pypi.org/project/bcrypt/), and [argon2-cffi](https://pypi.org/project/argon2-cffi/), none of which the Python core team supports or maintains.

[Python 3.12](https://docs.python.org/3.12/library/crypt.html) was the final release that shipped the `crypt` module.
