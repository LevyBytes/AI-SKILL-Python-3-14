## pipes - Interface to shell pipelines

### `pipes` - Interface to shell pipelines

Deprecated since version 3.11, removed in version 3.13.

The Python standard library no longer includes this module. Following its deprecation in Python 3.11, it was [removed in Python 3.13](https://docs.python.org/3.14/whatsnew/3.13.html#whatsnew313-pep594). That removal came out of [**PEP 594**](https://peps.python.org/pep-0594/).

For their needs, applications ought to turn to the [`subprocess`](https://docs.python.org/3.14/library/subprocess.html#module-subprocess) module.

[Python 3.12](https://docs.python.org/3.12/library/pipes.html) was the final Python release to ship the `pipes` module.
