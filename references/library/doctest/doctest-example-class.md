# doctest: `doctest.Example`

### Example Objects

 *class *doctest.Example(*source*, *want*, *exc_msg=None*, *lineno=0*, *indent=0*, *options=None*)

A single interactive example, made up of a Python statement plus the output it is expected to produce. The constructor's arguments serve to initialize the attributes that bear the same names.

`Example` defines the attributes below. The constructor initializes them, and they should not be altered directly.
