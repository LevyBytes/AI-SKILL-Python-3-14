# doctest: `doctest.DocTest`

### DocTest Objects

 *class *doctest.DocTest(*examples*, *globs*, *name*, *filename*, *lineno*, *docstring*)

A grouping of doctest examples meant to run within one shared namespace. The constructor's arguments serve to initialize the attributes that bear the same names.

`DocTest` defines the attributes below. The constructor initializes them, and they should not be altered directly.
