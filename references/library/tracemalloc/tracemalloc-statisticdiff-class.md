# tracemalloc: `tracemalloc.StatisticDiff`

### StatisticDiff

 *class *tracemalloc.StatisticDiff

A statistic difference about memory allocations measured between an earlier and a newer `Snapshot` instance.

`Snapshot.compare_to()` hands back a list of `StatisticDiff` instances. Refer also to the `Statistic` class.
