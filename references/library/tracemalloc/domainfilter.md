# tracemalloc: DomainFilter inclusion and address-space properties

inclusive

When *inclusive* is `True` (include), match the memory blocks allocated within the address space `domain`.

When *inclusive* is `False` (exclude), match the memory blocks that were not allocated within the address space `domain`.

 domain

Address space of a memory block (`int`). Read-only property.
