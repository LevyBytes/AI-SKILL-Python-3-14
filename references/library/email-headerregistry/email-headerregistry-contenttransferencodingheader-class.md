# email.headerregistry`email.headerregistry`: Custom Header Objects

*class *email.headerregistry.ContentTransferEncodingHeader

Takes care of the *Content-Transfer-Encoding* header.

 cte

The valid values are `7bit`, `8bit`, `base64`, and `quoted-printable`. Consult [**RFC 2045**](https://datatracker.ietf.org/doc/html/rfc2045.html) for further detail.
