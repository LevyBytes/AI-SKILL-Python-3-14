# Xdrlib

### `xdrlib` — Encode and decode XDR data

Deprecated since version 3.11, removed in version 3.13.

You will no longer find this module shipped with the Python standard library. Following its deprecation back in Python 3.11, it was [removed in Python 3.13](https://docs.python.org/3.14/whatsnew/3.13.html#whatsnew313-pep594). That decision traces back to [**PEP 594**](https://peps.python.org/pep-0594/).

If you need a release where `xdrlib` still ships, the final one to carry it was [Python 3.12](https://docs.python.org/3.12/library/xdrlib.html).
