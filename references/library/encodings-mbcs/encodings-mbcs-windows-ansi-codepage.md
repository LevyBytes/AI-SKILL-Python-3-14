# encodings.mbcs`encodings.mbcs` - Windows ANSI codepage

### `encodings.mbcs` - Windows ANSI codepage

What this module provides is the ANSI codepage (CP_ACP).

[Availability](https://docs.python.org/3.14/library/intro.html#availability): Windows.

Changed in version 3.2: In releases prior to 3.2 the *errors* argument went unheeded; encoding always relied on `'replace'` and decoding on `'ignore'`.

Changed in version 3.3: Every error handler is now supported.
