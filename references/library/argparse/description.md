# argparse — description

### description

The `description=` keyword argument shows up in the majority of `ArgumentParser` constructor calls. It supplies a short summary of what the program is for and how it operates. Inside help messages, that description sits between the command-line usage string and the per-argument help text.

The description is line-wrapped by default so it fits the available width. The formatter_class argument is what you reach for to alter that behavior.
