# sqlite3 — PrepareProtocol objects

### PrepareProtocol objects

 *class *sqlite3.PrepareProtocol

The PrepareProtocol type exists solely to serve as a [**PEP 246**](https://peps.python.org/pep-0246/) style adaption protocol for objects able to adapt themselves into native SQLite types.
