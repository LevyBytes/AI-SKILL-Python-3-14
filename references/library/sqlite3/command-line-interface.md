# sqlite3 - Command-line interface

### Command-line interface

You can run the `sqlite3` module as a script through the interpreter's [`-m`](https://docs.python.org/3.14/using/cmdline.html#cmdoption-m) switch to get a basic SQLite shell. Here is the argument signature:

```python
python -m sqlite3 [-h] [-v] [filename] [sql]

```

Enter `.quit` or press CTRL-D to leave the shell.

 -h, --help

Print CLI help.

 -v, --version

Print underlying SQLite library version.

Added in version 3.12.
