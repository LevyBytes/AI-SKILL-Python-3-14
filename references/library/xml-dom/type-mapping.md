# xml.dom - Type Mapping

### Type Mapping

The table below shows how the DOM specification's IDL types correspond to Python types.

| IDL Type | Python Type |
| --- | --- |
| `boolean` | `bool` or `int` |
| `int` | `int` |
| `long int` | `int` |
| `unsigned int` | `int` |
| `DOMString` | `str` or `bytes` |
| `null` | `None` |
