# xml.dom - Comment Objects

### Comment Objects

`Comment` stands for a comment within the XML document. It derives from `Node`, yet is barred from holding child nodes.

 Comment.data

The comment's content as a string. The attribute spans every character sitting between the opening `<!-``-` and closing `-``->`, but those markers themselves are excluded.
