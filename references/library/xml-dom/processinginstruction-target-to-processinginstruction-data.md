# xml.dom - ProcessingInstruction Objects

### ProcessingInstruction Objects

Stands for a processing instruction within the XML document; it builds on the `Node` interface and is barred from holding child nodes.

 ProcessingInstruction.target

The processing instruction's content running up to the first whitespace character. This is a read-only attribute.

 ProcessingInstruction.data

The processing instruction's content that trails the first whitespace character.
