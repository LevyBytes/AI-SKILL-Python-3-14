# tkinter.ttk - Tag Options

### Tag Options

The options below can be set on tags:

| Option | Description |
| --- | --- |
| foreground | Sets the text foreground color. |
| background | Sets the cell or item background color. |
| font | Sets which font is used when drawing text. |
| image | Sets the item image, for when the item's image option is empty. |
