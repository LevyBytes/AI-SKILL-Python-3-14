# tkinter.ttk / ttk.Combobox: `tkinter.ttk.Combobox`, `current()`

### ttk.Combobox

 *class *tkinter.ttk.Combobox

 current(*newindex=None*)

When *newindex* is given, this sets the combobox value to the element sitting at position *newindex*. Otherwise it returns the index of the present value, or -1 if that value isn't among the values list.
