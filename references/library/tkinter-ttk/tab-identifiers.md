# tkinter.ttk - Tab Identifiers

### Tab Identifiers

The tab_id that shows up across several `ttk.Notebook` methods can be written in any of these ways:

- An integer between zero and the number of tabs

- The name of a child window

- A positional specification of the form "@x,y", which identifies the tab

- The literal string "current", which identifies the currently selected tab

- The literal string "end", which yields the tab count (valid solely for `Notebook.index()`)
