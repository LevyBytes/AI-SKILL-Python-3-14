# tkinter.ttk — Item Options

### Item Options

The item options below can be set on items through the insert and item widget commands.

| Option | Description |
| --- | --- |
| text | The textual label shown for the item. |
| image | A Tk Image, shown to the left of the label. |
| values | The list of values tied to the item. Each item ought to carry as many values as the columns widget option. Should there be fewer values than columns, the leftover values are taken as empty. Should there be more values than columns, the surplus values are dropped. |
| open | `True`/`False` value telling whether the item's children show or stay hidden. |
| tags | A list of tags tied to this item. |
