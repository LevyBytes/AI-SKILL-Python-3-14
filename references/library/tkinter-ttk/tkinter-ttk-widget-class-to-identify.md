# tkinter.ttk / ttk.Widget: `tkinter.ttk.Widget`, `identify()`

### ttk.Widget

Apart from the methods covered below, `ttk.Widget` also supports the `tkinter.Widget.cget()` and `tkinter.Widget.configure()` methods.

 *class *tkinter.ttk.Widget

 identify(*x*, *y*)

Gives back the name of the element sitting at position *x* *y*, or an empty string when the point falls outside every element.

*x* and *y* are pixel coordinates relative to the widget.
