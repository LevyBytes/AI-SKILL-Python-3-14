# tkinter.ttk / ttk.Progressbar: `tkinter.ttk.Progressbar`, `start()`

### ttk.Progressbar

 *class *tkinter.ttk.Progressbar

 start(*interval=None*)

Enter autoincrement mode: this sets up a repeating timer event that fires `Progressbar.step()` once every *interval* milliseconds. When *interval* is omitted, it defaults to 50 milliseconds.
