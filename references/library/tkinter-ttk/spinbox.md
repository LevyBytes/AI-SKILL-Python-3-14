# tkinter.ttk - Spinbox

### Spinbox

The `ttk.Spinbox` widget is a `ttk.Entry` augmented with increment and decrement arrows. It works for numbers or for lists of string values. It is a subclass of `Entry`.

On top of the methods picked up from `Widget`: `Widget.cget()`, `Widget.configure()`, `Widget.identify()`, `Widget.instate()` and `Widget.state()`, plus these picked up from `Entry`: `Entry.bbox()`, `Entry.delete()`, `Entry.icursor()`, `Entry.index()`, `Entry.insert()`, `Entry.xview()`, it carries a few more methods, covered at `ttk.Spinbox`.
