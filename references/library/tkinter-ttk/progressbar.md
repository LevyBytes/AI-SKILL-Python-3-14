# tkinter.ttk - Progressbar

### Progressbar

The `ttk.Progressbar` widget reports on how a lengthy operation is coming along. Two modes are available: 1) determinate mode, which conveys how much has been finished out of the total work, and 2) indeterminate mode, which runs an animation so the user can tell that progress is happening.
