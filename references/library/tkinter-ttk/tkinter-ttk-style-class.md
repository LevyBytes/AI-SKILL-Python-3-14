# tkinter.ttk: `tkinter.ttk.Style`

### Ttk Styling

Every widget in `ttk` carries a style, which states the collection of elements that compose the widget and the way they are laid out, plus the dynamic and default settings for element options. The style name matches the widget's class name by default, yet the widget's style option can override it. When the class name of a widget is unknown to you, reach for the method `Misc.winfo_class()` (somewidget.winfo_class()).
