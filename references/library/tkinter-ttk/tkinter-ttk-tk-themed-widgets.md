### `tkinter.ttk` - Tk themed widgets

**Source code:** [Lib/tkinter/ttk.py](https://github.com/python/cpython/tree/3.14/Lib/tkinter/ttk.py)

---

Access to the Tk themed widget set, which arrived in Tk 8.5, is what the `tkinter.ttk` module gives you. Among the extras it brings are anti-aliased font rendering on X11 and window transparency (the latter needing a composition window manager on X11).

At its core, the goal of `tkinter.ttk` is to keep the code that drives a widget's behavior as distinct as it can be from the code that governs how the widget looks.
