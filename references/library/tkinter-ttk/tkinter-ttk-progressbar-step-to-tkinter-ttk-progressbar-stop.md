# tkinter.ttk / ttk.Progressbar: `step()`, `stop()`

step(*amount=None*)

Increments the progress bar's value by *amount*.

*amount* defaults to 1.0 if omitted.

 stop()

Leave autoincrement mode: this calls off any repeating timer event that `Progressbar.start()` set up for this progress bar.
