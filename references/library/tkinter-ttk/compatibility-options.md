# tkinter.ttk - Compatibility Options

### Compatibility Options

| Option | Description |
| --- | --- |
| state | Can be assigned "normal" or "disabled" to govern the "disabled" state bit. The option is write-only: assigning it alters the widget state, yet the `Widget.state()` method leaves this option unchanged. |
