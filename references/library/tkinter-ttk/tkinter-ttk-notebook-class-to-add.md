# tkinter.ttk / ttk.Notebook: `tkinter.ttk.Notebook`, `add()`

### ttk.Notebook

 *class *tkinter.ttk.Notebook

 add(*child*, ***kw*)

Adds a new tab to the notebook.

Should the window already be under the notebook's management yet hidden, it returns to the spot it held before.

See Tab Options for the list of available options.
