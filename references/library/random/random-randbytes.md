# random — Functions for bytes

### Functions for bytes

 random.randbytes(*n*)

Generate *n* random bytes.

Do not employ this method to create security tokens. Reach for [`secrets.token_bytes()`](https://docs.python.org/3.14/library/secrets.html#secrets.token_bytes) instead.

Added in version 3.9.
