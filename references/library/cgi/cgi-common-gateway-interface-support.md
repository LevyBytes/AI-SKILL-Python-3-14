### `cgi` - Common Gateway Interface support

Deprecated since version 3.11, removed in version 3.13.

This module no longer belongs to the Python standard library. It was [removed in Python 3.13](https://docs.python.org/3.14/whatsnew/3.13.html#whatsnew313-pep594) after a deprecation in Python 3.11. That removal was settled in [**PEP 594**](https://peps.python.org/pep-0594/).

You can instead rely on a fork of the module hosted on PyPI: [legacy-cgi](https://pypi.org/project/legacy-cgi/). This is a copy of the cgi module that the core Python team no longer maintains or supports.

The most recent Python release to ship the `cgi` module was [Python 3.12](https://docs.python.org/3.12/library/cgi.html).
