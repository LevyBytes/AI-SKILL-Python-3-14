# signal: `signal.SIGPIPE`, `signal.SIGPROF`, `signal.SIGQUIT`, `signal.SIGSEGV`, `signal.SIGSTOP`, `signal.SIGSTKFLT`, `signal.SIGTERM`, `signal.SIGUSR1`, `signal.SIGUSR2`, `signal.SIGVTALRM`, `signal.SIGWINCH`, `signal.SIGXCPU`

signal.SIGPIPE

Broken pipe: write to pipe with no readers.

Default action is to ignore the signal.

[Availability](https://docs.python.org/3.14/library/intro.html#availability): Unix.

 signal.SIGPROF

Profiling timer expired.

[Availability](https://docs.python.org/3.14/library/intro.html#availability): Unix.

 signal.SIGQUIT

Terminal quit signal.

[Availability](https://docs.python.org/3.14/library/intro.html#availability): Unix.

 signal.SIGSEGV

Segmentation fault: invalid memory reference.

 signal.SIGSTOP

Stop executing (cannot be caught or ignored).

[Availability](https://docs.python.org/3.14/library/intro.html#availability): Unix.

 signal.SIGSTKFLT

Stack fault on coprocessor. This signal is never generated by the Linux kernel itself; only user space can generate it.

[Availability](https://docs.python.org/3.14/library/intro.html#availability): Linux.

Only on architectures that provide the signal. Consult the man page *[signal(7)](https://manpages.debian.org/signal(7))* for additional detail.

Added in version 3.11.

 signal.SIGTERM

Termination signal.

 signal.SIGUSR1

User-defined signal 1.

[Availability](https://docs.python.org/3.14/library/intro.html#availability): Unix.

 signal.SIGUSR2

User-defined signal 2.

[Availability](https://docs.python.org/3.14/library/intro.html#availability): Unix.

 signal.SIGVTALRM

Virtual timer expired.

[Availability](https://docs.python.org/3.14/library/intro.html#availability): Unix.

 signal.SIGWINCH

Window resize signal.

[Availability](https://docs.python.org/3.14/library/intro.html#availability): Unix.

 signal.SIGXCPU

CPU time limit exceeded.

[Availability](https://docs.python.org/3.14/library/intro.html#availability): Unix.

 SIG*

Each signal number has a symbolic definition. The hangup signal, say, is given as `signal.SIGHUP`; these variable names match exactly the ones C programs use, the ones declared in `<signal.h>`. The Unix man page for ‘`signal`’ enumerates the signals that exist (on certain systems that page is *[signal(2)](https://manpages.debian.org/signal(2))*, while on others the listing appears in *[signal(7)](https://manpages.debian.org/signal(7))*). Keep in mind that systems differ in which signal names they provide; this module exposes only the names that the system itself defines.
