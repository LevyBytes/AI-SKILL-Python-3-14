# queue: `queue.SimpleQueue`

*class *queue.SimpleQueue

Constructor for an unbounded FIFO queue. Simple queues go without advanced functionality such as task tracking.

Simple queues are [generic](https://docs.python.org/3.14/library/typing.html#generics) over the type of their items.

Added in version 3.7.
