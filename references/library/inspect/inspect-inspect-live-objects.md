# inspect — `inspect` — Inspect live objects

### `inspect` — Inspect live objects

**Source code:** [Lib/inspect.py](https://github.com/python/cpython/tree/3.14/Lib/inspect.py)

---

A handful of handy functions live in the `inspect` module for pulling details out of live objects: modules, classes, methods, functions, tracebacks, frame objects, and code objects, among others. You might use it to walk through what a class holds, fetch a method's source text, pull out and format a function's argument list, or assemble everything required to render a thorough traceback.

This module breaks down into four broad categories of service: checking types, fetching source code, examining classes and functions, and looking into the interpreter stack.
