# inspect - Command-line interface

### Command-line interface

A modest amount of introspection is available straight from the command line through the `inspect` module as well.

Out of the box, it takes a module name and writes out that module’s source. To print a particular class or function from the module instead, tack on a colon followed by the qualified name of the object you want.

 --details

Emit details about the named object in place of its source code
