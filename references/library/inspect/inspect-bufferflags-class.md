# inspect: `inspect.BufferFlags`

### Buffer flags

 *class *inspect.BufferFlags

This is an [`enum.IntFlag`](https://docs.python.org/3.14/library/enum.html#enum.IntFlag) standing for the flags you may hand to the [`__buffer__()`](https://docs.python.org/3.14/reference/datamodel.html#object.__buffer__) method on objects that implement the [buffer protocol](https://docs.python.org/3.14/c-api/buffer.html#bufferobjects).

What each flag signifies is spelled out under [Buffer request types](https://docs.python.org/3.14/c-api/buffer.html#buffer-request-types).
