## msilib — Read and write Microsoft Installer files

### `msilib` — Read and write Microsoft Installer files

Deprecated since version 3.11, removed in version 3.13.

The Python standard library no longer includes this module. Having been deprecated in Python 3.11, it was [removed in Python 3.13](https://docs.python.org/3.14/whatsnew/3.13.html#whatsnew313-pep594). That removal was settled in [**PEP 594**](https://peps.python.org/pep-0594/).

[Python 3.12](https://docs.python.org/3.12/library/msilib.html) was the final Python release to ship the `msilib` module.
