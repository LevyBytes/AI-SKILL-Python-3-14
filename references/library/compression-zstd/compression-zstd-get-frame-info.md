# Miscellaneous: `compression.zstd.get_frame_info()`

### Miscellaneous

 compression.zstd.get_frame_info(*frame_buffer*)

Fetch a `FrameInfo` object that carries metadata describing a Zstandard frame. Each frame holds metadata tied to the compressed data living inside it.
