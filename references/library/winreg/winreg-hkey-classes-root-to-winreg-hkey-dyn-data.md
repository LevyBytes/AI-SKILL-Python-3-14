# HKEY_* Constants

### HKEY_* Constants

 winreg.HKEY_CLASSES_ROOT

Registry entries that fall under this key spell out kinds (or classes) of documents along with the properties tied to those kinds. The data held beneath this key is consumed by Shell and COM applications.

 winreg.HKEY_CURRENT_USER

Registry entries that fall under this key spell out the preferences of the user currently signed in. Among these preferences are environment variable settings, details about program groups, colors, printers, network connections, and application preferences.

 winreg.HKEY_LOCAL_MACHINE

Registry entries that fall under this key spell out the computer's physical state, covering details about the bus type, system memory, and the hardware and software that are installed.

 winreg.HKEY_USERS

Registry entries that fall under this key spell out the default user configuration for fresh users on the local computer plus the user configuration for the user currently signed in.

 winreg.HKEY_PERFORMANCE_DATA

Registry entries that fall under this key give you a way to reach performance data. That data isn't truly kept in the registry; the registry functions prompt the system to gather it from where it originates.

 winreg.HKEY_CURRENT_CONFIG

Contains information about the current hardware profile of the local computer system.

 winreg.HKEY_DYN_DATA

This key is not used in versions of Windows after 98.
