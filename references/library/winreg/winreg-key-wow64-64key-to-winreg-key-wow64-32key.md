# 64-bit Specific

#### 64-bit Specific

For more information, see [Accessing an Alternate Registry View](https://msdn.microsoft.com/en-us/library/aa384129(v=VS.85).aspx).

 winreg.KEY_WOW64_64KEY

Signals that a program running under 64-bit Windows ought to work against the 64-bit registry view. Under 32-bit Windows the constant has no effect.

 winreg.KEY_WOW64_32KEY

Signals that a program running under 64-bit Windows ought to work against the 32-bit registry view. Under 32-bit Windows the constant has no effect.
