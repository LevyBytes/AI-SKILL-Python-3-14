# tkinter — Packer Options

### Packer Options

For a fuller treatment of the packer and the options it accepts, turn to the man pages and to page 183 of John Ousterhout’s book.

anchor

An anchor type. Says where within its parcel the packer should set each content.

expand

Boolean, `0` or `1`.

fill

Legal values: `'x'`, `'y'`, `'both'`, `'none'`.

ipadx and ipady

A distance value - it sets the internal padding along each side of the content.

padx and pady

A distance value - it sets the external padding along each side of the content.

side

Legal values are: `'left'`, `'right'`, `'top'`, `'bottom'`.
