# base64: `base64.z85decode()`

base64.z85decode(*s*)

Take the Z85-encoded [bytes-like object](https://docs.python.org/3.14/glossary.html#term-bytes-like-object) or ASCII string *s*, decode it, and give back the resulting [`bytes`](https://docs.python.org/3.14/library/stdtypes.html#bytes).

Added in version 3.13.
