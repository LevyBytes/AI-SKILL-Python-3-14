### `ossaudiodev` - Access to OSS-compatible audio devices

Deprecated since version 3.11, removed in version 3.13.

The Python standard library no longer carries this module. Following its deprecation in Python 3.11, it was [removed in Python 3.13](https://docs.python.org/3.14/whatsnew/3.13.html#whatsnew313-pep594). That removal was settled in [**PEP 594**](https://peps.python.org/pep-0594/).

The `ossaudiodev` module was last shipped with [Python 3.12](https://docs.python.org/3.12/library/ossaudiodev.html), the final Python version to include it.
