# plistlib: `plistlib.FMT_XML`, `plistlib.FMT_BINARY`, `plistlib.InvalidFileException`

plistlib.FMT_XML

Denotes the XML format that plist files use.

Added in version 3.4.

 plistlib.FMT_BINARY

Denotes the binary format that plist files use

Added in version 3.4.

The exceptions this module defines are these:

 *exception *plistlib.InvalidFileException

Thrown whenever a file proves impossible to parse.

Added in version 3.4.
