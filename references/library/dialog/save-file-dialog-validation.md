# tkinter.filedialog / Native Load/Save Dialogs: `tkinter.filedialog.SaveFileDialog`, `ok_command()`

*class *tkinter.filedialog.SaveFileDialog(*master*, *title=None*)

A FileDialog subclass whose dialog window is for picking a destination file.

 ok_command()

Determines whether the pick lands on a valid file rather than a directory. When a file that already exists is picked, confirmation is asked for.
