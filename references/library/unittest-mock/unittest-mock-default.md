# unittest.mock — DEFAULT

### DEFAULT

 unittest.mock.DEFAULT

`DEFAULT` is a sentinel that already exists (under the hood it is `sentinel.DEFAULT`). A `side_effect` callable can return it to signal that the usual return value ought to apply.
