# gzip - Command-line interface

### Command-line interface

The `gzip` module ships with a straightforward command line interface for compressing or decompressing files.

After it runs, the `gzip` module retains the input file(s).

Changed in version 3.8: Introduces a fresh command line interface complete with usage text. Out of the box, running the CLI applies a default compression level of 6.
