# gzip - Command-line options

### Command-line options

 file

When *file* is left out, input is taken from [`sys.stdin`](https://docs.python.org/3.14/library/sys.html#sys.stdin).

 --fast

Selects the quickest compression approach (weaker compression).

 --best

Selects the slowest compression approach (strongest compression).

 -d, --decompress

Decompress the supplied file.

 -h, --help

Display the help text.
