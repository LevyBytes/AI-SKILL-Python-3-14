# urllib.request: `urllib.request.HTTPSHandler`

*class *urllib.request.HTTPSHandler(*debuglevel=0*, *context=None*, *check_hostname=None*)

A class for opening HTTPS URLs. *context* and *check_hostname* carry the same meaning as in [`http.client.HTTPSConnection`](https://docs.python.org/3.14/library/http.client.html#http.client.HTTPSConnection).

Changed in version 3.2: *context* and *check_hostname* were added.
