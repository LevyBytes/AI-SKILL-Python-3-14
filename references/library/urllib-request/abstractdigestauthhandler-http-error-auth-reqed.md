# urllib.request - AbstractDigestAuthHandler Objects

### AbstractDigestAuthHandler Objects

 AbstractDigestAuthHandler.http_error_auth_reqed(*authreq*, *host*, *req*, *headers*)

*authreq* ought to name the header that carries the realm information within the request, *host* ought to be the host being authenticated to, *req* ought to be the (failed) `Request` object, and *headers* ought to be the error headers.
