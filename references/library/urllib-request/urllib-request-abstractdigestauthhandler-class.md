# urllib.request: `urllib.request.AbstractDigestAuthHandler`

*class *urllib.request.AbstractDigestAuthHandler(*password_mgr=None*)

A mixin class that assists with HTTP authentication, toward both the remote host and a proxy. *password_mgr*, when supplied, should be something compatible with `HTTPPasswordMgr`; see section HTTPPasswordMgr Objects for the interface that must be supported.

Changed in version 3.14: Added support for HTTP digest authentication algorithm `SHA-256`.
