# urllib.request: `urllib.request.HTTPBasicAuthHandler`

*class *urllib.request.HTTPBasicAuthHandler(*password_mgr=None*)

Manage authentication toward the remote host. *password_mgr*, when supplied, should be something compatible with `HTTPPasswordMgr`; see section HTTPPasswordMgr Objects for the interface that must be supported. HTTPBasicAuthHandler will raise a [`ValueError`](https://docs.python.org/3.14/library/exceptions.html#ValueError) when handed a wrong Authentication scheme.
