# urllib.request - HTTPCookieProcessor Objects

### HTTPCookieProcessor Objects

`HTTPCookieProcessor` instances have one attribute:

 HTTPCookieProcessor.cookiejar

The [`http.cookiejar.CookieJar`](https://docs.python.org/3.14/library/http.cookiejar.html#http.cookiejar.CookieJar) in which cookies are stored.
