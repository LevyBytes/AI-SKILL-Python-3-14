# urllib.request: `urllib.request.HTTPPasswordMgrWithDefaultRealm`

*class *urllib.request.HTTPPasswordMgrWithDefaultRealm

Maintain a database of `(realm, uri) -> (user, password)` mappings. A realm of `None` acts as a catch-all realm, consulted when no other realm matches.
