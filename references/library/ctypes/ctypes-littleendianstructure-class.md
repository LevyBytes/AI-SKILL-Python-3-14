# ctypes: `ctypes.LittleEndianStructure`

*class *ctypes.LittleEndianStructure(**args*, ***kw*)

Abstract base class for structures in *little endian* byte order.

Structures and unions whose byte order is non-native may not hold pointer type fields, nor any other data types that contain pointer type fields.
