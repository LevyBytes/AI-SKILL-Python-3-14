# ctypes: `ctypes.c_ssize_t`

*class *ctypes.c_ssize_t

Stands for the [`Py_ssize_t`](https://docs.python.org/3.14/c-api/intro.html#c.Py_ssize_t) datatype. This is the signed counterpart of `size_t`; namely, the POSIX `ssize_t` type. Usually an alias for some other integer type.

Added in version 3.2.
