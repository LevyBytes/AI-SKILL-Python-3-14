# ctypes: `ctypes.c_ulonglong`

*class *ctypes.c_ulonglong

Stands for the C unsigned long long datatype. The constructor takes an optional integer initializer; no overflow checking happens. On platforms where `sizeof(long long) == sizeof(long)` it is an alias to `c_long`.
