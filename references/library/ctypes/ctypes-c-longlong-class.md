# ctypes: `ctypes.c_longlong`

*class *ctypes.c_longlong

Stands for the C signed long long datatype. The constructor takes an optional integer initializer; no overflow checking happens. On platforms where `sizeof(long long) == sizeof(long)` it is an alias to `c_long`.
