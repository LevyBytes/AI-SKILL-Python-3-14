# ctypes: `ctypes.c_char_p`

*class *ctypes.c_char_p

Stands for the C char* datatype when it refers to a zero-terminated string. When you need a general character pointer that might also refer to binary data, use `POINTER(c_char)` instead. The constructor takes an integer address or a bytes object.
