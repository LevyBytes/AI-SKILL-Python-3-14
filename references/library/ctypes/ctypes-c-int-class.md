# ctypes: `ctypes.c_int`

*class *ctypes.c_int

Stands for the C signed int datatype. The constructor takes an optional integer initializer; no overflow checking happens. On platforms where `sizeof(int) == sizeof(long)` it is an alias to `c_long`.
