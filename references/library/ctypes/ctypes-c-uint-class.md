# ctypes: `ctypes.c_uint`

*class *ctypes.c_uint

Stands for the C unsigned int datatype. The constructor takes an optional integer initializer; no overflow checking happens. On platforms where `sizeof(int) == sizeof(long)` it is an alias for `c_ulong`.
