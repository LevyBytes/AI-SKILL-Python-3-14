# ctypes - ctypes tutorial

### ctypes tutorial

Note: Several of the code examples make use of the ctypes `c_int` type. On any platform where `sizeof(long) == sizeof(int)` holds, it serves as an alias for `c_long`. For that reason, do not be surprised to see `c_long` printed where you might have anticipated `c_int` — the two are, in fact, identical.
