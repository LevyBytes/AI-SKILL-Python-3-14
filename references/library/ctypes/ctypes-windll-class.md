# ctypes: `ctypes.WinDLL`

*class *ctypes.WinDLL

Refer to the superclass `CDLL` for shared details.

The functions in these libraries follow the `stdcall` calling convention and, by default, are expected to return int.

[Availability](https://docs.python.org/3.14/library/intro.html#availability): Windows
