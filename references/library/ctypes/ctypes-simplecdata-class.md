# ctypes: `ctypes._SimpleCData`

### Fundamental data types

 *class *ctypes._SimpleCData

This non-public class is the parent of every fundamental ctypes data type. It appears here because it carries the shared attributes of the fundamental ctypes data types. `_SimpleCData` derives from `_CData`, and therefore inherits its methods and attributes. ctypes data types that neither are nor hold pointers can now be pickled.
