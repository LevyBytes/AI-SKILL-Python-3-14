# socket: `socket.SocketType`

*class *socket.SocketType

The base class behind the `socket` type, re-exported out of `_socket`. An instance test like `isinstance(socket(...), SocketType)` comes out true, yet `SocketType` differs from `type(socket(...))`, which is `socket` itself.
