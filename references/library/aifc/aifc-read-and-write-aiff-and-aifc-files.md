## aifc — Read and write AIFF and AIFC files

### `aifc` — Read and write AIFF and AIFC files

Deprecated since version 3.11, removed in version 3.13.

This module has dropped out of the Python standard library. Having been deprecated back in Python 3.11, it was [removed in Python 3.13](https://docs.python.org/3.14/whatsnew/3.13.html#whatsnew313-pep594). That removal was settled in [**PEP 594**](https://peps.python.org/pep-0594/).

The final Python release to ship the `aifc` module was [Python 3.12](https://docs.python.org/3.12/library/aifc.html).
