# Sndhdr

### `sndhdr` — Determine type of sound file

Marked deprecated as of version 3.11; dropped entirely in version 3.13.

You will no longer find this module shipped with the Python standard library. Having first been deprecated in Python 3.11, it was [removed in Python 3.13](https://docs.python.org/3.14/whatsnew/3.13.html#whatsnew313-pep594). That decision to drop it was set out in [**PEP 594**](https://peps.python.org/pep-0594/).

If you need a substitute, several outside packages on PyPI fit the bill: [filetype](https://pypi.org/project/filetype/), [puremagic](https://pypi.org/project/puremagic/), or [python-magic](https://pypi.org/project/python-magic/). Bear in mind the Python core team neither backs nor looks after any of them.

[Python 3.12](https://docs.python.org/3.12/library/sndhdr.html) was the final release where the `sndhdr` module could still be found.
