# collections.abc: `collections.abc.Buffer`

*class *collections.abc.Buffer

ABC for classes that provide the [`__buffer__()`](https://docs.python.org/3.14/reference/datamodel.html#object.__buffer__) method, implementing the [buffer protocol](https://docs.python.org/3.14/c-api/buffer.html#bufferobjects). See [**PEP 688**](https://peps.python.org/pep-0688/).

Added in version 3.12.
