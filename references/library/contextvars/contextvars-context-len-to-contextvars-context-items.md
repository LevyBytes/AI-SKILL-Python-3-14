# contextvars.Context: `len()`, `keys()`, `values()`, `items()`

len(proxy)

Report how many variables are set within the context object.

 keys()

Produce a list naming every variable in the context object.

 values()

Produce a list holding the value of each variable in the context object.

 items()

Produce a list of 2-tuples that pair each variable with its value from the context object.
