# Spwd

### `spwd` — The shadow password database

Deprecated since version 3.11, removed in version 3.13.

The standard library no longer bundles this module. Having first been deprecated in Python 3.11, it was later [removed in Python 3.13](https://docs.python.org/3.14/whatsnew/3.13.html#whatsnew313-pep594), a change that stems from [**PEP 594**](https://peps.python.org/pep-0594/).

For a substitute, you might turn to the external package [python-pam](https://pypi.org/project/python-pam/). Note that the Python core developers neither support nor maintain it.

The most recent release to include the `spwd` module was [Python 3.12](https://docs.python.org/3.12/library/spwd.html).
