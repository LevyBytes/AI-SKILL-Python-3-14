# difflib: `difflib.ndiff()`, `difflib.restore()`, `difflib.unified_diff()`

difflib.ndiff(*a*, *b*, *linejunk=None*, *charjunk=IS_CHARACTER_JUNK*)

Contrast *a* and *b* (lists of strings); hand back a `Differ`-style delta (a [generator](https://docs.python.org/3.14/glossary.html#term-generator) generating the delta lines).

The optional keyword parameters *linejunk* and *charjunk* are filtering functions (or `None`):

*linejunk*: A function taking one string argument that returns true when the string is junk, or false otherwise. Its default is `None`. There is also a module-level function `IS_LINE_JUNK()` that drops lines with no visible characters apart from at most a single hash character (`'#'`) — yet the underlying `SequenceMatcher` class performs a dynamic study of which lines recur so often that they amount to noise, and that approach generally outperforms this function.

*charjunk*: A function taking a character (a string of length 1) that returns whether the character is junk, or false otherwise. Its default is the module-level function `IS_CHARACTER_JUNK()`, which drops whitespace characters (a blank or tab; including newline here is a bad idea!).

```python
>>> diff = ndiff('one\ntwo\nthree\n'.splitlines(keepends=True),
...              'ore\ntree\nemu\n'.splitlines(keepends=True))
>>> print(''.join(diff), end="")
- one
?  ^
+ ore
?  ^
- two
- three
?  -
+ tree
+ emu

```

 difflib.restore(*sequence*, *which*)

Hand back one of the two sequences that gave rise to a delta.

From a *sequence* generated by `Differ.compare()` or `ndiff()`, pull out the lines that came from file 1 or 2 (per the *which* parameter), trimming the line prefixes away.

Example:

```python
>>> diff = ndiff('one\ntwo\nthree\n'.splitlines(keepends=True),
...              'ore\ntree\nemu\n'.splitlines(keepends=True))
>>> diff = list(diff) # materialize the generated delta into a list
>>> print(''.join(restore(diff, 1)), end="")
one
two
three
>>> print(''.join(restore(diff, 2)), end="")
ore
tree
emu

```

 difflib.unified_diff(*a*, *b*, *fromfile=''*, *tofile=''*, *fromfiledate=''*, *tofiledate=''*, *n=3*, *lineterm='\n'*)

Contrast *a* and *b* (lists of strings); hand back a delta (a [generator](https://docs.python.org/3.14/glossary.html#term-generator) generating the delta lines) rendered as a unified diff.

A unified diff is a terse way to display only the lines that differ together with a handful of surrounding lines. The edits appear inline (rather than in separate before/after blocks). How many context lines accompany them is governed by *n*, whose default is three.

By default the diff control lines (the ones carrying `---`, `+++`, or `@@`) end with a trailing newline. That is convenient because inputs built from [`io.IOBase.readlines()`](https://docs.python.org/3.14/library/io.html#io.IOBase.readlines) then yield diffs fit for passing to [`io.IOBase.writelines()`](https://docs.python.org/3.14/library/io.html#io.IOBase.writelines), since both inputs and outputs carry trailing newlines.

When your inputs lack trailing newlines, give the *lineterm* argument the value `""` so that the result comes out entirely free of newlines.

A unified diff usually carries a header listing filenames and modification times. You may supply any or all of them through strings for *fromfile*, *tofile*, *fromfiledate*, and *tofiledate*. The modification times are usually written in the ISO 8601 format. Left unset, these strings default to blanks.

```python
>>> s1 = ['bacon\n', 'eggs\n', 'ham\n', 'guido\n']
>>> s2 = ['python\n', 'eggy\n', 'hamster\n', 'guido\n']
>>> sys.stdout.writelines(unified_diff(s1, s2, fromfile='before.py', tofile='after.py'))
--- before.py
+++ after.py
@@ -1,4 +1,4 @@
-bacon
-eggs
-ham
+python
+eggy
+hamster
 guido

```
