# errno — `errno` — Standard errno system symbols

errno.EADDRNOTAVAIL

Cannot assign requested address

 errno.ENETDOWN

Network is down

 errno.ENETUNREACH

Network is unreachable

 errno.ENETRESET

Network dropped the connection due to a reset

 errno.ECONNABORTED

Software caused the connection to abort. The exception this maps to is [`ConnectionAbortedError`](https://docs.python.org/3.14/library/exceptions.html#ConnectionAbortedError).

 errno.ECONNRESET

Connection reset by peer. The exception this maps to is [`ConnectionResetError`](https://docs.python.org/3.14/library/exceptions.html#ConnectionResetError).

 errno.ENOBUFS

No buffer space available

 errno.EISCONN

Transport endpoint is already connected

 errno.ENOTCONN

Transport endpoint is not connected

 errno.ESHUTDOWN

Cannot send once the transport endpoint has shut down. The exception this maps to is [`BrokenPipeError`](https://docs.python.org/3.14/library/exceptions.html#BrokenPipeError).

 errno.ETOOMANYREFS

Too many references: cannot splice

 errno.ETIMEDOUT

Connection timed out. The exception this maps to is [`TimeoutError`](https://docs.python.org/3.14/library/exceptions.html#TimeoutError).

 errno.ECONNREFUSED

Connection refused. The exception this maps to is [`ConnectionRefusedError`](https://docs.python.org/3.14/library/exceptions.html#ConnectionRefusedError).

 errno.EHOSTDOWN

Host is down

 errno.EHOSTUNREACH

No route to host

 errno.EHWPOISON

Memory page has hardware error.

Added in version 3.14.

 errno.EALREADY

Operation already in progress. The exception this maps to is [`BlockingIOError`](https://docs.python.org/3.14/library/exceptions.html#BlockingIOError).

 errno.EINPROGRESS

Operation now in progress. The exception this maps to is [`BlockingIOError`](https://docs.python.org/3.14/library/exceptions.html#BlockingIOError).

 errno.ESTALE

Stale NFS file handle

 errno.EUCLEAN

Structure needs cleaning
