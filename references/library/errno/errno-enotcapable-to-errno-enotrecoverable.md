# errno — `errno` — Standard errno system symbols

errno.ENOTCAPABLE

Capabilities insufficient. The exception this maps to is [`PermissionError`](https://docs.python.org/3.14/library/exceptions.html#PermissionError).

[Availability](https://docs.python.org/3.14/library/intro.html#availability): WASI, FreeBSD

Added in version 3.11.1.

 errno.ECANCELED

Operation canceled

Added in version 3.2.

 errno.EOWNERDEAD

Owner died

Added in version 3.2.

 errno.ENOTRECOVERABLE

State not recoverable

Added in version 3.2.
