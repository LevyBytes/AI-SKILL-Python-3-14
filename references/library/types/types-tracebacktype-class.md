# types: `types.TracebackType`

*class *types.TracebackType(*tb_next*, *tb_frame*, *tb_lasti*, *tb_lineno*)

The type of traceback objects, like the one found at `sys.exception().__traceback__`.

Consult [the language reference](https://docs.python.org/3.14/reference/datamodel.html#traceback-objects) for the details of the attributes and operations on offer, plus guidance on building tracebacks dynamically.
