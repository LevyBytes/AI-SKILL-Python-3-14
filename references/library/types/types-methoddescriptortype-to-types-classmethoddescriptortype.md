# types: `types.MethodDescriptorType`, `types.ClassMethodDescriptorType`

types.MethodDescriptorType

The type of methods belonging to certain built-in data types, [`str.join()`](https://docs.python.org/3.14/library/stdtypes.html#str.join) for instance.

Added in version 3.7.

 types.ClassMethodDescriptorType

The type of the *unbound* class methods of certain built-in data types, `dict.__dict__['fromkeys']` for instance.

Added in version 3.7.
