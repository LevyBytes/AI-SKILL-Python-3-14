# Types

### `types` — Dynamic type creation and names for built-in types

**Source code:** [Lib/types.py](https://github.com/python/cpython/tree/3.14/Lib/types.py)

---

This module supplies utility functions that help with creating new types dynamically.

On top of that, it supplies names for certain object types that the standard Python interpreter relies on yet does not surface as builtins the way [`int`](https://docs.python.org/3.14/library/functions.html#int) or [`str`](https://docs.python.org/3.14/library/stdtypes.html#str) are.

Lastly, it offers a few more type-related utility classes and functions that are not central enough to warrant being builtins.
