# collections — `UserDict` objects

### `UserDict` objects

The `UserDict` class serves as a wrapper sitting around dictionary objects. Direct subclassing of [`dict`](https://docs.python.org/3.14/library/stdtypes.html#dict) has taken over much of what this class was for; even so, this class can be more convenient to use because the wrapped dictionary is reachable as an attribute.
