### Runners

**Source code:** [Lib/asyncio/runners.py](https://github.com/python/cpython/tree/3.14/Lib/asyncio/runners.py)

What this section covers is the high-level asyncio primitives used to run asyncio code.

They rest on an [event loop](https://docs.python.org/3.14/library/asyncio-eventloop.html#asyncio-event-loop) and exist to make working with async code easier across the common, widespread cases.
