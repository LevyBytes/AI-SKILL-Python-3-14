# weakref: `weakref.ProxyTypes`

weakref.ProxyTypes

A sequence holding all the proxy type objects. It can ease checking whether an object is a proxy without your having to spell out both proxy types by name.

See also

[**PEP 205**](https://peps.python.org/pep-0205/) - Weak References

The proposal behind this feature and the reasoning for it, with links out to earlier implementations and notes on comparable features found in other languages.
