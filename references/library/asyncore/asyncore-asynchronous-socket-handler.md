## asyncore — Asynchronous socket handler

### `asyncore` — Asynchronous socket handler

Deprecated since version 3.6, removed in version 3.12.

The Python standard library no longer includes this module. Having been deprecated back in Python 3.6, it was [removed in Python 3.12](https://docs.python.org/3.14/whatsnew/3.12.html#whatsnew312-removed). That removal was settled in [**PEP 594**](https://peps.python.org/pep-0594/).

For their needs, applications ought to switch to the [`asyncio`](https://docs.python.org/3.14/library/asyncio.html#module-asyncio) module.

[Python 3.11](https://docs.python.org/3.11/library/asyncore.html) was the final Python release to ship the `asyncore` module.
