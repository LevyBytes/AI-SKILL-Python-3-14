## Python Development Mode

### Python Development Mode

Added in version 3.7.

The Python Development Mode layers on extra runtime checks whose cost is too high to keep switched on by default. When your code is sound, it stays no chattier than the default; fresh warnings surface only where a problem turns up.

You turn it on either through the [`-X dev`](https://docs.python.org/3.14/using/cmdline.html#cmdoption-X) command line option or by giving the [`PYTHONDEVMODE`](https://docs.python.org/3.14/using/cmdline.html#envvar-PYTHONDEVMODE) environment variable a value of `1`.

Refer as well to [Python debug build](https://docs.python.org/3.14/using/configure.html#debug-build).
