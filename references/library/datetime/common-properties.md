# datetime — Common properties

### Common properties

These traits are shared across the `date`, `datetime`, `time`, and `timezone` types:

- Objects of these types are immutable.

- Objects of these types are [hashable](https://docs.python.org/3.14/glossary.html#term-hashable), which is to say they work as keys within a dictionary.

- Objects of these types support efficient pickling via the [`pickle`](https://docs.python.org/3.14/library/pickle.html#module-pickle) module.
