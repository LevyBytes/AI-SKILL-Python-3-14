# logging.handlers: `logging.NullHandler`

### NullHandler

Added in version 3.1.

Found in the core [`logging`](https://docs.python.org/3.14/library/logging.html#module-logging) package, the `NullHandler` class performs neither formatting nor output. In essence it's a 'no-op' handler meant for library developers to use.

 *class *logging.NullHandler

Hands back a fresh instance of the `NullHandler` class.
