# optparse — Other actions

### Other actions

A few other actions `optparse` supports are:

`"store_const"`

store a constant value, pre-set via `Option.const`

`"append"`

append this option's argument to a list

`"count"`

increment a counter by one

`"callback"`

call a specified function

These are taken up in section Reference Guide, and section Option Callbacks.
