# optparse: `OptionParser.get_option_group()`

OptionParser.get_option_group(*opt_str*)

Give back the `OptionGroup` that owns the short or long option string *opt_str* (for instance `'-o'` or `'--option'`). When no `OptionGroup` matches, hand back `None`.
