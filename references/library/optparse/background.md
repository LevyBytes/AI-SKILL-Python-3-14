# optparse - Background

### Background

`optparse` was deliberately built to nudge people toward writing programs whose command-line interfaces are simple and stick to the conventions laid down by the `getopt()` family of functions that C developers have. With that goal, it backs only the most common command-line syntax and semantics conventionally seen under Unix. If these conventions are new to you, reading this section will help you get acquainted with them.
