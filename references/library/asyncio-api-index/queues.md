# asyncio — Queues

### Queues

Reach for Queues when you need to spread work across several asyncio Tasks, build connection pools, or set up pub/sub patterns.

| `Queue` | A FIFO queue. |
| --- | --- |
| `PriorityQueue` | A priority queue. |
| `LifoQueue` | A LIFO queue. |

Examples
