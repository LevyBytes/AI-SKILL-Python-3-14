# asyncio — Subprocesses

### Subprocesses

Helpers for launching subprocesses and executing shell commands.

| `await` `create_subprocess_exec()` | Create a subprocess. |
| --- | --- |
| `await` `create_subprocess_shell()` | Run a shell command. |

Examples

- [Executing a shell command](https://docs.python.org/3.14/library/asyncio-subprocess.html#asyncio-example-subprocess-shell).

- See also the [subprocess APIs](https://docs.python.org/3.14/library/asyncio-subprocess.html#asyncio-subprocess) documentation.
