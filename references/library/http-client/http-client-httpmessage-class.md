# http.client — HTTPMessage Objects

### HTTPMessage Objects

 *class *http.client.HTTPMessage(*email.message.Message*)

An `http.client.HTTPMessage` instance carries the headers belonging to an HTTP response. Its implementation builds on the [`email.message.Message`](https://docs.python.org/3.14/library/email.compat32-message.html#email.message.Message) class.
