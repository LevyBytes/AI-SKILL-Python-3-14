# http.client: `http.client.responses`

http.client.responses

The HTTP 1.1 status codes are mapped to their W3C names by this dictionary.

Example: `http.client.responses[http.client.NOT_FOUND]` is `'Not Found'`.

For the roster of HTTP status codes offered as constants by this module, see [HTTP status codes](https://docs.python.org/3.14/library/http.html#http-status-codes).
