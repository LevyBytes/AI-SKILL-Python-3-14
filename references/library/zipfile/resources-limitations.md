# zipfile — Resources limitations

### Resources limitations

A shortage of memory or disk volume will bring on decompression failure. Decompression bombs (also known as [ZIP bomb](https://en.wikipedia.org/wiki/Zip_bomb)), for one, target the zipfile library and can drive disk volume to exhaustion.
