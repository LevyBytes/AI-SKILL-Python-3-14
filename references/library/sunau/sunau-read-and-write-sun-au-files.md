# sunau — `sunau` — Read and write Sun AU files

### `sunau` — Read and write Sun AU files

Deprecated since version 3.11, removed in version 3.13.

You will not find this module in the Python standard library anymore. Following its deprecation in Python 3.11, it was [removed in Python 3.13](https://docs.python.org/3.14/whatsnew/3.13.html#whatsnew313-pep594), a removal settled on in [**PEP 594**](https://peps.python.org/pep-0594/).

The final release to still ship the `sunau` module was [Python 3.12](https://docs.python.org/3.12/library/sunau.html).
