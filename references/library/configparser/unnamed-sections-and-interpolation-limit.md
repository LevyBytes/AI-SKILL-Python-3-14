# configparser: `configparser.UNNAMED_SECTION`, `configparser.MAX_INTERPOLATION_DEPTH`

configparser.UNNAMED_SECTION

A special object that stands for a section name used to refer to the unnamed section (see Unnamed Sections).

 configparser.MAX_INTERPOLATION_DEPTH

The ceiling on recursive interpolation depth for `get()` when the *raw* parameter is false. This applies only when the default *interpolation* is in use.
