# Operators

### Operators

A few operators work on address objects. Except where noted, an operator applies only between compatible objects (that is, IPv4 with IPv4, IPv6 with IPv6).

### Operators

A handful of operators work on network objects. Barring any note to the contrary, an operator may join only compatible objects (that is, IPv4 with IPv4, IPv6 with IPv6).

### Operators

A handful of operators work on interface objects. Barring any note to the contrary, an operator may join only compatible objects (that is, IPv4 with IPv4, IPv6 with IPv6).
