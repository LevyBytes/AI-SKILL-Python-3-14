# `ipaddress` ? IPv4/IPv6 manipulation library

### `ipaddress` — IPv4/IPv6 manipulation library

**Source code:** [Lib/ipaddress.py](https://github.com/python/cpython/tree/3.14/Lib/ipaddress.py)

---

`ipaddress` supplies the tools needed to build, alter, and work with IPv4 and IPv6 addresses along with networks.

With the classes and functions this module exposes, a wide range of IP-address chores become easy: testing whether two hosts share a subnet, walking through every host inside a given subnet, confirming that some string is a legitimate IP address or network definition, and more.

What follows is the complete module API reference — if you instead want a tutorial-style overview, consult [An introduction to the ipaddress module](https://docs.python.org/3.14/howto/ipaddress.html#ipaddress-howto).

Added in version 3.3.
