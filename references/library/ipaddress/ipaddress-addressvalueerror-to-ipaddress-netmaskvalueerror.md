# Custom Exceptions

### Custom Exceptions

So that class constructors can report errors with greater precision, the module declares these exceptions:

 *exception *ipaddress.AddressValueError(*ValueError*)

Covers any value error tied to the address.

 *exception *ipaddress.NetmaskValueError(*ValueError*)

Covers any value error tied to the net mask.
