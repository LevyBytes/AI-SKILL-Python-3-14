# csv: `csv.unix_dialect`

*class *csv.unix_dialect

Typical traits of a CSV file produced on UNIX systems, namely `'\n'` for the line terminator and quotes around every field, are captured by the `unix_dialect` class, which is registered under the dialect name `'unix'`.

Added in version 3.2.
