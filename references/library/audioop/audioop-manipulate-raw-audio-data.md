## audioop — Manipulate raw audio data

### `audioop` — Manipulate raw audio data

Deprecated since version 3.11, removed in version 3.13.

The Python standard library no longer carries this module. After its deprecation in Python 3.11, it was [removed in Python 3.13](https://docs.python.org/3.14/whatsnew/3.13.html#whatsnew313-pep594). That decision to remove it came through [**PEP 594**](https://peps.python.org/pep-0594/).

[Python 3.12](https://docs.python.org/3.12/library/audioop.html) was the last Python release to bundle the `audioop` module.
