# The NotImplemented Object

### The NotImplemented Object

Comparisons and binary operations hand back this object whenever they are called on to act upon types they do not handle. For further detail, consult [Comparisons](https://docs.python.org/3.14/reference/expressions.html#comparisons). There is precisely one [`NotImplemented`](https://docs.python.org/3.14/library/constants.html#NotImplemented) object. `type(NotImplemented)()` yields the singleton instance.

It is shown as `NotImplemented`.
