# Functions

### Functions

A function definition is what brings function objects into being. Calling it is the only operation a function object permits: `func(argument-list)`.

In truth there are two kinds of function objects: built-in functions and user-defined functions. The two share the same operation (calling the function), yet their implementations diverge, which is why the object types differ.

For further detail, consult [Function definitions](https://docs.python.org/3.14/reference/compound_stmts.html#function).
