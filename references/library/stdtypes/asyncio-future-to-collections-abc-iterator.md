# stdtypes: Builtin and collection classes supporting parameterized generics

#### Standard Generic Classes

Parameterized generics are supported by the standard library classes listed below. The list is not exhaustive.

- `tuple`

- `list`

- `dict`

- `set`

- `frozenset`

- [`type`](https://docs.python.org/3.14/library/functions.html#type)

- [`asyncio.Future`](https://docs.python.org/3.14/library/asyncio-future.html#asyncio.Future)

- [`asyncio.Task`](https://docs.python.org/3.14/library/asyncio-task.html#asyncio.Task)

- [`collections.deque`](https://docs.python.org/3.14/library/collections.html#collections.deque)

- [`collections.defaultdict`](https://docs.python.org/3.14/library/collections.html#collections.defaultdict)

- [`collections.OrderedDict`](https://docs.python.org/3.14/library/collections.html#collections.OrderedDict)

- [`collections.Counter`](https://docs.python.org/3.14/library/collections.html#collections.Counter)

- [`collections.ChainMap`](https://docs.python.org/3.14/library/collections.html#collections.ChainMap)

- [`collections.abc.Awaitable`](https://docs.python.org/3.14/library/collections.abc.html#collections.abc.Awaitable)

- [`collections.abc.Coroutine`](https://docs.python.org/3.14/library/collections.abc.html#collections.abc.Coroutine)

- [`collections.abc.AsyncIterable`](https://docs.python.org/3.14/library/collections.abc.html#collections.abc.AsyncIterable)

- [`collections.abc.AsyncIterator`](https://docs.python.org/3.14/library/collections.abc.html#collections.abc.AsyncIterator)

- [`collections.abc.AsyncGenerator`](https://docs.python.org/3.14/library/collections.abc.html#collections.abc.AsyncGenerator)

- [`collections.abc.Iterable`](https://docs.python.org/3.14/library/collections.abc.html#collections.abc.Iterable)

- [`collections.abc.Iterator`](https://docs.python.org/3.14/library/collections.abc.html#collections.abc.Iterator)
