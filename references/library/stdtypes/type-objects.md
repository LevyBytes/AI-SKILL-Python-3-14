# Type Objects

### Type Objects

The assorted object types are represented by type objects. You reach an object’s type via the built-in function [`type()`](https://docs.python.org/3.14/library/functions.html#type). Types carry no special operations. The standard module [`types`](https://docs.python.org/3.14/library/types.html#module-types) supplies names for each of the standard built-in types.

Types are shown like this: `<class 'int'>`.
