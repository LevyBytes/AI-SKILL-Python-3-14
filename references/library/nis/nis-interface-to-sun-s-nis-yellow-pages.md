## nis — Interface to Sun’s NIS (Yellow Pages)

### `nis` — Interface to Sun’s NIS (Yellow Pages)

Deprecated since version 3.11, removed in version 3.13.

You will no longer find this module in the Python standard library. Following its deprecation back in Python 3.11, it was [removed in Python 3.13](https://docs.python.org/3.14/whatsnew/3.13.html#whatsnew313-pep594); that removal traces to [**PEP 594**](https://peps.python.org/pep-0594/).

[Python 3.12](https://docs.python.org/3.12/library/nis.html) was the final release to ship the `nis` module.
