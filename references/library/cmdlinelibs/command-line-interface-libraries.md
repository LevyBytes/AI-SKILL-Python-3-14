# Command-line interface libraries

## Command-line interface libraries

### Command-line interface libraries

Building command line and terminal front-ends for your applications is what the modules covered in this chapter help you do.

Here’s an overview:

- [`argparse` — Parser for command-line options, arguments and subcommands](https://docs.python.org/3.14/library/argparse.html)
- [`optparse` — Parser for command line options](https://docs.python.org/3.14/library/optparse.html)
- [`getpass` — Portable password input](https://docs.python.org/3.14/library/getpass.html)
- [`fileinput` — Iterate over lines from multiple input streams](https://docs.python.org/3.14/library/fileinput.html)
- [`curses` — Terminal handling for character-cell displays](https://docs.python.org/3.14/library/curses.html)
- [`curses.textpad` — Text input widget for curses programs](https://docs.python.org/3.14/library/curses.html#module-curses.textpad)
- [`curses.ascii` — Utilities for ASCII characters](https://docs.python.org/3.14/library/curses.ascii.html)
- [`curses.panel` — A panel stack extension for curses](https://docs.python.org/3.14/library/curses.panel.html)
- [`cmd` — Support for line-oriented command interpreters](https://docs.python.org/3.14/library/cmd.html)
