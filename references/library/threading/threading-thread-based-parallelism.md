### `threading` - Thread-based parallelism

**Source code:** [Lib/threading.py](https://github.com/python/cpython/tree/3.14/Lib/threading.py)

---

Built atop the lower-level [`_thread`](https://docs.python.org/3.14/library/_thread.html#module-_thread) module, this module supplies more convenient, higher-level threading constructs.

[Availability](https://docs.python.org/3.14/library/intro.html#availability): not WASI.

On WebAssembly this module is either unavailable or non-functional. Consult [WebAssembly platforms](https://docs.python.org/3.14/library/intro.html#wasm-availability) for further details.
