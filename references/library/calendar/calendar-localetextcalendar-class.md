# calendar: `calendar.LocaleTextCalendar`

*class *calendar.LocaleTextCalendar(*firstweekday=0*, *locale=None*)

You may hand this subclass of `TextCalendar` a locale name in its constructor, and it then returns month and weekday names in that locale.
