# calendar: Calendar CLI invocation and year selection

### Command-line usage

Added in version 2.5.

You can run the `calendar` module as a script from the command line to print a calendar interactively.

```shell
python -m calendar [-h] [-L LOCALE] [-e ENCODING] [-t {text,html}]
                   [-w WIDTH] [-l LINES] [-s SPACING] [-m MONTHS] [-c CSS]
                   [-f FIRST_WEEKDAY] [year] [month]

```

The accepted options are:

 --help, -h

Show the help message and exit.

 --locale LOCALE, -L LOCALE

The locale applied to month and weekday names. Defaults to English.

 --encoding ENCODING, -e ENCODING

The encoding applied to the output. `--encoding` is mandatory whenever `--locale` is set.

 --type {text,html}, -t {text,html}

Render the calendar to the terminal as text, or as an HTML document.

 --first-weekday FIRST_WEEKDAY, -f FIRST_WEEKDAY

The weekday on which each week opens. Has to be a number between 0 (Monday) and 6 (Sunday). Defaults to 0.

Added in version 3.13.

 year

The year whose calendar is printed. Defaults to the current year.
