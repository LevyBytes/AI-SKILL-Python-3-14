# importlib.metadata: `importlib.metadata.metadata()`

### Distribution metadata

 importlib.metadata.metadata(*distribution_name*)

Return the distribution metadata for the named distribution package as a `PackageMetadata` instance.

Raises `PackageNotFoundError` when the named distribution package is not installed in the current Python environment.
