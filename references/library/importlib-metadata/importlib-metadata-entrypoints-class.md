# importlib.metadata: `importlib.metadata.EntryPoints`

*class *importlib.metadata.EntryPoints

Details of a collection of installed entry points.

It additionally exposes a `.groups` attribute listing every entry point group it found, and a `.names` attribute listing every entry point name it found.
