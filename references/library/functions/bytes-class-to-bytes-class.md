# Built-in Functions

*class *bytes(*source=b''*)

 *class *bytes(*source*, *encoding*, *errors='strict'*)

Give back a fresh “bytes” object, an immutable sequence holding integers within `0 <= x < 256`. [`bytes`](https://docs.python.org/3.14/library/stdtypes.html#bytes) is the immutable counterpart of [`bytearray`](https://docs.python.org/3.14/library/stdtypes.html#bytearray) – it shares the same non-mutating methods along with identical indexing and slicing behavior.

Its constructor arguments are therefore read the same way as for [`bytearray()`](https://docs.python.org/3.14/library/stdtypes.html#bytearray).

You can also build bytes objects from literals; refer to [String and Bytes literals](https://docs.python.org/3.14/reference/lexical_analysis.html#strings).

Consult [Binary Sequence Types — bytes, bytearray, memoryview](https://docs.python.org/3.14/library/stdtypes.html#binaryseq), [Bytes Objects](https://docs.python.org/3.14/library/stdtypes.html#typebytes), and [Bytes and Bytearray Operations](https://docs.python.org/3.14/library/stdtypes.html#bytes-methods) as well.
