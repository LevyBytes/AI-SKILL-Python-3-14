# Built-in Functions

*class *object

This serves as the topmost base class from which every other class derives. It carries methods shared across all instances of Python classes. Invoking the constructor produces a fresh featureless object. No arguments are accepted by the constructor.

Note

`object` instances do *not* carry [`__dict__`](https://docs.python.org/3.14/reference/datamodel.html#object.__dict__) attributes, which means you cannot attach arbitrary attributes onto an instance of `object`.
