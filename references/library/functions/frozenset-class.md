# Built-in Functions

*class *frozenset(*iterable=()*, */*)

Return a new [`frozenset`](https://docs.python.org/3.14/library/stdtypes.html#frozenset) object, optionally holding elements drawn from *iterable*. `frozenset` is a built-in class. Also consult [Set Types - set, frozenset](https://docs.python.org/3.14/library/stdtypes.html#types-set) for documentation covering this class.

Regarding other containers, see the built-in [`set`](https://docs.python.org/3.14/library/stdtypes.html#set), [`list`](https://docs.python.org/3.14/library/stdtypes.html#list), [`tuple`](https://docs.python.org/3.14/library/stdtypes.html#tuple), and [`dict`](https://docs.python.org/3.14/library/stdtypes.html#dict) classes, along with the [`collections`](https://docs.python.org/3.14/library/collections.html#module-collections) module.
