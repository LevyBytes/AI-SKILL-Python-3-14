# Built-in Functions

*class *dict(***kwargs*)

 *class *dict(*mapping*, */*, ***kwargs*)

 *class *dict(*iterable*, */*, ***kwargs*)

Build a fresh dictionary. The [`dict`](https://docs.python.org/3.14/library/stdtypes.html#dict) object is the dictionary class. For documentation covering this class, consult [Mapping Types - dict](https://docs.python.org/3.14/library/stdtypes.html#typesmapping) as well.

For the other containers, consult the built-in [`list`](https://docs.python.org/3.14/library/stdtypes.html#list), [`set`](https://docs.python.org/3.14/library/stdtypes.html#set), and [`tuple`](https://docs.python.org/3.14/library/stdtypes.html#tuple) classes, along with the [`collections`](https://docs.python.org/3.14/library/collections.html#module-collections) module.
