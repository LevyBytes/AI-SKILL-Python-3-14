# Built-in Functions

*class *set(*iterable=()*, */*)

Hand back a fresh [`set`](https://docs.python.org/3.14/library/stdtypes.html#set) object, populating it from *iterable* if you choose. `set` is a built-in class. Refer as well to [Set Types - set, frozenset](https://docs.python.org/3.14/library/stdtypes.html#types-set) for this class's documentation.

Regarding other containers, look at the built-in [`frozenset`](https://docs.python.org/3.14/library/stdtypes.html#frozenset), [`list`](https://docs.python.org/3.14/library/stdtypes.html#list), [`tuple`](https://docs.python.org/3.14/library/stdtypes.html#tuple), and [`dict`](https://docs.python.org/3.14/library/stdtypes.html#dict) classes, plus the [`collections`](https://docs.python.org/3.14/library/collections.html#module-collections) module.
