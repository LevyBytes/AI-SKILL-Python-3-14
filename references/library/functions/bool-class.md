# Built-in Functions

*class *bool(*object=False*, */*)

Give back a Boolean, i.e. either `True` or `False`. The argument passes through the standard [truth testing procedure](https://docs.python.org/3.14/library/stdtypes.html#truth) to be converted. A false or omitted argument yields `False`; anything else yields `True`. The `bool` class derives from `int` (refer to [Numeric Types - int, float, complex](https://docs.python.org/3.14/library/stdtypes.html#typesnumeric)). No further subclassing of it is allowed. The lone instances it has are `False` and `True` (refer to [Boolean Type - bool](https://docs.python.org/3.14/library/stdtypes.html#typebool)).

Changed in version 3.7: The parameter is now positional-only.
