# Built-in Functions

*class *str(***, *encoding='utf-8'*, *errors='strict'*)

 *class *str(*object*)

 *class *str(*object*, *encoding*, *errors='strict'*)

 *class *str(*object*, ***, *errors*)

Hand back a [`str`](https://docs.python.org/3.14/library/stdtypes.html#str) rendering of *object*. The full details live at [`str()`](https://docs.python.org/3.14/library/stdtypes.html#str).

`str` is the built-in string [class](https://docs.python.org/3.14/glossary.html#term-class). For broader coverage of strings, see [Text Sequence Type — str](https://docs.python.org/3.14/library/stdtypes.html#textseq).
