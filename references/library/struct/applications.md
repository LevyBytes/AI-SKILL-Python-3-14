# struct - Applications

### Applications

The `struct` module serves two principal purposes: trading data between Python and C code inside one application — or another application built with the same compiler — via native formats, and trading data among applications that have settled on a common data layout via standard formats. As a rule, the format strings you build for each of these two domains differ.
