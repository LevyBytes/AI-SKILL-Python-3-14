# selectors: SelectorKey registered-file, event and attached-data fields

fileobj

File object registered.

 fd

Underlying file descriptor.

 events

The set of events to be awaited on this particular file object.

 data

Opaque data, optional, attached to the file object here: one use, say, would be holding a per-client session ID.
