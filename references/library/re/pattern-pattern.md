# re: `Pattern.pattern`

Pattern.pattern

The pattern string from which the pattern object was compiled.

Changed in version 3.7: gained support for [`copy.copy()`](https://docs.python.org/3.14/library/copy.html#copy.copy) and [`copy.deepcopy()`](https://docs.python.org/3.14/library/copy.html#copy.deepcopy). A compiled regular expression object is regarded as atomic.
