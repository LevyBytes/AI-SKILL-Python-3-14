# numbers: `numbers.Rational`

*class *numbers.Rational

Derives from `Real` while contributing the `numerator` and `denominator` properties. A default for [`float()`](https://docs.python.org/3.14/library/functions.html#float) is supplied too.

Both the `numerator` and `denominator` ought to be `Integral` instances, reduced to lowest terms with a positive `denominator`.

 numerator

Abstract. The numerator of this rational number.

Abstract. The denominator of this rational number.
