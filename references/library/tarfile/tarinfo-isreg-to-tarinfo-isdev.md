# tarfile: `TarInfo.isreg()`, `TarInfo.isdir()`, `TarInfo.issym()`, `TarInfo.islnk()`, `TarInfo.ischr()`, `TarInfo.isblk()`, `TarInfo.isfifo()`, `TarInfo.isdev()`

TarInfo.isreg()

Same as `isfile()`.

 TarInfo.isdir()

Return [`True`](https://docs.python.org/3.14/library/constants.html#True) if it is a directory.

 TarInfo.issym()

Return [`True`](https://docs.python.org/3.14/library/constants.html#True) if it is a symbolic link.

 TarInfo.islnk()

Return [`True`](https://docs.python.org/3.14/library/constants.html#True) if it is a hard link.

 TarInfo.ischr()

Return [`True`](https://docs.python.org/3.14/library/constants.html#True) if it is a character device.

 TarInfo.isblk()

Return [`True`](https://docs.python.org/3.14/library/constants.html#True) if it is a block device.

 TarInfo.isfifo()

Return [`True`](https://docs.python.org/3.14/library/constants.html#True) if it is a FIFO.

 TarInfo.isdev()

Return [`True`](https://docs.python.org/3.14/library/constants.html#True) if it is one of character device, block device or FIFO.
