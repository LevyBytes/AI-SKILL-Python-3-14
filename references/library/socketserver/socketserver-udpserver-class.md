# socketserver: `socketserver.UDPServer`

*class *socketserver.UDPServer(*server_address*, *RequestHandlerClass*, *bind_and_activate=True*)

This relies on datagrams — separate chunks of data that can show up in the wrong sequence or vanish during delivery. Its parameters match those of `TCPServer`.
