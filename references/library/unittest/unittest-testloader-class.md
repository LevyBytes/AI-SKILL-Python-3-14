# unittest: `unittest.TestLoader`

### Loading and running tests

 *class *unittest.TestLoader

The `TestLoader` class serves to build test suites out of classes and modules. Usually you need not build an instance of this class; the `unittest` module supplies one that can be shared via `unittest.defaultTestLoader`. Using a subclass or instance, though, opens up tuning of several configurable properties.
