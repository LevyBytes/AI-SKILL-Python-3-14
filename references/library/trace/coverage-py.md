# Trace

### `trace` — Trace or track Python statement execution

**Source code:** [Lib/trace.py](https://github.com/python/cpython/tree/3.14/Lib/trace.py)

---

With the `trace` module you can follow how a program runs, build annotated statement-coverage listings, print out caller/callee relationships, and enumerate which functions ran over the course of a program. You may drive it from inside another program or straight from the command line.

See also

[Coverage.py](https://coverage.readthedocs.io/)

A widely used external coverage utility that emits HTML reports and offers richer capabilities, branch coverage among them.
