# trace — Filters

### Filters

You are free to supply these options more than once.

 --ignore-module=&lt;mod&gt;

Skip every module name listed along with its submodules (when the name refers to a package). You may pass the argument as a comma-separated list of names.

 --ignore-dir=&lt;dir&gt;

Skip every module and package found in the given directory and beneath it. You may pass the argument as a list of directories joined by [`os.pathsep`](https://docs.python.org/3.14/library/os.html#os.pathsep).
