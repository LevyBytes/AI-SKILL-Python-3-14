# turtle: Vec2D coordinate arithmetic and rotation

*class *turtle.Vec2D(*x*, *y*)

A class representing a two-dimensional vector, serving as a helper for building turtle graphics. It can also come in handy within turtle graphics programs. Since it derives from tuple, a vector is itself a tuple!

Supplies (where *a*, *b* are vectors and *k* is a number):

- `a + b` vector addition

- `a - b` vector subtraction

- `a * b` inner product

- `k * a` and `a * k` multiplication with scalar

- `abs(a)` absolute value of a

- `a.rotate(angle)` rotation
