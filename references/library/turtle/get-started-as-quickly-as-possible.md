# Get started as quickly as possible

### Get started as quickly as possible

A real pleasure of turtle graphics lies in the prompt, visual response you get from plain commands ? which makes it a fine way to bring programming notions to kids, carrying almost no setup cost (and adults benefit too, naturally).

The turtle module enables this by surfacing all of its core behavior as plain functions, reachable via `from turtle import *`. That route is what the turtle graphics tutorial walks through.

Note, too, that a good number of turtle commands carry shorter aliases as well, like `fd()` standing in for `forward()`. Aliases of this kind really help when you're teaching learners who don't yet type fluently.

>

For turtle graphics to function, the [`Tk interface package`](https://docs.python.org/3.14/library/tkinter.html#module-tkinter) has to be present on your system. Keep in mind this step isn't always painless, so verify it up front if you intend to bring turtle graphics to a learner.
