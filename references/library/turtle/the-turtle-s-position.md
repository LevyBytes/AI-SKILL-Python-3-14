# The turtle's position

#### The turtle's position

Return your turtle to where it began (handy if it has wandered off-screen):

```python
home()

```

That home spot sits dead center in the turtle's screen. Whenever you want the values, read off the turtle's x-y coordinates this way:

```python
pos()

```

Home is at `(0, 0)`.

After working for a bit, wiping the window clean to begin fresh tends to come in handy:

```python
clearscreen()

```
