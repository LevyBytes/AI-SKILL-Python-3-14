# Introduction

### Introduction

The turtle graphics system here is a take on [the popular geometric drawing tools introduced in Logo](https://en.wikipedia.org/wiki/Turtle_(robot)), a language built by Wally Feurzeig, Seymour Papert and Cynthia Solomon in 1967.

This counts as an [optional module](https://docs.python.org/3.14/glossary.html#term-optional-module). Should your build of CPython lack it, consult whatever documentation came from your distributor (meaning whoever handed you Python in the first place). Distributors themselves should read [Requirements for optional modules](https://docs.python.org/3.14/using/configure.html#optional-module-requirements).
