# Pen control

#### Pen control

Try adjusting the color ? say, `color('blue')` ? along with the line's thickness ? say, `width(3)` ? and then sketch some more.

The turtle can also travel without leaving any marks: raise the pen first with `up()` before you move. When you want marks again, call `down()`.
