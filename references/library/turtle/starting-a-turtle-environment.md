# Starting a turtle environment

### Starting a turtle environment

Within a Python shell, pull in every object that the `turtle` module exposes:

```python
from turtle import *

```

Should a `No module named '_tkinter'` error appear, the [`Tk interface package`](https://docs.python.org/3.14/library/tkinter.html#module-tkinter) must be added to your system first.
