# Basic drawing

### Basic drawing

Move the turtle ahead by 100 steps:

```python
forward(100)

```

What you should observe (probably inside a fresh window on your screen) is a line the turtle has drawn while heading East. Now reorient the turtle, rotating it 120 degrees to the left (anti-clockwise):

```python
left(120)

```

Carry on and sketch a triangle:

```python
forward(100)
left(120)
forward(100)

```

Watch how the turtle ? shown as an arrow ? aims at varying directions while you guide it around.

Play with these commands, plus `backward()` and `right()` too.
