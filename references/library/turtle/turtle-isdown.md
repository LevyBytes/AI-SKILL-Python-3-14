# turtle: `turtle.isdown()`

turtle.isdown()

Give back `True` when the pen is down and `False` when it's raised.

```pycon
>>> turtle.penup()
>>> turtle.isdown()
False
>>> turtle.pendown()
>>> turtle.isdown()
True

```
