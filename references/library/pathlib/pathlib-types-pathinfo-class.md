# pathlib: `pathlib.types.PathInfo`

### Protocols

For static type checking, the `pathlib.types` module supplies the relevant types.

Added in version 3.14.

 *class *pathlib.types.PathInfo

A [`typing.Protocol`](https://docs.python.org/3.14/library/typing.html#typing.Protocol) that describes the `Path.info` attribute. An implementation is free to hand back cached results from its methods.
