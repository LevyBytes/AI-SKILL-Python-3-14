# pathlib: `pathlib.PurePosixPath`

*class *pathlib.PurePosixPath(**pathsegments*)

A subclass of `PurePath`, this path flavour stands for non-Windows filesystem paths:

```python
>>> PurePosixPath('/etc/hosts')
PurePosixPath('/etc/hosts')

```

*pathsegments* is specified similarly to `PurePath`.
