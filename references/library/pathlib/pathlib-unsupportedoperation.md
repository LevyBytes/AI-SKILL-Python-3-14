# pathlib — Exceptions

### Exceptions

 *exception *pathlib.UnsupportedOperation

An exception deriving from [`NotImplementedError`](https://docs.python.org/3.14/library/exceptions.html#NotImplementedError) that gets raised once an unsupported operation is invoked on a path object.

Added in version 3.13.
