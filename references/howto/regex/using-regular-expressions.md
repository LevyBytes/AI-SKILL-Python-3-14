# Using regular expressions

### Using regular expressions

Having surveyed a few simple regular expressions, how do we put them to work in Python? The [`re`](https://docs.python.org/3.14/library/re.html#module-re) module exposes an interface onto the regular expression engine, letting you compile REs into objects and then run matches against them.
