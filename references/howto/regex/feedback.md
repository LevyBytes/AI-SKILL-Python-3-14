# Feedback

### Feedback

Regular expressions make for an intricate subject. Did this write-up bring them into focus for you? Were any portions murky, or did you run into problems it never addressed? If that's the case, do route your improvement ideas to the [issue tracker](https://docs.python.org/3.14/bugs.html#using-the-tracker).

The fullest treatment of regular expressions in book form is, near enough, Jeffrey Friedl's Mastering Regular Expressions out of O'Reilly. Sadly, it trains its attention solely on the Perl and Java dialects of regular expressions and carries no Python material whatsoever, so as a reference for coding in Python it falls flat. (Its first edition discussed Python's `regex` module, since removed, which is of little use to you.) You might borrow a copy from your library.
