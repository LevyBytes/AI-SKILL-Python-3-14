### How to port Python 2 Code to Python 3

author:

Brett Cannon

Python 2 hit its official end-of-life when 2020 began. From that point on, the language gets no fresh bug reports, fixes, or changes — support has ended: consult [**PEP 373**](https://peps.python.org/pep-0373/) along with the [status of Python versions](https://devguide.python.org/versions).

Those who want to port an extension module rather than plain Python code should turn instead to [Porting Extension Modules to Python 3](https://docs.python.org/3.14/howto/cporting.html#cporting-howto).

You might find some helpful advice in the archived [python-porting](https://mail.python.org/pipermail/python-porting/) mailing list.

The original porting guide has been retired as of Python 3.11. The earlier version is still available in the [archive](https://docs.python.org/3.10/howto/pyporting.html).
