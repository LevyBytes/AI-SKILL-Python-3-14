# How to translate the argparse output

### How to translate the argparse output

Everything the [`argparse`](https://docs.python.org/3.14/library/argparse.html#module-argparse) module emits, such as its help text and error messages, is made translatable by way of the [`gettext`](https://docs.python.org/3.14/library/gettext.html#module-gettext) module. That lets applications readily localize the messages `argparse` puts out. See also [Internationalizing your programs and modules](https://docs.python.org/3.14/library/gettext.html#i18n-howto).
