# A Note on IP Versions

### A Note on IP Versions

If IP addressing is not something you know well, it helps to realize that the Internet Protocol (IP) is right now shifting away from version 4 of the protocol toward version 6. What chiefly drives that shift is that version 4 of the protocol simply runs out of addresses to cover the entire planet's demand, all the more so as the count of devices wired straight to the internet keeps climbing.

Laying out exactly how the two protocol versions differ falls outside what this introduction sets out to cover, yet you should at minimum recognize that both versions are in play, and that on occasion you will have to compel the use of one or the other.
