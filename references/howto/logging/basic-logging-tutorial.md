# Basic Logging Tutorial

### Basic Logging Tutorial

Through logging you keep track of the events that occur while a program is executing. A program's author inserts logging calls throughout the code to signal that particular events have taken place. Each event is captured by a descriptive message that may, if desired, carry variable data (that is, data that could differ on every occurrence of the event). Each event also carries an importance that the author assigns to it; that importance is sometimes referred to as the *level* or *severity*.
