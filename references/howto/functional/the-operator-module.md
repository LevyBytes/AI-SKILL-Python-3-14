# The operator module

### The operator module

We brought up the [`operator`](https://docs.python.org/3.14/library/operator.html#module-operator) module already. It bundles a set of functions matching Python's operators. Such functions often prove handy in functional-style code, since they spare you from authoring trivial functions that carry out one single operation.

Among the functions this module provides are:

- Math operations: `add()`, `sub()`, `mul()`, `floordiv()`, `abs()`, …

- Logical operations: `not_()`, `truth()`.

- Bitwise operations: `and_()`, `or_()`, `invert()`.

- Comparisons: `eq()`, `ne()`, `lt()`, `le()`, `gt()`, and `ge()`.

- Object identity: `is_()`, `is_not()`.

See the operator module's documentation for the full listing.
