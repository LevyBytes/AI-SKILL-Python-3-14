# The itertools module

### The itertools module

The [`itertools`](https://docs.python.org/3.14/library/itertools.html#module-itertools) module supplies a collection of frequently needed iterators together with functions that merge multiple iterators. The discussion here walks through what the module offers using brief examples.

You can sort the module's functions into several large categories:

- Functions producing a fresh iterator out of an existing one.

- Functions that pass an iterator's elements along as function arguments.

- Functions that pick out slices of an iterator's output.

- A function that groups an iterator's output.
