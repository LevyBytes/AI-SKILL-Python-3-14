# Composability

### Composability

While building a functional-style program, you'll author a range of functions taking various inputs and yielding various outputs. A few of these functions will inevitably be tailored to one particular application, but others will prove handy across a broad assortment of programs. For instance, a function that accepts a directory path and hands back every XML file within that directory, or one that takes a filename and returns its contents, can be reused in numerous distinct scenarios.

As time passes you'll build up a personal collection of utilities. Frequently you'll put together new programs by arranging existing functions into a fresh layout and writing a handful of functions tailored to the task at hand.
