# Functional Programming HOWTO

### Functional Programming HOWTO

Author:

A. M. Kuchling

Release:

0.32

This document surveys the Python facilities that are well-suited to building programs in a functional manner. We begin by introducing what functional programming means, then we examine language constructs like [iterator](https://docs.python.org/3.14/glossary.html#term-iterator)s and [generator](https://docs.python.org/3.14/glossary.html#term-generator)s along with pertinent library modules such as [`itertools`](https://docs.python.org/3.14/library/itertools.html#module-itertools) and [`functools`](https://docs.python.org/3.14/library/functools.html#module-functools).
