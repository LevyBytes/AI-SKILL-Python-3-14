# Modularity

### Modularity

A more down-to-earth advantage of functional programming is that it compels you to split your problem into small chunks. The upshot is that programs end up more modular. Specifying and authoring a small function that handles one task is simpler than a big function carrying out an intricate transformation. Small functions are likewise simpler to read and to scan for mistakes.
