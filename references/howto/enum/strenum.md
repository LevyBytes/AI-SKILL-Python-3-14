# StrEnum

### StrEnum

The second [`Enum`](https://docs.python.org/3.14/library/enum.html#enum.Enum) variant on offer also subclasses [`str`](https://docs.python.org/3.14/library/stdtypes.html#str). You can compare the members of a [`StrEnum`](https://docs.python.org/3.14/library/enum.html#enum.StrEnum) against strings; and by the same token, string enumerations of differing types compare against each other as well.

Added in version 3.11.
