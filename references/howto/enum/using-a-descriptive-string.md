# Using a descriptive string

#### Using a descriptive string

Employing a string for the value would look like:

```python
>>> class Color(Enum):
...     RED = 'stop'
...     GREEN = 'go'
...     BLUE = 'too fast!'
...
>>> Color.GREEN
<Color.GREEN: 'go'>

```
