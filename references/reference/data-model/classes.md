# 3.2.8.8. Classes

#### 3.2.8.8. Classes

Classes can be called. Ordinarily these objects serve as factories producing fresh instances of themselves, though class types that redefine `__new__()` can behave differently. The call's arguments flow into `__new__()` and, in the usual case, onward to `__init__()` so as to set up the new instance.
