# 3.2.8.1. User-defined functions

#### 3.2.8.1. User-defined functions

A function definition creates a user-defined function object (see section [Function definitions](https://docs.python.org/3.14/reference/compound_stmts.html#function)). It ought to be invoked with an argument list holding as many items as the function’s formal parameter list does.
