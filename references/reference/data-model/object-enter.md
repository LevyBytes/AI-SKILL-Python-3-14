# object.__enter__(*self*)

object.__enter__(*self*)

Enter the runtime context tied to this object. The [`with`](https://docs.python.org/3.14/reference/compound_stmts.html#with) statement binds this method's return value to the target(s) named in the `as` clause of the statement, when one is present.
