# module.__spec__

module.__spec__

A capture of the module’s state relating to the import system.

Holds the [`module spec`](https://docs.python.org/3.14/library/importlib.html#importlib.machinery.ModuleSpec) that applied when the module was imported. Consult [Module specs](https://docs.python.org/3.14/reference/import.html#module-specs) for further information.

Added in version 3.4.
