# 3.2. The standard type hierarchy

### 3.2. The standard type hierarchy

What follows is a catalog of the types Python provides built in. Additional types may be defined by extension modules (coded in C, Java, or other languages, according to the implementation). Later releases of Python could extend the type hierarchy with more types (for example, rational numbers, compactly stored arrays of integers, and so on), though such extensions will frequently come through the standard library rather than the core.

A few of the type descriptions that follow include a paragraph that enumerates ‘special attributes.’ Such attributes grant access into the implementation and are not meant for ordinary use. Their definition is subject to change later on.
