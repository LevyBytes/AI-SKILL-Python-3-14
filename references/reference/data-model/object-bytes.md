# object.__bytes__(*self*)

object.__bytes__(*self*)

Invoked by [bytes](https://docs.python.org/3.14/library/functions.html#func-bytes) to derive a byte-string form of an object. The result should be a [`bytes`](https://docs.python.org/3.14/library/stdtypes.html#bytes) object. This method is not furnished by the [`object`](https://docs.python.org/3.14/library/functions.html#object) class itself.
