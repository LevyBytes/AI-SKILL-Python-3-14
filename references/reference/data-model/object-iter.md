# object.__iter__(*self*)

object.__iter__(*self*)

This method runs whenever an [iterator](https://docs.python.org/3.14/glossary.html#term-iterator) is needed for a container. It should hand back a fresh iterator object capable of traversing every object in the container. For mappings, it should traverse the keys of the container.
