# module.__annotations__

module.__annotations__

A dictionary holding the [variable annotations](https://docs.python.org/3.14/glossary.html#term-variable-annotation) gathered while the module body ran. For guidance on handling `__annotations__` well, consult [`annotationlib`](https://docs.python.org/3.14/library/annotationlib.html#module-annotationlib).

Changed in version 3.14: Annotations now undergo [lazy evaluation](https://docs.python.org/3.14/reference/executionmodel.html#lazy-evaluation). See [**PEP 649**](https://peps.python.org/pep-0649/).
