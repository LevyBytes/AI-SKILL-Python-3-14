# 3.2.1. None

### 3.2.1. None

A single value belongs to this type. Exactly one object holds that value. You reach this object via the built-in name `None`. In numerous situations it serves to mark the absence of a value, for example it is what functions hand back when they return nothing explicitly. Its truth value is false.
