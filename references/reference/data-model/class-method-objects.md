# 3.2.13.6. Class method objects

#### 3.2.13.6. Class method objects

Much like a static method object, a class method object wraps another object and changes how that object gets fetched from classes and from class instances. How class method objects act when fetched this way is covered above, under “instance methods”. The built-in [`classmethod()`](https://docs.python.org/3.14/library/functions.html#classmethod) constructor produces class method objects.
