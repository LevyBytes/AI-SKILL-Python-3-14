# 3.3.12. Annotations

### 3.3.12. Annotations

Functions, classes, and modules can carry [annotations](https://docs.python.org/3.14/glossary.html#term-annotation), which offer a means to attach information (typically [type hints](https://docs.python.org/3.14/glossary.html#term-type-hint)) to a symbol.
