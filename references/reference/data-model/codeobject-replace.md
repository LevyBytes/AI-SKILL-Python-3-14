# codeobject.replace(***kwargs*)

codeobject.replace(***kwargs*)

Hand back a duplicate of the code object in which the named fields carry new values.

The generic function [`copy.replace()`](https://docs.python.org/3.14/library/copy.html#copy.replace) also accepts code objects.

Added in version 3.8.
