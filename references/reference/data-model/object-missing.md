# object.__missing__(*self*, *key*)

object.__missing__(*self*, *key*)

Invoked by [`dict`](https://docs.python.org/3.14/library/stdtypes.html#dict).`__getitem__()` to back `self[key]` for dict subclasses whenever key is missing from the dictionary.
