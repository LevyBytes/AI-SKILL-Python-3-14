# object.__dir__(*self*)

object.__dir__(*self*)

Invoked once [`dir()`](https://docs.python.org/3.14/library/functions.html#dir) is called on the object. An iterable has to be returned. `dir()` turns the returned iterable into a list and sorts that list.
