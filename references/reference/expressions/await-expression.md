# 6.4. Await expression

### 6.4. Await expression

Pause the execution of a [coroutine](https://docs.python.org/3.14/glossary.html#term-coroutine) on an [awaitable](https://docs.python.org/3.14/glossary.html#term-awaitable) object. This is permitted only inside a [coroutine function](https://docs.python.org/3.14/glossary.html#term-coroutine-function).

```text

await_expr: "await" primary
```

Added in version 3.5.
