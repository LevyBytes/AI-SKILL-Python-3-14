# 6. Expressions

### 6. Expressions

The purpose of this chapter is to set out what the components of Python expressions actually mean.

**Syntax Notes:** Throughout this chapter and the ones that follow, syntax is described with [grammar notation](https://docs.python.org/3.14/reference/introduction.html#notation) rather than the notation used for lexical analysis.

Whenever (one alternative of) a syntax rule takes the form:

```text

name: othername
```

with no accompanying semantics, this variant of `name` carries exactly the same meaning as `othername`.
