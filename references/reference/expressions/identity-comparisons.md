# 6.10.3. Identity comparisons

### 6.10.3. Identity comparisons

Object identity is what the `is` and `is not` operators examine: `x is y` is true exactly when *x* and *y* refer to one and the same object. The [`id()`](https://docs.python.org/3.14/library/functions.html#id) function is what fixes an object's identity. `x is not y` produces the opposite truth value. [4]
