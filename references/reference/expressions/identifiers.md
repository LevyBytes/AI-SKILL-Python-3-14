# 6.2.2. Identifiers (Names)

### 6.2.2. Identifiers (Names)

A name is an identifier that appears as an atom. Refer to the section [Names (identifiers and keywords)](https://docs.python.org/3.14/reference/lexical_analysis.html#identifiers) for the lexical definition, and to [Naming and binding](https://docs.python.org/3.14/reference/executionmodel.html#naming) for how naming and binding are documented.

If the name has been bound to some object, then evaluating the atom returns that object. If instead the name has no binding, trying to evaluate it triggers a [`NameError`](https://docs.python.org/3.14/library/exceptions.html#NameError) exception.
