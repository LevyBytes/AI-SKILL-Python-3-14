# 8.6.4.7. Group Patterns

#### 8.6.4.7. Group Patterns

By letting users wrap parentheses around patterns, a group pattern highlights the grouping they intend. Beyond that it brings no extra syntax. Syntax:

```text

group_pattern: "(" pattern ")"
```

Put simply, `(P)` behaves the same as `P`.
