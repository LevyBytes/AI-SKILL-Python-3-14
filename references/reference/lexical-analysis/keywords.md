# 2.3.1. Keywords

### 2.3.1. Keywords

The names listed here act as the language's reserved words, or *keywords*, and may not serve as ordinary identifiers. Their spelling has to match exactly what appears here:

```text
False      await      else       import     pass
None       break      except     in         raise
True       class      finally    is         return
and        continue   for        lambda     try
as         def        from       nonlocal   while
assert     del        global     not        with
async      elif       if         or         yield

```
