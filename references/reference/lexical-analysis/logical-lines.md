# 2.1.1. Logical lines

### 2.1.1. Logical lines

A logical line concludes with the [`NEWLINE`](https://docs.python.org/3.14/library/token.html#token.NEWLINE) token. Outside the places where the syntax permits `NEWLINE` (for instance, separating statements inside compound statements), statements may not span logical line boundaries. One or more *physical lines* combine into a logical line by way of the explicit or implicit *line joining* rules.
