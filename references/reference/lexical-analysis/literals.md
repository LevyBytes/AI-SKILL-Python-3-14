# 2.4. Literals

### 2.4. Literals

Constant values belonging to certain built-in types are notated by literals.

As far as lexical analysis goes, Python provides string, bytes and numeric literals.

Keywords (`None`, `True`, `False`) plus the special ellipsis token (`...`) lexically denote the remaining “literals”.
