# 2.5.8. t-strings

### 2.5.8. t-strings

Added in version 3.14.

A *template string literal*, or *t-string*, is a string literal carrying the ‘`t`’ or ‘`T`’ prefix. The syntax rules these strings obey are the same ones that govern formatted string literals. For where their evaluation rules diverge, see the [Standard Library section on t-strings](https://docs.python.org/3.14/library/stdtypes.html#stdtypes-tstrings)
