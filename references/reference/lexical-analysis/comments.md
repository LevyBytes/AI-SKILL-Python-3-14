# 2.1.3. Comments

### 2.1.3. Comments

A comment begins at a hash character (`#`) lying outside a string literal and runs to the end of that physical line. Unless the implicit line joining rules come into play, a comment marks the close of the logical line. The syntax pays no attention to comments.
