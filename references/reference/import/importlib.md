# 5.1. `importlib`

### 5.1. [`importlib`](https://docs.python.org/3.14/library/importlib.html#module-importlib)

A full-featured API for working with the import system is offered by the [`importlib`](https://docs.python.org/3.14/library/importlib.html#module-importlib) module. As one illustration, [`importlib.import_module()`](https://docs.python.org/3.14/library/importlib.html#importlib.import_module) gives you an endorsed and more straightforward API for kicking off the import machinery than the built-in [`__import__()`](https://docs.python.org/3.14/library/functions.html#import__). See the `importlib` library docs if you want more depth.
