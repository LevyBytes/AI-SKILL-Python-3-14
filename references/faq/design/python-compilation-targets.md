# Can Python be compiled to machine code, C or some other language?

### Can Python be compiled to machine code, C or some other language?

[Cython](https://cython.org/) compiles a modified flavor of Python, carrying optional annotations, into C extensions. [Nuitka](https://nuitka.net/) is a rising compiler that turns Python into C++ code, with the goal of supporting the complete Python language.
