### “Why is Python Installed on my Computer?” FAQ

### What is Python?

Python happens to be a programming language, and it powers a wide variety of applications. Plenty of high schools and colleges reach for it as a first language to teach, owing to how approachable Python is to pick up — yet seasoned software developers lean on it too, at outfits the likes of Google, NASA, and Lucasfilm Ltd.

Should you want a deeper look at Python, your starting point is the [Beginner’s Guide to Python](https://wiki.python.org/moin/BeginnersGuide).

### Why is Python installed on my machine?

When Python turns up on your system yet you have no recollection of putting it there, a handful of explanations could account for how it arrived.

- It may be that someone else who uses the computer set out to learn programming and put it on; you would then need to work out who has had access to the machine and could have done so.

- Some third-party program already on the machine could have been built in Python and bundled a Python installation along with it. Applications of that sort are numerous, spanning GUI programs, network servers, and administrative scripts alike.

- Certain Windows machines arrive with Python on board as well. As of this writing, we know of systems from Hewlett-Packard and Compaq that ship Python. It seems a number of HP/Compaq’s administrative tools were coded in Python.

- A great many Unix-compatible operating systems — macOS and a number of Linux distributions among them — come with Python already set up; it forms part of the base installation.

### Can I delete Python?

The answer hinges on how Python got onto the system in the first place.

Where a person put it there on purpose, taking it back off does no harm. Under Windows, reach for the Add/Remove Programs icon found in the Control Panel.

Where a third-party application brought Python in, you are free to uninstall it too, but then that application stops functioning. The right move is to run that application’s own uninstaller instead of pulling Python out directly.

Where Python shipped as part of your operating system, getting rid of it is something we advise against. Strip it out and any tools built on Python cease to run — a few of which may well matter to you. Setting things straight again could then demand a full reinstall of the system.
