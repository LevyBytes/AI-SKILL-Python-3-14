# How can I find the methods or attributes of an object?

### How can I find the methods or attributes of an object?

For an instance `x` of a user-defined class, [`dir(x)`](https://docs.python.org/3.14/library/functions.html#dir) gives back an alphabetized list of the names covering the instance attributes plus the methods and attributes its class defines.
