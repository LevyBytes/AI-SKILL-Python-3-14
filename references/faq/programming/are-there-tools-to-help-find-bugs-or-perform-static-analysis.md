# Are there tools to help find bugs or perform static analysis?

### Are there tools to help find bugs or perform static analysis?

Yes.

[Ruff](https://docs.astral.sh/ruff/), [Pylint](https://pylint.readthedocs.io/) and [Pyflakes](https://github.com/PyCQA/pyflakes) perform fundamental checks that let you spot bugs earlier.

Type hints in Python source code can be verified by static type checkers like [mypy](https://mypy-lang.org/), [ty](https://docs.astral.sh/ty/), [Pyrefly](https://pyrefly.org/), and [pytype](https://github.com/google/pytype).
