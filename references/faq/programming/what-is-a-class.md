# What is a class?

### Objects

### What is a class?

A class is the specific kind of object that a class statement produces when run. These class objects serve as blueprints for building instance objects, each of which carries both the data (attributes) and the code (methods) tied to a given datatype.

A class may derive from one or several other classes, referred to as its base class(es), inheriting their attributes and methods in turn. By way of inheritance, an object model can be progressively refined. For instance, a broad `Mailbox` class might supply basic accessor methods for a mailbox, with subclasses like `MboxMailbox`, `MaildirMailbox`, `OutlookMailbox` covering particular mailbox layouts.
