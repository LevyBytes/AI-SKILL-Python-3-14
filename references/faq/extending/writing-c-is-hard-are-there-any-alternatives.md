# Writing C is hard; are there any alternatives?

### Writing C is hard; are there any alternatives?

Quite a few options exist beyond hand-rolling your own C extensions, and which fits depends on your aim. The [Recommended third party tools](https://docs.python.org/3.14/c-api/intro.html#c-api-tools) span everything from gentler to more advanced routes for building C and C++ extensions for Python.
