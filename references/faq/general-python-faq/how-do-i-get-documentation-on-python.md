# How do I get documentation on Python?

### How do I get documentation on Python?

You'll find the standard documentation for Python's current stable version at [https://docs.python.org/3/](https://docs.python.org/3/). EPUB, plain text, and downloadable HTML editions are offered too, at [https://docs.python.org/3/download.html](https://docs.python.org/3/download.html).

Authored in reStructuredText, the documentation is run through [the Sphinx documentation tool](https://www.sphinx-doc.org/). The Python source distribution ships with the reStructuredText source of the documentation.
