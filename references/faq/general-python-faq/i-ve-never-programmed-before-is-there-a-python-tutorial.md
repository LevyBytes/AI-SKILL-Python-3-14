### I've never programmed before. Is there a Python tutorial?

Plenty of tutorials and books are out there. Among the standard documentation you'll find [The Python Tutorial](https://docs.python.org/3.14/tutorial/index.html#tutorial-index).

Turn to [the Beginner's Guide](https://wiki.python.org/moin/BeginnersGuide) for resources aimed at people new to Python, tutorial lists included.
