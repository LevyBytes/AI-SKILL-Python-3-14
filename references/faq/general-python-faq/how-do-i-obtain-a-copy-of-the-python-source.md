# How do I obtain a copy of the Python source?

### How do I obtain a copy of the Python source?

You can always grab the newest Python source distribution from python.org, at [https://www.python.org/downloads/](https://www.python.org/downloads/). For the freshest development sources, head to [https://github.com/python/cpython/](https://github.com/python/cpython/).

Packaged as a gzipped tar file, the source distribution holds the full C source, documentation in Sphinx format, the Python library modules, sample programs, and a handful of handy freely distributable utilities. On the majority of UNIX platforms, the source compiles and runs straight away.

For more guidance on fetching the source code and building it, see the [Getting Started section of the Python Developer's Guide](https://devguide.python.org/setup/).
