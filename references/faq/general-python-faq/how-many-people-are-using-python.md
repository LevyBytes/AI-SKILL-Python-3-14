# How many people are using Python?

### How many people are using Python?

The user base likely runs into the millions, although pinning down a precise figure is hard.

Since Python downloads for free, there are no sales records, and because it comes from many sites and rides along with many Linux distributions, download counts can't paint the full picture either.

Although the comp.lang.python newsgroup buzzes with activity, plenty of Python users never post there or so much as glance at it.
