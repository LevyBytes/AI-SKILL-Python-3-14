# Have any significant projects been done in Python?

### Have any significant projects been done in Python?

Browse [https://www.python.org/about/success](https://www.python.org/about/success) for a roster of projects built on Python. Going through the proceedings of [past Python conferences](https://www.python.org/community/workshops/) surfaces contributions from a wide array of companies and organizations.

Among the well-known Python projects are [the Mailman mailing list manager](https://www.list.org) and [the Zope application server](https://www.zope.dev). A number of Linux distributions, [Red Hat](https://www.redhat.com) being the most prominent, have coded some or all of their installer and system administration tools in Python. Among the firms running Python in-house are Google, Yahoo, and Lucasfilm Ltd.
