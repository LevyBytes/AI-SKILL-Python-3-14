# How do I get a beta test version of Python?

### How do I get a beta test version of Python?

You can fetch alpha and beta releases from [https://www.python.org/downloads/](https://www.python.org/downloads/). Two newsgroups, comp.lang.python plus comp.lang.python.announce, carry an announcement of every release, as does Python's home page at [https://www.python.org/](https://www.python.org/); a news RSS feed is provided as well.

Git also gives you a way to reach Python's development version. Refer to [The Python Developer's Guide](https://devguide.python.org/) for the specifics.
