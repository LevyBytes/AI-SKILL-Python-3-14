# Why is it called Python?

### Why is it called Python?

As he set about building Python, Guido van Rossum happened to be reading the published scripts of ["Monty Python's Flying Circus"](https://en.wikipedia.org/wiki/Monty_Python), a 1970s BBC comedy show. Wanting a name that was brief, distinctive, and a touch enigmatic, van Rossum settled on calling the language Python.
