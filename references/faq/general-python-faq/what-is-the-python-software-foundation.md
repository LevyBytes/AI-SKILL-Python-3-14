# What is the Python Software Foundation?

### What is the Python Software Foundation?

An independent non-profit body, the Python Software Foundation owns the copyright covering Python release 2.1 and every version after it. Its stated purpose is to push forward the open source technology surrounding the Python programming language and to spread word of Python's adoption. You can reach the PSF's home page at [https://www.python.org/psf/](https://www.python.org/psf/).

In the US, gifts to the PSF qualify as tax-exempt. Should Python prove useful to you, please consider giving through [the PSF donation page](https://www.python.org/psf/donations/).
