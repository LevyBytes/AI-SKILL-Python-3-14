# How do I submit bug reports and patches for Python?

### How do I submit bug reports and patches for Python?

When you want to flag a bug or hand in a patch, turn to the issue tracker at [https://github.com/python/cpython/issues](https://github.com/python/cpython/issues).

To learn more about how Python's development works, see [the Python Developer's Guide](https://devguide.python.org/).
