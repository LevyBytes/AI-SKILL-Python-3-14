# What new developments are expected for Python in the future?

### What new developments are expected for Python in the future?

Head to [https://peps.python.org/](https://peps.python.org/) for the Python Enhancement Proposals (PEPs). A PEP is a design document that lays out a proposed new Python feature, offering a tight technical specification together with a rationale. Watch for a PEP named "Python X.Y Release Schedule", in which X.Y stands for a version not yet released to the public.

Discussion of new development happens on [the python-dev mailing list](https://mail.python.org/mailman3/lists/python-dev.python.org/).
