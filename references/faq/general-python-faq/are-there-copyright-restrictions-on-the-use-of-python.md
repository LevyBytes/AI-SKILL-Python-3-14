# Are there copyright restrictions on the use of Python?

### Are there copyright restrictions on the use of Python?

The source is yours to do with as you please, provided you keep the copyrights intact and reproduce them in whatever Python documentation you write. Respecting those copyright terms means you may freely deploy Python commercially, distribute copies of it in source or binary form (whether altered or untouched), or market products that bundle Python in any fashion. Naturally, we'd always appreciate hearing about every commercial Python deployment.

For more detail and the complete wording of the PSF License, visit [the license page](https://docs.python.org/3/license.html).

There is a trademark on the Python logo, and using it sometimes calls for permission. For the full picture, refer to [the Trademark Usage Policy](https://www.python.org/psf/trademarks/).
