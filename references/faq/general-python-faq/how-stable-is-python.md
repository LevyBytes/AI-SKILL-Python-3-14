# How stable is Python?

### Python in the real world

### How stable is Python?

Extremely stable. Fresh stable releases have shipped about every 6 to 18 months ever since 1991, and that pace looks set to hold. Beginning with version 3.9, Python adopts a new feature release every 12 months ([**PEP 602**](https://peps.python.org/pep-0602/)).

Because the developers put out bugfix releases for older versions, existing releases steadily grow more reliable. Bugfix releases — marked by a third element in the version number (for example 3.5.3, 3.6.2) — are run with stability in mind; only fixes for known issues make it into one, and interfaces are guaranteed to stay constant across a series of them.

You can always locate the newest stable releases on the [Python download page](https://www.python.org/downloads/). Python 3.x is the version to choose and enjoys support from most of the popular libraries. Python 2.x [**is not maintained anymore**](https://peps.python.org/pep-0373/).
