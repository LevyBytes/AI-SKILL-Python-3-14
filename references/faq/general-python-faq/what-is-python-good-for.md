# What is Python good for?

### What is Python good for?

As a high-level, general-purpose programming language, Python lends itself to a broad range of problem domains.

Bundled with it is a sizable standard library spanning domains like text handling (regular expressions, Unicode, computing file diffs), internet protocols (HTTP, FTP, SMTP, XML-RPC, POP, IMAP), software engineering tasks (unit testing, logging, profiling, parsing Python code), and operating-system access (system calls, filesystems, TCP/IP sockets). Browse the table of contents of [The Python Standard Library](https://docs.python.org/3.14/library/index.html#library-index) for a sense of what ships with it. On top of that, a broad selection of third-party add-ons exists. Browse [the Python Package Index](https://pypi.org) to track down packages that suit your needs.
