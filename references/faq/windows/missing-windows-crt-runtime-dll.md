# How do I solve the missing api-ms-win-crt-runtime-l1-1-0.dll error?

### How do I solve the missing api-ms-win-crt-runtime-l1-1-0.dll error?

This tends to crop up on Python 3.5 and later when you are on Windows 8.1 or earlier and have not installed every update. Start by confirming that your operating system is supported and fully current; should that fail to fix things, head to the [Microsoft support page](https://support.microsoft.com/en-us/help/3118401/) for instructions on installing the C Runtime update by hand.
