### How do I find a module or application to perform task X?

Look first at [the Library Reference](https://docs.python.org/3.14/library/index.html#library-index) and see whether a fitting standard library module already exists. (Over time you'll come to know the standard library well enough to bypass this step.)

When you need a third-party package, browse the [Python Package Index](https://pypi.org), or fall back on [Google](https://www.google.com) or some other web search engine. A search combining ?Python? with one or two keywords about your subject typically turns up something useful.
