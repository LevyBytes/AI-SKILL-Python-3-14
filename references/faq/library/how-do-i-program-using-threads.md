### How do I program using threads?

Make sure to reach for the [`threading`](https://docs.python.org/3.14/library/threading.html#module-threading) module rather than the [`_thread`](https://docs.python.org/3.14/library/_thread.html#module-_thread) module. On top of the low-level primitives the `_thread` module exposes, the `threading` module layers handy abstractions.
