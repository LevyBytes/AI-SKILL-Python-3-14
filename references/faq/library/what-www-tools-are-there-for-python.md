### Network/Internet Programming

### What WWW tools are there for Python?

Consult the chapters [Internet Protocols and Support](https://docs.python.org/3.14/library/internet.html#internet) and [Internet Data Handling](https://docs.python.org/3.14/library/netdata.html#netdata) in the Library Reference Manual. Python ships with numerous modules to help you assemble both server-side and client-side web systems.

Paul Boddie keeps a rundown of the available frameworks at [https://wiki.python.org/moin/WebProgramming](https://wiki.python.org/moin/WebProgramming).
