# Tutorial

### The Python Tutorial

Tip

The audience for this tutorial is *programmers* coming to Python for the first time — **not** *beginners* who have never programmed at all.

Powerful yet easy to pick up, Python is a programming language with efficient high-level data structures alongside a straightforward but capable take on object-oriented programming. Thanks to its graceful syntax, dynamic typing, and interpreted execution, Python serves as an ideal choice for scripting and rapid application development across many domains and on nearly every platform.

Both the Python interpreter and its rich standard library can be obtained at no cost, as source or as binaries for every major platform, from the Python website at [https://www.python.org/](https://www.python.org/), and you are free to redistribute them. That same site hosts, and links out to, plenty of free third-party Python modules, programs, tools, and further documentation.

Adding new functions and data types written in C or C++ (or any language that C can call) extends the Python interpreter with little effort. Python likewise works well as an extension language embedded in customizable applications.

In an informal way, this tutorial walks the reader through the core concepts and capabilities of the Python language and system. You'll get the most from it if you already grasp the basics of programming in general. Keeping a Python interpreter open for hands-on practice helps, yet because every example stands on its own, you can just as easily read the tutorial offline.

For details on the standard objects and modules, turn to [The Python Standard Library](https://docs.python.org/3.14/library/index.html#library-index). A more rigorous definition of the language lives in [The Python Language Reference](https://docs.python.org/3.14/reference/index.html#reference-index). If you intend to write extensions in C or C++, consult [Extending and Embedding the Python Interpreter](https://docs.python.org/3.14/extending/index.html#extending-index) along with the [Python/C API reference manual](https://docs.python.org/3.14/c-api/index.html#c-api-index). A number of books also treat Python thoroughly.

Rather than aiming to be exhaustive and document every feature — or even every frequently used one — this tutorial presents a great many of Python's most notable capabilities, giving you a solid sense of the language's character and style. Once you've worked through it, you'll be capable of reading and writing Python modules and programs, and prepared to dig deeper into the assorted Python library modules documented in [The Python Standard Library](https://docs.python.org/3.14/library/index.html#library-index).

Reading through the [Glossary](https://docs.python.org/3.14/glossary.html#glossary) is worthwhile too.
