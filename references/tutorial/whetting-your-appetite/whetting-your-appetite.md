## 1. Whetting Your Appetite

### 1. Whetting Your Appetite

Spend enough time at a computer and sooner or later a chore turns up that begs to be automated. Maybe you want to run a search-and-replace across heaps of text files, or shuffle and rename a pile of photos according to some intricate scheme. You might fancy building a little homegrown database, a niche GUI program, or a quick game.

As a working software developer, you might juggle a handful of C/C++/Java libraries while chafing at how sluggish the customary write/compile/test/re-compile loop feels. Perhaps you are assembling a test suite for one such library and find the chore of coding those tests dull. Or you have built a program that would benefit from an embedded extension language, yet you have no desire to invent and implement an entire new language just for your app.

In each of these cases, Python is exactly what you need.

Some of these jobs could be tackled with a Unix shell script or Windows batch files, yet shell scripting really shines at relocating files and massaging text, while struggling with GUI programs or games. A C/C++/Java program is another option, but coaxing even a rough first cut out of it can eat up plenty of development time. Python, by contrast, is gentler to use, runs on Windows, macOS, and Unix operating systems alike, and gets you to a finished result sooner.

Though Python is easy to pick up, it remains a genuine programming language that delivers far more structure and scaffolding for sizeable programs than shell scripts or batch files ever could. It likewise performs much stricter error checking than C, and, as a *very-high-level language*, it bakes in advanced data types like resizable arrays and dictionaries. Thanks to those broader data types, Python fits a substantially wider range of problems than Awk or even Perl, and yet plenty of tasks are at least as straightforward in Python as in either of them.

With Python you can break a program up into modules and reuse those modules across other Python programs. The language ships with an extensive set of standard modules that can serve as the foundation of your own programs — or as worked examples while you learn to program in Python. A number of them cover things such as file I/O, system calls, sockets, and even bindings to graphical user interface toolkits like Tk.

Being an interpreted language, Python can shave a great deal of time off development since you skip the compile-and-link step entirely. Because the interpreter runs interactively, it is simple to play with language features, knock out disposable scripts, or try out functions as you build something from the bottom up. On top of that, it doubles nicely as a desk calculator.

Code in Python tends to come out both terse and easy to read. A given Python program is usually far shorter than its C, C++, or Java counterpart, and that owes to a few factors:

- its advanced built-in data types let a single statement capture a complicated operation;

- indentation, rather than opening and closing braces, is what groups statements together;

- there is no requirement to declare variables or arguments up front.

Python is *extensible*: given some C know-how, bolting a fresh built-in function or module onto the interpreter is straightforward, whether to run performance-critical work at top speed or to wire your Python code to libraries shipped only as binaries (a vendor-specific graphics library, say). And once you are truly sold on it, you can embed the Python interpreter inside a C application and wield it there as an extension or command language.

Incidentally, the language took its name from the BBC program “Monty Python’s Flying Circus” and bears no connection to snakes at all. Sprinkling nods to Monty Python sketches throughout documentation is not merely permitted — it is positively welcomed!

With your enthusiasm for Python now kindled, you will naturally want a closer look at it. Because hands-on practice is the surest route to learning any language, this tutorial encourages you to tinker with the Python interpreter while you read along.

The chapter that follows lays out how the interpreter actually works. The material is fairly humdrum, yet you will need it to follow along with the examples presented further on.

From there, the remainder of the tutorial walks through assorted capabilities of the Python language and runtime by way of examples — starting with basic expressions, statements, and data types, moving on to functions and modules, and eventually reaching more advanced topics such as exceptions and user-defined classes.
