### 3. An Informal Introduction to Python

Throughout the examples that follow, what you type and what the machine returns are told apart by whether a prompt is shown ([>>>](https://docs.python.org/3.14/glossary.html#term-0) and […](https://docs.python.org/3.14/glossary.html#term-...)): to reproduce any sample, key in each character that comes after the prompt once the prompt is displayed; any line lacking a leading prompt is text the interpreter sent back. Be aware that a secondary prompt sitting alone on its own line indicates that an empty line is expected from you, which is how a command spanning several lines is closed off.

A "Copy" control is available — it shows up at the top-right while you hover over or tap a code sample — and it removes prompts together with output, letting you copy just the input lines and paste them straight into your interpreter.

A great many of the samples in this guide carry comments, including the ones keyed in at the interactive prompt. In Python a comment opens with the hash sign, `#`, and runs through to the close of that physical line. You may place a comment at a line's beginning, or trailing some whitespace or code, though never inside a string literal. A hash sign sitting within a string literal counts merely as a hash sign. Because comments exist to explain code and carry no meaning to Python itself, feel free to leave them out while keying in the samples.

Some examples:

```python
# this is the first comment
spam = 1  # and this is the second comment
          # ... and now a third!
text = "# This is not a comment because it's inside quotes."

```
