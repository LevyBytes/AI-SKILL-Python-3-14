# 4.9.3.3. Keyword-Only Arguments

#### 4.9.3.3. Keyword-Only Arguments

If you want parameters treated as *keyword-only*, requiring callers to name them as keyword arguments, drop an `*` into the parameter list immediately ahead of the earliest *keyword-only* parameter.
