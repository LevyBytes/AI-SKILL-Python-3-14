## 14. Interactive Input Editing and History Substitution

### 14. Interactive Input Editing and History Substitution

Certain builds of the Python interpreter let you edit the line you're currently typing and perform history substitution, much like what the Korn shell and the GNU Bash shell provide. Underneath, this rests on the [GNU Readline](https://tiswww.case.edu/php/chet/readline/rltop.html) library, which offers several editing styles. That library ships its own documentation, which we won't repeat in this place.
