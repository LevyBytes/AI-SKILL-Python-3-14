### 13. What Now?

Working through this tutorial has likely deepened your enthusiasm for Python, leaving you keen to put it to work on the actual problems you face. So where do you turn next to deepen your knowledge?

What you've been reading sits within the larger collection of Python's documentation. A few of the other pieces in that collection include:

- [The Python Standard Library](https://docs.python.org/3.14/library/index.html#library-index):

It's worth paging through this manual, since it supplies full (if compact) reference coverage of the types, functions, and modules that make up the standard library. Bundled with the standard Python distribution is a *lot* of extra code. You'll find modules for reading Unix mailboxes, fetching documents over HTTP, producing random numbers, handling command-line options, compressing data, and a great deal more. A quick scan of the Library Reference will show you what's on offer.

- [Installing Python modules](https://docs.python.org/3.14/installing/index.html#installing-index) walks you through adding extra modules that other Python users have authored.

- [The Python Language Reference](https://docs.python.org/3.14/reference/index.html#reference-index): A thorough account of how Python's syntax and semantics work. The going is dense, yet it serves as an exhaustive reference to the language proper.

More Python resources:

- [https://www.python.org](https://www.python.org): Python's primary website, which holds code, documentation, and links pointing to Python-related pages elsewhere on the web.

- [https://docs.python.org](https://docs.python.org): A quick route straight to Python's documentation.

- [https://pypi.org](https://pypi.org): The Python Package Index, once also known by the nickname the Cheese Shop [1], is a catalog of downloadable Python modules contributed by users. As soon as you start publishing your own code, you can list it here for others to discover.

- [https://code.activestate.com/recipes/langs/python/](https://code.activestate.com/recipes/langs/python/): The Python Cookbook gathers a substantial assortment of code snippets, sizable modules, and handy scripts. The standout entries have been compiled into a book of the same name, Python Cookbook (O’Reilly & Associates, ISBN 0-596-00797-3.)

- [https://pyvideo.org](https://pyvideo.org) gathers links to Python-related video recordings drawn from conferences and user-group gatherings.

- [https://scipy.org](https://scipy.org): The Scientific Python effort bundles modules for speedy array math and reshaping, along with a range of packages covering domains such as statistical analysis, Fourier transforms, distributions of random numbers, non-linear solvers, linear algebra, and the like.

If you have Python questions or bugs to report, you might post to the newsgroup *comp.lang.python* or direct them to the mailing list at [python-list@python.org](mailto:python-list%40python.org). Because the two are bridged together, anything posted on one side is relayed across to the other automatically. Each day brings hundreds of messages: people raising (and resolving) questions, floating feature ideas, and unveiling fresh modules. You can browse the mailing-list archives over at [https://mail.python.org/pipermail/](https://mail.python.org/pipermail/).

Ahead of posting, take a look at the [Frequently Asked Questions](https://docs.python.org/3.14/faq/index.html#faq-index) list (better known as the FAQ). It addresses plenty of the questions that surface over and over, and the fix for your situation might already be sitting there.
