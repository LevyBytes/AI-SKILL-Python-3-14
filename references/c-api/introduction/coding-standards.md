# Coding standards

### Coding standards

When you author C code destined to land in CPython, you **must** abide by the rules and standards laid out in [**PEP 7**](https://peps.python.org/pep-0007/). Those rules hold no matter which Python release you're contributing toward. You needn't honor these conventions in your own third party extension modules, though, unless you anticipate someday contributing them upstream to Python.
