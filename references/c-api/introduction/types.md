# Types

### Types

A handful of additional data types matter in the Python/C API; the bulk of them are plain C types like int, long, double and char*. Several structure types serve to describe static tables that catalog the functions a module exports or the data members of a fresh object type, and one more describes a complex number's value. Each will be covered alongside the functions that make use of it.
