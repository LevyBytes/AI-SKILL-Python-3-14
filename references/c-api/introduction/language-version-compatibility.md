# Language version compatibility

### Language version compatibility

The C API of Python works with the C11 and C++11 editions of C and C++.

Treat that as a floor: nothing in the C API depends on capabilities from newer C/C++ revisions. There's *no* obligation to switch on your compiler's "c11 mode."
