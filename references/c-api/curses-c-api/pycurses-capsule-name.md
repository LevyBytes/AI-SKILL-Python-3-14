# Internal data

### Internal data

Although the C API makes the objects below visible, treat them as strictly internal.

 PyCurses_CAPSULE_NAME

Name of the curses capsule to pass to [`PyCapsule_Import()`](https://docs.python.org/3.14/c-api/capsule.html#c.PyCapsule_Import).

Internal usage only. Use `import_curses` instead.
