# cell objects C API: Closure cell ownership across scopes

## Cell Objects

### Cell Objects

“Cell” objects exist to back variables that more than one scope refers to. A cell object is built for every such variable to keep its value; within each stack frame that touches the value, the local variables carry references to the cells coming from outer scopes that share that variable. Reading the value yields whatever the cell holds rather than the cell object itself. That unwrapping of the cell object leans on support baked into the generated byte-code — the cells do not unwrap on their own when read. Outside this role, cell objects are unlikely to be of much use.
