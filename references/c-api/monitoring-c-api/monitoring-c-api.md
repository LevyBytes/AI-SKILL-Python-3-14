## Monitoring C API

### Monitoring C API

Added in version 3.13.

There are times when an extension has to work with the event monitoring system. To subscribe to events and hook up callbacks, you go through the Python API surfaced by [`sys.monitoring`](https://docs.python.org/3.14/library/sys.monitoring.html#module-sys.monitoring).
