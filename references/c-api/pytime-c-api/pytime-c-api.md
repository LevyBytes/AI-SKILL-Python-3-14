## PyTime C API

### PyTime C API

Added in version 3.13.

System clocks are reachable through the clock C API, which parallels what Python's [`time`](https://docs.python.org/3.14/library/time.html#module-time) module offers.

Looking for the C API tied to the [`datetime`](https://docs.python.org/3.14/library/datetime.html#module-datetime) module? Consult [DateTime Objects](https://docs.python.org/3.14/c-api/datetime.html#datetimeobjects) instead.
