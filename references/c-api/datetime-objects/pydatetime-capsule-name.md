# Internal data

### Internal data

Although the C API makes the symbols below visible, you should regard them as meant for internal use only.

 PyDateTime_CAPSULE_NAME

Name of the datetime capsule to pass to [`PyCapsule_Import()`](https://docs.python.org/3.14/c-api/capsule.html#c.PyCapsule_Import).

Internal usage only. Use `PyDateTime_IMPORT` instead.
