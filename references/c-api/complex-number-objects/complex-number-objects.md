# Complex Number Objects

## Complex Number Objects

### Complex Number Objects

Seen from the C API, Python's complex number objects take the form of two separate types: one being the Python object that Python programs work with, the other a C structure that carries the actual complex number value. Functions for handling each are supplied by the API.
