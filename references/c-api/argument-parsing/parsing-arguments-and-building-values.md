# Parsing arguments and building values

### Parsing arguments and building values

You will find these functions handy while writing extension functions and methods of your own. Further details and examples can be found in [Extending and Embedding the Python Interpreter](https://docs.python.org/3.14/extending/index.html#extending-index).

The first three functions covered here — `PyArg_ParseTuple()`, `PyArg_ParseTupleAndKeywords()`, and `PyArg_Parse()` — each rely on *format strings*, which communicate to the function what arguments it should expect. Every one of these functions follows the same format-string syntax.
